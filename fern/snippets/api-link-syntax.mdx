Use the `api:` link syntax to link to an API endpoint by its HTTP method and path, instead of hardcoding the endpoint's URL slug. Fern resolves these links to the correct endpoint URL at build time.

The format is `api:METHOD/path`, where `METHOD` is an HTTP method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) and `/path` is the endpoint path from your API definition.

<div className="highlight-frame">
View the [Current user information](api:mcp-tools:GET/api/fern-docs/whoami) endpoint.
</div>

```mdx Markdown
View the [Current user information](api:mcp-tools:GET/api/fern-docs/whoami) endpoint.
```

Path parameters are supported — include them in the endpoint path with curly braces, such as `api:GET/v2/payments/{paymentId}`.

If your project has [multiple APIs](/learn/docs/api-references/generate-api-ref#include-more-than-one-api-reference), prefix the link with the API name, such as `api:payments-api:POST/v2/payments`.

<Note>
The `api:` link syntax works in any Markdown content rendered by Fern, including page files and API endpoint descriptions in your OpenAPI spec or Fern Definition.
</Note>
