Use the `api:` link syntax to link to an API endpoint by its HTTP method and path, instead of hardcoding the endpoint's URL slug. Fern resolves these links to the correct endpoint URL at build time.

<CodeBlock title='API link syntax'>
```mdx
[Create a payment](api:POST/v2/payments)
```
</CodeBlock>

The format is `api:METHOD/path`, where `METHOD` is an HTTP method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) and `/path` is the endpoint path from your API definition. Path parameters are supported:

<CodeBlock title='API link with path parameter'>
```mdx
[Get a payment](api:GET/v2/payments/{paymentId})
```
</CodeBlock>

If your project has [multiple APIs](/learn/docs/api-references/generate-api-ref#include-more-than-one-api-reference), prefix the link with the API name:

<CodeBlock title='API link with API name'>
```mdx
[Create a payment](api:payments-api:POST/v2/payments)
```
</CodeBlock>

Here's a live example — this link points to the [Current user information](api:mcp-tools:GET/api/fern-docs/whoami) endpoint in the Fern Public API.

<Note>
The `api:` link syntax works in any Markdown content rendered by Fern, including page files and API endpoint descriptions in your OpenAPI spec or Fern Definition.
</Note>
