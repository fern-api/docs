Use different {{type}} files for SDK generation versus documentation by creating separate folders with their own `generators.yml`:

```bash
fern/
  ├─ fern.config.json
  ├─ openapi.yml
  ├─ docs/
  │   ├─ generators.yml
  │   └─ docs-{{type}}.yml
  └─ sdks/
      ├─ generators.yml
      └─ sdk-{{type}}.yml
```

```yaml title="sdks/generators.yml"
api:
  specs:
    - openapi: ../openapi.yml
      {{type}}: sdk-{{type}}.yml
```
