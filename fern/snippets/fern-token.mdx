Use `fern token` to generate a token for authenticating the Fern CLI in CI/CD environments. The token is specific to your organization defined in [`fern.config.json`](/learn/sdks/overview/project-structure#fernconfigjson) and doesn't expire. You can also create and manage tokens from the [API Tokens](/learn/dashboard/configuration/api-tokens) page in the Dashboard.

<CodeBlock title="terminal">
```bash
fern token
```
</CodeBlock>
