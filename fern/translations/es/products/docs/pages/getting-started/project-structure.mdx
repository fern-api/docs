Esta página proporciona una descripción general de la estructura de archivos y carpetas de un proyecto de Fern Docs.

## Estructura de directorios

Los archivos de configuración de tu documentación viven en la carpeta `fern`:

```
fern/
├── docs/                  # Contenido de la documentación
│   ├── pages/             # Archivos MDX
│   ├── assets/            # Imágenes, logotipos, favicon
│   ├── changelog/         # Entradas del registro de cambios
│   └── snippets/          # Fragmentos MDX reutilizables
├── docs.yml               # Define la navegación, el tema y el alojamiento
├── openapi.yml            # Definición de la API (OpenAPI, AsyncAPI, etc.)
├── generators.yml         # Referencias de especificaciones, configura SDKs
├── fern.config.json       # Nombre de la organización y versión de la CLI
└── styles.css             # Estilos CSS personalizados
```

Las carpetas `fern` y `changelog` son nombres reservados; Fern no las reconocerá si se renombran. Todos los demás nombres de carpetas son personalizables.

## Carpeta de páginas

La carpeta `pages` contiene los archivos Markdown (MDX) que conforman tu documentación. Cada archivo MDX representa una página en tu documentación.

Puedes organizar la carpeta `pages` en subcarpetas según las secciones de tu documentación, o mantener las páginas planas.

## Carpeta de activos

La carpeta `assets` contiene las imágenes o vídeos utilizados en tu documentación. Puedes referenciar estos activos en tus archivos MDX usando rutas relativas.

```
assets/
├── favicon.svg
├── logo.svg          # Logotipo en modo claro
└── logo-dark.svg     # Logotipo en modo oscuro
```

## `docs.yml`

El archivo `docs.yml` es el corazón de tu sitio de documentación de Fern. Este archivo de configuración controla la estructura de navegación, el diseño visual, la funcionalidad del sitio y los ajustes de alojamiento.

Ejemplo de `fern/docs.yml`:

```yaml
instances:
  - url: plantstore.docs.buildwithfern.com

title: Fern Docs Starter

navigation:
  - section: Primeros pasos
    contents:
      - page: Bienvenido
        path: docs/pages/welcome.mdx

navbar-links:
  - type: filled
    text: Panel de control
    url: https://dashboard.buildwithfern.com

logo:
  light: docs/assets/logo.svg
  dark: docs/assets/logo-dark.svg

colors:
  accent-primary:
    dark: "#70E155"
    light: "#008700"

favicon: docs/assets/favicon.svg
```

## Definiciones de API y `generators.yml`

Para generar documentación de Referencia de API, debes proporcionar tu definición de API.

**OpenAPI**

Coloca tu archivo de especificación OpenAPI en el directorio `fern/`. Fern admite formato YAML o JSON.

Referencíalo en `generators.yml`:

```yaml
api:
  specs:
    - openapi: openapi.yml
```

**AsyncAPI**

```yaml
api:
  specs:
    - openapi: openapi.yml
    - asyncapi: asyncapi.yaml
```

## `fern.config.json`

El archivo `fern.config.json` almacena el nombre de tu organización y la versión de la CLI de Fern.

```json
{
  "organization": "plantstore",
  "version": "5.23.3"
}
```
