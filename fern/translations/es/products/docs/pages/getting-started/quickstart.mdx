Fern combina tus especificaciones de API, archivos Markdown estáticos, activos multimedia y configuraciones personalizadas definidas en tu archivo `docs.yml` para generar un sitio de documentación interactivo y alojado.

## Usar la interfaz guiada

O sigue esta guía para comenzar con Fern usando la CLI.

## Pasos

### 1. Instalar la CLI

Instala la CLI de Fern para gestionar tu proyecto desde la línea de comandos:

```bash
npm install -g fern-api
```

### 2. Iniciar tu documentación

Toda la configuración de tu documentación vive en la carpeta `fern`. Crea una carpeta fern usando la plantilla de inicio o desde cero.

**Usar la plantilla de inicio**

Usa el repositorio `fern-api/docs-starter` como plantilla para tu sitio:

1. Navega a fern-api/docs-starter y haz clic en el botón **Use this template** (en la parte superior derecha). Debes estar conectado a GitHub.
2. Elige la opción de **crear un nuevo repositorio**. Nómbralo `fern-docs`.
3. Clona tu repositorio recién creado y ábrelo en tu editor de código favorito (por ejemplo, Cursor, VS Code).

Verás un sitio básico con una carpeta `fern` que contiene una definición de API, páginas Markdown y archivos de configuración.

**Empezar desde cero**

```bash
fern init --docs
```

### 3. Configurar tu organización

Configura dos ajustes:

- **Nombre de la organización** en `fern.config.json`: Identifica tu organización en el sistema de Fern.
- **URL de la documentación** en `docs.yml`: Determina dónde se publica tu documentación.

```json
{
  "organization": "{{TU_ORGANIZACIÓN}}",
  "version": "5.23.3"
}
```

```yaml
instances:
  - url: {{TU_DOMINIO}}.docs.buildwithfern.com
```

### 4. Personalizar tu documentación

Ahora que tienes un sitio básico, puedes personalizarlo añadiendo tutoriales, generando una Referencia de API o ajustando la marca.

**Añadir contenido**

Crea archivos Markdown (`.mdx`) y complétalos.

```mdx
---
title: "Título de la página"
description: "Subtítulo (opcional)"
---

¡Hola mundo!
```

**Añadir una Referencia de API**

```bash
fern init --openapi /ruta/a/openapi.yml
```

**Personalizar la marca**

Configura los colores, el logotipo y la fuente en el archivo `docs.yml`.

### 5. Previsualizar tu documentación

Antes de publicar, previsualiza los cambios en tu entorno de desarrollo local:

```bash
fern docs dev
```

### 6. Publicar en producción

Cuando estés listo para que tu documentación sea accesible públicamente:

```bash
fern generate --docs
```

## Explorar las funciones de Fern

Ahora que tu documentación está en línea, explora estas funciones para mejorarla.

- **Configurar ajustes del sitio**: Usa el archivo `docs.yml` para configurar colores, SEO, tipografía, diseños y más.
- **Explorar componentes**: Usa los componentes integrados de Fern para crear documentación interactiva y bien organizada.
- **Personalizar la navegación**: Añade productos, versiones, secciones anidadas, pestañas y más.
- **Colaborar con tu equipo**: Usa el Editor de Fern para que miembros no técnicos editen la documentación.
- **Configurar un dominio personalizado**: Aloja tu documentación en tu propio dominio o subdominio.
- **Configurar análisis**: Integra con PostHog, Segment, Intercom, Google Tag Manager y otras plataformas.
