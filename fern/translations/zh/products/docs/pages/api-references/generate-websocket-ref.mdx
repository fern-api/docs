## 配置

<Steps>
<Step title="设置项目结构">

将规范文件添加到 `/fern` 目录中，并创建一个引用该文件的 `generators.yml`：

```yaml generators.yml
api:
  path: asyncapi.yml
  origin: https://github.com/your-org/your-repo/blob/main/asyncapi.yml # 可选
```

</Step>
<Step title="将 WebSocket 参考添加到导航中">

在 `docs.yml` 的导航中添加 `- api: API Reference`：

```yml docs.yml
navigation:
  - api: API Reference
```

</Step>
<Step title="自定义布局">

有关完整的配置选项和布局自定义列表，请参阅 [自定义 API 参考布局](/learn/zh/docs/api-references/customize-api-reference-layout)。

</Step>
</Steps>

### 包含多个 WebSocket 参考

要在文档中包含多个 WebSocket 定义，请使用 `api-name` 属性。`api-name` 对应于包含 WebSocket 定义的文件夹名称。

<Files>
  <Folder name="fern" defaultOpen>
    <File name="fern.config.json" />
    <File name="docs.yml" />
    <Folder name="streaming-api" defaultOpen>
      <File name="asyncapi.yml" comment="流式 WebSocket AsyncAPI 规范" />
      <File name="generators.yml" />
    </Folder>
    <Folder name="realtime-api" defaultOpen>
      <File name="asyncapi.yml" comment="实时 WebSocket AsyncAPI 规范" />
      <File name="generators.yml" />
    </Folder>
  </Folder>
</Files>

```yaml title="docs.yml"
navigation:
  - api: Streaming API
    api-name: streaming-api
  - api: Realtime API
    api-name: realtime-api
```
