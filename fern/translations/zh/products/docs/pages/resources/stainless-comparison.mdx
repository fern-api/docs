## 概述

Fern 已[生产就绪](/learn/docs/getting-started/quickstart)，具有稳定的 API 和全面的企业级功能。Stainless 目前处于[早期访问](https://www.stainless.com/docs/docs-platform/)阶段，在 1.0 版本发布前预计会有重大变更。

选择 Fern 适用于企业需求、受监管行业或生产关键文档。选择 Stainless 适用于简单文档，仅使用 Git 工作流和偏好 Astro 的场景。

| 能力 | Fern | Stainless |
|------------|------|-----------|
| **成熟度** | 生产就绪，稳定 API | 早期访问，预计有重大变更 |
| **内容创作** | [可视化编辑器](/learn/docs/writing-content/fern-editor) + Git | 仅 Git |
| **企业级功能** | [RBAC](/learn/docs/authentication/features/rbac)、[SSO](/learn/docs/authentication/setup/sso)、[版本控制](/learn/docs/configuration/site-level-settings) | 无 |
| **API 测试** | [交互式浏览器](/learn/docs/api-references/api-explorer) | 无 |
| **部署** | 云端 + [全栈自托管](/learn/docs/self-hosted/overview) | 仅静态文件 |

## 详细功能对比

<AccordionGroup>
<Accordion title="平台成熟度和稳定性" defaultOpen={true}>

Fern 已生产就绪，具有稳定的 API 和向后兼容性。Stainless 处于早期访问阶段，在达到 1.0 版本前[预计会有重大变更](https://www.stainless.com/docs/docs-platform/)。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **生产状态** | ✅ [生产就绪](/learn/docs/getting-started/quickstart)，稳定 | ⚠️ 早期访问，预计有重大变更 |
| **企业级部署** | ✅ 广泛部署（[ElevenLabs](https://elevenlabs.io/docs)、[Webflow](https://developers.webflow.com)、[Hume AI](https://dev.hume.ai)） | ⚠️ 生产使用有限 |
<br/>
</Accordion>

<Accordion title="内容创作和治理">

Stainless 对所有内容创作使用基于 Git 的工作流。Fern 支持 Git 工作流和 [Fern Editor](/learn/docs/writing-content/fern-editor)，这是一个面向技术写作人员、产品经理和支持团队的基于浏览器的可视化编辑器。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **可视化编辑器** | ✅ [Fern Editor](/learn/docs/writing-content/fern-editor) 与 GitHub App 集成 | ❌ 无 |
| **内容格式** | ✅ [MDX](/learn/docs/writing-content/markdown-basics) 与 React 组件 | ✅ MDX/Markdoc |
| **可重用内容** | ✅ [片段系统](/learn/docs/writing-content/reusable-snippets) | ✅ Markdown 部分 |
<br/>
</Accordion>

<Accordion title="API 参考和交互式测试">

Stainless 不提供交互式测试环境。Fern 的 [API Explorer](/learn/docs/api-references/api-explorer) 支持浏览器内端点测试，具有自动凭据注入功能。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **API Explorer** | ✅ [完整的游乐场](/learn/docs/api-references/api-explorer)，支持[自动填充凭据](/learn/docs/authentication/features/api-key-injection)、WebSocket 和音频流 | ❌ 无 |
| **SDK 文档** | ✅ [多语言支持](/learn/docs/api-references/sdk-snippets) | ✅ 特定语言页面 |
| **API 规范格式** | ✅ [OpenAPI、AsyncAPI、gRPC、OpenRPC、Fern](/learn/docs/api-references/overview) | ⚠️ 仅 OpenAPI + Stainless 配置 |
<br/>
</Accordion>

<Accordion title="RBAC、版本控制和多产品支持">

Stainless 不提供面向特定受众的内容过滤、多版本 API 或统一的多产品站点。Fern 为复杂的 API 产品组合提供 [RBAC](/learn/docs/authentication/features/rbac) 和[版本控制](/learn/docs/configuration/site-level-settings)功能。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **RBAC** | ✅ [基于受众的内容过滤](/learn/docs/authentication/features/rbac)，用于内部与公共站点 | ❌ 无 |
| **API 版本控制** | ✅ [多版本支持](/learn/docs/configuration/site-level-settings)，具有可用性状态和按版本内容 | ❌ 无 |
| **多产品站点** | ✅ [多个产品](/learn/docs/configuration/site-level-settings)在统一文档中 | ⚠️ 基础标签页（指南/参考） |
<br/>
</Accordion>

<Accordion title="AI 驱动的搜索和辅助">

Stainless 提供基于 RAG 的搜索。Fern 提供额外的 AI 功能，包括[指导文档](/learn/docs/ai-features/ask-fern/guidance)、[自定义知识来源](/learn/docs/ai-features/ask-fern/content-sources)和用于运营控制的分析。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **AI 聊天机器人** | ✅ [Ask Fern](/learn/docs/ai-features/ask-fern/overview) 搭配 Claude，[指导文档](/learn/docs/ai-features/ask-fern/guidance)和自定义知识来源 | ✅ 基于 RAG 的问答 |
| **AI 分析** | ✅ [内容缺口识别](/learn/docs/ai-features/ask-fern/overview)和洞察 | ❌ 无 |
| **搜索** | ✅ 向量搜索，按语言、产品、版本分面 | ⚠️ 元数据驱动，基础分面 |
| **LLM 友好格式** | ✅ [/llms.txt](/learn/docs/ai-features/llms-txt) | ✅ URL 上的 .md 扩展名 |
<br/>
</Accordion>

<Accordion title="身份验证和安全">

Stainless 的[身份验证](https://www.stainless.com/docs/docs-platform/advanced/stainless-authentication/)专注于其服务的 API 密钥。Fern 的 [WorkOS 集成](/learn/docs/authentication/setup/sso)为最终用户身份验证提供企业级 SSO（SAML/OIDC），具有基于角色的内容可见性。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **企业级 SSO** | ✅ [WorkOS](/learn/docs/authentication/setup/sso)（SAML/OIDC/SCIM）与 [RBAC](/learn/docs/authentication/features/rbac) | ❌ 无 |
| **身份验证页面** | ✅ [登录保护的文档](/learn/docs/authentication/overview)，具有[自动填充凭据](/learn/docs/authentication/features/api-key-injection) | ⚠️ 仅用于 Stainless 服务的 API 密钥 |
<br/>
</Accordion>

<Accordion title="托管和部署">

Stainless [部署静态文件](https://www.stainless.com/docs/docs-platform/hosting-and-deploys/)到托管平台。Fern 的[自托管 Docker](/learn/docs/self-hosted/overview) 包含完整的技术栈（PostgreSQL、MinIO、MeiliSearch）用于本地部署。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **云托管** | ✅ [Vercel 搭配 AWS VPC 后端](/learn/docs/preview-publish/publishing-your-docs) | ✅ Cloudflare（默认） |
| **自托管** | ✅ [全栈 Docker](/learn/docs/self-hosted/overview)（PostgreSQL、S3/MinIO、MeiliSearch） | ❌ 仅静态文件 |
| **自定义域名** | ✅ [完全支持](/learn/docs/preview-publish/setting-up-your-domain) | ✅ 完全支持 |
<br/>
</Accordion>

<Accordion title="重定向、SEO 和大型站点运营">

Stainless 目前没有记录重定向功能。Fern 的[重定向系统](/learn/docs/seo/redirects)支持模式匹配和数百个规则，用于内容迁移和重组。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **重定向** | ✅ [299+ 规则](/learn/docs/seo/redirects)，支持模式匹配（`:slug`、`:splat`） | ❌ 无 |
| **SEO 优化** | ✅ [元标签、JSON-LD、RSS、OG 图片、Twitter 卡片](/learn/docs/seo/setting-seo-metadata) | ✅ 基础元标签 |
| **站点地图和 robots.txt** | ✅ [自动生成](/learn/docs/seo/setting-seo-metadata) | ✅ 自动生成（假设） |
<br/>
</Accordion>

<Accordion title="分析和可观测性">

Stainless 目前没有记录内置分析功能。Fern 提供[分析集成](/learn/docs/integrations/overview)，用于页面访问、搜索查询、AI 聊天洞察和用户旅程。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **分析集成** | ✅ [PostHog](/learn/docs/integrations/analytics/posthog)、[Google Analytics](/learn/docs/integrations/analytics/google)、[Segment](/learn/docs/integrations/analytics/segment)、[Mixpanel](/learn/docs/integrations/analytics/mixpanel)（[完整列表](/learn/docs/integrations/overview)） | ❌ 无 |
| **文档洞察** | ✅ 搜索分析、AI 聊天跟踪、内容缺口识别 | ❌ 无 |
| **性能监控** | ✅ Vercel Analytics | ⚠️ Cloudflare Analytics |
<br/>
</Accordion>

<Accordion title="扩展性和集成">

两个平台都支持[自定义](https://www.stainless.com/docs/docs-platform/customization/styles-and-fonts/)，但 Fern 提供更深入的企业级集成，包括 webhooks 和 [30+ 预构建组件](/learn/docs/writing-content/components/overview)。

| 功能 | Fern Docs | Stainless Docs |
|---------|-----------|----------------|
| **组件库** | ✅ [30+ 预构建组件](/learn/docs/writing-content/components/overview)（[手风琴](/learn/docs/writing-content/components/accordions)、[标注](/learn/docs/writing-content/components/callouts)、[卡片](/learn/docs/writing-content/components/cards)、[标签页](/learn/docs/writing-content/components/tabs) 等） | ⚠️ 标准库 |
| **自定义组件** | ✅ [React 组件](/learn/docs/customization/custom-react-components)，支持[自定义 CSS/JS](/learn/docs/customization/custom-css-js) | ✅ Astro 组件，支持自定义 CSS/JS |
| **第三方集成** | ✅ [Algolia、PostHog、WorkOS、Intercom 等](/learn/docs/integrations/overview) | ⚠️ Astro 生态系统 |
| **开发者 API** | ✅ Webhooks、FDR API | ❌ 无 |
<br/>
</Accordion>
</AccordionGroup>

## 技术栈对比

| 组件 | Fern Docs | Stainless Docs |
|-----------|-----------|----------------|
| **前端** | Next.js (React) 搭配 SSR/SSG | Astro（静态站点生成器） |
| **后端** | Node.js/Express (FDR) on AWS VPC | Stainless API 服务 |
| **数据库** | PostgreSQL | 不适用（静态） |
| **缓存** | Redis、Vercel KV (Upstash) | Cloudflare CDN |
| **存储** | S3 (AWS/MinIO) | 不适用（静态） |
| **搜索** | Algolia、MeiliSearch（自托管） | 元数据驱动索引 |
| **向量数据库** | TurboPuffer | 无 |
| **AI** | Bedrock、Claude | RAG 搭配 LLM（提供商未指定） |
| **身份验证** | WorkOS | API 密钥（用于 Stainless 服务） |
| **CDN** | Cloudflare + Vercel Edge | Cloudflare |
| **分析** | PostHog | 无 |
| **部署** | Vercel、Docker（自托管） | Cloudflare、任何静态托管 |
