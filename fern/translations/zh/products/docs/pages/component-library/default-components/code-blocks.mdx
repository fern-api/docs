`<CodeBlock>` 组件显示带有语法高亮的代码示例。代码块支持行高亮、聚焦、标题和深层链接，使您的代码示例更具可读性和交互性。

## 用法

使用三个反引号和可选的语言标识符。

<div className="highlight-frame">
  ```js
  console.log("hello world")
  ```
</div>

````mdx Markdown
```js
console.log("hello world")
```
````

### 最大高度

通过在语言标识符后添加 `maxLines` 属性来控制代码块的最大高度。`maxLines` 属性应该是一个表示要显示的最大行数的数字。默认情况下，代码块最多显示 20 行。（要禁用默认的 20 行限制，请将 `maxLines` 设置为 `0`。）

当您使用 `maxLines` 时，悬停时在右上角会自动出现一个展开按钮，允许用户在页面上显示的扩展覆盖层中查看完整的代码内容。

<div className="highlight-frame">
```python maxLines=10
def is_prime(num):
    """Check if a number is prime."""
    if num <= 1:
        return False
    for i in range(2, num):
        if num % i == 0:
            return False
    return True

start = 10
end = 50

print(f"Prime numbers between {start} and {end} are:")

prime_numbers = []

for num in range(start, end+1):
    if is_prime(num):
        prime_numbers.append(num)

for prime in prime_numbers:
    print(prime)
```
</div>


### 深层链接

通过定义 `links` 映射，使代码块内的特定文本可点击。这对于从代码示例直接链接到文档、API 参考或相关资源很有用。

`links` 属性接受一个映射，其中键是匹配模式（精确字符串或正则表达式），值是要链接到的 URL。

<AccordionGroup>
<Accordion title="精确字符串匹配">
  <div className="highlight-frame">
  <CodeBlock
    links={{"PlantClient": "/learn/docs/writing-content/demo#plantclient", "createPlant": "/learn/docs/writing-content/demo#createplant"}}
  >
  ```typescript
  import { PlantClient } from "@plantstore/sdk";

  const client = new PlantClient({ apiKey: "YOUR_API_KEY" });
  const plant = await client.createPlant({
    name: "Monstera",
    species: "Monstera deliciosa"
  });
  ```
  </CodeBlock>
  </div>

  ````markdown Markdown
  <CodeBlock
    links={{"PlantClient": "/learn/docs/writing-content/demo#plantclient", "createPlant": "/learn/docs/writing-content/demo#create_plant"}}
  >
  ```typescript 
  import { PlantClient } from "@plantstore/sdk";

  const client = new PlantClient({ apiKey: "YOUR_API_KEY" });
  const plant = await client.createPlant({
    name: "Monstera",
    species: "Monstera deliciosa"
  });
  ```
  </CodeBlock>
  ````

  <Note>
    `links` 属性使用 JSON 格式。映射中的每个键都会与代码块中的文本精确匹配，匹配的文本将成为指向相应 URL 的可点击链接。
  </Note>
</Accordion>

<Accordion title="正则表达式模式匹配">

在下面的示例中，模式 `/get\\w+/` 匹配 `getPlant` 和 `getGarden`，而 `/Plant(Store|Client)/` 匹配 `PlantStore` 和 `PlantClient`。

</CodeBlock>
</div>

## 属性

### 代码块属性

这些可以在 Markdown 代码块的语言标识符后添加，或者作为 `<CodeBlock>` 组件的属性。

<ParamField path="language" type="string" required={false}>
  用于语法高亮的编程语言。支持的语言：`javascript`（别名：`js`、`node`）、`python`、`java`、`typescript`（别名：`ts`）、`csharp`、`cpp`、`c`、`php`、`go`、`rust`、`ruby`、`swift`、`kotlin`、`sql`、`bash`（别名：`shell`、`sh`）、`curl`、`markdown`（别名：`md`）、`http`。
</ParamField>

<ParamField path="title" type="string" required={false}>
  显示在代码块上方的标题。可以在语言标识符后内联指定，或使用 `title="..."` 或 `filename="..."` 属性。
</ParamField>

<ParamField path="highlight" type="string" required={false}>
  要高亮的行，指定为 `{2-4, 6}` 语法。支持单个数字、范围和逗号分隔的列表。
</ParamField>

<ParamField path="focus" type="string" required={false}>
  要聚焦的行，指定为 `focus={2-4}`。与高亮的工作方式相同，但会使非聚焦行变暗。
</ParamField>

<ParamField path="startLine" type="number" required={false}>
  开始显示的行号。对于显示较长代码文件的特定部分很有用。
</ParamField>

<ParamField path="maxLines" type="number" required={false} default="20">
  添加滚动之前显示的最大行数。设置为 `0` 以禁用限制。
</ParamField>

<ParamField path="wordWrap" type="boolean" required={false} default="false">
  是否换行长行而不是使其可滚动。
</ParamField>

<ParamField path="showLineNumbers" type="boolean" required={false} default="true">
  是否在边栏中显示行号，包括 `bash`/`shell` 代码块中的行号和命令提示符号（`$` 和 `>`）。设置为 `false` 可隐藏行号，使代码示例看起来更简洁。
</ParamField>

<ParamField path="for" type="string" required={false}>
  自定义同步组标识符。覆盖默认的基于语言的同步。
</ParamField>

<ParamField path="links" type="object" required={false}>
  文本模式到 URL 的映射，用于在代码内创建可点击链接。键可以是精确字符串或正则表达式模式（例如，`{"/get\\w+/": "/api-docs"}`）。
</ParamField>

### `<Code>` 属性

`<Code>` 组件用于从文件中嵌入代码。它接受上面列出的所有代码块属性，以及：

<ParamField path="src" type="string" required={true}>
  本地文件的路径（相对于文档目录）或外部文件的完整 URL（例如，GitHub 原始 URL）。
</ParamField>

<ParamField path="lines" type="number[]" required={false}>
  要从源文件中提取的行。支持单行（`[5]`）、范围（`[2-4]`）和组合（`[1-3,5,7-10]`）。行索引从 1 开始。
</ParamField>
