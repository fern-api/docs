`<WebhookPayloadSnippet>` 组件从您的 API 参考中显示 webhook 的请求负载架构。它呈现与 webhook 完整 API 参考页面相同的字段、类型和示例值，因此读者可以在您的内容中内联检查负载。

要显示常规 HTTP 端点的架构，请使用 [`<EndpointSchemaSnippet>`](/learn/zh/docs/writing-content/components/endpoint-schema-snippet) 组件。

## 用法

通过其 `operationId` 引用 webhook。

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <WebhookPayloadSnippet webhook="on-conversation-completed" />
  </div>
</div>

```jsx Markdown
<WebhookPayloadSnippet webhook="on-conversation-completed" />
```

## 属性

<ParamField path="webhook" type="string" required={true}>
  要显示的 webhook 的 `operationId`。如果您的 API 使用[命名空间](/learn/zh/api-definitions/overview/project-structure#combined-sdks-from-multiple-apis)，请使用命名空间和 `::` 作为前缀（例如，`payments::on-payment-succeeded`）。
</ParamField>
