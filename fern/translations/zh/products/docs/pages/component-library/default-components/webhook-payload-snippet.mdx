使用 `<WebhookPayloadSnippet>` 组件从你的 API 参考文档中引用 webhook 负载。

## 用法

```jsx Markdown
<WebhookPayloadSnippet webhook="on-order-created" />
```

## 属性

<ParamField path="webhook" type="string" required={true}>
  要显示的 webhook 的操作 ID。
</ParamField>
