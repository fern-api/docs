## 推出产品切换器

按产品组织您的文档，让开发者能快速找到所需内容。非常适合拥有多个 API 的公司，每个 API 都有自己的参考文档、指南、版本和变更日志。

功能特性：

- **搜索优化** 具有 SEO 友好的结构。
- **关键词搜索和 Ask Fern** 可在产品内和跨产品工作。
- **可定制** 支持版本和独特图标来体现您的品牌标识。
