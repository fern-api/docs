# 2024年7月

## Meta图片系统
实现了全面的meta图片支持，改善社交分享效果。文档页面在社交媒体平台上分享时现在可以正确显示。

```yaml
og:image: /assets/og-image.png
og:type: documentation
twitter:card: summary_large_image
twitter:image: /assets/twitter-card.png
```
