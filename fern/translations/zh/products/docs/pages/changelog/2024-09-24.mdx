# 2024年9月

## 环境测试界面
创建了可编辑的playground环境系统，用于测试API端点。用户现在可以在文档内无缝切换不同的API环境。

```yaml openapi.yml
servers:
  - url: https://api.example.com
    x-fern-server-name: Production
  - url: https://sandbox.example.com
    x-fern-server-name: Sandbox
```
