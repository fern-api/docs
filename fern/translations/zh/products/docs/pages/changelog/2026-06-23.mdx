## 每条目更新日志标签

<ChangelogTags>navigation, components</ChangelogTags>

包含多个发布的更新日志条目可以使用 `<ChangelogTags>` 组件为每个标题独立添加标签：

```mdx
## New dashboard analytics
<ChangelogTags>analytics, dashboard</ChangelogTags>
```

单个条目页面上的标签可点击，点击后链接回时间线并预选该标签作为过滤器。
