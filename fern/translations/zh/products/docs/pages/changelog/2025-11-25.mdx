## API 参考文档的标签描述页面

您现在可以使用 OpenAPI 标签描述作为 API 参考文档部分的摘要页面。当您在 API 参考文档配置中设置 `tag-description-pages: true` 时，Fern 会自动为每个标签创建一个摘要页面，使用您 OpenAPI 规范中的描述。

```yaml docs.yml
navigation:
  - api: API Reference
    tag-description-pages: true
```
