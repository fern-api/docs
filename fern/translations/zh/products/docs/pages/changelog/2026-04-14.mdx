## 使用 `api:` 语法链接到 API Reference 部分

`api:` 链接语法现在支持链接到 API Reference 部分的根目录。使用 `api:apiName` 创建一个在构建时解析到特定 API Reference 着陆页的链接。这在您的项目有多个 API 时很有用。

```mdx Markdown
Explore the [Plant Store API](api:plant-store) reference.
```
