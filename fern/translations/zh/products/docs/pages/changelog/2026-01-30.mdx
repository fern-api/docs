## 可搜索表格

`<SearchableTable>` 组件为大型表格提供客户端过滤功能。表格上方会出现一个搜索输入框，使用不区分大小写的子字符串匹配对行进行实时过滤。将任何 markdown 表格用 `<SearchableTable>` 包装即可添加搜索功能：

```jsx Markdown
<SearchableTable>
| Plant | Light Requirements | Water |
|-------|-------------------|-------|
| Fern | Partial shade | Weekly |
| Snake Plant | Low to bright indirect | Bi-weekly |
</SearchableTable>
```

使用 `<StickySearchableTable>` 可以同时结合粘性表头和搜索功能：

```jsx Markdown
<StickySearchableTable>
| Plant | Light Requirements | Water |
|-------|-------------------|-------|
| Fern | Partial shade | Weekly |
| Snake Plant | Low to bright indirect | Bi-weekly |
</StickySearchableTable>
```

或者，也可以为 HTML 表格添加 `searchable` 属性：

```jsx Markdown
<table searchable className="fern-table">
  ...
</table>
```

## 切换器位置配置

使用 `docs.yml` 布局配置中的 `switcher-placement` 选项控制产品和版本切换器在文档站点中的显示位置。可选择 `header`（默认）在顶部导航栏中显示切换器，或选择 `sidebar` 将其放置在侧边栏导航中。

```yaml docs.yml
layout:
  switcher-placement: sidebar
```

## 代码块中的智能续行

Bash 和终端代码块现在能够智能地显示 `$` 表示新命令，`>` 表示使用 `\` 跨多行的命令续行。这使得在同一个代码块中更容易区分独立命令和多行命令。

```bash
fern init
fern generate --group external \
    --log-level debug \
    --version 1.0.0
fern check
fern docs dev
```
