## 在代码块中隐藏行号

`<CodeBlock>` 组件现在支持 `showLineNumbers` 属性，允许您隐藏侧边栏中的行号。这对于短代码片段、命令示例或单函数演示很有用，在这些场景中行号会增加不必要的视觉干扰。

```python showLineNumbers={false}
def get_plant(plant_id):
    return plants.get(plant_id)
```
