## 带有直接页面链接的预览工作流

您现在可以使用更新的 GitHub Actions 预览工作流，它会在您的拉取请求上评论直接链接到每个您更改的页面，这样审查者可以直接跳转到受影响的页面，而无需浏览整个站点。当您推送新提交时，评论会更新新的预览链接和刷新的页面链接。

<Frame>
    <img
    src="../getting-started/images/markdown-links-preview.png"
    alt="GitHub Actions bot comment showing a preview URL and a list of direct links to changed documentation pages"
    />
</Frame>

要采用此工作流，请将您的 `.github/workflows/preview-docs.yml` 替换为更新版本。通过[引导式 UI](https://dashboard.buildwithfern.com/get-started) 或 [CLI 快速开始](/learn/zh/docs/getting-started/quickstart) 创建的新站点会自动包含此功能。
