## GraphQL API 参考文档

从 GraphQL schema 生成 API 参考文档。将您的 `.graphql` schema 文件添加到 `generators.yml`，Fern 将查询、变更、订阅和类型渲染为交互式参考文档。

```yaml generators.yml
api:
  specs:
    - graphql: schema.graphql
```
