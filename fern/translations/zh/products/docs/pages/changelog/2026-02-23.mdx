## 使用 `api:` 语法链接到 API 端点

使用 `api:` 链接语法通过 HTTP 方法和路径链接到 API 端点，而不是硬编码 URL slug。Fern 在构建时将这些链接解析为正确的端点 URL。

```mdx
[Create a payment](api:POST/v2/payments)
```

这在 Markdown 页面、OpenAPI `description` 字段和 Fern Definition `docs` 字段中都有效。
