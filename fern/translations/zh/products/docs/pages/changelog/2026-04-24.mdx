## "连接到 Claude Code" 页面操作

启用了 [Ask Fern](/learn/zh/docs/ai-features/ask-fern/overview) 的 Fern Docs 网站现在会在现有页面操作旁显示"连接到 Claude Code"按钮。点击按钮会复制一个 `claude mcp add` 命令。读者可以将其粘贴到终端中，以将您网站的 [MCP 服务器](/learn/zh/docs/ai-features/mcp-server)注册到 Claude Code。

此操作默认启用，可以通过在 `docs.yml` 中设置 `page-actions.options.claude-code: false` 来关闭。
