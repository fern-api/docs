## 快速开始

通过导入您现有的样式和规范来构建文档网站。

- [快速开始](/learn/zh/docs/getting-started/quickstart)：在 5 分钟内建立一个文档网站。
- [轻松配置](/learn/zh/docs/configuration/site-level-settings)：使用一个简单的文件生成符合您品牌的文档。

## 功能特性

构建您自己的组件，启用 Ask Fern，生成 API 参考，并更新您的文档。

- [灵活的组件库](/learn/zh/docs/writing-content/components/overview)：使用预构建或自定义 React 组件获得精美外观。
- [Fern Editor](/learn/zh/docs/writing-content/fern-editor)：无需编写代码即可修改您的文档并发布到 GitHub。
- [使用您自己的 API 规范](/learn/zh/docs/api-references/generate-api-ref)：支持 OpenAPI、AsyncAPI、gRPC、OpenRPC 和 Fern 规范。
- [AI 功能](/learn/zh/docs/ai-features/overview)：AI 原生功能，包括 Ask Fern 和 AI 生成的示例。
- [自托管您的文档](/learn/zh/docs/self-hosted/overview)：在您自己的基础设施上部署，满足安全或合规要求。
</llms-only>
