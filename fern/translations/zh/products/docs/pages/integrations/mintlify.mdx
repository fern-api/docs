使用 Fern 为您的 API 生成 SDK，然后在 Mintlify 中使用自动丰富的代码示例进行文档编写。

## 工作原理

Fern 生成 SDK 并提供一个包含 SDK 代码示例的公开可访问的 OpenAPI 规范。在您的 Mintlify 文档中引用此规范，即可在 API playground 中显示 SDK 使用示例。

## 设置

将 Fern OpenAPI 规范 URL 添加到您的 Mintlify `docs.json` 配置中：

```json docs.json
{
  "anchors": [
    {
      "name": "API Reference",
      "openapi": "https://registry.buildwithfern.com/{org}/{api-name}/openapi/openapi.json",
      "url": "api-reference"
    }
  ]
}
```

将 `{org}` 替换为您的组织名称，将 `{api-name}` 替换为 `fern.config.json` 中的 API 名称。
