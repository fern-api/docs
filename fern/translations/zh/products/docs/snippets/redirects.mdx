<ParamField path="source" type="string" required={true}>
  您要重定向的相对路径（例如，`/old-path`）。必须是相对路径，而不是绝对 URL。不能包含搜索参数（例如，`?key=value`）。匹配前会对末尾斜杠进行归一化，因此 `/old-path/` 和 `/old-path` 等价。请与所重定向 URL 的大小写保持一致。
</ParamField>

<ParamField path="destination" type="string" required={true}>
  您要路由到的路径。可以是内部路径（`/new-path`）或外部 URL（`https://example.com`）。外部 URL 必须包含完整地址，包括 `https`。
</ParamField>

<ParamField path="permanent" type="boolean" required={false} default="true">
  默认使用 308 状态码指示客户端和搜索引擎永久缓存重定向。只有在需要使用 307 状态码的临时重定向时才设置为 `false`，这不会被缓存。
</ParamField>
