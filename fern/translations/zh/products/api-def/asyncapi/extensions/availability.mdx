标记功能在特定 SDK 版本中的可用性：

```yaml title="asyncapi.yml" {6-8}
operations:
  newFeature:
    action: send
    channel:
      $ref: '#/channels/new~1feature'
    x-fern-availability:
      status: beta
      message: "This feature is in beta and may change"
```
