---


为服务器指定自定义名称：

```yaml title="asyncapi.yml" {4-5}
servers:
  production:
    host: api.yourcompany.com
    x-fern-server-name: Production
    protocol: wss
  staging:
    host: staging.api.yourcompany.com
    x-fern-server-name: Staging
    protocol: wss
```
