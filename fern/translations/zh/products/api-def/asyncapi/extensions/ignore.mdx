使用 `x-fern-ignore` 在 SDK 生成中排除特定的操作、通道或模式：

```yaml title="asyncapi.yml" {6-7, 13-14}
operations:
  debugOperation:
    action: send
    channel:
      $ref: '#/channels/debug'
    x-fern-ignore: true
    summary: Debug operation (internal only)

channels:
  internal/debug:
    address: internal/debug
    x-fern-ignore: true
    messages:
      DebugMessage:
        $ref: '#/components/messages/DebugMessage'
```
