---
title: Fern 定义中的导入
description: 使用导入来引用其他 Fern 定义文件中的 API 类型和错误。
noindex: true
---


导入允许您引用其他文件中的类型和错误。

```yaml title="person.yml"
types:
  Person: ...
```

```yaml title="family.yml"
imports:
  person: ./path/to/person.yml
types:
  Family:
    properties:
      people: list<person.Person> # use an imported type
```

请注意，您只能导入 Fern 定义中存在的文件（即，在同一个 `definition/` 文件夹中）。
