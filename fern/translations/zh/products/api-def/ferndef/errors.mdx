---
title: Fern Definition 中的错误
description: 在 Fern Definition 中添加表示 API 端点失败响应的错误。
noindex: true
---

错误表示端点的失败（非 200）响应。

一个错误具有：

- HTTP 状态码
- 响应体类型 _（可选）_

<CodeBlock title="user.yml">
```yaml
errors:
  UserNotFoundError:
    status-code: 404
    type: UserNotFoundErrorBody

types:
  UserNotFoundErrorBody:
    properties:
      requestedUserId: string
```
</CodeBlock>
