`generators.yml` 文件有两个作用：它在 `api.specs` 部分声明你的 OpenAPI 规范位置，并在可选的 `groups` 部分配置 SDK 生成。

这里声明的 API 可以通过 `docs.yml` 在你的文档中渲染。请参阅[生成你的 API 参考文档](/learn/zh/docs/api-references/generate-api-ref)。
