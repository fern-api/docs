sidebar-title: 属性名称
---

`x-fern-property-name` 扩展允许您自定义对象属性的变量名称。

例如，如果您的模式中有一个名为 `_metadata` 的属性，但您希望在 SDK 中将变量称为 `data`，您可以执行以下操作：

```yaml {6}
components:
  schemas:
    MyUser:
      _metadata:
        type: object
        x-fern-property-name: data
```
