您可以定义您的 API 版本方案，例如 `X-API-Version` 请求头。支持的版本和默认值按如下方式指定：

```yaml title="openapi.yaml"
x-fern-version:
  header: X-API-Version
  default: "2.0.0"
  values:
    - "1.0.0"
    - "2.0.0"
    - "latest"
paths: ...
```
