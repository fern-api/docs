`generators.yml` 文件有两个作用：它声明你的 gRPC 规范位置（在 `api.specs` 部分），并配置 SDK 生成（在可选的 `groups` 部分）。

在此声明的 API 可以通过 `docs.yml` 在你的文档中渲染。请参阅 [生成你的 API 参考](/learn/zh/docs/api-references/overview)。
