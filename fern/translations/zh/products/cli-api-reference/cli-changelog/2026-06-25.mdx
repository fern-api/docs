## 5.54.0
**`(feat):`** 检测 NuGet 输出配置中的 `api-key: OIDC`，并将 OIDC 标记传递给
C# 生成器以生成 Trusted Publishing 工作流。


## 5.53.1
**`(fix):`** 修复省略 `--version AUTO` 时下一个 SDK 版本回退到过期基线（例如 `0.0.200`）的问题。
计算下一个版本时，Fern 现在会查询所有可用来源（包注册表、GitHub 发布和
`.fern/metadata.json` 中记录的 `sdkVersion`）并递增最高版本号，
因此过期的注册表版本不会再覆盖 Fern 上次生成的版本。例如，
`5.0.0` 现在正确递增为 `5.0.1`。


## 5.53.0
**`(feat):`** 添加对 generators.yml 中远程 git 源的支持。API 规范现在可以使用包含 `repo`、`ref` 和 `path` 字段的
`git` 块引用 git 仓库中的文件。CLI 在生成时使用原生 git 凭据浅克隆仓库。


## 5.52.0
**`(feat):`** 为 docs.yml 添加 `layout.changelog-layout` 选项。设置为 `classic` 可渲染
旧版堆叠式更新日志布局，设置为 `timeline`（默认）可渲染可搜索的
时间线卡片布局。
