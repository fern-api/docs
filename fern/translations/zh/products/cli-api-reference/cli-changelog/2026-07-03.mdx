## 5.64.2
**`(fix):`** OpenAPI 导入：当端点同时声明了带请求体的 2xx 响应和 204 No Content
响应时，现在可正确生成可选的成功响应体，即使 204 错误地声明了响应体。
根据 RFC 9110，204 不能携带请求体，因此声明的 204 请求体将被忽略（并发出警告），
成功响应类型将被包装为可选。此前 204 被丢弃且返回类型保持非可选，
导致真正的 204（空请求体）在生成的 SDK 中解码失败。
适用于旧版和 v3 OpenAPI 导入器。
