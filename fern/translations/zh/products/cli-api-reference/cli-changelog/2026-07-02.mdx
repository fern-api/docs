## 5.64.1
**`(fix):`** 修复 GraphQL 命名空间类型（如 Inventory、Geography）未注册到
类型注册表的问题，以及查询页面缺少父操作的问题。命名空间类型现已注册，
其字段可在着陆页上正确渲染。


## 5.64.0
**`(fix):`** 修复使用远程 git 源时 proto `target` 路径解析的问题。此前 target
相对于工作区而非克隆的仓库进行解析，导致"文件缺失"错误。


**`(feat):`** 支持在 git 源的 `ref` 字段中使用提交 SHA 引用。此前仅支持分支名称
和标签；现在提交 SHA 可通过 fetch+checkout 方式使用。
