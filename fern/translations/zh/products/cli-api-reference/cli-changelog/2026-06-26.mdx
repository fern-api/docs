## 5.55.1
**`(fix):`** 修复 `--instance` 标志在提供的 URL 与任何已配置实例不匹配时静默发布到错误文档实例的问题。此前 CLI 会回退到第一个配置的实例；现在会报错并列出可用实例。


**`(fix):`** 在本地生成模式中将基于 sed 的魔术版本替换替换为纯 Node.js 实现。修复了二进制文件上的"非法字节序列"错误并消除了平台特定的行为。


**`(fix):`** 修复当翻译后的 OpenAPI 规范更改了结构标识符（例如 OpenAPI 标签名称，这些名称派生子包和端点 ID）相对于默认区域设置规范时，本地化文档出现 500（PruneEmptyError）的问题。API 参考导航节点现在通过稳定的定位器（HTTP 方法 + 路径）以及 ID 匹配翻译后的定义，因此本地化侧边栏标题仍然有效，渲染器可以解析提供的 API。当节点完全无法匹配时，受影响的 API 会回退到默认区域设置定义并发出警告，而不是崩溃。


## 5.55.0
**`(feat):`** 默认文档部署模式现在是"ledger"，支持更快的增量部署和未缓存页面更快的首次页面渲染。要利用此功能，请将 `fern/fern.config.json` 中的 `version` 字段升级到此版本或更高版本——CLI 会自动重定向到固定版本，因此旧的固定版本不会采用新的默认值。您也可以从 Fern 仪表板一键升级版本。要恢复到旧版流程，请在 GitHub Actions 工作流的 `env` 部分添加 `FERN_DOCS_DEPLOY_MODE: legacy`。旧版部署将在未来的 CLI 版本中移除。
