## 5.57.0
**`(feat):`** 在 GitHub Actions 中运行时，重要的 SDK 生成事件现在以
`::notice::` 注解的形式显示在工作流运行页面并附加到步骤摘要中。
注解的事件包括 PR 创建、包发布（npm、PyPI、Maven 等）、
无更改检测和版本标记。此前这些详细信息仅在调试级别的日志输出中可见。


## 5.56.4
**`(fix):`** 修复远程生成 CLI 在 S3 下载停滞时无限挂起的问题。
为 downloadZipForTask 和 downloadAndExtractZipToDirectory 添加了
连接超时（60秒）和总体下载超时（5分钟），
使 CLI 以清晰的错误消息失败而不是永远阻塞。


## 5.56.3
**`(fix):`** 修复 ledger 发布路径未转发多源文档站点的 `basepathAware` 标志的问题，
导致清单写入错误的存储键。受影响的站点提供上次旧版发布的过期内容，
而不是更新的 ledger 清单。


## 5.56.2
**`(chore):`** 将库文档解析器 Docker 镜像从 `fernapi` 迁移到 `fernenterprise` 注册表。


## 5.56.1
**`(fix):`** 修复 `fern docs dev` 在 pnpm 10+ 上失败的问题，原因是生成的
`pnpm-workspace.yaml` 缺少 `packages` 字段以及 `pnpm i esbuild` 缺少 `-w` 标志。
