[管理员](/learn/dashboard/configuration/permissions)可以在 [Fern Dashboard](https://dashboard.buildwithfern.com/fern/tokens) 中创建和管理 API 密钥。API 密钥用于在 CI/CD 流水线中验证 Fern CLI 身份，例如从 GitHub Actions 发布 SDK 或文档时。

<Note>
  API 密钥不会过期。请定期轮换密钥并删除不再使用的密钥。
</Note>

## 创建 API 密钥

<Steps>
<Step title="打开 API 密钥页面">

导航到 [Fern Dashboard](https://dashboard.buildwithfern.com/) 并从侧边栏选择 **API Keys**。
</Step>

<Step title="创建新的 API 密钥">

选择 **Create key**，输入名称（例如 `CI/CD pipeline`），然后选择 **Generate**。

API 密钥仅显示一次。请立即复制；之后将无法再次查看。

</Step>

<Step title="将 API 密钥存储为密钥">

在 CI/CD 提供商（例如 GitHub Actions、GitLab CI）中将 API 密钥添加为名为 `FERN_TOKEN` 的仓库密钥。Fern CLI 从环境中读取此值进行身份验证，因此任何运行 `fern` 命令的工作流都可以引用它：

```yaml title="GitHub Actions 示例"
env:
  FERN_TOKEN: ${{ secrets.FERN_TOKEN }}
```

工作流的其余部分取决于您发布的内容：同一个令牌可用于[发布文档](/learn/docs/preview-publish/publishing-your-docs)和[将 SDK 发布到包注册表](/learn/sdks/generators/typescript/publishing)的身份验证。

</Step>
</Steps>

## 管理 API 密钥

在 **API Tokens** 页面中，您可以：

- **删除 API 密钥** — 选择 API 密钥旁的选项菜单并选择 **Delete**。已删除的 API 密钥会立即吊销且无法恢复。

<Note>
  所有[成员](/learn/dashboard/configuration/permissions)都可以查看 API 密钥名称和创建日期。只有管理员可以创建或删除 API 密钥。
</Note>
