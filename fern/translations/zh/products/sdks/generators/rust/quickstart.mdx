按照本页面的说明生成 Rust SDK。

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="添加 SDK 生成器">

运行以下命令将 Rust SDK 生成器添加到 `generators.yml`：

<Template
  data={{ GROUP_NAME: "rust-sdk" }}
  tooltips={{
    GROUP_NAME: (<p><code>generators.yml</code> 组的名称，用于配置您的 Rust SDK 的输出位置和其他元数据。您可以自定义此组名称，以区分不同语言的多个 SDK。</p>)
  }}
>
```bash
fern add fern-rust-sdk --group {{GROUP_NAME}}
```
</Template>

此命令会将以下 `group` 添加到 `generators.yml`：

```yaml title="generators.yml"
  rust-sdk: # group name
    generators:
      - name: fern-rust-sdk
        version: <Markdown src="/snippets/version-number-rust.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/rust
```
</Step>
<Step title="生成 SDK">

运行以下命令生成您的 SDK：

```bash
fern generate --group rust-sdk
```
