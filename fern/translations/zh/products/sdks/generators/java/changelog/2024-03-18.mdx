## 0.8.5
**`(feat):`** 添加发布配置，允许对发布的构件进行签名，这是发布到 Maven Central 所必需的。
要签名您的构件，您必须在发布配置中添加以下内容：
```yaml
generators:
  - name: fernapi/fern-java-sdk
    version: 0.X.Y
    output:
      location: maven
      registryUrl: ""
      signature:
        keyId: ""
        password: ""
        secretKey: ""
```
可以使用密钥，类似于今天指定 API 密钥的方式：
```yaml
generators:
  - name: fernapi/fern-java-sdk
    version: 0.X.Y
    output:
      location: maven
      registryUrl: ""
      signature:
        keyId: ${MY_KID_ENVVAR}
        password: ${MY_SECRET_ENVVAR}
        secretKey: ${MY_SECRET_KEY_ENVVAR}
```
