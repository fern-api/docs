## 4.2.0-rc.1
**`(chore):`** 将 IR 依赖升级到 v66.1.0 Maven 构件，用原生 irV66 类型替换自定义反序列化器变通方法。


**`(feat):`** 支持联合的默认判别值。当有判别联合变体在其判别器字段上有默认值时，
Java SDK 现在回退到该变体，而不是将缺失的判别器视为未知。这修复了在省略判别器
且 API 期望默认变体的负载的反序列化问题。


## 4.1.4
**`(chore):`** 在生成器 Docker 镜像中将 Node.js 从 24.13.0 更新到 24.14.1，
以修复 7 个 CVE（CVE-2026-21710、CVE-2026-21717、CVE-2026-21713、
CVE-2026-21714、CVE-2026-21712、CVE-2026-21715、CVE-2026-21716）。
