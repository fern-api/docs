## 3.25.0
**`(feat):`** 添加 `gradle-distribution-url` 配置选项，允许覆盖 Gradle wrapper 分发 URL。这使企业网络无法访问 `services.gradle.org` 时能够指向内部 Gradle 分发镜像进行 SDK 生成。

配置示例：
```yaml
config:
  gradle-distribution-url: https://internal-mirror.example.com/gradle/gradle-8.14.3-bin.zip
```
