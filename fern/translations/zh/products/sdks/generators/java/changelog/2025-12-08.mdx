## 3.23.3
**`(fix):`** 修复 OptionalNullable 查询参数，正确应用 .orElse(default) 处理带有默认值的参数。之前只识别 java.util.Optional 进行默认值处理，导致 OptionalNullable 参数直接传递而不解包。现在 Optional 和 OptionalNullable 类型都能正确处理：带有默认值的参数使用 .orElse(default)，没有默认值的参数使用适当的存在性检查（OptionalNullable 使用 !isAbsent()，Optional 使用 isPresent()）。
