## 2.40.0
**`(feat):`** 通过 `use-default-request-parameter-values` 标志添加对客户端默认参数值的支持。
启用时，具有默认值的查询和头部参数变为 Optional 类型，当未提供时自动
应用默认值。示例：

```yaml
customConfig:
  use-default-request-parameter-values: true
```

生成的代码：
```java
// 有默认值的参数变为 Optional
private final Optional<Integer> perPage;  // 有默认值：50

// 自动应用默认值
QueryStringMapper.addQueryParameter(httpUrl, "per_page", request.getPerPage().orElse(50), false);
```
