## 4.0.6
**`(fix):`** 修复在使用本地生成（`--local`）时，自定义许可证在 `build.gradle` 中未被解析的问题。
许可证文件在 Docker 内挂载在 `/tmp/LICENSE`，但生成器在一个不存在的相对路径中查找它。
生成器现在检查 `/tmp/<filename>` 作为回退。此外，当许可证文件的第一行用作许可证名称时，
现在会剥离 markdown 格式（标题、粗体等）。


## 4.0.5
**`(fix):`** 修复生成的 README 异常处理代码片段在指定 `client-class-name` Java 自定义配置时，
使用 `{org}ApiException` 而不是 `{clientClassName}ApiException` 的问题。
README 现在使用与 SDK 中实际生成的相同异常类型名称。
