## 3.0.0
**`(break):`** SDK 生成器现在默认使用前向兼容的枚举，提供对后端添加新枚举变体的弹性。
这是一个破坏性更改，会影响生成的枚举类型的结构。

要恢复到使用传统 Java 枚举的先前行为，请在 `generators.yml` 文件中添加以下配置：
```yaml
generators:
  - name: fernapi/fern-java-sdk
    config:
      enable-forward-compatible-enums: false
```


**`(feat):`** 前向兼容的枚举现在默认启用。生成的 SDK 在遇到未知枚举变体时不再抛出错误，
而是通过 UNKNOWN 值优雅处理。这对以下场景特别重要：
- 无法轻松更新的移动应用程序
- 当后端添加新枚举值时保持向后兼容性
- 先前导致客户端失败的枚举值数组中出现新变体

使用前向兼容的枚举，生成的代码从传统 Java 枚举更改为支持通过访问者模式处理未知值的基于类的枚举。
