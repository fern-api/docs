## 2.0.0
**`(break):`** SDK 生成器现在升级到主要版本 2。要在不中断的情况下进行此升级，请在您的 `generators.yml` 文件中添加以下配置：
```yaml
generators:
  - name: fernapi/fern-java-sdk
    config:
      disable-required-property-builder-checks: true
```


**`(feat):`** 生成的构建器方法现在对必需字段强制执行非空检查，确保在对象构造期间正确验证所有必需字段：
  ```java
  @java.lang.Override
  @JsonSetter("name")
  public NameStage name(@NotNull String name) {
      this.name = Objects.requireNonNull(name, "name must not be null");
      return this;
  }
  ```
