## 3.34.0
**`(feat):`** 添加 `output-directory` 配置选项，用于控制本地生成期间 Java 文件的写入位置。
- `project-root`（默认）：文件写入到 `<path>/src/main/java/`（当前行为）
- `source-root`：文件直接写入到 `<path>/`（v3.8.2 之前将 SDK 嵌入现有项目的行为）

这允许将 SDK 嵌入现有项目的客户避免出现双重 `src/main/java` 路径。
