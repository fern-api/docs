## 3.19.0
**`(feat):`** 为 OAuth API 和多 URL 环境添加线路测试支持。线路测试现在：
- 通过每个测试的令牌排队正确模拟 OAuth 令牌端点
- 对 OAuth 认证的 API 使用 `.clientId()/.clientSecret()`
- 支持令牌端点所需的自定义 OAuth 头部（例如 `apiKey`）
- 为多 URL 环境 API 配置 `Environment.custom()` 构建器
- 处理允许响应中额外默认字段的灵活 JSON 比较
