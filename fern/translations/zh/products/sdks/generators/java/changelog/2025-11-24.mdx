## 3.18.10
**`(fix):`** 修复启用 use-local-date-for-dates 时的 Java 动态代码片段。日期字段的代码片段现在生成 LocalDate.parse(...) 而不是字符串字面量，匹配配置为对日期使用 LocalDate 的 SDK。这修复了当 use-local-date-for-dates 标志为 true 时 Java v2 生成的动态代码片段中的编译错误。


## 3.18.9
**`(fix):`** 修复线路测试生成以在启用 collapse-optional-nullable 时使用 OptionalNullable。线路测试现在正确地生成 OptionalNullable.absent() 和 OptionalNullable.of() 而不是 Optional.empty() 和 Optional.of()，用于配置 collapse-optional-nullable: true 时的可选请求体和方法参数。这包括对嵌套可选/可空类型的支持，这些类型会合并为单个 `OptionalNullable<T>`。
