## 2.38.1
**`(fix):`** 修复 JavaDoc 生成以在使用 JavaPoet 时正确转义美元符号 ($)。

使用 JavaPoet 生成 JavaDoc 注释时，美元符号需要转义为 `$$` 以防止
JavaPoet 将它们解释为模板变量。这确保文档中的美元符号
在最终生成的代码中正确渲染。


## 2.38.0
**`(chore):`** 添加对自定义配置 publish-to 的支持，以启用使用正确的元数据和签名配置发布到 Maven Central。

```yaml
customConfig:
  publish-to: central
```

此配置启用使用正确的元数据和签名配置自动发布到 Maven Central。
