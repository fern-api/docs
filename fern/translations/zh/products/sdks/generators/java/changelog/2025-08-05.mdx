## 2.39.6
**`(feat):`** 通过 `enable-extensible-builders` 标志添加可选的可扩展构建器模式。启用时，构建器使用自类型
模式，允许用户扩展生成的构建器同时保持类型安全。示例：

```java
class CustomBuilder extends BaseClientBuilder<CustomBuilder> {
    @Override
    protected CustomBuilder self() { return this; }

    public CustomBuilder workspaceId(String id) {
        // custom logic
        return this;
    }
}
```


## 2.39.5
**`(fix):`** 修复无区分联合反序列化以捕获所有 RuntimeException 类型而不是仅 IllegalArgumentException。
