## 3.34.5
**`(fix):`** 修复流式端点错误设置 `Accept: application/json` 头部的问题。流式端点（SSE、NDJSON 等）现在完全省略 Accept 头部，允许服务器协商适当的流式格式。


## 3.34.4
**`(fix):`** 修复当路径参数命名为 `key` 时 Java SDK 编译错误的问题。`requestOptions.getQueryParameters().forEach((key, value) -> {...})` 中的 lambda 变量遮蔽了路径参数，导致"变量 key 已定义"编译错误。Lambda 变量现在使用下划线前缀以避免冲突。
