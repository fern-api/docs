## 3.8.0
**`(feat):`** 向 `BasePage` 添加 `getResponse()` 方法，用于访问分页元数据（如游标令牌）。
这通过提供对完整 API 响应对象的访问来启用无状态分页。

使用示例：
```java
SyncPagingIterable<User> users = client.users().list();
users.getResponse().ifPresent(response -> {
    String cursor = response.getNext();
    // 使用游标进行无状态分页
});
```


## 3.7.0
**`(feat):`** Wire 测试现在默认为所有 Java SDK 启用，使用 MockWebServer 提供全面的 HTTP 协议
验证测试。Wire 测试验证请求/响应序列化、HTTP 方法、标头和 API 合约遵守情况。
要禁用 wire 测试，请在生成器配置中显式设置 `enable-wire-tests: false`。
