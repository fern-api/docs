## 3.1.0-rc0
**`(chore):`** 根客户端现在从主 `__init__.py` 导出。

### 已更改的内容
- 改进：用户交互的根客户端现在从主 `__init__.py` 导出，这允许用户通过 `from my_sdk import my_sdk_client` 访问客户端，而不是 `from my_sdk.client import my_sdk_client`。

### 已移除的功能
- 注意这带来了一个边缘情况的破坏性变更。在不太可能出现的情况下，如果您有一个与导出的根客户端命名冲突的类型，该类型模型会被后缀为"Model"。例如，在导出客户端 `Merge` 的 SDK 中，类型 `Merge` 变为 `MergeModel`。

## 3.0.0-rc2
**`(fix):`** `update_forward_refs` 不再引发错误，保持原始行为，即 3.x 版本之前的行为。
