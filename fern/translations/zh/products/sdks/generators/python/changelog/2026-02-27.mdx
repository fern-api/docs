## 4.61.2
**`(fix):`** 重新添加 `@fern-api/generator-cli` 到 Python SDK Docker 镜像。在 4.60.1 版本中，当基于 JS 的生成器迁移到直接使用 generator-cli JS API 时，CLI 被意外移除。Python 生成器仍然依赖 CLI 二进制文件通过子进程进行 README.md 和 reference.md 生成。


## 4.61.1
**`(fix):`** 修复了 `positional_single_property_constructors` 破坏 pydantic 响应反序列化的问题。自定义的 `__init__` 现在使用带有宽松的 `*args, **kwargs` 运行时签名的 `@typing.overload`，因此 pydantic 可以在反序列化期间自由传递别名键数据，同时仍然允许位置构造，如 `Wrapper("value")`。
