## 2.14.1
**`(fix):`** Sync 和 AsyncPagers 中的类型现在正确传递给 BasePager。

### 已修复的问题
- Sync 和 AsyncPage 现在将泛型类型传递给 BasePage，允许在类型检查系统中适当地使用 `.items` 等类型化功能。

## 2.14.0
**`(fix):`** 偏移页面现在允许使用 0 作为页面起始值。

### 已修复的问题
- 偏移页面现在允许使用 0 作为页面起始值，之前使用 `page or 1` 会让 Python 强制转换布尔值变为 1，忽略用户提供的 0。
