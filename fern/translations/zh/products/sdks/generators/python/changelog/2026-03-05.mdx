## 4.62.0
**`(feat):`** 为 python-v2 SDK 生成器添加了 `README.md` 和 `reference.md` 生成功能。v2 生成器现在生成包含功能片段的 README 文档（安装、使用、超时、自定义客户端、异常处理、原始响应、websockets、自定义部分）和端点参考文档。


**`(chore):`** 使用尾随逗号格式化多行函数调用的 AST 输出，以及内联列表/字典格式化，以提高代码可读性。


## 4.61.5
**`(fix):`** 修复 WebSocket 客户端生成以遵守 `pydantic_config.skip_validation: true`。之前，socket 客户端始终使用 `parse_obj_as`（完整的 Pydantic 验证），无论 skip_validation 标志如何。现在当启用该标志时，它们正确使用 `construct_type`（无验证），与 HTTP 客户端的行为一致。
