## 4.45.0
**`(feat):`** 为 `pydantic_config` 添加 `coerce_numbers_to_str` 选项。启用时，数值类型（int、float、Decimal）
将在验证期间被强制转换为字符串。这对于返回数值作为字符串的 API 很有用。


## 4.44.2
**`(fix):`** 修复枚举类型头部使用 `.value` 而不是 `str()` 以在所有 Python 版本中保持一致的线格式。
以前，`str(enum)` 在 Python `< 3.11` 上返回枚举名（例如 `Operand.GREATER_THAN`），
但在使用 StrEnum 的 Python `>= 3.11` 上返回线值（例如 `>`）。


## 4.44.1
**`(fix):`** 移除 `oauth-token-override` 配置标志。OAuth 令牌覆盖现在始终为 OAuth 客户端
凭证流程启用，允许用户通过 client_id/client_secret 或直接通过 `token` 参数使用预生成的
bearer 令牌进行身份验证，无需任何配置。
