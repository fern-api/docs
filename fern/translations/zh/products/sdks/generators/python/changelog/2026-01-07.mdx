## 4.46.7-rc3
**`(fix):`** 修复流式端点的线路测试生成。流式方法返回惰性迭代器（Iterator[bytes] 或 AsyncIterator[bytes]），直到迭代时才执行 HTTP 请求。线路测试现在将流式端点调用包装在 'for _ in ...: pass' 循环中，以确保实际发出 HTTP 请求。这适用于 streaming、streamParameter 和 fileDownload 响应类型。
