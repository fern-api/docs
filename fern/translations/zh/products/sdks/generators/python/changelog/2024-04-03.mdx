## 1.1.0-rc0
**`(feat):`** Python SDK 现在包含跳过 pydantic 验证的配置选项。

### 新功能
- [实验性]: Python SDK 现在包含跳过 pydantic 验证的配置选项。这确保如果从 API 返回的模型不完全匹配 Pydantic 模型，Pydantic 不会立即失败。这意味着增加灵活性，如果您的 SDK 落后于您的 API，但应该谨慎使用，因为用户的类型提示仍将完全反映 Pydantic 模型。

## 1.0.1
**`(fix):`** 解决在 Pydantic V1 中引入 `pydantic.v1` 导入时的 Pydantic 破坏

### 已修复的问题
- Pydantic 通过添加不镜像 pydantic v2 附带的 .v1 子模块，对其 1.x 库引入了"破坏"。为了解决这个问题，我们现在只在 pydantic 版本为 v2 时强制使用 v1 子模块。
