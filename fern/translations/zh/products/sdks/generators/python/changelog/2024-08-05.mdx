## 3.5.1
**`(fix):`** 利用联合工具的联合体自动补全现在能正常工作。

### 已修复的问题
- 带有访问器的联合体的根类型现在其父类型已正确输入。这使得当联合体嵌套在其他 pydantic 模型中时，自动补全能够再次工作。

## 3.5.0
**`(chore):`** 生成的代码现在遵循 pydantic 版本配置标志。

### 已更改的内容
- 改进：生成的 SDK 现在遵循 pydantic 版本标志，如果指定的话，生成仅限 V1 的代码和仅限 V2 的代码。如果未指定，SDK 将像今天一样生成，同时兼容两个 Pydantic 版本。这清理了生成的代码，并为仅限 V1 的 SDK 恢复了诸如包装别名等功能。

## 3.4.2
**`(fix):`** Python 生成器现在将 `Any` 类型实例化为 `Optional[Any]`，以便能够减轻 Pydantic V2 中的中断。
