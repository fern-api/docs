## 4.0.0-rc2
**`(fix):`** 更新 Pydantic V2 中的 .dict 调用，为继续使用 Pydantic 别名的 SDK 回到 3.10.4 之前的逻辑。

## 4.0.0-rc1
**`(fix):`** 更新 Pydantic V2 中的 .dict 调用，回到 3.10.4 之前的逻辑。

### 已修复的问题
- Pydantic V2 `.dict` 调用被更新为回到 3.10.4 之前的逻辑。这是为了修复一个回归问题，其中嵌套字面量由于 Pydantic V2 序列化器不遵循递归 .dict 逻辑而被省略，因为 Pydantic V2 将 `model_dump` 调用转移到 Rust 库和序列化器，而不是递归调用 `model_dump`。
预计性能不会降低，因为基于 Rust 的序列化器相比 Pydantic V1 .dict 方法具有优化的性能。
