## 5.3.6
**`(fix):`** 修复 wire 测试和代码片段导入忽略 `package_path` 配置的问题。当设置了 `package_path`（例如 `package_path: myorganization`）时，生成的 wire 测试和 README/reference 代码片段会从根包导入类型（例如 `from auth0 import OrgBranding`），而不是从嵌套模块导入（例如 `from auth0.myorganization import OrgBranding`），导致 mypy 和 pytest 失败。


## 5.3.5
**`(fix):`** 修复具有字面量/常量类型的对象属性的 wire 测试生成产生无效语法（例如 `strategy=,`）的问题。解析为空操作值的字面量属性现在会从生成的构造函数参数中过滤掉。


## 5.3.4
**`(fix):`** 修复布尔路径参数在 URL 路径中被序列化为 Python 风格的 `True`/`False` 而不是 JSON 风格的 `true`/`false` 的问题。添加了 `encode_path_param` 实用程序，确保路径段的正确小写布尔编码。
