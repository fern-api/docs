## 5.4.0-rc.1
**`(fix):`** 修复 `auth: any` 与 OAuth + header auth 方案（如 API key）的问题：
- Header auth 参数现在包含在生成的客户端构造函数中（之前在存在 OAuth 时被静默丢弃）
- Header auth 参数被传递给客户端包装器（之前缺失，导致运行时 `TypeError`）
- 在与 OAuth 并存时，Header auth 类型设为可选，并有条件地设置 header
- 现在可以仅使用 header auth 凭据（如 `api_key`）实例化客户端，而无需 OAuth 凭据或 bearer token
