## 5.4.0-rc.0
**`(feat):`** 升级到 IR v66，压缩了 IR Name 类型，减小了 IR 大小并提高了性能。


## 5.3.11
**`(fix):`** 修复具有流条件属性的判别联合请求体生成代码中的重复关键字参数问题。当联合变体通过 extends 从基础模式继承流条件字段时，该属性会被发出两次——一次来自联合的基础属性，一次来自变体的扩展属性——导致生成的 Python 代码出现 SyntaxError。


**`(fix):`** 转义文档字符串中的三重引号，以防止当 OpenAPI 描述包含带有三重引号字符串的 Python 代码示例时过早终止文档字符串。


**`(fix):`** 通过镜像基础客户端的 @overload 签名并使用 **kwargs 传递，而不是使用 type: ignore 注释抑制错误，修复导出的客户端包装器中的 mypy 调用重载错误。
