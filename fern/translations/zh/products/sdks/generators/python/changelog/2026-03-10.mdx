## 4.63.2
**`(fix):`** 修复了 wire 测试日期时间格式不匹配。当 `datetime_milliseconds` 为 false（默认值）时，WireMock 存根现在会剥离 `.000` 毫秒以匹配 SDK 的默认 `serialize_datetime` 输出。当为 true 时，测试验证值包含 `.000` 以匹配毫秒精度输出。修复了带有日期时间查询参数的 API 的 wire 测试失败。

## 4.63.0
**`(feat):`** 新增 `datetime_milliseconds` 自定义配置选项。设置为 `true` 时，`serialize_datetime` 始终在 ISO 8601 输出中包含毫秒精度（例如，`2008-01-02T00:00:00.000Z` 而不是 `2008-01-02T00:00:00Z`）。对于需要固定宽度日期时间格式和小数秒的 API 很有用。默认行为保持不变。
