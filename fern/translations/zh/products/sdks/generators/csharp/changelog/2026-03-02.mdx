## 2.23.1
**`(chore):`** 在 csharp-codegen 中用浏览器兼容的替代方案替换 Node.js 内置导入
（`assert`、`path`），使动态代码片段包能够
在浏览器环境中运行，无需 Node.js polyfills。


## 2.23.0
**`(feat):`** 在生成的 README.md 中添加 AdditionalQueryParameters 和 AdditionalHeaders 文档
部分，让用户可以了解如何
通过 RequestOptions 传递额外的查询参数和头部信息。


## 2.22.9
**`(chore):`** 在 `BaseRequest` 中使 `BaseUrl` 可选，并从生成的
端点代码中省略它，除非需要（例如多基础 URL 环境）。
当请求上未设置 `BaseUrl` 时，`RawClient` 现在回退到 `Options.BaseUrl`，
移除每个生成的 API 调用中冗余的
`BaseUrl = _client.Options.BaseUrl`。
