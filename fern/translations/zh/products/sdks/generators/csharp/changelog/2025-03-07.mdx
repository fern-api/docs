## 1.12.0-rc13
**`(feat):`** 添加通过新的 `AdditionalProperties` 字段在对象类型中接收附加属性的支持。
当您想要解析具有在 SDK 中不可用的属性的对象时（例如，alpha 和/或未记录的属性），这将非常有用。

```csharp
// 调用端点。
var response = await client.GetUser(...);

// 打印附加属性。
Console.WriteLine(response.AdditionalProperties);
```
