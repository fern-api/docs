## 2.18.0
**`(feat):`** 添加 `QueryStringBuilder` 类用于构建具有适当 URL 编码的查询字符串。

使用示例：
```csharp
var queryString = new QueryStringBuilder.Builder()
    .Add("access_token", "abc123")
    .Add("config_id", "cfg-456")
    .AddDeepObject("session_settings", new { SystemPrompt = "Hello" })
    .Build();
// 结果: ?access_token=abc123&config_id=cfg-456&session_settings%5BSystemPrompt%5D=Hello
```


**`(chore):`** 改进标头合并逻辑以提高可靠性和可维护性。

**`(chore):`** 移除 `additional-properties` 和 `experimental-additional-properties` 配置选项。
现在为所有生成的 SDK 始终启用 AdditionalProperties 支持，简化生成器并确保所有生成代码的一致行为。此功能允许处理 JSON 响应中的额外/未知属性。
