## 2.55.2
**`(fix):`** 支持使用 `AuthSchemesRequirement.Any` 的多个 Basic Auth 方案。当 API 定义多个基本认证方案时（例如，accountId/authToken 和 apiKey/apiKeySecret），生成的客户端现在生成条件 if/else if 块来检查提供了哪个凭据对，并相应地设置 Authorization 头。此前仅使用第一个基本认证方案。

## 2.55.1
**`(fix):`** 在 WireMock 模拟服务器响应对象中包含 extraProperties (AdditionalProperties)。此前，具有 `[JsonExtensionData]` 附加属性的对象类型在生成的模拟响应中缺少这些属性，导致 WireMock stubs 不完整。
