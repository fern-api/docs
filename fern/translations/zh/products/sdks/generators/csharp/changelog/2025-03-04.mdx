## 1.12.0-rc10
**`(feat):`** 在模拟线路测试中比较对象时，比较 .NET 对象而不是 JSON 字符串。
通过此更改，我们可以移除对 FluentAssertions.Json 包的依赖（以及对 Newtonsoft.Json 包的隐式依赖）。


**`(chore):`** 更新生成的测试项目中的依赖项：
- `Microsoft.NET.Test.Sdk`：17.12.0 => 17.13.0
- `NUnit`：4.2.2 => 4.3.2
- `NUnit3TestAdapter`：4.6.0 => 5.0.0
- `NUnit.Analyzers`：4.4.0 => 4.6.0
- `coverlet.collector`：6.0.2 => 6.0.4
- `WireMock.Net`：1.6.8 => 1.7.4


**`(fix):`** 在模拟线路测试中比较 .NET 对象而不是 JSON 字符串，这修复了 JSON 反序列化和序列化会导致 JSON 字符串差异的错误。
