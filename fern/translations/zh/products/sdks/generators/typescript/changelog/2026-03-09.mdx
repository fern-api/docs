## 3.53.9
**`(fix):`** 通过向 Debian slim 基础镜像添加 `ca-certificates` 来修复 Docker 中的 README 生成。自 v3.48.4 版本从 Alpine 切换到 Debian slim 以来，容器缺少 CA 证书，导致 `git clone` 通过 HTTPS 失败，出现"服务器证书验证失败"错误。这导致生成空的 README 文件。

## 3.53.8
**`(chore):`** 改进 README.md、reference.md 和 CONTRIBUTING.md 生成失败时的错误日志。生成器现在记录实际的错误消息和堆栈跟踪，而不是一般的"这没关系"消息，使诊断生成问题变得更容易。
