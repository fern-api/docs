## 3.9.0
**`(feat):`** 添加对 `Uploadable.FromPath` 和 `Uploadable.WithMetadata` 类型的支持，以将带有元数据的文件上传到 multipart-form 端点。

用户可以使用 `Uploadable.WithMetadata` 类型在将文件上传到 multipart-form 上传端点时配置元数据：
```typescript
import { createReadStream } from "fs";

await client.upload({
    file: {
      data: createReadStream("path/to/file"),
      filename: "my-file",
      contentType: "audio/mpeg",
    },
    otherField: "other value",
});
```
`filename`、`contentType` 和 `contentLength` 属性是可选的。

另外，用户可以使用 `Uploadable.FromPath` 类型直接从文件路径上传：
```typescript
await client.upload({
    file: {
        path: "path/to/file",
        filename: "my-file",
        contentType: "audio/mpeg",
    },
    otherField: "other value",
});
```

元数据用于设置 `Content-Type` 和 `Content-Disposition` 头部。如果未提供，客户端将尝试自动确定它们。
```
