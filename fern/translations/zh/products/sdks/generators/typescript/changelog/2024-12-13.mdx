## 0.44.0
**`(feat):`** 通过在生成器配置中将 `inlinePathParameters` 设置为 `true` 来将路径参数内联到请求类型中。

下面是用户在不使用和使用 `inlinePathParameters` 设置为 `true` 时如何使用相同端点方法的示例。

不使用 `inlinePathParameters`：

```ts
await service.getFoo("pathParamValue", { id: "SOME_ID" });
```

使用 `inlinePathParameters`：

```ts
await service.getFoo({ pathParamName: "pathParamValue", id: "SOME_ID" });
```
