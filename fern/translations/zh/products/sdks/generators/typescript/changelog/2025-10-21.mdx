## 3.12.0
**`(feat):`** 添加对[使用GitHub Actions的OIDC发布到npmjs.org](https://docs.npmjs.com/trusted-publishers)的支持。

要使用OIDC发布到npmjs.org，您需要执行以下两个步骤：
1. 按照["步骤1：在npmjs.com上添加信任的发布者"](https://docs.npmjs.com/trusted-publishers#step-1-add-a-trusted-publisher-on-npmjscom)中的说明进行操作。
2. 在_generators.yml_中将`output.token`字段设置为`OIDC`以启用此功能：

    ```yml
    # In generators.yml
    groups:
      ts-sdk:
        generators:
          - name: fernapi/fern-typescript-sdk
            output:
              location: npm
              package-name: your-package-name
              token: OIDC # previously this would be set to something like ${NPM_TOKEN}
            ...
    ```

    这将处理["步骤2：配置您的CI/CD工作流"](https://docs.npmjs.com/trusted-publishers#step-2-configure-your-cicd-workflow)。

对于本地生成，您需要Fern CLI版本0.94.0或更高版本。


**`(feat):`** 在生成的CI工作流中将GitHub Actions `setup-node`操作更新到v4。

## 3.11.0
**`(feat):`** 添加`linter`和`formatter`配置选项来配置生成SDK的代码检查器和格式化工具。
- `linter`：
  - `biome`：使用Biome作为代码检查器。这是默认选项。
  - `none`：不包含代码检查器。
- `formatter`：
  - `biome`：使用Biome作为代码格式化工具。这是默认选项。
  - `prettier`：使用Prettier作为代码格式化工具。

为了保持一致性，_package.json_脚本将始终包含以下脚本：
- `lint`：运行配置的检查器。
- `lint:fix`：运行配置的检查器并自动修复。
- `format`：运行配置的格式化工具。
- `format:check`：在检查模式下运行配置的格式化工具。
- `check`：在检查模式下同时运行检查器和格式化工具。
- `check:fix`：运行检查器和格式化工具并自动修复。
当`linter`设置为`none`时，`lint`和`lint:fix`脚本将输出一条消息，指示没有配置检查器。
