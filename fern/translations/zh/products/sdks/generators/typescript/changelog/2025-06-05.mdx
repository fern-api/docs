## 1.4.0
**`(feat):`** 您现在可以向根客户端传递请求头。这些请求头将与服务和端点特定的请求头合并。

**`(internal):`** 通过将请求头从根客户端传递到子包客户端来减少重复的代码生成。

## 1.3.2
**`(fix):`** 修复构建的 dist/esm 代码中的动态导入问题。

## 1.3.1
**`(fix):`** MSW 用于生成的连线测试，但无意中也会捕获真实的 HTTP 请求，例如在集成测试中。
当 HTTP 请求不匹配任何配置的谓词时，它会抛出错误，包括在不相关的集成测试中。
在此版本中，MSW 被配置为在 HTTP 请求不匹配配置的谓词时进行绕过而不是抛出错误。
