## 0.26.0-rc1

## 0.26.0-rc0
**`(feat):`** TypeScript 生成器现在支持基于游标的自动分页。通过自动分页，用户可以简单地自动迭代结果：

```ts
for (const user of client.users.list()) {
  consoler.log(user);
}
```

用户也可以手动分页数据

```ts
const page = client.users.list();
for (const user of page.data) {
  consoler.log(user);
}

// 用于手动分页的辅助方法：
while (page.hasNextPage()) {
  page = page.getNextPage();
  // ...
}
```
