## 3.69.0
**`(feat):`** 在 `BaseClientOptions` 上添加 `auth` 选项，用于自定义身份验证处理。接受一个未判别联合：返回身份验证标头的函数、`AuthProvider` 实现，或现有的身份验证凭据选项。这允许使用 `alwaysSendAuth: true` 的用户通过自定义 fetcher 处理身份验证，而不会因内置身份验证提供器在缺少凭据时抛出错误。


## 3.68.1
**`(fix):`** 修复带有可空值的 map 类型的序列化模式。此前，模式生成器会从 map 值类型中剥离可空包装器，导致 API 类型（正确包含 `| null`）与序列化层（在值模式上省略了 `.nullable()`）之间的类型不匹配。
