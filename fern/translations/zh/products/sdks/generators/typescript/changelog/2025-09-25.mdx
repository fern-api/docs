## 3.2.1
**`(fix):`** 在 _tsconfig.json_ 中将 `compilerOptions.isolatedModules` 和 `compilerOptions.isolatedDeclarations` 设置为 `true`，并更新 TypeScript 代码以符合此设置。
启用 `isolatedModules` 的用户现在可以使用 SDK 而不会出现任何 TypeScript 编译错误。
虽然 TypeScript 中默认未启用 `isolatedModules`，但更多框架和工具会默认启用它。

**Warning**: 如果您有自定义代码，这可能会导致编译错误。请参考 TypeScript 文档了解有关这些设置的更多信息：
* [Isolated Declarations](https://www.typescriptlang.org/tsconfig#isolatedDeclarations)
* [Isolated Modules](https://www.typescriptlang.org/tsconfig#isolatedModules)
