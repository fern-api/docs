## 3.66.6
**`(fix):`** 修复启用 `enableForwardCompatibleEnums` 时生成的序列化文件中的 TS2322 类型错误。枚举模式构建器现在使用 `forwardCompatibleEnum_`，它正确地将解析后的类型扩展为 `string`，与扩展后的 API 类型匹配。


## 3.66.5
**`(fix):`** 修复带有协议判别联合的 SSE 端点的生成线路测试。预期事件断言不再将反序列化的数据包装在重复的判别字段键中（这在严格类型检查下会产生 TS2783 "specified more than once" 错误）。当示例将判别字段放在数据负载中并使 SSE 事件行为空时，判别字段现在会先提升到事件行，然后从数据中剥离，使模拟的线路体与运行时 SDK 产生的内容相匹配。


## 3.66.4
**`(fix):`** 修复未判别联合查询参数，使列表变体作为重复键发送（`?key=a&key=b`），而不是 URL 编码的 JSON blob。镜像 #15526 中的 Go 修复。
