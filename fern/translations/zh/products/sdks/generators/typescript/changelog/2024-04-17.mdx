## 0.14.1-rc5
**`(fix):`** 现在为使用 `fs.readStream` 的文件上传端点生成代码片段。之前这些端点的生成被跳过了。

**`(fix):`** 如果未启用集成测试，将创建带有 `yarn test` 脚本的简单 jest 测试。

**`(feat):`** 为了使生成的代码兼容 JSR，生成器现在直接从文件导入，而不是使用目录导入。

**`(feat):`** 为了使生成的代码兼容 JSR，我们确保所有方法都具有强类型的返回签名（在这种情况下是 `_getAuthorizationHeader()`）。

**`(fix):`** 为 FileDownload 端点生成代码片段

**`(fix):`** `Fetcher.ts` 中 `node-fetch` 的导入使用动态导入而不是 `require`，这样 SDK 就能在使用本地文件输出的 ESM 环境中工作。当 `outputEsm` 配置标志开启时，动态导入将转换为 ESM 特定的导入。

**`(fix):`** `ci.yml` 中的测试任务即使在您未配置 Fern 生成集成测试的情况下也能工作。

没有集成测试时，测试任务将运行 `yarn && yarn test`。有集成测试时，测试任务将委托给 fern cli `fern yarn test`。

**`(feat):`** 添加 `allowExtraFields` 选项以允许序列化请求中的额外字段。

```yaml
- name: fernapi/fern-typscript-node-sdk
  version: 0.14.0-rc0
  ...
  config:
    allowExtraFields: true
```
