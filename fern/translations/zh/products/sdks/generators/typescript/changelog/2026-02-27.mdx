## 3.52.6
**`(fix):`** 修复当判别联合体判别值以数字开头时（例如 "1foo"、"1bar"）TypeScript 生成器崩溃的问题。生成的代码现在会为此类标识符添加下划线前缀，以生成有效的 TypeScript 代码。


## 3.52.5
**`(fix):`** 修复 Next.js 中的 Edge Runtime 兼容性警告。运行时检测代码之前直接使用 `process.versions.node`，这导致 Next.js 打包器（Turbopack/webpack）在静态分析时发出"A Node.js API is used which is not supported in the Edge Runtime"警告，即使代码路径受到 Edge Runtime 检查保护。修复方法是先将 `process` 分配给局部变量，防止打包器标记间接属性访问。


## 3.52.4
**`(fix):`** 修复 package.json 导出中模糊 `types` 的 publint 警告。从 `package.json` 中的导出条目移除顶级 `types` 条件，使 `import` 和 `require` 条件各自解析到正确类型的声明文件（ESM 使用 `.d.mts`，CJS 使用 `.d.ts`）。这消除了关于在使用"import"条件解析时使用 CJS 类型的 publint 警告。


## 3.52.3
**`(fix):`** 通过将 null 转换为 undefined 来处理可为空的标头类型。HTTP 标头没有"null"概念——它们要么存在并有值，要么不存在。当标头类型可为空时（通过规范中的 `nullable: true` 显式指定），生成的代码现在会用 `?? undefined` 包装值，确保 null 值被视为"不发送标头"而不是导致类型错误。


## 3.52.2
**`(fix):`** 修复在 github 输出模式下未应用 biome 格式化的问题。生成器在未首先安装 biome 的情况下调用 checkFix()（biome），导致格式化静默失败。现在当工具不是全局可用时会安装 checkFix 依赖项，与 downloadFiles 模式中的现有行为保持一致。


## 3.52.1
**`(feat):`** 为 SDK 端点方法添加 JSDoc 可用性注释。在 Fern 定义中标记为 `deprecated` 的端点现在会生成 `@deprecated` JSDoc 标签，使 IDE 显示删除线和弃用警告。标记为 `in-development` 或 `pre-release` 的端点会生成 `@beta` JSDoc 注释。这适用于所有端点类型（默认、文件下载和流式传输）。
