## 2.5.0
**`(feat):`** 支持为二进制上传端点（非 multipart-form）上传类文件类型：
* 缓冲类型：`Buffer`、`Blob`、`File`、`ArrayBuffer`、`ArrayBufferView` 和 `Uint8Array`
* 流类型：`fs.ReadStream`、`stream.Readable` 和 `ReadableStream`


**`(feat):`** 用户可以使用 `Uploadable.WithMetadata` 类型在向二进制上传端点上传文件时配置元数据：
```typescript
import { createReadStream } from "fs";

await client.upload({
    data: createReadStream("path/to/file"),
    filename: "my-file",
    contentType: "audio/mpeg",
    contentLength: 1949,
});
```
`filename`、`contentType` 和 `contentLength` 属性是可选的。

另外，用户可以使用 `Uploadable.FromPath` 类型直接从文件路径上传：
```typescript
await client.upload({
    path: "path/to/file",
    filename: "my-file",
    contentType: "audio/mpeg",
    contentLength: 1949,
});
```

元数据用于设置 `Content-Length`、`Content-Type` 和 `Content-Disposition` 头。如果未提供，客户端将尝试自动确定它们。
例如，`fs.ReadStream` 有一个 `path` 属性，SDK 使用它从文件系统检索文件大小，而无需将其加载到内存中：
```typescript
import { createReadStream } from "fs";

await client.upload(createReadStream("path/to/file"));
```
