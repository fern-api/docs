## 3.39.0
**`(feat):`** 添加对自定义分页的支持，使用专用的 `CustomPager` 类，类似于 C# SDK 生成器。
`CustomPager` 类提供：
- `CustomPagerParser` 回调类型，供 SDK 作者实现以定义分页逻辑
- 支持向前（`getNextPage`）和向后（`getPreviousPage`）分页
- `AsyncIterable` 实现，便于使用 `for await...of` 进行人性化消费
- 通过 `response` 和 `rawResponse` 属性访问原始响应数据

生成的端点返回一个 `CustomPager`，带有默认解析器，从配置的结果属性中提取项目，并将 `hasNextPage`/`hasPreviousPage` 设置为 `false`。需要自定义分页逻辑的 SDK 作者可以创建自己的包装器/工厂，使用自己的 `CustomPagerParser` 实现来调用 `CustomPager.create()`。


## 3.38.3
**`(chore):`** 在生成的 TypeScript SDK 文件中对导入和导出进行排序，以产生一致、确定性的输出。
这消除了依赖 prettier、biome 或 oxfmt 等格式化工具来排序导入和导出的需要。


## 3.38.2
**`(chore):`** 预格式化和检查现有文件和核心工具。


## 3.38.1
**`(fix):`** 如果偏移量分页端点上的 `step` 属性设置了默认值，`hasNextPage` 会使用该默认值。


## 3.38.0
**`(feat):`** `oauthTokenOverride` 功能标志已被移除，现在始终启用。
OAuth token 覆盖允许用户通过直接提供预生成的 bearer token 来跳过 OAuth 流程。
此功能现在是默认行为，不再需要配置。
