## 0.11.3
**`(fix):`** 确保 SDK 生成器在 Node.js 环境中始终使用 `node-fetch`。较新版本的 Node.js 中包含了实验性的 fetch，但它在文件上传时会导致意外行为。


## 0.11.2
**`(fix):`** 确保 SDK 生成器不会从执行文件上传的请求中丢弃额外的参数。之前，如果端点有 `file` 输入但没有额外的 `body` 参数，查询参数会被错误地忽略。


## 0.11.1
**`(fix):`** SDK 生成器不再生成启用 `noUnusedParameters` 的 `tsconfig.json`。这个检查过于严格。

## 0.11.0
**`(feat):`** SDK 生成器现在会转发它所使用的运行时信息。`X-Fern-Runtime` 头部将报告运行时（例如 `browser`、`node`、`deno`），`X-Fern-Runtime-Version` 头部将报告版本。
