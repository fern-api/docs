## 0.20.0-rc1
**`(fix):`** 将 `abortSignal` 传递给 `Stream` 以用于服务器发送事件和 JSON 流，以便用户可以选择退出并中断流。


## 0.20.0-rc0
**`(feat):`** 在 `RequestOptions` 中添加 `abortSignal`。SDK 使用者现在可以指定任意中止信号来中断 API 调用。

```ts
const controller = new AbortController();
client.endpoint.call(..., {
  abortSignal: controller.signal,
})
```
