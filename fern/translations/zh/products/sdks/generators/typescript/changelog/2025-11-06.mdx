## 3.28.2
**`(fix):`** 修复 WebSocket 连接选项中路径参数大小写不一致的问题。
大小写现在遵循与其他 HTTP 路径参数相同的规则：
- `retainOriginalCasing: true`: 使用 OpenAPI 规范中的原始大小写，不受 `noSerdeLayer` 设置影响。
- `noSerdeLayer: true`: 使用 OpenAPI 规范中的原始大小写。
- `noSerdeLayer: false`: 对路径参数使用 camelCase。
