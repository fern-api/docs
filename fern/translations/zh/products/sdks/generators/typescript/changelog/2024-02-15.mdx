## 0.11.5
**`(fix):`** 之前 `core.Stream` 在浏览器中无法工作。现在生成的 Fern SDK 包含了 `ReadableStream` 的 polyfill 并使用 `TextDecoder` 代替 `Buffer`。


**`(feat):`** 添加参考 markdown 文件，显示可用端点的快速大纲、文档、代码片段和参数。

此功能目前处于名为 `includeApiReference` 的功能标志后面，可以这样使用：

```yaml
config:
  includeApiReference: true
```


## 0.11.4
**`(fix):`** `Fetcher` 现在支持发送二进制数据作为请求正文。这对于接受 `application/octet-stream` 内容类型的 API 或为使用获取器的自定义工具添加了 .fernignored 的用户来说很重要。
