## 3.52.8
**`(fix):`** 更新生成的 CI 工作流程，使用 `--tag backport` 而不是默认的 `latest` 标签发布较旧的补丁版本。当发布版本早于 npm 上当前 `latest` 版本时（例如在 v1.4.0 之后发布 v1.3.2），发布步骤现在使用 `semver` 与 npm 当前 `latest` 进行比较，并使用 `--tag backport` 以避免将 `latest` 指针向后移动。


## 3.52.7
**`(fix):`** 在 `deleteGitIgnoredFiles` 中禁用提交签名并跳过钩子，避免在本地生成期间触发提示（例如 macOS 上的 Touch ID、1Password SSH 代理）。
