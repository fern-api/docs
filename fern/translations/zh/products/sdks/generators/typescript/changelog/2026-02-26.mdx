## 3.52.0
**`(feat):`** 默认启用 `generateSubpackageExports`。生成的 TypeScript SDK 现在在 `package.json` 中包含
子包导出条目，允许用户直接导入子包客户端
（例如，`import { FooClient } from '@acme/sdk/foo'`）。这使得 JavaScript
打包工具能够摇树优化未使用的子包，从而减小打包体积。
要选择退出，请在生成器配置中显式设置 `generateSubpackageExports: false`。


**`(feat):`** 添加摇树优化冒烟测试，验证导入单个子包产生的
webpack 打包体积明显小于导入完整 SDK。


## 3.51.6
**`(chore):`** 在 downloadFiles 模式下，当仅输出源文件时，仅安装配置的格式化程序/代码检查器
包，而不是完整的依赖树。这将原本约 1.8 秒的完整 `pnpm install` 
替换为仅针对 check:fix 包（例如 @biomejs/biome、
prettier、oxfmt、oxlint）的目标性 `pnpm add`。


## 3.51.5
**`(fix):`** 修复当两个不同包定义同名类型时序列化模式中的重复标识符冲突。
模式生成器现在追踪直接导入的类型名称，当发生冲突时切换到命名空间导入，
防止跨包类型引用中出现"重复标识符"TypeScript 错误。


## 3.51.4
**`(fix):`** 为流式传输和 SSE fetch 请求添加 `cache: "no-store"`，防止
Next.js 缓冲流式响应。该选项通过缓存的运行时特性检测进行保护，
在不支持 `cache` RequestInit 选项的运行时中（例如 Cloudflare Workers）会安全跳过。


## 3.51.3
**`(fix):`** 修复当多个错误映射到相同状态码时错误处理 switch 语句中的重复 case 子句。
生成器现在按状态码去重错误，为每个状态码保留第一个错误。


**`(fix):`** 修复测试生成器，跳过状态码已被先前错误处理的错误示例，
与代码生成器的去重行为保持一致。


**`(fix):`** 修复测试生成器，在属性判别错误的模拟响应体中包含错误判别属性（例如 errorName），
以便生成的 switch 语句能够匹配正确的错误情况。


**`(fix):`** 修复推断的认证提供程序，处理没有包装请求类型的端点，
防止在为非包装端点生成时崩溃。


## 3.51.2
**`(chore):`** 直接使用 generator-cli JS API 而不是生成子进程。
从 Docker 镜像中移除 generator-cli，因为现在通过 esbuild 进行打包。
