## 0.27.2
**`(fix):`** 生成的 readme 现在将 `AbortController`、`Runtime Compatibility` 和 `Custom Fetcher` 的部分移至生成的 README 中的高级部分下。

## 0.27.1
**`(feat):`** 支持 JSR 发布。如果您希望您的 SDK 发布到 JSR，现在有一个名为 `publishToJsr: true` 的配置选项。启用后，生成器将
生成 `jsr.json` 以及发布到 JSR 的 GitHub 工作流。

```yaml
- name: fernapi/fern-typescript-sdk
  version: 0.27.1
  config:
    publishToJsr: true
```

## 0.27.0
**`(fix):`** 布尔字面量标头现在可以通过 `RequestOptions` 覆盖。

**`(feat):`** 生成的 `.github/workflows/ci.yml` 文件现在支持使用 alpha/beta 发布标签的 NPM 发布。如果选择的版本包含 `alpha` 或 `beta` 子字符串，
相关的发布标签将添加到 `npm publish` 命令中，如下所示：

```sh
# Version 1.0.0-beta
npm publish --tag beta
```

有关 NPM 发布标签的更多信息，请参见 https://docs.npmjs.com/adding-dist-tags-to-packages
