## 3.59.3
**`(fix):`** 修复当注册表 URL 包含端口号时 npm 发布身份验证失败的问题。
`.npmrc` 身份验证令牌键使用 `URL.hostname`（删除端口）而不是 `URL.host`（保留端口）构造。例如，位于 `http://host.docker.internal:4873` 的注册表会将令牌写在 `//host.docker.internal/:_authToken` 下，而不是正确的 `//host.docker.internal:4873/:_authToken`。


## 3.59.2
**`(fix):`** 修复在多 URL 环境 SDK 上没有显式设置环境时透传 `fetch()` 方法失败的问题。当用户依赖默认环境时，`Supplier.get(undefined)` 返回 `undefined`，IIFE 不产生基础 URL。
生成的代码现在从 IR 派生正确的基础 URL 属性（使用 HTTP 端点解析到的相同基础 URL）并回退到 IR 定义的默认环境，与常规端点方法解析其基础 URL 的方式匹配。
