## 3.45.1
**`(fix):`** 移除对 body 是否为 `null` 或 `undefined` 的检查。如果为 `null`，它是有效的 JSON `null`，如果为 `undefined`，它能正确处理为没有 body。

## 3.45.0
**`(feat):`** 为 WebSocket 连接添加对额外查询参数的支持。`ConnectArgs`
接口现在包含一个可选的 `queryParams` 属性，允许用户传递
额外的查询参数，这些参数会与任何频道定义的查询参数一起合并到 WebSocket URL 中。


## 3.44.2
**`(fix):`** 修复当 SDK 没有自动分页端点时 README 分页部分仍被包含的问题。
现在只有当至少有一个定义了分页的端点时，分页部分才会包含在 README 中。
