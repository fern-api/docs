## 0.20.2
**`(fix):`** OAuth token provider 支持启用 `neverThrowErrors` 设置的 SDK。
如果 OAuth token provider 无法检索和/或刷新访问令牌，将不会抛出错误。
相反，将使用原始访问令牌，用户将能够对响应中可用的错误进行操作。例如：

```ts
const response = await client.user.get(...)
if (!response.ok) {
  // Handle the response.error ...
}
```
