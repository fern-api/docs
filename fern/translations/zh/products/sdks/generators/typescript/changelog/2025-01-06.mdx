## 0.46.0
**`(feat):`** SDK 现在以 CommonJS（遗留）和 ESModule 格式构建和导出。

**`(feat):`** 从根包导出中导出 `serialization` 代码。
```ts
import { serialization } from `@packageName`;
```

序列化代码也作为 `@packageName/serialization` 导出。
```ts
import * as serialization from `@packageName/serialization`;
```


**`(feat):`** `package.json` 本身在 `package.json` 中导出，允许使用者轻松读取他们正在使用的包的元数据。
