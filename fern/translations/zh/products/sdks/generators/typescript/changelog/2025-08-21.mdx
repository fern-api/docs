## 2.8.4
**`(feat):`** 在 SDK 生成器配置中添加 `flattenRequestParameters`。
`flattenRequestParameters` 是一个布尔值，控制是否展平请求参数。
当为 `false`（默认）时，使用传统的展平逻辑。
当为 `true` 时，使用新的展平逻辑。

```yml
# In generators.yml
groups:
  ts-sdk:
    generators:
      - name: fernapi/fern-typescript-sdk
        config:
          flattenRequestParameters: true
```


## 2.8.3
**`(fix):`** 当生成的 SDK 客户端上有身份验证可用时，为 WebSocket 连接设置 `Authorization` 头。
无论 AsyncAPI 服务器或通道是否标记为需要身份验证，都会发生这种情况。


**`(fix):`** 在 WebSocket 连接中添加对推断 bearer 身份验证的支持。
