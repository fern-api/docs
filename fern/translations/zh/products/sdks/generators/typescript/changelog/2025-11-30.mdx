## 3.34.3
**`(fix):`** 改善 SDK 运行时和获取器中的 React Native 兼容性：
* 将 React Native 检测移到 Node.js 检测之前，因为 React Native 可能有 process polyfill
* 使用 `ReturnType<typeof setTimeout>` 替代 `NodeJS.Timeout` 以获得更好的跨平台兼容性
* 移除在 React Native 环境中错误失败的 `ResponseWithBody` 类型保护，其中 `response.body` 可能为 null
* 更新 `BinaryResponse` 类型以直接使用 Response 类型以获得更好的兼容性
* 当 `response.body` 不可用时，为 SSE 和流式端点添加具有 `body-is-null` 原因的结构化错误响应
* 简化 JSON 解析错误处理，返回具有 `non-json` 原因的一致错误结构
