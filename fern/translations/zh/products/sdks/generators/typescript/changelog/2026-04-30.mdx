## 3.68.0
**`(feat):`** 添加 `alwaysSendAuth` 配置选项，强制生成的 SDK 在所有端点上包含身份验证标头，即使是那些在 API 定义中标记为 `auth: false` 的端点。当使用同一份 API 定义同时生成服务端（身份验证由网关处理）和客户端 SDK 时，这非常有用。


## 3.67.0
**`(feat):`** 添加 `retryStatusCodes` 生成器配置选项，包含 `legacy` 和 `recommended` 模式。`legacy`（默认）保留当前行为（重试 408、429 和所有 5xx）。`recommended` 仅重试 408、429、502、503 和 504，避免像 500 这样非瞬态的服务器错误的幂等性问题。
