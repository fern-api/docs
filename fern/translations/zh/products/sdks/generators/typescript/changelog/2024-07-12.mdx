## 0.31.0
**`(feat):`** 新增 `omitUndefined` 生成器选项。可通过以下配置启用：

```yaml
groups:
  generators:
    - name: fernapi/fern-typscript-node-sdk
      version: 0.31.0
      ...
      config:
        omitUndefined: true
```

启用后，任何设置为显式 `undefined` 的属性都 _不会_ 包含在序列化结果中。例如：

```typescript
const request: Acme.CreateUserRequest = {
  firstName: "John",
  lastName: "Doe",
  email: undefined
};
```

默认情况下，显式的 `undefined` 值会被序列化为 `null`，如下所示：

```json
{
  "firstName": "John",
  "lastName": "Doe",
  "email": null
}
```

启用 `omitUndefined` 后，JSON 对象会被序列化为：

```json
{
  "firstName": "John",
  "lastName": "Doe"
}
```
