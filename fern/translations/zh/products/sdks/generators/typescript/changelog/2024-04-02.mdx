## 0.13.0-rc0
**`(feat):`** 添加 `retainOriginalCasing` 选项以保留 API 中表达的命名约定。
例如，以下 Fern 定义将生成如下类型：

```yaml
types:
  GetUsersRequest
    properties:
      group_id: string
```

**之前**

```typescript
export interface GetUsersRequest {
  groupId: string;
}

export interface GetUsersRequest = core.serialization.object({
groupId: core.serialization.string("group_id")
})

export namespace GetUsersRequest {
  interface Raw {
    group_id: string
  }
}
```

**之后**

```typescript
export interface GetUsersRequest {
  group_id: string;
}

export interface GetUsersRequest = core.serialization.object({
group_id: core.serialization.string()
})

export namespace GetUsersRequest {
  interface Raw {
    group_id: string
  }
}
```
