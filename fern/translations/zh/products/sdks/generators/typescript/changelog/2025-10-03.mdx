## 3.3.9
**`(fix):`** 使用 `// ... file header ...` 文件头而不是 `/** ... file header ... */`。
后者被视为 JSDoc 注释，可能会在某些工具中引起问题。
TypeScript 编译器会移除 `//` 注释但不会移除 `/** */` 注释。


## 3.3.7
**`(fix):`** 基于常量动态构建枚举类型以减少生成的代码。

之前：
```ts
export type Operand =
    | ">"
    | "="
    | "<";
export const Operand = {
    GreaterThan: ">",
    EqualTo: "=",
    LessThan: "<",
} as const;
```
之后：
```ts
export const Operand = {
    GreaterThan: ">",
    EqualTo: "=",
    LessThan: "<",
} as const;
export type Operand = (typeof Operand)[keyof typeof Operand];
```
