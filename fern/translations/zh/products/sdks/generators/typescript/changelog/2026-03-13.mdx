## 3.56.0
**`(feat):`** 添加 `naming` 配置对象，让您对导出的命名空间和生成的类名（客户端、错误、超时错误、环境、环境 URLs、版本）进行细粒度控制。

您可以使用简单的字符串简写来设置命名空间：
```yaml
# generators.yml
groups:
  ts-sdk:
    generators:
      - name: fernapi/fern-typescript-node-sdk
        config:
          naming: acme
```

或者作为完整对象来覆盖单个名称：
```yaml
# generators.yml
groups:
  ts-sdk:
    generators:
      - name: fernapi/fern-typescript-node-sdk
        config:
          naming:
            namespace: acme
            client: AcmeApiClient
            error: AcmeApiError
            environment: AcmeRegion
```

当未提供单个覆盖时，它们从命名空间使用 `PascalCase(namespace) + Suffix` 模式派生（例如 `namespace: acme` 默认生成 `AcmeClient`、`AcmeError`、`AcmeTimeoutError`、`AcmeEnvironment`、`AcmeEnvironmentUrls` 和 `AcmeVersion`）。

现有的 `namespaceExport` 配置继续工作以保持向后兼容性。

## 3.55.0
**`(feat):`** 向所有生成的 TypeScript SDK 的根客户端类添加直通 `fetch` 方法。该方法模拟标准 `fetch` API，同时自动应用 SDK 的配置身份验证、基础 URL 解析、指数退避重试逻辑、请求超时、自定义头部和日志记录。这允许用户对 SDK 定义中尚未公开的端点（例如新的公共端点、封闭测试版端点）进行请求，无需额外设置。该方法接受三个参数：`url`（字符串或相对路径）、`init`（标准 `RequestInit`）和 `requestOptions`（SDK 特定的超时、重试、头部和中止信号覆盖）。
