## 0.50.0
**`(feat):`** 所有端点函数现在返回 `HttpResponsePromise<T>` 而不是 `Promise<T>`。
在这些 promise 上使用 `await`、`.then()`、`.catch()` 和 `.finally()` 的行为与之前相同，
但您可以调用 `.withRawResponse()` 来获取包含解析响应和原始响应的 promise。
原始响应让您可以检索响应头、状态码等。

```ts
const fooBar = await client.foo.bar("id", options);
const { data: alsoFooBar, rawResponse } = await client.foo.bar("id", options).withRawResponse();
const {
    headers,
    status,
    url,
    ...
} = rawResponse;
```
