## 0.40.4
**`(fix):`** 升级了 `stream-json` 依赖，提高了读取大型 API 规范时的性能。此版本将改善你的 `fern generate` 性能。

## 0.40.3
**`(fix):`** 如果启用了序列化层，则所有序列化器都在 `serializers` 命名空间下导出。

```ts
import { serializers } from "@plantstore/sdk";

export function main(): void {
  // serialize to json

  const json = serializers.Plant.toJson({
    name: "fern"
  });

  const parsed = serializers.Plant.parseOrThrow(`{ "name": "fern" }`);
}
```


## 0.40.2
**`(fix):`** 生成的 SDK 现在可以处理大于 500MB 的 IR JSON 文件读取。为了做到这一点，使用了 `streamObjectFromFile` 函数而不是 `JSON.parse`。

## 0.40.1
**`(fix):`** 生成的代码片段现在会内联引用的请求对象，因为它们没有命名，需要被内联。

## 0.40.0
**`(feat):`** 新增了一个配置标志，将自动为 `long` 和 `bigint` 基础类型生成 `BigInt`。要启用此标志：

```yml
groups:
  ts-sdk:
    name: fernapi/fern-typescript-sdk
    version: 0.40.0
    config:
      useBigInt: true
```
