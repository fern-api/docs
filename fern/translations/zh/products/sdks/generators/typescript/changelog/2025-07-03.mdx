## 2.3.2
**`(fix):`** 从源生成器代码的 ESM 导入中移除 ".js" 扩展名。
如果 `useLegacyExports` 为 `true`，你在 ESM 导入中不会看到 ".js" 扩展名。
如果 `useLegacyExports` 为 `false`（默认），后处理步骤将添加 `.js` 扩展名，所以你不会看到区别。

我们这样做是因为 Jest 有一个错误，即使 TypeScript 和导入都是有效的，它也不能正确加载 TypeScript 模块。

## 2.2.0
**`(feat):`** 改进生成的 package.json 文件：
* 添加 `engines` 字段以指定支持的最低 Node.js 版本为 Node.js 18。
* 添加 `sideEffects: false`
* 将 `README.md` 和 `LICENSE` 添加到 `files` 数组
* 对 `repository` 字段使用 GitHub 简写。

你可以使用 `packageJson` 配置覆盖这些字段：
```yml
# 在 generators.yml 中
groups:
  ts-sdk:
    generators:
      - name: fernapi/fern-typescript-sdk
        config:
          packageJson:
            engines:
              node: ">=16.0.0"
```
