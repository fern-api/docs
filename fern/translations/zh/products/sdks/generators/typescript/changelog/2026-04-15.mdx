## 3.63.7
**`(fix):`** 修复当顶级服务器定义了多个带有 x-fern-server-name 的基础 URL 时，
每个端点的服务器覆盖被忽略的问题。端点现在正确解析到其指定的服务器 URL，
而不是总是使用默认值。


## 3.63.6
**`(fix):`** 修复 OAuth token 请求未包含来自 token 端点请求的字面量自定义属性
（例如 grant_type）的问题。之前只传递了 client_id 和 client_secret，
导致需要在 token 请求上添加 grant_type 等额外字面量属性的 API 出现
TypeScript 编译错误。


## 3.63.5
**`(fix):`** 支持使用表单编码（application/x-www-form-urlencoded）token 端点的
推断 OAuth 认证。之前，当 token 端点使用 justRequestBody 形状而不是包装器
形状时，生成器会崩溃并显示"Cannot get exported name for request wrapper"错误。
