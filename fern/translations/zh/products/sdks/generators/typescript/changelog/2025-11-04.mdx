## 3.25.0
**`(feat):`** 在生成的 SDK 中新增日志记录支持。
用户可以通过向客户端选项传入 `logging` 对象来配置日志记录器。

```ts
import { FooClient, logging } from "foo";

const client = new FooClient({
    logging: {
       level: logging.LogLevel.Info, // LogLevel.Info 是默认值
       logger: new logging.ConsoleLogger(), // ConsoleLogger 是默认值
       silent: false, // true 是默认值，设置为 false 启用日志记录
    }
});
```

`logging` 对象可以包含以下属性：
- `level`: 要使用的日志级别。默认为 `logging.LogLevel.Info`。
- `logger`: 要使用的日志记录器。默认为 `logging.ConsoleLogger`。
- `silent`: 是否静默日志记录器。默认为 `true`。

`level` 属性可以是以下值之一：
- `logging.LogLevel.Debug`
- `logging.LogLevel.Info`
- `logging.LogLevel.Warn`
- `logging.LogLevel.Error`

要提供自定义日志记录器，用户可以传入实现 `logging.ILogger` 接口的自定义日志记录器实现。
