## 3.31.0
**`(feat):`** 添加 `generateSubpackageExports` 配置选项，启用子包客户端的直接导入。
这使得 JavaScript 打包工具能够进行摇树优化，仅包含导入的子包代码，从而显著减小打包大小。

示例：
```ts
import { BarClient } from '@acme/sdk/foo/bar';

const client = new BarClient({...});
```

要启用此功能，请将以下配置添加到您的 _generators.yml_ 文件中：
```yaml
# In generators.yml
groups:
  generators:
    - name: fernapi/fern-typescript-sdk
      config:
        generateSubpackageExports: true
```
