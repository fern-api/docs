## 0.24.2
**`(feat):`** 从请求/响应 README.md 部分中移除不必要的客户端调用。

**`(fix):`** 生成的 README.md 代码片段现在正确引用嵌套方法。例如，
在以下代码中使用 `client.users.create`（而不是 `client.create`）：

```ts
import { AcmeClient } from "acme";

const client = new AcmeClient({ apiKey: "YOUR_API_KEY" });
await client.users.create({
  firstName: "john",
  lastName: "doe"
});
```
