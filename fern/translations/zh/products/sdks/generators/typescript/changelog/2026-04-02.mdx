## 3.63.0
**`(feat):`** 支持通过 IR 中的 `usernameOmit` 或 `passwordOmit` 配置省略
基本认证的用户名或密码。省略的字段从 SDK 的公共 API 中移除，并在内部
被视为空字符串（例如，省略密码编码为 `username:`，省略用户名编码为
`:password`）。当两者都被省略时，Authorization 头部将被完全跳过。


## 3.62.1
**`(fix):`** 修复使用自定义包路径（例如 `src/management`）时生成的测试文件
中导入路径不正确的问题。测试文件中的多行导入（如 `makeRequest.test.ts`）
输出的是 `../../../src/management/core/...` 而不是 `../../../core/...`，
导致导入解析到不存在的路径。


## 3.62.0
**`(feat):`** 添加 `maxRetries` 自定义配置选项来覆盖失败请求的默认最大
重试次数。未指定时默认值仍为 2。


## 3.61.1
**`(feat):`** 使用 ES2022 `Error.cause` 标准将原始错误作为 `cause` 传播
到 SDK 错误类。当自定义 fetcher 抛出异常时（例如网络故障、DNS 问题
或自定义逻辑），抛出的错误现在会作为 `error.cause` 保留在生成的 SDK
错误中，让消费者能够访问完整的堆栈跟踪和原始错误的任何自定义属性。


## 3.60.9
**`(fix):`** 修复线协议测试生成器为结果属性类型是列表的命名别名而非
直接列表类型的端点生成分页断言（hasNextPage、getNextPage）的问题。
在这种情况下客户端生成器不会产生 Page 对象，因此测试调用了响应中
不存在的方法。测试生成器现在检查结果属性值类型是否为具体列表
（或可选/可空包装的列表）后再生成 Page 特定的断言，与客户端
生成器的行为保持一致。
