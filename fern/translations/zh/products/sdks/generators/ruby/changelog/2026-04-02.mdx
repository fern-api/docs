## 1.4.0
**`(feat):`** 支持在通过 IR 中的 `usernameOmit` 或 `passwordOmit` 配置时从基本认证中省略用户名或密码。省略的字段从 SDK 的公共 API 中移除并在内部被视为空字符串（例如，省略密码编码为 `username:`，省略用户名编码为 `:password`）。当两者都省略时，完全跳过 Authorization 请求头。


## 1.2.0
**`(feat):`** 添加 `maxRetries` 自定义配置选项以覆盖失败请求的默认最大重试次数。未指定时默认值仍为 2。


## 1.1.13
**`(chore):`** 在生成的 CI 工作流中移除遗留的美元符号变通方法，因为 Eta 模板引擎不解释 `${}` 语法。


## 1.1.12
**`(chore):`** 将模板引擎从 lodash 迁移到 Eta，以与其他生成器保持一致。
