## 1.0.0-rc73
**`(fix):`** 修复端点头部参数被包含在请求体而不是 HTTP 头部中。
头部参数（如 Idempotency-Key）现在正确地从 params 中提取并
通过 Request.new() 调用中的 headers 参数传递。


**`(feat):`** 添加 normalize_keys 工具以接受 snake_case 和 camelCase 参数键。
SDK 端点方法现在在每个方法开始时自动将 camelCase 键（例如 refundMethod）
转换为 snake_case（例如 refund_method）。这允许用户
直接将带有 camelCase 键的 JSON 数据传递给 SDK 方法而无需手动转换。


## 1.0.0-rc72
**`(chore):`** 在生成的 metadata.json 文件中添加 sdkVersion 作为顶级字段。
