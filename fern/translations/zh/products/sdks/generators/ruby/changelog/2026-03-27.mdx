## 1.1.6
**`(chore):`** 使用 2 空格缩进美化打印生成的 wiremock-mappings.json 文件，以减少后续 SDK 生成时的差异大小。


## 1.1.5
**`(fix):`** 防止请求选项中的 `additional_headers` 覆盖 SDK 设置的请求头，如 Authorization、Content-Type 和 SDK 元数据。由 SDK 或 API 定义设置的请求头现在受到保护（不区分大小写）并从 additional_headers 中静默过滤。


**`(fix):`** 拒绝非本地主机的 HTTP URL。对 `http://` URL 的请求现在会引发 `ArgumentError`，除非主机是 localhost、127.0.0.1 或 [::1]，防止意外以明文传输认证凭据。


**`(fix):`** 在 HTTPS 连接上显式设置 `verify_mode = OpenSSL::SSL::VERIFY_PEER`。这已经是 Ruby 的默认设置，但现在在代码中声明以满足安全审计。
