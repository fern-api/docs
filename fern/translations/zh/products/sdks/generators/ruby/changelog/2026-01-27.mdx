## 1.0.0-rc82
**`(feat):`** 实现基于 HTTP 状态码的重试逻辑，使用指数退避算法。SDK 现在会自动
重试因可重试的 HTTP 状态码（408、429、500、502、503、504、521、
522、524）而失败的请求，使用带抖动的指数退避算法。重试逻辑在存在
Retry-After 头时会遵守该头。这解决了 SDK 之前
仅使用 Net::HTTP 的网络级重试的功能缺口，网络级重试不处理诸如 429
（请求过多）等 HTTP 状态码。max_retries 参数现在控制具有
适当退避的应用级重试，实现对诸如 Square App Marketplace 等速率限制要求的合规。
