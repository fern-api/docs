## 0.32.0
**`(feat):`** 添加对 `inlineFileProperties` 配置选项的支持，在生成的请求类型中生成文件属性，而不是作为单独的位置参数。
```yaml # generators.yml
- name: fern-api/fern-go-sdk
  version: 0.32.0
  config:
    inlineFileProperties: true
```

**`(fix):`** 修复为未定义任何文件上传端点的 SDK 生成新的 `core.MultipartWriter` 的问题。

**`(internal):`** 通过将 `internal.WithMultipartContentType` 重构为 `internal.WithDefaultContentType` 来简化 0.29.0 中引入的新 `core.MultipartWriter` 生成的代码。

## 0.31.3
**`(fix):`** 更新重试器，默认情况下停止对 `409 Conflict` HTTP 状态码进行重试。
