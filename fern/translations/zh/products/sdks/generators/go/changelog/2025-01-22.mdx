## 0.36.0
**`(feat):`** 添加对几个新配置选项的支持，所有选项如下所示：
```yaml - name: fern-api/fern-go-sdk
  version: 0.36.0
  config:
    packageLayout: flat
    clientName: Acme
    clientConstructorName: New
```
使用此配置，生成的 SDK 将全部存放在模块的根目录，客户端可以像这样构造：
```go package main
import (
  "context"
  "fmt"
  "log"
  acme "github.com/acme/acme-go"
)
func main() {
  client := acme.New()
  response, err := client.GetUser(
    context.Background(),
    &acme.GetUserRequest{
      ID: "85307b0b-094b-41b5-b61d-347ca15e5da2",
    },
  )
  if err != nil {
    log.Fatal(err)
  }
  fmt.Println(response)
} ```
