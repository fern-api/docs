## 1.25.0-rc3
**`(fix):`** 修复具有字节体和路径参数的端点的动态代码片段和线路测试生成。之前，生成器为 `io.Reader` 体参数生成了 `nil` 而不是有效的 `bytes.NewReader([]byte(...))` 调用，导致线路测试失败。
同时修复了 nop 请求分支，在方法调用中包含选项参数（例如测试 ID 标头），修复路径参数解析以使用 associateByWireValueOrDefault，因此会合成缺失的路径参数值，并修复 WireMock 存根响应生成，在示例响应体为 null 但端点声明了命名（结构体）响应类型时返回空 JSON 对象 `{}` 而不是 JSON 字符串 `""`。
