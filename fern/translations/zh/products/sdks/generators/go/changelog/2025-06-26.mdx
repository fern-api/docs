## 1.3.0
**`(feat):`** 添加通过新的 `WithRawResponse` 客户端字段从 API 调用接收原始响应头的支持。

```go
response, err := client.WithRawResponse.GetUser(...)
fmt.Printf("Got response headers: %v", response.Header)
```

**`(feat):`** 将最低 Go 版本提升至 `1.18`，因为 SDK 现在需要泛型。版本 1.18 在三年多前发布，因此这完全在
https://go.dev/doc/devel/release#policy 的官方 Go 支持窗口内
