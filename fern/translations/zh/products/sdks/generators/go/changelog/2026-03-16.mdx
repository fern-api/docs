## 1.30.3
**`(fix):`** 对于未知类型模式使用 `any` 而不是 `interface{}`。从 Go 1.18+ 开始，`any` 是 `interface{}` 的惯用别名。这是一个纯粹的外观现代化改进，没有行为变化。


## 1.30.2
**`(fix):`** 修复当用户名为空字符串时 Basic Auth 头未发送的问题。根据 RFC 7617，空的 user-id 在 Basic Auth 中是有效的（例如 `:password`）。`ToHeader()` 中的条件现在使用 `||` 而不是 `&&`，因此只要用户名或密码任一不为空就会设置 Authorization 头。
