按照此页面的说明生成 PHP SDK。

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="添加 SDK 生成器">

运行以下命令将 PHP SDK 生成器添加到 `generators.yml`：

<Template
  data={{ GROUP_NAME: "php-sdk" }}
  tooltips={{
    GROUP_NAME: (<p>配置 PHP SDK 输出位置和其他元数据的 <code>generators.yml</code> 组名。您可以自定义此组名，以区分不同语言的多个 SDK。</p>)
  }}
>
```bash
fern add fern-php-sdk --group {{GROUP_NAME}}
```
</Template>

此命令将以下 `group` 添加到 `generators.yml`：

```yaml title="generators.yml"
  php-sdk: # group name
    generators:
      - name: fern-php-sdk
        version: <Markdown src="/snippets/version-number-php.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/php/sdk
```
</Step>

<Step title="生成 SDK">

运行以下命令生成您的 SDK：

```bash
fern generate --group php-sdk
```

<Note>
  如果您有多个 API，请使用 [`--api` 标志](/learn/zh/cli-api-reference/cli-reference/commands#api) 指定要生成的 API：

  ```bash
  fern generate --group php-sdk --api your-api-name
  ``` 
</Note>
