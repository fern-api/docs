## 1.19.1
**`(feat):`** 添加对多 URL 环境的支持。生成的 SDK 现在使用基于类的 Environments，为每个服务 URL 提供只读属性，使 API 能够为每个服务使用不同的基础 URL（例如 EC2 和 S3）。子客户端接收完整的 Environments 实例，并通过属性访问来访问其特定的 URL。


## 1.18.3
**`(fix):`** 通过在日志消息中包含类名来修复 PHP SDK 生成器中的重复日志记录。以前，同一目录中的多个类型会记录相同的"Generating `{directory}`"消息，造成日志垃圾信息。现在每个类型记录唯一的"Generating `{directory}/{className}`"消息。


## 1.18.2
**`(fix):`** 对于自定义分页回退到非分页方法而不是硬性失败。具有自定义分页的端点现在会生成正常的请求/响应方法，而不是抛出错误。
