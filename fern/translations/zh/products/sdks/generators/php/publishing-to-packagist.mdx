将您面向公众的 Fern PHP SDK 发布到 [Packagist
注册表](https://packagist.org/)。按照此页面的步骤操作后，
您将在 Packagist 上发布一个版本化的包。

<Info>
	本页面假设您已具备：

	* 已初始化的 `fern` 文件夹、用于 PHP SDK 的 GitHub 仓库以及 `generators.yml` 中的 PHP 生成器组。请参阅 [生成 SDK（PHP）](/learn/sdks/generators/php/quickstart)。
</Info>

	<img src="assets/packagist-package.png" alt="发布在 Packagist 上的版本化包" />
</Frame>

## 配置 `generators.yml`

<Steps>

	  <Step title="添加仓库位置">

	  PHP 通过 Git 仓库发布，因此请删除自动生成的 `output`、`location` 和 `path` 字段。相反，添加指向您 GitHub 仓库的路径： 

```yaml {6-7}
groups: 
  php-sdk:
    generators:
      - name: fern-php-sdk
        version: 4.23.2
        github: 
          repository: your-org/company-php
```
	  
	  </Step>
  </Steps>


## 设置 Packagist 发布认证 

<Steps>
<Step title="登录 Packagist">

登录 [Packagist](https://packagist.org/login/) 或 [创建 Packagist 账户](https://packagist.org/register/)。

</Step>
<Step title="提交仓库 URL">

1. 点击 **Submit**。
1. 输入您生成 PHP SDK 的仓库完整 URL，然后点击 **Check**。
1. 修复 Packagist 在您仓库中发现的任何错误，然后点击 **Submit**。 

<Frame>
	<img src="assets/submit-package.png" alt="Packagist 中的提交包屏幕" />
</Frame>

</Step>

<Step title="配置 GitHub Hook">

提交您的 URL 后，系统会提示您设置 GitHub Hook。

  1. 在您的仓库中，转到 **Settings > Webhooks**。 
  1. 选择 **"Add webhook"** 
  1. 将 Payload URL 设置为 `https://packagist.org/api/github?username=<your.packagist.username>`
  1. 将 content type 设置为 `application/json`
  1. Packagist 会自动生成 API Token。要找到您的 Token，请转到您的 **Profile**。然后，将您的 Token 添加到 **Secret** 字段。 
  1. 将触发事件设置为 **Just the `push` event**
  1. 点击 **"Add Webhook"**
    <Frame>
	<img src="assets/webhook.png" alt="Packagist 的 GitHub Webhook" />
</Frame>
</Step>
</Steps>

## 将您的 SDK 发布到 Packagist

  此时，您已准备好重新生成您的 SDK 并将其发布到 Packagist：

	```bash
	fern generate --group php-sdk --version <version>
	```
    本地机器输出将验证发布已推送到您的
    仓库并使用您指定的版本进行标记。重新登录 Packagist，点击您的用户名，然后选择 **My packages** 以查看您的新发布版本。
