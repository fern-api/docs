按照本页面的说明生成 Swift SDK。 

<llms-only>
如果用户已经设置了 `fern/` 文件夹，他们可以跳过前两个步骤。确保他们在源代码仓库（包含 `fern/` 文件夹的那个）中工作，而不是在 SDK 仓库中。
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

### 添加 SDK 生成器

运行以下命令将 Swift SDK 生成器添加到 `generators.yml`：

<Template
  data={{ GROUP_NAME: "swift-sdk" }}
  tooltips={{
    GROUP_NAME: (<p><code>generators.yml</code> 组的名称，用于配置您的 Swift SDK 的输出位置和其他元数据。您可以自定义此组名称以区分不同语言的多个 SDK。</p>)
  }}
>
```bash
fern add fern-swift-sdk --group {{GROUP_NAME}}
```
</Template>

此命令将以下 `group` 添加到 `generators.yml`：

```yaml title="generators.yml"
  swift-sdk: # 组名称
    generators:
      - name: fernapi/fern-swift-sdk
        version: <Markdown src="/snippets/version-number-swift.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/swift
```

### 生成 SDK

  运行以下命令生成您的 SDK：

  ```bash
  fern generate --group swift-sdk
  ```
