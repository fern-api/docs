按照此页面上的说明生成 Swift SDK。

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="添加 SDK 生成器">

运行以下命令将 Swift SDK 生成器添加到 `generators.yml` 中：

<Template
  data={{ GROUP_NAME: "swift-sdk" }}
  tooltips={{
    GROUP_NAME: (<p><code>generators.yml</code> 组的名称，用于配置你的 Swift SDK 的输出位置和其他元数据。你可以自定义此组名称，以区分不同语言的多个 SDK。</p>)
  }}
>
```bash
fern add fern-swift-sdk --group {{GROUP_NAME}}
```
</Template>

此命令将以下 `group` 添加到 `generators.yml` 中：

```yaml title="generators.yml"
  swift-sdk: # group name
    generators:
      - name: fern-swift-sdk
        version: <Markdown src="/snippets/version-number-swift.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/swift
```
</Step>

<Step title="生成 SDK">

  运行以下命令来生成你的 SDK：

  ```bash
  fern generate --group swift-sdk
  ```

  <Markdown src="/products/sdks/snippets/generate-sdk.mdx"/>

</Step>

<Step title="发布为 Swift 包">

按照[发布为 Swift 包](/learn/sdks/generators/swift/publishing)指南来配置你的包并通过 GitHub Actions 设置自动发布。
</Step>
</Steps>
