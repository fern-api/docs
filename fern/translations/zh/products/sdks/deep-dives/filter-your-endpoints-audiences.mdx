使用受众为不同的 API 消费者群体（如内部团队、Beta 测试者或客户）生成定制的 SDK。

受众通过基于标签的过滤工作：你在规范中使用受众标签来标记 API 元素，然后在 `generators.yml` 中配置生成 SDK 时要包含哪些受众。对于 OpenAPI，[基于路径的过滤也可用](/learn/zh/api-definitions/openapi/extensions/audiences#path-based-filtering)。

## 受众入门

完整说明请参见 [OpenAPI 中的受众](/learn/zh/api-definitions/openapi/extensions/audiences) — 使用 `x-fern-audiences` 标记元素，然后在 `generators.yml` 中配置 SDK 过滤。
