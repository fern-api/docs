<Note title="默认版本" id="default-version">

  版本在您网站上的下拉菜单中按照 `docs.yml` 中列出的顺序显示。您的 `versions` 列表中的第一个版本是默认版本，使用无版本路径，如 `example.com/getting-started`。其他版本使用带版本的路径，如 `example.com/v2/getting-started`。

  Fern 通过[重定向](/learn/zh/docs/seo/redirects)损坏的版本链接到默认版本来自动处理版本路由。规范 URL 指向无版本路径以整合 SEO 信号。要为特定版本页面覆盖此设置，请参阅 [SEO 元数据](/learn/zh/docs/seo/setting-seo-metadata#canonical-url)。
</Note>
