| Property | Description |
| --- | --- |
| `offset` | 请求中偏移量参数的路径（例如，`$request.page`） |
| `cursor` | 请求中游标参数的路径（例如，`$request.cursor`） |
| `next_cursor` | 响应中下一个游标值的路径（游标分页必需） |
| `next_uri` | 响应中下一页URL的路径（例如，`$response.next_page_url`） |
| `next_path` | 响应中下一页相对路径的路径（例如，`$response.next_page_path`） |
| `results` | 响应中结果数组的路径（例如，`$response.data`） |
| `step` | 页面大小参数的路径，确保偏移量正确递增 |
| `has-next-page` | 指示是否有其他页面的布尔值路径 |
