您可以在 `docs.yml` 配置中为整个 API 参考文档或特定部分设置可用性。选项包括：`stable`、`generally-available`、`in-development`、`pre-release`、`deprecated` 或 `beta`。

当您设置某个部分的可用性时，该部分中的所有端点都会自动标记为该可用性，除非明确设置为其他值。

```yaml title="docs.yml" {3, 6}
navigation: 
  - api: API Reference
    availability: generally-available
    layout: 
      - section: My Section
        availability: beta
        icon: flower
        contents: 
        # endpoints here
```
