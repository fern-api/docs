在任何 Markdown 内容中使用 `api:` 链接语法来链接到 API 端点或 API 参考部分。Fern 在构建时会解析这些链接，因此您无需硬编码 slug。

<AccordionGroup>
<Accordion title="链接到端点">

使用 `api:METHOD/path`，其中 `METHOD` 是 HTTP 方法（`GET`、`POST`、`PUT`、`PATCH`、`DELETE`），`/path` 是您 API 定义中的端点路径。路径参数使用花括号，例如 `api:GET/v2/payments/{paymentId}`。

对于具有[多个 API](/learn/zh/docs/api-references/generate-api-ref#include-more-than-one-api-reference) 的项目，请在前面加上 API 名称：`api:API-NAME:METHOD/path`。

```mdx Markdown
查看[当前用户信息](api:mcp-tools:GET/api/fern-docs/whoami)端点。
```
</Accordion>
<Accordion title="链接到 API 参考部分的根目录">

使用 `api:apiName`，其中 `apiName` 与您的 `generators.yml` 文件中的 API 名称匹配。当您的项目有多个 API 并且您想要链接到特定 API 参考的根登录页面时，这很有用。

```mdx Markdown
探索[Plant Store API](api:plant-store)参考。
```
</Accordion>
</AccordionGroup>
