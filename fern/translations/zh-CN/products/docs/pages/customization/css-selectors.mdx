## 按钮组件

按钮的选择器。
<AccordionGroup>
<Accordion title=".fern-button">

带变体的按钮。

```css Default CSS
.fern-button {
  transition-property: color, background-color;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  border-radius: var(--radius-2);
  height: 2.5rem;
  padding: 0.25rem 0.75rem;
  font-size: 0.875rem;
  cursor: pointer;
}

@media (min-width: 640px) {
  .fern-button {
    height: 2rem;
  }
}

.fern-button:hover {
  transition: none;
}
```

**变体：**
- `.minimal` - 透明背景，悬停时有细微效果
- `.filled` - 实心背景色
- `.outlined` - 边框，透明背景
- `.primary` - 主色调变体
- `.success` - 绿色变体
- `.warning` - 琥珀色变体
- `.danger` - 红色变体

**尺寸修饰符：**
- `.small` - 较小按钮（桌面端高度：1.75rem，移动端：1.5rem）
- `.large` - 较大按钮（桌面端高度：2.75rem，移动端：2.5rem）
- `.square` - 等宽高的方形按钮

</Accordion>
