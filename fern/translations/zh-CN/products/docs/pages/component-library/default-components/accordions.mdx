`<Accordion>` 组件创建可展开的部分，其中包含可搜索的、SEO 友好的内容，即使在折叠状态下仍可访问。使用折叠面板来显示 FAQ、文档部分、设置面板，或任何通过渐进式展示改善可读性的内容。

您可以使用单个折叠面板，或使用 `<AccordionGroup>` 将多个折叠面板组合在一起。

## 使用方法

<div className="highlight-frame">
<AccordionGroup>
  <Accordion title="部分 1" defaultOpen={true}>
    部分 1 的内容，默认展开
  </Accordion>
  <Accordion title="部分 2">
    部分 2 的内容
  </Accordion>
</AccordionGroup>
</div>

```jsx Markdown
<AccordionGroup>
  <Accordion title="Section 1" defaultOpen={true}>
    Content for section 1, expanded by default
  </Accordion>
  <Accordion title="Section 2">
    Content for section 2
  </Accordion>
</AccordionGroup>
```

## 变体

在每个折叠面板中，您可以嵌入图片、视频和其他组件（警告框、代码块等），创建丰富的交互式内容。

### 多媒体

<div className="highlight-frame">
  <Accordion title="包含多媒体的文本内容">
  <Frame caption="示例图片">
    <img src="https://images.pexels.com/photos/1867601/pexels-photo-1867601.jpeg" alt="A sample image" />
  </Frame>
  </Accordion>
</div>

```jsx Markdown
<Accordion title="Text content with multimedia">
<Frame caption="Sample image">
  <img src="https://images.pexels.com/photos/1867601/pexels-photo-1867601.jpeg" alt="A sample image" />
</Frame>
</Accordion>
```

### 嵌套组件

<div className="highlight-frame">
  <Accordion title="嵌套组件">
  <Note>
    这是嵌套在折叠面板中的提示框
  </Note>
  </Accordion>
</div>

```jsx Markdown
<Accordion title="Nested components">
<Note>
  Here's a callout nested in an accordion
</Note>
</Accordion>
```

### 默认展开

<div className="highlight-frame">
  <Accordion title='默认展开的折叠面板' defaultOpen={true}>
    使用 `defaultOpen` 属性可以让特定的折叠面板在页面加载时默认展开。这对于突出显示重要信息或频繁访问的内容很有用。
  </Accordion>
</div>

```jsx Markdown
<Accordion title='Accordion open by default' defaultOpen={true}>
  Use the `defaultOpen` property to have specific accordions expanded by default when the page loads. This is useful for highlighting important information or frequently accessed content.
</Accordion>
```

## 属性

<ParamField path="title" type="string" required={true}>
  折叠面板标题栏中显示的标题
</ParamField>

<ParamField path="children" type="string | JSX" required={true}>
  折叠面板展开时显示的内容。可以包含文本、markdown 和组件。
</ParamField>

<ParamField path="defaultOpen" type="boolean" default={false}>
  折叠面板在页面加载时是否应该展开。如果未指定，折叠面板默认为折叠状态。
</ParamField>

<ParamField path="id" type="string" required={false}>
  折叠面板的唯一 ID。用于链接和导航。如果未指定，将自动生成 ID。
</ParamField>

<ParamField path="className" type="string" required={false}>
  应用于折叠面板的额外 CSS 类
</ParamField>
