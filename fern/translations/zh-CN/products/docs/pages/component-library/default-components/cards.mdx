`<Card>` 组件将相关内容和操作分组显示在一个视觉上独特的框中。可选元素包括图标、标题和链接。

您可以使用单独的卡片，或使用 `<CardGroup>` 组件在响应式网格布局中排列多个卡片。卡片组用于组织功能列表、导航选项或分步指南。

## 用法

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Card 
      title="浇水指南" 
      icon="regular droplet" 
      href="/learn/docs/writing-content/components/cards"
  >
      图标字段引用 Font Awesome 图标。
  </Card>
  </div>
</div>

```jsx Markdown
<Card 
    title="浇水指南" 
    icon="regular droplet" 
    href="/learn/docs/writing-content/components/cards"
>
    图标字段引用 Font Awesome 图标。
</Card>
```

### 自定义图标

您可以通过传递图像标签或 SVG 文件的相对路径来使用自定义图标。

<div className="highlight-frame">
  <Card 
      title="植物护理" 
      icon={<img src="https://images.unsplash.com/photo-1466781783364-36c955e42a7f?w=100" alt="Plant icon"/>} 
      href="/learn/docs/writing-content/components/cards"
  >
      传递图像标签以使用自定义图标。
  </Card>
</div>

```jsx Markdown
<Card 
    title="植物护理" 
    icon={<img src="https://images.unsplash.com/photo-1466781783364-36c955e42a7f?w=100" alt="Plant icon"/>} 
    href="/learn/docs/writing-content/components/cards"
>
    传递图像标签以使用自定义图标。
</Card>
```

要使用存储在项目中的 SVG 文件的相对路径：

```jsx Markdown
<Card 
    title="蕨类物种" 
    icon="./images/fern-leaf.svg"
    href="/learn/docs/writing-content/components/cards"
>
    使用相对路径引用项目中的 SVG 文件。
</Card>
```

### 图像

卡片支持与内容一起显示图像。图像会自动调整大小以适应卡片尺寸，因此通常不需要指定 `imageWidth` 或 `imageHeight`，除非您想覆盖默认行为。

<div className="highlight-frame">
  <Card 
      title="植物护理指南" 
      src="https://images.unsplash.com/photo-1466781783364-36c955e42a7f"
      imagePosition="left"
  >
      在卡片内容旁显示图像。图像会自动缩放以适应卡片。
  </Card>
</div>

```jsx Markdown
<Card 
    title="植物护理指南" 
    src="https://images.unsplash.com/photo-1466781783364-36c955e42a7f"
    imagePosition="left"
>
    在卡片内容旁显示图像。图像会自动缩放以适应卡片。
</Card>
```

## 属性

### `<CardGroup>` 属性

<ParamField path="cols" type="number" required={false} default="2">
  网格中显示的列数
</ParamField>

### `<Card>` 属性

<ParamField path="title" type="string">
  卡片中显示的标题文本
</ParamField>
<ParamField path="icon" type="string | img">
  [Font Awesome](https://fontawesome.com/icons) 图标类（例如 'brands python'）、SVG 文件的相对路径（例如 './images/icon.svg'）或自定义图像元素
</ParamField>
<ParamField path="href" type="string">
  使整个卡片可点击的可选 URL
</ParamField>
<ParamField path="iconPosition" type="'top' | 'left'" default="top">
  图标相对于文本的位置。
</ParamField>
<ParamField path="iconSize" type="number" default="8">
  图标大小（宽度和高度）按 `iconSize * 4` 像素计算（例如，6 = 24px × 24px，8 = 32px × 32px）。
</ParamField>
<ParamField path="color" type="string">
  图标的十六进制颜色值（例如 `#FF0F00`）。如果同时设置了 `lightModeColor` 和 `darkModeColor`，则被忽略
</ParamField>
<ParamField path="darkModeColor" type="string">
  暗色模式下图标的十六进制颜色值（例如 `#FF0F00`）
</ParamField>
<ParamField path="lightModeColor" type="string">
  亮色模式下图标的十六进制颜色值（例如 `#FF0F00`）
</ParamField>
<ParamField path="src" type="string">
  卡片中显示的图像 URL。设置时，卡片会在内容旁显示图像。
</ParamField>
<ParamField path="imagePosition" type="'top' | 'left' | 'right' | 'bottom'" default="top">
  图像相对于卡片内容的位置。使用 `imagePosition` 控制布局。
</ParamField>
<ParamField path="imageWidth" type="string">
  图像宽度（例如 `200px`，`50%`）。仅在需要覆盖默认大小时使用。默认情况下图像会自动调整大小以适应卡片。
</ParamField>
<ParamField path="imageHeight" type="string">
  图像高度（例如 `150px`，`100%`）。仅在需要覆盖默认大小时使用。默认情况下图像会自动调整大小以适应卡片。
</ParamField>
