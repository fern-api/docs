`<Steps>` 组件使用自动编号和锚点链接组织顺序内容。使用步骤来创建教程、演练、设置指南或任何需要按顺序执行的内容。

## 用法

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Steps>
    <Step>
      登录您的账户并导航到 **设置**。
    </Step>
    <Step>
      选择 **修改密码** 并输入新密码。
    </Step>
  </Steps>
  </div>
</div>

```jsx Markdown
<Steps>
  <Step>
    登录您的账户并导航到 **设置**。
  </Step>
  <Step>
    选择 **修改密码** 并输入新密码。
  </Step>
</Steps>
```

## 变体

### 带标题的步骤

为步骤添加标题以提高组织性和清晰度。

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Steps>
    <Step title="安装 Plants SDK">
    首先，使用您的包管理器安装 Plants API SDK。
    </Step>
    <Step title="获取您的花园 API 密钥">
    注册 Plants API 账户并生成您的花园访问密钥。
    </Step>
    <Step title="初始化您的花园客户端">
    导入并设置 Plants 客户端以开始跟踪您的植物。
    </Step>
  </Steps>
  </div>
</div>

### 使用 Markdown 标题的步骤

您还可以使用 Markdown 标题而不是 `<Step>` 组件来定义步骤。直接在 `<Steps>` 内放置 `##` 或 `###` 标题，它们会自动转换为带有锚点链接的步骤标题。

当设置 `toc={true}` 时，每个步骤在目录中的位置与其标题级别匹配 — `##` 标题出现在深度 2，`###` 出现在深度 3。

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Steps toc={true}>

  ## 安装 Plants SDK

  首先，使用您的包管理器安装 Plants API SDK。

  ## 配置您的 API 密钥

  注册 Plants API 账户并生成您的花园访问密钥。

  ## 初始化您的花园客户端

  导入并设置 Plants 客户端以开始跟踪您的植物。

  </Steps>
  </div>
</div>

```jsx Markdown
<Steps toc={true}>

## 安装 Plants SDK

首先，使用您的包管理器安装 Plants API SDK。

## 配置您的 API 密钥

注册 Plants API 账户并生成您的花园访问密钥。

## 初始化您的花园客户端

导入并设置 Plants 客户端以开始跟踪您的植物。

</Steps>
```

### 包含嵌套组件的步骤

步骤可以包含丰富的内容，包括说明框、折叠面板、代码块和其他组件。

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Steps>
    <Step title="检查您的植物兼容性">
      在向花园添加新植物之前，请确认它能在您的气候条件下茁壮成长。大多数室内植物喜欢 65-75°F 的温度和适中的湿度。
    </Step>
    <Step title="选择您的浇水计划">
      不同的植物有不同的浇水需求。
      <AccordionGroup>
      <Accordion title="多肉植物">
        多肉植物和仙人掌将水分储存在叶子和茎中，因此需要较少的浇水。每 2-3 周浇水一次，让土壤在两次浇水之间完全干燥。过度浇水是多肉植物死亡的最常见原因。
      </Accordion>
      <Accordion title="热带植物">
        热带植物如龟背竹、黄金葛和喜林芋喜欢持续的湿润。当表层土壤感觉干燥时浇水，通常每周一次。这些植物在高湿度环境中茁壮成长。
      </Accordion>
      </AccordionGroup>
    </Step>
    <Step title="将您的植物添加到跟踪器">
      在系统中记录您的植物，以获得个性化的护理提醒并跟踪随时间的生长。

      <Note>记得包括您植物的位置（室内或室外）和光照条件，以获得准确的护理建议。</Note>
    </Step>
  </Steps>
  </div>
</div>

## 属性

### `<Steps>` 属性

<ParamField path="toc" type="boolean" required={false}>
  是否在目录中包含步骤。默认为 `false`。

  当在 `<Steps>` 内使用 [Markdown 标题](#使用-markdown-标题的步骤)时，标题级别控制步骤在目录层次结构中的位置。使用 `##` 表示深度 2 或 `###` 表示深度 3。
</ParamField>

<ParamField path="tocDepth" type="number" required={false}>
  启用 `toc` 时步骤在目录中出现的深度。接受 `1`、`2` 或 `3`。默认为 `3`。

  当使用 [Markdown 标题](#使用-markdown-标题的步骤)时，`tocDepth` 会从标题级别自动设置。当使用 `<Step>` 组件时，手动设置此项以控制在目录中的嵌套。

  ```jsx Markdown
  <Steps toc={true} tocDepth={2}>
    <Step title="第一步">
      此步骤在目录中出现在深度 2。
    </Step>
    <Step title="第二步">
      此步骤也出现在深度 2。
    </Step>
  </Steps>
  ```
</ParamField>

### `<Step>` 属性

<ParamField path="title" type="string" required={false}>
  步骤的可选标题
</ParamField>

<ParamField path="id" type="string" required={false}>
  步骤的唯一 ID。用于链接和导航。如果未指定，将自动生成 ID。
</ParamField>

<ParamField path="className" type="string" required={false}>
  要应用到步骤的额外 CSS 类
</ParamField>
