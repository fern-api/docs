`<Tabs>` 组件将内容组织到不同的选项卡中，用户可以在它们之间切换。每个选项卡可以包含不同类型的内容，如示例、代码片段或文档部分。

## 用法

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Tabs>
    <Tab title="第一个选项卡">
      ☝️ 欢迎来到只能在第一个选项卡中看到的内容。
    </Tab>
    <Tab title="第二个选项卡">
      ✌️ 这里是只在第二个选项卡中显示的内容。
    </Tab>
    <Tab title="第三个选项卡">
      💪 这里是只在第三个选项卡中显示的内容。
    </Tab>
  </Tabs>
  </div>
</div>

## 变体

### 语言同步

具有[相同语言](/learn/docs/writing-content/components/code-blocks#supported-languages)的选项卡会在您的文档站点中自动同步。当用户选择一种语言时，所有具有该语言的选项卡都会切换到相匹配的状态。语言偏好在浏览器会话间持久保存。

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <Tabs>
    <Tab title="TypeScript" language="typescript">
      ```typescript
      console.log("First code block!");
      ```
    </Tab>
    <Tab title="Python" language="python">
      ```python
      print("First code block!")
      ```
    </Tab>
    <Tab title="Java" language="java">
      ```java
      System.out.println("First code block!");
      ```
    </Tab>
  </Tabs>

  <Tabs>
    <Tab title="TypeScript" language="typescript">
      ```typescript
      console.log("Second code block – language syncs with the one above!");
      ```
    </Tab>
    <Tab title="Python" language="python">
      ```python
      print("Second code block – language syncs with the one above!")
      ```
    </Tab>
    <Tab title="Java" language="java">
      ```java
      System.out.println("Second code block – language syncs with the one above!");
      ```
    </Tab>
  </Tabs>
  </div>
</div>

<CodeBlock title="Markdown">
````jsx
<Tabs>
  <Tab title="TypeScript" language="typescript">
    ```typescript
    console.log("Content inside the TypeScript tab");
    ```
  </Tab>

    ```python

    ```
  </Tab>
  <Tab title="Java" language="java">
    ```java

````
</CodeBlock>

<Info>

</Info>

## 属性

<ParamField path="title" type="string" required={true}>
  在选项卡标题中显示的标题
</ParamField>

<ParamField path="language" type="string" required={false}>
  与代码块关联的语言。可以使用任何任意字符串。
  
  当指定时，启用与具有相同语言值的所有选项卡和代码块的全局语言同步。
</ParamField>

<ParamField path="children" type="string | JSX" required={true}>
  选择选项卡时要显示的内容。可以包括文本、markdown 和组件。
</ParamField>

<ParamField path="id" type="string" required={false}>
  选项卡的唯一 ID。用于链接和导航。如果未指定，将自动生成 ID。
</ParamField>

<ParamField path="className" type="string" required={false}>
  应用到选项卡的附加 CSS 类
</ParamField>

### `<TabGroup>` 属性

<ParamField path="className" type="string" required={false}>
  应用到选项卡组的附加 CSS 类
</ParamField>
