---
title: Single sign-on (SSO)
subtitle: Let teammates sign in to Fern with your IdP (SAML or OIDC)
---

<Info>
  SSO is available on enterprise plans. Ping us in your Fern Slack channel or [contact us](https://buildwithfern.com/contact) to get setup with a plan.
</Info>

Use SAML or OIDC so your team signs in with the identity provider they already use. We have steps for Okta, Google Workspace, and Microsoft Entra; if you use another IdP, we’ll help you wire it up.

## Okta

<Tabs>
  <Tab title="SAML">
    <Steps>
      <Step title="Create an application">
        In **Applications**, create a new app integration using **SAML 2.0**.
      </Step>

      <Step title="Configure integration">
        Use these Fern values:
        - Single sign-on URL: provided by Fern
        - Audience URI: provided by Fern
        - Name ID format: `EmailAddress`
        - Attribute Statements:
          | Name   | Value                                  |
          | ------ | -------------------------------------- |
          | `name` | `user.firstName + " " + user.lastName` |
          | `email`| `user.email`                           |
      </Step>

      <Step title="Send Fern your IdP info">
        From the **Sign-On** tab, copy the Metadata URL and X.509 certificate. Send them through the secure channel we provide (not Slack/email). We’ll enable the connection and do a test login with you.
      </Step>
    </Steps>
  </Tab>

  <Tab title="OIDC">
    <Steps>
      <Step title="Create an application">
        In **Applications**, create a new **Web Application** using OIDC.
      </Step>

      <Step title="Configure integration">
        Use Authorization Code grant and set the Redirect URI to what we have provided you.
      </Step>

      <Step title="Send Fern your IdP info">
        Share the Client ID, Client Secret, and your Okta domain (e.g., `<your-tenant>.okta.com`) via a secure tool (1Password/SendSafely). We’ll finish the hookup and test together.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Google Workspace

<Tabs>
  <Tab title="SAML">
    <Steps>
      <Step title="Create an application">
        In **Web and mobile apps**, choose **Add app → Add custom SAML app**.
      </Step>

      <Step title="Send Fern your IdP info">
        Copy the SSO URL, Entity ID, and x509 certificate and send them via the secure channel we provide.
      </Step>

      <Step title="Configure integration">
        On **Service provider details**, enter:
        - ACS URL: provided by Fern
        - Entity ID: provided by Fern
        - Name ID format: `EMAIL`
        - Name ID: `Primary email`

        Attribute statements:
        | Google Directory Attribute | App Attribute |
        | -------------------------- | ------------- |
        | `First name`               | `firstName`   |
        | `Last name`                | `lastName`    |

        Assign users to the app, then tell us so we can turn on SSO.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Microsoft Entra

<Tabs>
  <Tab title="SAML">
    <Steps>
      <Step title="Create an application">
        Under **Enterprise applications**, select **New application → Create your own application → Non-gallery**.
      </Step>

      <Step title="Configure SAML">
        In **Single Sign-On**, choose **SAML** and set:
        - Identifier (Entity ID): provided by Fern
        - Reply URL (ACS): provided by Fern
      </Step>

      <Step title="Configure attributes & claims">
        - Set **Name ID** to `user.primaryauthoritativeemail` (email).
        - Add claims:
          | Name        | Value            |
          | ----------- | ---------------- |
          | `firstName` | `user.givenname` |
          | `lastName`  | `user.surname`   |
      </Step>

      <Step title="Send Fern your IdP info">
        From **SAML Certificates**, copy the **App Federation Metadata URL**. Send it via the secure channel we provide, and we’ll enable the connection.
      </Step>

      <Step title="Assign users">
        In **Users and groups**, add the people who should access Fern.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Using another provider?

Share your IdP type (SAML/OIDC), the metadata URL (or issuer + client credentials for OIDC), and your docs domain(s). We’ll send a secure upload link, configure the connection, and run a quick login test with you.
