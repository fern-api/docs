---
title: Connect a GitHub repository
description: Link your GitHub repository to your Fern project for automated deployments.
---

Connect your GitHub repository to your Fern project to enable automated documentation deployments when you push changes.

## Requirements

To complete the repo connection, you need:

- **Admin access** to the GitHub organization where the repository exists
- The [Fern API GitHub app](https://github.com/apps/fern-api) installed on the repository

## Setup

<Steps>
<Step title="Open the Dashboard">

Navigate to the [Fern Dashboard](https://dashboard.buildwithfern.com/) and select your documentation site.
</Step>

<Step title="Connect your repository">

In the **GitHub** section of the **Overview** tab, select **Connect Repository** and follow the prompts to authorize the Fern API GitHub app.

</Step>

<Step title="Install the GitHub app">

If you haven't already installed the [Fern API GitHub app](https://github.com/apps/fern-api), you'll be prompted to install it on your repository. You must be an admin on the GitHub organization to complete this step.

</Step>

<Step title="Select your repository">

Choose the repository containing your Fern configuration files. Once connected, Fern automatically deploys your documentation when you push changes to the configured branch.
</Step>
</Steps>
