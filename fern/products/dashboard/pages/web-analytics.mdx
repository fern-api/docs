---
title: Web analytics
description: Understand traffic, acquisition, and developer intent from the Fern Dashboard.
---

Fern automatically collects aggregated web analytics for every published Fern docs site. No `docs.yml` configuration is required. View the metrics in the [Fern Dashboard](https://dashboard.buildwithfern.com/).

Select a 7, 14, 30, 90, or 180-day time window. Data isn't real-time and typically lags by three to four hours.

## Traffic and audience

The dashboard reports:

- Page views
- Unique visitors
- Sessions
- Top pages (a ranked subset, not every page)
- Top countries
- Device types

## Acquisition

The dashboard reports traffic channels (direct, organic, and referral) and referring domains.

## Developer intent

The dashboard reports:

- API Explorer request volume, split into successful and failed requests
- Views of `llms.txt` and Markdown files
- LLM and other AI bot traffic by provider

Built-in web analytics is separate from [third-party analytics integrations](/learn/docs/integrations/overview). The `analytics:` block in `docs.yml` forwards [analytics events](/learn/docs/integrations/analytics/events) to configured providers.

## Disable analytics

Analytics collection is enabled by default. Set [`settings.disable-analytics`](/learn/docs/configuration/site-level-settings) to `true` in `docs.yml` to turn it off:

```yaml docs.yml
settings:
  disable-analytics: true
```

This setting also disables providers configured under `analytics:`.
