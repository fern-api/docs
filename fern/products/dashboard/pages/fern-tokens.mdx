---
title: Fern tokens
description: Create and manage Fern tokens for CLI authentication in CI/CD environments.
---


[Admins](/learn/dashboard/configuration/permissions) can create and manage Fern tokens from the [Fern Dashboard](https://dashboard.buildwithfern.com/). Tokens authenticate the Fern CLI in CI/CD pipelines, for example when publishing SDKs or documentation from GitHub Actions.

<Note>
  Tokens don't expire. Rotate tokens periodically and delete any that are no longer in use.
</Note>

## Create a token

<Steps>
<Step title="Open the API Tokens page">

Navigate to the [Fern Dashboard](https://dashboard.buildwithfern.com/) and select **API Tokens** from the sidebar.
</Step>

<Step title="Create a new token">

Select **Create token**, enter a name (e.g. `CI/CD pipeline`), then select **Generate token**.

The token value is displayed once. Copy it immediately — you won't be able to view it again.
</Step>

<Step title="Store the token as a secret">

Add the token as a repository secret named `FERN_TOKEN` in your CI/CD provider (e.g. GitHub Actions, GitLab CI). Reference it in your workflow:

```yaml title="GitHub Actions example"
env:
  FERN_TOKEN: ${{ secrets.FERN_TOKEN }}
```

</Step>
</Steps>

## Manage tokens

From the **API Tokens** page, you can:

- **Rename a token** — select the options menu next to a token and choose **Edit name**.
- **Delete a token** — select the options menu and choose **Delete**. Deleted tokens are immediately revoked and can't be restored.

<Note>
  All [members](/learn/dashboard/configuration/permissions) can view token names and creation dates. Only Admins can create, rename, or delete tokens.
</Note>
