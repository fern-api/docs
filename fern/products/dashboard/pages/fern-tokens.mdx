---
title: Fern tokens
description: Create and manage Fern tokens that authenticate the Fern CLI without an interactive login.
---

[Admins](/learn/dashboard/configuration/permissions) can create and manage Fern tokens from the [Fern Dashboard](https://dashboard.buildwithfern.com/). 

A Fern token authenticates the CLI for commands that reach Fern — like [publishing docs](/learn/docs/preview-publish/publishing-your-docs) and SDKs — in CI/CD pipelines, [self-hosted deployments](/learn/sdks/deep-dives/self-hosted), and other environments where [`fern login`](/learn/cli-api-reference/cli-reference/commands#fern-login) isn't available. Set it as the `FERN_TOKEN` environment variable.

To generate a token from the CLI instead, run [`fern token`](/learn/cli-api-reference/cli-reference/commands#fern-token). Any organization member can run it, and it returns a new token on each call rather than a persistent, named one.

## Create a token

<Steps>
<Step title="Open the API Tokens page">

Navigate to the [Fern Dashboard](https://dashboard.buildwithfern.com/) and select **API Tokens** from the sidebar.
</Step>

<Step title="Create a new token">

Select **Create token**, optionally add a **Description** (e.g. `CI/CD pipeline`), then select **Generate**.

The token value is displayed once. Copy it immediately, as you won't be able to view it again.
</Step>
</Steps>

## Revoke a token

From the **API Tokens** page, select the options menu next to a token and choose **Revoke**. Revoking a token invalidates it immediately and permanently. The revoked token stays listed with a **Revoked** status so you can audit past tokens.

<Tip>
  Rotate tokens periodically and revoke any that are no longer in use.
</Tip>
