---
title: User permissions
description: Manage team member roles and access levels in your organization.
---

Use the Fern Dashboard to assign roles to your teammates. Roles control access to organization settings and publishing capabilities. Users can be Admins, Editors, or Viewers.

  <Callout intent="info"> 
    [**CLI access**](/learn/cli-api-reference/cli-reference/overview) is a permission that varies by role and controls who can
    publish SDKs and documentation sites to production. It's not required for
    local development. 
  </Callout>  

## Admin

Full administrative access to your organization and full CLI access. Admins can:

- Manage members, including adding and removing roles.
- Generate and publish SDKs and documentation sites to production.

## Editor

Editors can work with SDKs and documentation, but can't edit organization settings or manage members. CLI access is enabled or disabled per Editor:

- Editors **with** CLI access can publish SDKs and documentation sites via the CLI. 
- Editors **without** CLI access can generate locally, validate API specs, and preview output, but cannot publish to production.

## Viewer

Read-only access to the Dashboard and analytics. Viewers can't generate locally, validate API specs, preview output, or publish to production. Viewers can't edit organization settings or manage members.
