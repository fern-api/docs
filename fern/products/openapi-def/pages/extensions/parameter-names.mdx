<Note>
  Fern provides extensions to customize how parameters are named and handled in your generated SDKs.
</Note>

## Parameter Name Customization

### x-fern-parameter-name

Use `x-fern-parameter-name` to rename parameters in your generated SDKs to be more human-readable and intuitive.

```yaml
paths:
  "/users":
    get:
      parameters:
        - in: header
          name: X-API-Version 
          x-fern-parameter-name: version
          schema:
            type: string
```

### x-fern-sdk-variables

Use `x-fern-sdk-variables` to define variables that can be set once and reused across multiple endpoints. This is useful for values like project IDs or API versions that are used consistently.

```yaml
components:
  x-fern-sdk-variables:
    project_id:
      type: string
      description: The project identifier
      pattern: "^proj_[a-zA-Z0-9]+$"

paths:
  "/v1/projects/{project_id}/users":
    parameters:
      - name: project_id
        in: path
        required: true
        schema:
          type: string
        x-fern-sdk-variable: project_id
```

## Examples

### Headers

Rename headers to be more readable in your SDK:

```yaml
paths:
  "/user":
    get:
      parameters:
        - in: header
          name: X-API-Version
          x-fern-parameter-name: version
          schema:
            type: string
          required: true
```

### Query Parameters 

Make query parameter names more descriptive:

```yaml
paths:
  "/user/search":
    get:
      parameters:
        - in: query
          name: q
          x-fern-parameter-name: search_terms
          schema:
            type: string
          required: false
```

### Path Parameters

Simplify path parameter names:

```yaml
paths:
  "/user/{userId}":
    get:
      parameters:
        - in: path
          name: userId
          x-fern-parameter-name: id
          schema:
            type: string
          required: false
```

### SDK Variables

Define a reusable variable for project ID:

```yaml
components:
  x-fern-sdk-variables:
    project_id:
      type: string 
      description: "Project identifier"
      pattern: "^proj_[a-zA-Z0-9]+$"

paths:
  "/v1/projects/{project_id}/resources":
    parameters:
      - name: project_id
        in: path
        required: true 
        schema:
          type: string
        x-fern-sdk-variable: project_id
```

<Note>
  SDK variables are supported in Fern generators version 4.24.0 and later. Make sure you're using a compatible version in your generators.yml file.
</Note>

## Best Practices

- Use consistent naming conventions across your API spec
- Choose descriptive names that reflect the parameter's purpose
- Consider backwards compatibility when renaming parameters
- Document any custom naming patterns for maintainability
- Test SDK variable usage across different generators
