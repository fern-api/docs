<Note>
  Extensions allow you to customize how parameters and variables are named in your generated SDKs to improve usability.
</Note>

## Parameter Naming with x-fern-parameter-name

The `x-fern-parameter-name` extension lets you customize how parameters appear in your SDK:

### Headers

Rename header parameters to be more human readable:

```yaml {8}
paths:
  "/user":
    get:
      operationId: list_user
      parameters:
        - in: header
          name: X-API-Version
          x-fern-parameter-name: version
          schema:
            type: string
          required: true
```

### Query Parameters

Make query parameters more descriptive:

```yaml {8}
paths:
  "/user/search":
    get:
      operationId: search_user
      parameters:
        - in: query
          name: q
          x-fern-parameter-name: search_terms
          schema:
            type: string
          required: false
```

### Path Parameters

Simplify path parameter names:

```yaml {8}
paths:
  "/user/{userId}":
    get:
      operationId: get_user
      parameters:
        - in: path
          name: userId
          x-fern-parameter-name: id
          schema:
            type: string
          required: false
```

## SDK Variables with x-fern-sdk-variables

The `x-fern-sdk-variables` extension allows you to define variables that can be passed once via the SDK client constructor and reused across operations:

```yaml
components:
  x-fern-sdk-variables:
    project_id:
      type: string
      description: "The ID of the project"
      pattern: "^proj_[a-zA-Z0-9]+$"
```

These variables can then be referenced in path parameters:

```yaml
paths:
  "/v1/connect/{project_id}/accounts":
    parameters:
      - name: project_id
        in: path
        required: true
        description: "The project ID"
        schema:
          type: string
          pattern: "^proj_[a-zA-Z0-9]+$"
        x-fern-sdk-variable: project_id
```

This allows SDK users to provide the variable once during client initialization rather than passing it to each individual method call.
