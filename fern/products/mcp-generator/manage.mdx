---
title: Manage in the dashboard
description: Find, connect, and manage your hosted MCP servers in the Fern dashboard.
availability: beta
---

The dashboard doesn't create servers. [Create them with the CLI](/learn/mcp-generator/get-started/quickstart), then find, connect, and manage them in the dashboard.

<Steps>

<Step title="Find your server">

Go to `https://dashboard.buildwithfern.com/<your-org>/mcp`, or choose **MCP Servers** in the left menu.

If the page says **Let's build your MCP server**, nothing is deployed for your organization yet.

Each server appears in the list with its **Status**, **URL**, number of **Tools**, and when it was last **Updated**. Select a server to open its overview. The overview shows the **Connection URL**, the number of tools, when the server was last generated, and recent activity.
</Step>

<Step title="Connect an agent">

Select **Connect**. Choose the credential your API needs, then choose the tab for your agent: **Claude Code**, **Cursor**, **VS Code**, **JSON**, or **URL**. Copy the snippet into your agent's settings.

If an agent can't reach the server, check that your network allows `*.fernmcp.dev`. Ask your IT team to add it to the allowlist if it's blocked.
</Step>

<Step title="Review and manage the server">

- **Tools** lists every tool generated from your spec.
- **Analytics** shows how often agents call the server. It stays empty until the first calls arrive.
- **Settings** has the server controls:
  - **Pause server** turns the endpoint off without deleting anything. **Resume server** turns it back on.
  - **Delete server** removes the server permanently, including its stored configuration. The URL then returns 404.
</Step>

</Steps>
