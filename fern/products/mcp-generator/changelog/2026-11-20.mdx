## MCP Generator is generally available

<ChangelogTags>features</ChangelogTags>

MCP Generator is out of beta. Add a `language: mcp` target to `sdk-config.yml` and `fern generate` turns your OpenAPI spec into an MCP server that Fern hosts at `https://<org>.fernmcp.dev/<slug>`, or that you can download and run yourself. Available at GA:

- [Tool selection, toolsets, and merged tools](/learn/mcp-generator/get-started/configure) to control which operations agents see and how they're grouped.
- [Custom tools and hooks](/learn/mcp-generator/get-started/configure#add-custom-tools-and-hooks), scaffolded with `fern sdk add-tool` and `fern sdk add-hook`.
- [OAuth sign-in](/learn/mcp-generator/get-started/authentication), alongside passing through the API keys and tokens your API already accepts.
- [Custom domains, analytics, rollback, and tool-call usage](/learn/mcp-generator/get-started/manage) in the Fern Dashboard.

```yaml title="sdk-config.yml"
targets:
  - language: mcp
    output:
      delivery: hosted
      slug: petstore
```
