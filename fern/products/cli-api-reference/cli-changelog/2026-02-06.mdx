## 3.66.0
**`(feat):`** Add support for server URL templating in multi-URL environments. The Fern definition
schema now supports `url-templates`, `default-urls`, and `variables` fields on
`MultipleBaseUrlsEnvironmentSchema`, enabling SDKs to expose server variables as
constructor parameters with runtime URL interpolation.


## 3.65.1
**`(fix):`** Fix `fern check --strict-broken-links` was not validating markdown files referenced by sections with paths.
