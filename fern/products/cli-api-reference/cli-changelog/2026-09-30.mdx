## 5.143.4
**`(fix):`** Generate configured README and API reference files for legacy SDK generators routed through SDK Gen API.


## 5.143.3
**`(fix):`** `fern docs preview delete --id` now loads the docs workspace and deletes the preview at each
`instances[].url` basepath, so previews built from a docs.yml instance with a path
(e.g. `acme.docs.buildwithfern.com/reference`) no longer fail with "Domain not registered".


## 5.143.2
**`(fix):`** `fern.config.json` now rejects a `version` that is not an exact semver version, `*`, or `latest`.
Previously any string was accepted and forwarded to `npx fern-api@<version>` during version
redirection, so specs like `file:`, `npm:`, git, or URL specs could make the CLI install and run
an arbitrary package.


## 5.143.1
**`(fix):`** Make `fern generate --package` / `--package-only` more reliable for Java SDKs on restricted networks.
Docker mode now gives the `gradle` toolchain container a persistent dependency cache
(`~/.fern/gradle-docker-home`), layers in the host's `gradle.properties` and `init.d` (from
`GRADLE_USER_HOME` or `~/.gradle`) and forwards `HTTP(S)_PROXY`/`NO_PROXY`; the Java build consults a
Maven Central mirror before Maven Central / the Gradle plugin portal to avoid HTTP 429 rate limits
(override with `FERN_MAVEN_CENTRAL_MIRROR=<url>` or disable with `FERN_MAVEN_CENTRAL_MIRROR=off`);
host mode prefers the generated `./gradlew` wrapper over a global `gradle`. Packaging now fails
instead of silently doing nothing when no generator in the group writes to `local-file-system`.
