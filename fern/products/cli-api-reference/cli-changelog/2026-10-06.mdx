## 5.147.1
**`(fix):`** `<Markdown src="..." />` snippets now resolve when a prop value contains `>`, e.g.
`<Markdown src="/snippets/intro.mdx" returnType="Promise<void>" />`. Previously the `>` inside the
quoted value ended the tag early, so the snippet was never inlined and the page rendered incorrectly.


## 5.147.0
**`(feat):`** `fern init` can now create `sdk-config.yml` for new OpenAPI projects. Initialized OpenAPI
files are bundled into the Fern workspace, while URL sources are preserved in the generated configuration.
