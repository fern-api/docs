## 5.147.4
**`(fix):`** `fern generate --docs` now registers each distinct API definition once per publish. Versioned
docs that reference the same API from every version no longer repeat its AI example
enhancement, dynamic snippet generation and upload for each version.


**`(fix):`** `fern generate --docs` now builds each OpenAPI workspace's IR once per run. The publish
reuses the IR that the `valid-markdown-links` check already built, instead of converting
every spec a second time.


**`(fix):`** `fern generate --docs` and `fern docs publish` no longer build the docs navigation twice.
The `missing-redirects` check now runs on the navigation the publish already resolves,
instead of resolving the docs a second time during validation. Its warnings are now
printed during publishing, and `missing-redirects: error` still stops the publish.


**`(chore):`** `fern generate --docs` no longer calls the AI example enhancement service while publishing,
so publishing API reference pages is faster. The service has been returning errors since
August, so examples on published pages were not being enhanced anyway. The `ai-examples`
setting in `docs.yml` is still accepted but has no effect. Existing
`ai_examples_override.yml` files next to OpenAPI specs are still applied.


## 5.147.3
**`(fix):`** Fix component schemas that are only a `$ref` to another schema (for example
`CopyBatchArg: { $ref: '#/components/schemas/RelocationBatchArgBase' }`) being imported
as `unknown`. Their API reference pages showed "any" instead of the referenced type's
fields. These schemas now become an alias of the referenced type.


## 5.147.2
**`(fix):`** `fern generate --docs` now registers API definitions with FDR four at a time instead of one
after another, which shortens publishes for docs sites with many APIs or API versions. Set
`FERN_DOCS_API_REGISTRATION_CONCURRENCY` to change the limit (`1` restores serial registration).


## 5.147.1
**`(fix):`** `<Markdown src="..." />` snippets now resolve when a prop value contains `>`, e.g.
`<Markdown src="/snippets/intro.mdx" returnType="Promise<void>" />`. Previously the `>` inside the
quoted value ended the tag early, so the snippet was never inlined and the page rendered incorrectly.


## 5.147.0
**`(feat):`** `fern init` can now create `sdk-config.yml` for new OpenAPI projects. Initialized OpenAPI
files are bundled into the Fern workspace, while URL sources are preserved in the generated configuration.
