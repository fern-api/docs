## 5.183.2
**`(fix):`** `fern generate --docs --guest` no longer prints the published site's own "Claim this site to keep it" link
next to the guest session's claim link. A guest session owns its docs site, so claiming the session (the
`Claim it to keep this work` link, or `fern claim`) is what keeps the site; the second link did not work.


## 5.183.1
**`(fix):`** Fix OpenRPC specs being dropped from docs when a schema or method example is a single
string, number or boolean value. The OpenRPC importer no longer crashes on these examples,
and falsy example results such as `0` or `false` are kept in the endpoint's response example.


## 5.183.0
**`(feat):`** OpenRPC methods now pass their `paramStructure` through to the docs, so the API Explorer
and code snippets can send JSON-RPC `params` as an object keyed by name for `by-name` methods.


## 5.182.2
**`(fix):`** Cloning a private repository with a personal access token (for example when generating the README in
self-hosted GitHub mode) no longer fails with `could not read Username` in containers with libcurl 8.23+.
The token is now also sent as an `Authorization` header, which git keeps after it rewrites the remote URL.


## 5.182.1
**`(fix):`** Large untabbed docs sites with very big API reference layouts (tens of thousands of endpoints) no longer fail
`fern check` / `fern generate --docs` with "Maximum call stack size exceeded". The docs.yml parser is now
generated with TypeScript SDK generator 3.108.3, which collects validation errors without spreading them.


## 5.182.0
**`(feat):`** `fern generate --docs --guest` publishes without `--preview`: the guest session publishes to the Fern Drop
site FDR holds for it (its own `drop-<id>` host, ignoring the docs.yml instance URL) and prints the drop URL
and the claim link, so a guest's docs can be claimed into an organization.


## 5.181.0
**`(feat):`** `fern sdk migrate` now carries every `proto` spec in `generators.yml` into `sdk-config.yml` as a
`proto` source, with its root (local or git), target, overrides, dependencies, `localGeneration` and an
explicit `fromOpenApi`. Proto-only APIs no longer fail to migrate, and `from-openapi: true` protos are no
longer dropped when the API also has OpenAPI specs. `docs.yml` is left unchanged, with a warning, for APIs
with proto specs, because docs API references cannot list them.


## 5.180.2
**`(fix):`** `fern check` and `fern generate --docs` no longer fail with "Maximum call stack size exceeded"
on large sites whose `docs.yml` uses `tabs`. The parser now tries the tabbed navigation shape
before the untabbed one, so a tab's `layout` is no longer validated as an API reference layout
first.
