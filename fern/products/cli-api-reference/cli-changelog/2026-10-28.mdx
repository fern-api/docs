## 5.182.0
**`(feat):`** `fern generate --docs --guest` publishes without `--preview`: the guest session publishes to the Fern Drop
site FDR holds for it (its own `drop-<id>` host, ignoring the docs.yml instance URL) and prints the drop URL
and the claim link, so a guest's docs can be claimed into an organization.


## 5.181.0
**`(feat):`** `fern sdk migrate` now carries every `proto` spec in `generators.yml` into `sdk-config.yml` as a
`proto` source, with its root (local or git), target, overrides, dependencies, `localGeneration` and an
explicit `fromOpenApi`. Proto-only APIs no longer fail to migrate, and `from-openapi: true` protos are no
longer dropped when the API also has OpenAPI specs. `docs.yml` is left unchanged, with a warning, for APIs
with proto specs, because docs API references cannot list them.


## 5.180.2
**`(fix):`** `fern check` and `fern generate --docs` no longer fail with "Maximum call stack size exceeded"
on large sites whose `docs.yml` uses `tabs`. The parser now tries the tabbed navigation shape
before the untabbed one, so a tab's `layout` is no longer validated as an API reference layout
first.
