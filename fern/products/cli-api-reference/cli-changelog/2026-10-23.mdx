## 5.172.0
**`(feat):`** `fern token` now mints the key through the managed api-keys path (same `fern_` token class), so the
key gets a `tokenId`, appears in `fern org token list` and the dashboard API Keys page, and is revocable.


**`(feat):`** Add `fern org token` commands to manage organization API keys:
`list` (with `--json`/`--csv` output), `create` (prints the secret once), and `revoke <token-id>`.
`list` shows each key's creator by email when Venus can resolve it.


## 5.171.6
**`(fix):`** `fern generate --preview` now asks sdk-gen-api for a file download instead of the
generators.yml GitHub or registry output, matching Fiddle's dry-run preview. A
`github.branch` set from `${ENV_VAR}` no longer fails with "Too small: expected string
to have >=1 characters", and previews no longer request a push or publish.


## 5.171.5
**`(chore):`** Internal cleanup: trailing-slash stripping, forward-slash path conversion and first-letter
capitalization now use shared helpers instead of inline copies. No behavior change.


**`(chore):`** Internal cleanup: `isRecord`, `sanitizePreviewId`, `decodeJsonPointerSegment` and a few other
helpers that were copied across packages now have a single shared definition. No behavior change.


## 5.171.4
**`(chore):`** Internal cleanup: the CLI migrations now share one fern-directory lookup and one
files-and-directories listing helper instead of per-migration copies. No behavior change.


## 5.171.3
**`(fix):`** `fern sdk migrate` carries a Go generator's `packageLayout` setting (`root` or `types`) over to the target's
`generation.packageLayout` instead of reporting it as unsupported and dropping it. Bumps
`@postman/sdk-config` to 0.16.0.
