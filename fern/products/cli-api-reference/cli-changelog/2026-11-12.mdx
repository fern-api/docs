## 5.210.2
**`(fix):`** `fern generate` now warns with the GitHub error when `github.auto-merge: true` (or `--auto-merge`)
was requested but auto-merge could not be enabled on the pull request (for example when the
repository has "Allow auto-merge" disabled or no required status checks), instead of failing
silently. Hosted-generation telemetry now reports `auto_merge_requested` from the effective
setting (flag or generators.yml) rather than the CLI flag alone.


## 5.210.1
**`(fix):`** When an API with `types: true` also has a GraphQL schema, the standalone schema section is titled
`Schemas` (matching its `schemas` slug) instead of a second `Types` section; type pages sort
with an explicit locale so their order is the same on every machine.


## 5.210.0
**`(feat):`** Add `types: true` to the `api` navigation item in `docs.yml`. When set, every schema that no endpoint,
webhook or WebSocket of the API references gets its own page under a `Types` section at the end of the
API reference (e.g. a schema-only OpenAPI document such as TwiML). Enums and objects declared inline in
another schema stay nested on their parent's page. The XML encoding of a type (OpenAPI `xml` object,
`x-fern-xml-text`) is kept so an XML element's page shows an XML example. Off by default.


## 5.209.1
**`(fix):`** `fern docs link check --output csv` and `--output json` now print only the results to stdout.
Warnings from loading the local Fern project (such as `Missing file: examples.yml`) and their
GitHub Actions `::error::` annotations go to stderr, so `> results.csv` no longer puts log lines
above the CSV header.


## 5.209.0
**`(feat):`** A tab can now have a `tab-menu`: a menu of other tabs that opens from the header tab. Menu entries are tabs
(`tab` id plus `display-name`, optional `subtitle` and `icon`), top-level `group` entries with a header and
`tabs`, and external links (`link` + `href`). Each menu tab gets its own `- tab:` entry in `navigation` with a
`layout` or `variants` (whose selector sits at the top of that tab's sidebar), and the menu tab's own bare
`- tab:` entry sets where the menu sits in the header. Member URLs nest under the menu tab
(`/products/agents/...`). Without header tabs, the menu falls back to a sidebar selector and `fern check` warns;
it also errors on members missing from `navigation`, members listed twice, and undefined navigation tabs. Tab
`variants` lists also accept `group` entries (a header plus `items`). Split menus into columns with
`tab-menu-column-height` on the tab (an integer or `no-limit`), with a site-wide default in
`layout.tab-menu.default-column-height`; sidebar selectors stay a single list. Menus open on hover; set
`layout.tab-menu.interact-on-click-only: true` to open them on click only, with no animation.


## 5.208.0
**`(feat):`** When `fern check` or `fern generate --docs` fails validation inside a coding agent, the CLI now
suggests up to three `fern instructions` topics based on which rules failed (for example,
`fern instructions docs configure seo` for a missing redirect).


## 5.207.0
**`(feat):`** A `cli` target in `sdk-config.yml` is always sent to sdk-gen-api as SDK Config, like every other language.
`ENABLE_SDK_GEN_RUST_CLI` is no longer read. With `--local`, the target is still translated into a
`generators.yml` for Fern's CLI generator and run in Docker.


## 5.206.0
**`(feat):`** Add the `layout.breadcrumbs.sticky` docs.yml setting. When set to true, the
breadcrumb row stays pinned below the header while the page scrolls.
Defaults to false.

(`Guest<id>ApiClient`, `Guest<id>ApiError`, ...): client and error classes keep the names derived from the
