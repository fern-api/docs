## 5.154.0
**`(feat):`** Restore `FERN_USE_SDK_GEN_API` as a runtime override of the `use-sdk-gen-api` feature flag. `true` routes every
generator through sdk-gen-api and `false` keeps every generator off it (generation on Fiddle, generator upgrades on
FDR versions), without a flag request. Unset, or any other value, follows the flag. It is intended for tests and
debugging.


## 5.153.0
**`(feat):`** Add the `layout.hide-webhook-method-badges` docs.yml setting. When set to true,
webhook entries in the sidebar render without an HTTP method badge (e.g. `POST`),
so webhooks no longer read like callable endpoints. Defaults to false.
