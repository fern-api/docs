## 5.155.0
**`(feat):`** `fern docs dev` now runs the Astro docs preview server by default, matching how published Fern Docs sites render.
Pass `--legacy` to run the previous Next.js preview server. `--astro` is still accepted but no longer needed,
and `--beta` is now a deprecated alias for `--legacy`. `--private` now applies to the Astro preview too.
The older pages-router preview server that `--legacy` used to start is no longer available.


## 5.154.2
**`(fix):`** Feature flag checks now report usage to PostHog (`$feature_flag_called`) when CLI telemetry
is enabled, so flags like `use-sdk-gen-api` show usage metrics. Setting
`FERN_DISABLE_TELEMETRY=true` still turns these events off; flag evaluation is unchanged.


## 5.154.1
**`(fix):`** Prevent the CLI from hanging indefinitely while flushing automation telemetry during exit.


## 5.154.0
**`(feat):`** Restore `FERN_USE_SDK_GEN_API` as a runtime override of the `use-sdk-gen-api` feature flag. `true` routes every
generator through sdk-gen-api and `false` keeps every generator off it (generation on Fiddle, generator upgrades on
FDR versions), without a flag request. Unset, or any other value, follows the flag. It is intended for tests and
debugging.


## 5.153.0
**`(feat):`** Add the `layout.hide-webhook-method-badges` docs.yml setting. When set to true,
webhook entries in the sidebar render without an HTTP method badge (e.g. `POST`),
so webhooks no longer read like callable endpoints. Defaults to false.
