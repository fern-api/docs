## 5.204.1
**`(fix):`** A generators.yml build sent to sdk-gen-api as a runtime bundle (the path `fern generate --guest` takes) is also
filed under the workspace name when the API definition carries the default name "api".


## 5.204.0
**`(feat):`** Add `remote-paths` to `docs.yml`. Each entry reverse-proxies a path prefix on your docs domain
(for example `/ui`) to an HTTPS service you run, while Fern keeps serving the rest of the site.
`fern check` validates each path and destination with the new `valid-remote-paths` rule.


**`(fix):`** A generators.yml build sent to sdk-gen-api is filed under the workspace name (`fern/apis/<name>`) when the
API definition carries the default name "api", so each API of an organization gets its own SDK.


## 5.203.0
**`(feat):`** `settings.search-text` in `translations/<lang>/docs.yml` now sets the search bar placeholder for that locale.
Locales without it keep the docs-level `search-text`.


## 5.202.1
**`(fix):`** The claim link `fern generate --guest` prints says what the run made (`from=sdk` for an SDK run, `from=docs` for a docs publish), so claiming it lands on that page of the organization — the SDKs after an SDK run even when the organization already has docs.
