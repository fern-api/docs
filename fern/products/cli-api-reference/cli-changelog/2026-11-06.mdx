## 5.200.0
**`(feat):`** `fern generate --docs --guest` now uploads your `fern/` folder with the site, so connecting a GitHub
repository after claiming the site adds the folder to it. Files ignored by git, `.env*` files and
`node_modules` are left out. Pass `--no-source` to publish without it.


## 5.199.1
**`(fix):`** `fern generate --docs` now sends the time the publish started. When two publishes of the same
docs site overlap, the one that started later stays live, even if its build finishes first.


## 5.199.0
**`(feat):`** Add `fern instructions [topic]`, which prints task-scoped instructions for coding agents
working in a Fern project. With no topic it prints the topic index from the Fern docs;
with a topic (for example `fern instructions docs publish domain`) it prints that page as
Markdown, without the docs site's agent preamble. It needs no login or workspace and is
exempt from version redirection, so it works in projects that pin an older CLI.


## 5.198.0
**`(feat):`** Add an optional `button-text` field to the `ai-search`/`ai-chat` docs.yml config.
It replaces the "Ask AI" label on the docs header button and in the search dialog.


## 5.197.1
**`(fix):`** Preserve repository files when GitHub SDK generation is routed through sdk-gen-api. The CLI now
forwards the configured GitHub license and supplies the runtime snippet path for GitHub outputs,
so LICENSE, README.md, reference.md, and CONTRIBUTING.md are generated before publishing.
