## 5.193.3
**`(fix):`** `fern generator upgrade` and `fern automations upgrade` no longer move a generators.yml entry to a version at or past
its SDK Config cutover (for example TypeScript 4.0.0+, Python 6.0.0+), which `fern generate` rejects. With
`--include-major`, the generator upgrades within its current major instead. Cutover versions are reported
under "SDK Config migration required" with a `fern sdk migrate` instruction rather than an `--include-major` hint,
and `fern automations upgrade --json` lists them in `sdkConfigMigrationRequired`.


## 5.193.2
**`(fix):`** `fern generate --docs --guest` prints the published site's own claim link again, next to the guest session's
claim link. Opening it enables the Claim button in the site's banner, which claims just the docs site into an
organization you administer; the session link (`Claim it to keep this work`, or `fern claim`) still claims the
whole session.
