## 5.161.1
**`(fix):`** Respect `github.workflows: false` in `generators.yml` when generation runs through sdk-gen-api.
The setting was dropped on that route, so generated `.github/workflows/*` files were still
committed. Requests that keep the default (`true`) are unchanged.


**`(fix):`** Upgrade `@postman/sdk-config` to 0.14.0, which adds optional `output.github.workflows` to SDK Config.
`output.github.workflows: false` in `sdk-config.yml` is now sent to sdk-gen-api the same way as
the `generators.yml` setting. The SDK Config `cli` target accepts the field and ignores it with a
warning, like the other GitHub delivery settings its translated `generators.yml` does not write.


## 5.161.0
**`(feat):`** `fern generator list` and `fern generator get` now describe SDK Config targets from `sdk-config.yml`
alongside legacy generator groups, so they stay accurate after `fern sdk migrate`.

`fern generator list` output now nests each API under `groups` (legacy groups from `generators.yml` or
`generators.legacy.yml`) and `targets` (SDK Config targets with their language, generator, and version,
where an unpinned target reports `latest`). A language configured in both files appears in both sections.
The new `--targets` option filters SDK Config targets by language or target id.

`fern generator get --target <language>` reads an SDK Config target's version, language, or repository.
Missing selections now fail with the configuration files inspected, and a legacy selection that was
migrated points at its SDK Config target.


## 5.160.0
**`(feat):`** `settings.search.prioritize-current-product` in `docs.yml` now defaults to `true`.
When unset, search boosts results from the current product/version without
hiding other products/versions. Set it to `false` to keep the previous ranking.


## 5.159.3
**`(fix):`** `webhook-signature.algorithm-header` now accepts `key-id-parameter` and `algorithm-parameter`
so key/value settings headers such as Twilio's
`X-Twilio-Webhooks-Signature-Settings: key=<id>,algorithm=HMAC_SHA256` are parsed into the
bare key ID and algorithm instead of `key=<id>` (IR 67.33.0).


## 5.159.2
**`(fix):`** Fix `fern docs dev` dropping uploaded (`file:`) icons and images from the navigation,
such as custom product switcher and navbar link icons. The Astro preview now maps the
preview's file IDs to file paths in the docs config, matching how `fern generate --docs`
publishes. Translated `navbar-links` overrides now also show up in the preview.
