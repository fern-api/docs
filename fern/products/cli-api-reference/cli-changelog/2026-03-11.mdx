## 4.24.0
**`(feat):`** Add support for `"latest"` as the `version` value in `fern.config.json`.
When set to `"latest"`, the CLI automatically resolves to the most recent
published version from npm on every invocation, removing the need to
manually run `fern upgrade` to stay current.


## 4.23.1
**`(fix):`** Preserve description, namespace, group name, and availability metadata for unknown
(empty-type) schemas in OpenAPI specs. Previously these fields were dropped during
parsing, causing loss of documentation on schemas with no explicit type.
