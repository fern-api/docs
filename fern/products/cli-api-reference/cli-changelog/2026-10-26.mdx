## 5.174.0
**`(feat):`** Add `auto-merge: true` to the `github` block (pull-request mode) in generators.yml and a matching
`fern generate --auto-merge` flag. When set, Fern enables GitHub auto-merge (squash) on the pull
request it opens, so the SDK PR merges as soon as the repository's required checks pass. Auto-merge
is skipped when the release contains breaking changes (MAJOR bump) or version analysis is
unavailable, and the SDK repository must allow auto-merge. Applies to both `--local` and remote
generation (the flag is now forwarded to Fiddle).


## 5.173.0
**`(feat):`** At `fern generate --docs`, find the snippets of the SDKs that docs.yml `snippets:` names (TypeScript,
Python, Java, Go, Ruby, C# and PHP) through sdk-gen-api, by the sdkName in sdk-config.yml, the language
and the version, and add them to the endpoints as code samples, in both deploy modes. The target needs
`docs.snippets.enabled` in sdk-config.yml so sdk-gen saves a snippets file with the build. This needs no
build ID and no files from the machine that built the SDK.
Off unless `FERN_UPLOAD_SDK_GEN_SNIPPETS=true` is set. A snippet failure never fails the docs publish.
