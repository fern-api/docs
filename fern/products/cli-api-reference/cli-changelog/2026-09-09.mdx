## 5.119.0
**`(feat):`** Add a `layout.api-reference-expand-properties` option to docs.yml. Set it to `true` to
render the first level of nested object and union fields in the API reference expanded on
page load instead of behind a "Show N properties" button. Deeper levels stay collapsed.


## 5.118.0
**`(feat):`** Allow `fern generate --sdk-config <path>` to validate an SDK Config v1 YAML or JSON document and submit it to sdk-gen-api for multi-target expansion. Generation without the flag continues through the existing legacy Fern configuration and IR flow.
