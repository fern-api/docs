## 5.218.0
**`(feat):`** Add `settings.search.popular-searches` to `docs.yml`. When set to `true`, the
empty search box lists the site's most popular searches before the reader
types. Defaults to `false`.


## 5.217.2
**`(fix):`** Running a version in `fern.config.json` older than 5.215.0 no longer fails in CI or asks for
confirmation. The CLI prints a prominent warning and runs the pinned version. Run `fern upgrade` to
update the pin; `--allow-old-cli-version` or `FERN_ALLOW_OLD_CLI_VERSION=true` shortens the warning.


## 5.217.1
**`(fix):`** Keep the Maven `signature` block when GitHub SDK generation runs through sdk-gen-api. The runtime
bundle omits publish credentials on that route and dropped the signature with them, so Java SDKs
configured for Maven Central got a release workflow that ran `./gradlew publish` without the
`MAVEN_SIGNATURE_*` secrets. The signature is now sent with empty values, so the generator writes
the signed `./gradlew sonatypeCentralUpload` workflow without receiving any credentials.


## 5.217.0
**`(feat):`** `fern claim` now moves the guest session's work, like the dashboard's claim page: after the claim it
moves the docs sites and SDK builds into the organization (also with `--org`), which drops the guest
expiry and the drop banner. New `--docs-url` renames the docs site and `--sdk-name` names the SDK. When docs.yml has a
single instance, its URL is pointed at the claimed site so the next `fern generate --docs` updates it. If a
move fails, the session is kept and rerunning `fern claim` retries the move.
