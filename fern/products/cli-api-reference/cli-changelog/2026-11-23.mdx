## 5.228.2
**`(fix):`** SDK Config targets delivered to GitHub now forward Maven and crates.io publish credential
`${NAME}` expressions to sdk-gen-api as repository secret names (`usernameEnvironmentVariable`,
`passwordEnvironmentVariable`, `signatureEnvironmentVariables`, `tokenEnvironmentVariable`), so the
generated release workflow publishes with the configured secrets. Literal credentials are not forwarded.


## 5.228.1
**`(fix):`** `fern generate --docs` now registers the OpenAPI or AsyncAPI `info.version` with the API definition, so the
`/openapi.json`, `/openapi/<api>.json` and AsyncAPI downloads on a docs site show the source spec's version
instead of `1.0.0`.


## 5.228.0
**`(feat):`** MCP targets now accept an `egress` block in the SDK Config `generation` config
(`@postman/sdk-config` 0.26.0): `egress.policy` (`open` | `allowlist`) and
`egress.allowedUpstreams`. This is an opt-in outbound allow-list that restricts which
hosts a generated MCP server's tools may call. Previously these keys were rejected
during SDK Config validation.
