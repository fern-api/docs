## 5.186.0
**`(feat):`** An MCP target in `sdk-config.yml` can now host its server with `output.delivery: hosted` and a
`slug`, the equivalent of `output.location: fern-hosted` in `generators.yml`. `fern generate
--sdk-config` deploys it like the `generators.yml` path does, and `fern sdk migrate` keeps
the hosting and the slug instead of converting the output to a zip download. The request sent to
sdk-gen-api still asks only for a download.


## 5.185.0
**`(feat):`** The CLI generator's `config.banner.file` in `generators.yml` points at a text asset (resolved relative to
`generators.yml`) whose contents become the generated CLI's startup banner, so logo art can live in the
config repo instead of inline in YAML.


## 5.184.0
**`(feat):`** Support `x-fern-explorer` in OpenRPC specs. Set it at the document root to
enable or disable the API Explorer for every method, or on a method to
override the root value.
