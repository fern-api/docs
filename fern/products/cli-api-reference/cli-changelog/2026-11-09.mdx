## 5.202.0
**`(feat):`** FDR now merges global themes server-side when it supports it; older FDR versions keep CLI-side stitching.


## 5.201.0
**`(feat):`** Set `ENABLE_SDK_GEN_RUST_CLI=true` to send a `cli` target in `sdk-config.yml` to sdk-gen-api as SDK Config, like
every other language. sdk-gen-api picks the CLI generator. Without it, the `cli` target is translated into a
`generators.yml` for the Fern CLI generator, as before.


**`(chore):`** The `cli` target translation now knows the fields added in `@postman/sdk-config` 0.20.0. The OAuth redirect,
parameter and device-authorization settings, custom `oauthTokenEndpoints` property names and `omitTokenPrefix`
are rejected with a clear error instead of being reported as unknown; `crateName` is reported as not written.
