## 3.62.0
**`(feat):`** Add `title-source` configuration option for folder navigation. When using `folder` navigation, you can now set `title-source: frontmatter` to use the `title` field from frontmatter for page and section titles instead of deriving titles from file names. The default behavior (`title-source: filename`) remains unchanged.


## 3.61.0
**`(feat):`** Add support for `@/` prefix in MDX import statements to indicate absolute paths from the fern folder root.
Users can now write `import { Banner } from '@/components/Banner'` instead of using relative paths like
`import { Banner } from '../../../components/Banner'`. The imports are transformed to relative paths at
publish time.
