## 5.130.0
**`(feat):`** Add `output: { location: fern-hosted, slug: <slug> }` to `generators.yml` for
`fernapi/fern-mcp-server`. `fern generate` builds the MCP server through sdk-gen-api,
deploys it to Fern's hosted MCP platform, and prints the server URL. `slug` is optional
(default `mcp`) and supports `${ENV_VAR}` substitution.
