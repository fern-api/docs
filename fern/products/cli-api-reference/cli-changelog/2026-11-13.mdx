## 5.213.0
**`(feat):`** Standalone type pages (`types: true` on an `api` navigation item) use the schema's own example:
an OpenAPI object schema's `example`/`examples`, or one assembled from its property-level `example`
values, reaches the Fern definition (`examples`), the IR (`userProvidedExamples`) and FDR
(`TypeDefinition.examples`), so the XML/JSON example on the page shows those values instead of
placeholders and renders every variant of a `oneOf` array the example lists. The schema examples are
only attached for API sections with `types: true` (parser option `objectSchemaExamples`); SDK
generation and `fern write-definition` output are unchanged.


## 5.212.0
**`(feat):`** Add docs profiles. A profile is a named set of values, like a product name or CLI command, that
fills `${NAME}` placeholders. Publish one set of pages as several editions without copying them.


## 5.211.0
**`(feat):`** `fern generate --local --version AUTO` logs a stable `AUTO versioning fallback: reason=<code>` line
(`diff-too-large` or `analysis-failed`) when it falls back to a PATCH bump, so CI can tell the
two cases apart. The diff size limit for AI analysis is raised from 10MB to 50MB.


**`(fix):`** `fern generate --docs --guest` no longer prints a "Missing redirects check skipped: could not
reach FDR (FDR returned 403)" warning. The check needs to read the site's previously published
pages, which a guest token is not allowed to do, and a guest's drop site has no redirects to
protect, so the check is skipped silently for guest publishes.
