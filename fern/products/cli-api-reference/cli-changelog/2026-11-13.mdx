## 5.215.2
**`(fix):`** Docs profiles: each edition of a page now gets its own sitemap entry and canonical URL in `fern docs dev`.


## 5.215.1
**`(fix):`** `fern --version` in a project that pins a CLI older than 5.215.0 prints the pinned version again
instead of failing; it no longer runs the older CLI to do it. When the CLI refuses to run an older
version, the message now goes to stderr, so scripts that capture stdout (for example
`$(fern --version)`) no longer pick it up.


## 5.215.0
**`(feat):`** The CLI no longer silently hands off to a version in `fern.config.json` older than 5.215.0. Those
versions run `npx` from the project directory, so a project could run its own executables in place
of the CLI or its tools. Interactive terminals ask for confirmation; elsewhere, pass
`--allow-old-cli-version` or set `FERN_ALLOW_OLD_CLI_VERSION=true` to run the older version anyway.
Without that opt-in, `fern upgrade` from such a project runs in the current CLI instead of the older one.


**`(fix):`** Bundling custom MDX components now runs `npx rolldown` from a temporary npm project instead of
the component's folder, so rolldown always comes from the registry.


**`(fix):`** When `fern.config.json` pins a different CLI version, the CLI now runs `npx` from a temporary
npm project instead of the project directory, so the pinned version always comes from the registry.


## 5.214.0
**`(feat):`** `fern init` ends with a hint for users who drive Fern through a coding agent: `npx skills add fern-api/skills --all`
installs the Fern skills, which teach the agent the whole workflow (docs, SDKs, publishing). The "No Fern account
found" error a run hits without a login or `FERN_TOKEN` carries the same hint next to its `--guest` suggestion.


## 5.213.0
**`(feat):`** Standalone type pages (`types: true` on an `api` navigation item) use the schema's own example:
an OpenAPI object schema's `example`/`examples`, or one assembled from its property-level `example`
values, reaches the Fern definition (`examples`), the IR (`userProvidedExamples`) and FDR
(`TypeDefinition.examples`), so the XML/JSON example on the page shows those values instead of
placeholders and renders every variant of a `oneOf` array the example lists. The schema examples are
only attached for API sections with `types: true` (parser option `objectSchemaExamples`); SDK
generation and `fern write-definition` output are unchanged.


## 5.212.0
**`(feat):`** Add docs profiles. A profile is a named set of values, like a product name or CLI command, that
fills `${NAME}` placeholders. Publish one set of pages as several editions without copying them.


## 5.211.0
**`(feat):`** `fern generate --local --version AUTO` logs a stable `AUTO versioning fallback: reason=<code>` line
(`diff-too-large` or `analysis-failed`) when it falls back to a PATCH bump, so CI can tell the
two cases apart. The diff size limit for AI analysis is raised from 10MB to 50MB.


**`(fix):`** `fern generate --docs --guest` no longer prints a "Missing redirects check skipped: could not
reach FDR (FDR returned 403)" warning. The check needs to read the site's previously published
pages, which a guest token is not allowed to do, and a guest's drop site has no redirects to
protect, so the check is skipped silently for guest publishes.
