## 5.144.3
**`(fix):`** `fern generate --docs --preview --id <id> --no-prompt` no longer asks for
confirmation when the preview ID already exists, so an existing preview can
be overwritten non-interactively (as `--force` and CI environments already
allowed).


**`(fix):`** Fix several gaps in docs translation navigation overlays: the `display-name`
of a changelog tab is now applied; overlays can now translate `link` labels,
`api` reference titles, API package titles and endpoint titles (via the api
node's `layout`); positional matching of sections/pages no longer shifts after
a sibling that was matched by an explicit slug; API layout `section` overlays
now apply to their API package nodes; endpoint overlays match by HTTP method
when it is unique among siblings; and multi-segment explicit overlay slugs
(e.g. `customization/voice`) now match. Overlay endpoint titles are no longer
reverted to the translated spec's endpoint name when that name is unchanged
from the default locale.


**`(fix):`** Translated OpenAPI specs now fall back to the v2 parser when the v3 parser
fails, matching the default-locale API build, instead of falling back to the
untranslated API definition. Translated specs are also built when
`experimental.openapi-parser-v3` is disabled.


**`(fix):`** Pages served in a translated locale with default-locale content (no
translated source file, or an API without a translated spec) are now
published as `noindex`, so they are excluded from that locale's sitemap and
`llms.txt` instead of being indexed as the locale.


## 5.144.2
**`(fix):`** `fern docs md generate` prints non-fatal library-docs parser warnings (e.g. a skipped Cython module).


**`(fix):`** Python library docs: fix 404 links to empty submodules and to private modules, emit cross-page
links as relative `.mdx` references so generated folders work under any navigation section,
use the shortest public import path in signatures, and link types named in docstring
`Parameters`/`Returns` sections to their class pages.
