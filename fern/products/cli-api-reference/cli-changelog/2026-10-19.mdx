## 5.166.0
**`(feat):`** The dynamic IR now marks whether each file-upload property (`file` and `fileArray`) is optional,
so dynamic snippet generators can add placeholders for required files only.


## 5.165.0
**`(feat):`** Initialize new SDK projects with sdk-config.yml instead of generators.yml by default. Set FERN_USE_SDK_CONFIG=false to temporarily use the legacy initialization path.


## 5.164.1
**`(fix):`** C/C++ library docs: generated page and group filenames no longer start with `_`
(e.g. `__be16` is written to `typedefs/be16.mdx`), so `folder:` navigation includes them.
URLs are unchanged. `fern check` now warns when only some generated library folders
(e.g. `macros/`) are wired into navigation.


## 5.164.0
**`(feat):`** `fern generate --version AUTO` now works for an `sdk-config.yml` target that delivers to GitHub, so
Fern Autorelease can release SDK Config targets. sdk-gen-api generates with a placeholder version,
and Fiddle picks the semver bump, replaces the placeholder and writes the changelog, as it does for
`generators.yml` groups. The CLI prints the picked version, and each AUTO run starts a new build
instead of replaying an earlier one. `AUTO` with download or direct registry output still fails
before generation, because nothing would replace the placeholder.
