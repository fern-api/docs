## 5.230.1
**`(fix):`** A spec loaded from a URL in `sdk-config.yml` (for example from `fern init --openapi <url>`) now has relative
`servers` URLs resolved against the spec URL, so a hosted MCP server deploys without extra config. For a local
spec file, an MCP target with a relative `servers` URL and no `api.baseUrl` now fails with a message that names
`servers` and `api.baseUrl`.


## 5.230.0
**`(feat):`** `fern generate --docs` can publish from GitHub Actions without a stored `FERN_TOKEN`. When neither `FERN_TOKEN`
nor a saved login is present and the job has `permissions: id-token: write`, the CLI exchanges the run's GitHub
OIDC token for a 1-hour organization token, provided an organization admin has trusted the repository.
`FERN_TOKEN` and a saved login keep precedence, and other commands are unchanged.
