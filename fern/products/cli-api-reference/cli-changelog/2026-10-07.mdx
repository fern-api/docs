## 5.147.6
**`(fix):`** `fern generate --docs` is faster on large multi-version API references. OpenAPI parsing
no longer rescans the whole spec for every operation's request body, type resolution no
longer rebuilds the map of definition files on every lookup while generating dynamic snippet
IRs, and external `$ref` resolution no longer re-shifts its work queue. Dynamic snippet IRs
are now generated on worker threads (bounded by CPU cores, available memory and
`FERN_DOCS_API_REGISTRATION_CONCURRENCY`; runners with less than about 10 GB of RAM, such as
the 2-core GitHub Actions runner, stay in-process), starting as soon as each API's IR is built so they
overlap the navigation build. Set `FERN_DOCS_API_REGISTRATION_CONCURRENCY=1` to generate them
serially in-process.


## 5.147.5
**`(fix):`** Fix translated navigation labels getting out of order after a top-level page, link, or
`collapsed` section. The CLI wraps those items in an internal sidebar group, and the
translation overlay now matches the group's items as siblings of the items around it, so
labels like API reference sections and endpoint titles no longer stay in English or pick up
another item's translation.
