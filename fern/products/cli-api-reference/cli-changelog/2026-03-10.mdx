## 4.21.1
**`(fix):`** Fix `fern check` rejecting `og:dynamic` and `og:background-image` keys in
`docs.yml` metadata. These fields were added to the MetadataConfig API types
but the serialization schema was not updated, causing validation to fail with
"Unexpected key" errors when using the dynamic OG image feature introduced in
v4.3.0.
