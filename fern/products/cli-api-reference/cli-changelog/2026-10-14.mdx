## 5.157.2
**`(fix):`** The `x-displayName` extension on OpenAPI tags now sets the API Reference section name
in the v3 parser. Previously it was only applied when the display name differed from
the tag by letter casing, so a display name such as `Plants` for tag `plant`, or any
multi-word tag, fell back to the title-cased tag name.


## 5.157.1
**`(fix):`** Allow `playground-docs` on `auth-schemes` in `generators.yml`. Previously the CLI rejected it with
`Unexpected key "playground-docs"`, so schemes defined there could not set playground-only auth text.


## 5.157.0
**`(feat):`** Docs sites can now show Fern CLI command snippets alongside the SDK languages. Declaring
`snippets: cli` on an API reference (with the Fern CLI generator in `generators.yml`) builds a
`cli` dynamic IR during docs publish and registers it with FDR, which the docs frontend renders
as runnable CLI commands.
