# Searching Fern Documentation

Fern uses Algolia to power documentation search functionality. You can integrate Fern documentation search into your own applications using our Algolia credentials.

## Getting Started

To search Fern documentation programmatically, you'll need:

- An Algolia application ID
- An API key with search permissions
- The index name for Fern documentation

## Authentication

You can obtain Algolia credentials by contacting the Fern team. These credentials will allow you to make search requests directly to Algolia's API.

## Making Search Requests

Once you have your credentials, you can use Algolia's search API to query Fern documentation. Here's an example using the JavaScript client:

```javascript
import algoliasearch from 'algoliasearch';

const client = algoliasearch('YOUR_APP_ID', 'YOUR_API_KEY');
const index = client.initIndex('fern_docs');

// Perform a search
const results = await index.search('your search query');
```

## Example Response

The search results will include relevant documentation matches:

```json
{
  "hits": [
    {
      "title": "Getting Started with Fern",
      "content": "...",
      "url": "/docs/getting-started",
      "hierarchy": {
        "lvl0": "Documentation",
        "lvl1": "Getting Started"
      }
    }
  ],
  "nbHits": 1,
  "page": 0,
  "nbPages": 1,
  "processingTimeMS": 1
}
```

## Rate Limits and Usage

Please be mindful of rate limits when implementing search functionality. If you need higher rate limits or have specific requirements, contact the Fern team for support.
