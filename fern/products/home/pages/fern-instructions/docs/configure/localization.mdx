Use this to add a language or update translations. Localization is an Enterprise feature in early access.

## Workflow

1. Confirm the user's plan includes localization. If not, they should contact support@buildwithfern.com.
2. Run `fern upgrade`. Localization needs the newest CLI release.
3. Add a `translations` key to `docs.yml` listing each language code (such as `ja` or `pt-BR`), with one marked as the default.
4. Create `fern/translations/<locale>/` and put translated pages and navigation files there, at the same relative paths as the originals. In translated navigation files, include only the fields you translate (`display-name`, `section`, `page`, and so on). To translate the search bar placeholder, set `settings.search-text` in the locale's root `docs.yml`.
5. To update a translation, edit the translated copy of the page. Keep its frontmatter, slugs and component structure the same as the source.
6. Run `fern docs dev` and switch languages from the header dropdown.

## Rules

- Fern doesn't translate content. The user supplies translations.
- Pages without a translation fall back to the default language.
- Ask Fern, `fern check` errors and API Reference pages don't support localization yet.

## Verify

- Each locale has its own URL path, and the language switcher shows every configured language.
