Use this to track readers or add a support widget.

## Workflow

1. Ask the user which tool they use and for its public key or ID. Don't invent IDs.
2. Add it under `analytics` (or `integrations` for support tools) in `docs.yml`, using the key names from that tool's page. For example:

   ```yaml
   analytics:
     posthog:
       api-key: phc_xxxxxxxx
     gtm:
       container-id: GTM-XXXXXXX
   ```

3. Publish and confirm events arrive in the tool.

## Rules

- Use the built-in integrations rather than adding tracking scripts through `js`.
- Fern also has built-in web analytics in the Dashboard and `llms.txt` analytics. Check whether those already answer the user's question.

## Verify

- After publishing, page views show in the tool. The analytics events page lists what Fern sends.
