Use this to change how the whole site looks or behaves. For the sidebar, see `docs configure navigation`. For CSS, JavaScript and components, see `docs configure customization`.

## Workflow

1. Open `fern/docs.yml`. Site-level settings are top-level keys in this file, even when navigation lives in product or version files.
2. Change the relevant key:

   ```yaml
   title: Plant Store Docs
   favicon: ./assets/favicon.svg
   logo:
     light: ./assets/logo-light.svg
     dark: ./assets/logo-dark.svg
     href: https://example.com
   colors:
     accent-primary:
       light: "#0A7D5A"
       dark: "#3DDC97"
   ```

3. Run `fern check` and review the result in `fern docs dev`.

## Main keys

| Key | Controls |
|---|---|
| `instances` | Where the site publishes: `url` and optional `custom-domain` |
| `title`, `favicon`, `logo` | Browser title, icon, and header logo (`light`, `dark`, `href`, `height`) |
| `colors` | `accent-primary`, `background`, `border`, `sidebar-background`, `header-background`, `card-background`, each with `light` and `dark` values |
| `typography` | Fonts |
| `layout` | Page, content and sidebar widths, header height, search bar and tab placement, breadcrumbs |
| `theme` | Sidebar, body, tabs, page actions and footer nav styles |
| `navbar-links`, `footer`, `header` | Header buttons and links, and the footer |
| `settings` | Search, API Explorer proxy, dark-mode code, HTTP snippet languages, analytics |
| `metadata` | Site-wide SEO defaults |
| `landing-page`, `background-image`, `default-language`, `global-theme` | Other site-level options |
| `check` | Severity of `fern check` rules |

## Rules

- Asset paths are relative to `docs.yml`.
- Look up a key in the reference before adding it. `fern check` rejects unknown keys.

## Verify

- `fern check` passes and the change shows in `fern docs dev` in both light and dark mode.
