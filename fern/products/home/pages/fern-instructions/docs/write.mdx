Use this before creating a page or writing more than a few sentences.

## Workflow

1. Search the repo for a page that already covers the topic. Prefer editing it over adding a new page.
2. Create the page as an `.mdx` file in the project's pages folder, starting with frontmatter:

   ```mdx
   ---
   title: Rotate API keys
   description: Rotate an API key without downtime.
   ---

   Body text starts here. Don't repeat the title as an H1.
   ```

3. Add the page to `docs.yml` navigation, or it won't appear. See `docs configure navigation`.
4. Link to other pages by URL path (for example `/learn/docs/seo/redirects`), derived from navigation and `slug` values, never from file paths.
5. Run `fern check`, then `fern docs dev` to see the page.

## Frontmatter

Common fields: `title`, `sidebar-title`, `subtitle`, `description`, `slug`, `image`, `last-updated`, `edit-this-page-url`, `hide-toc`, `max-toc-depth`, `hide-nav-links`, `hide-feedback`, `hide-page-actions`, `logo`, `layout`, `availability`, `search-metadata`, `noindex`, `tags` (changelogs). Don't invent other fields. A frontmatter `slug` is absolute within its product and replaces the section path.

## Snippets

Put content used on several pages in a snippet file, conventionally `fern/snippets/<name>.mdx`, and include it with a path relative to the `fern` folder:

```mdx
<Markdown src="/snippets/enterprise-plan.mdx" />
```

Pass values to `{{placeholder}}` variables in the snippet as props on `<Markdown>`. Check for an existing snippet before writing boilerplate such as a support line or prerequisites.

## Changelog entries

- One file per date in the `changelog/` folder, named `YYYY-MM-DD.mdx`. Subfolders are ignored.
- The filename date is the title and sets the sort order. Don't add an H1.
- Add a `tags` array in frontmatter, reusing existing tags.
- If a file for that date exists, add a `##` section to it instead of creating a second file.

## Rules

- MDX is strict: close every tag, and escape or backtick bare `<`, `{` and `}` in prose.
- Use sentence case for headings. Anchors only work for real `##` and `###` headings, not component `title` props.
- If a change moves, renames or deletes a published page, add a redirect. See `docs configure seo`.
- Images: put them under the project, reference them by relative path, and add alt text.
- Use components where they help the reader, not for decoration. See `docs write components`.

## Verify

- `fern check` passes with no new errors.
- The page renders in `fern docs dev` at the URL you expect, and every internal link resolves.
