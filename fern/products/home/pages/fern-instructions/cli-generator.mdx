Use this when the user wants a CLI for their API, not to use the Fern CLI itself.

## Workflow

1. Follow the CLI generator quickstart to add the generator to the project.
2. Configure commands, auth and output from the configuration, authentication and customization pages. Add custom commands where the generated ones aren't enough.
3. Generate locally to try it, then set up publishing.

## Rules

- Command names come from the spec. Fix them there or with the generator's OpenAPI extensions.
- Look up configuration keys on the CLI generator pages. Don't reuse SDK keys.
