Use this for Java-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: java
       output:
         delivery: files
         path: ../sdks/java
   ```

2. Set the package name and other Java options from the Java configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target java --preview` and build the output with the usual Java tooling.
4. To publish to Maven Central, follow `sdks publish` and the Java publishing page.
