Use this to turn on an SDK capability. Most are driven by the spec, and some by the SDK config.

| Feature | Set up with |
|---|---|
| Auth and environment variable fallbacks | Spec security schemes and `x-fern-*` auth extensions, or `api.auth` in `sdk-config.yml`. See `spec auth`. |
| Dynamic or refreshing auth | [Dynamic authentication](https://buildwithfern.com/learn/sdks/deep-dives/dynamic-authentication.md) |
| Global headers | `x-fern-global-headers`. [Global headers](https://buildwithfern.com/learn/sdks/deep-dives/global-headers.md) |
| Auto-pagination | `x-fern-pagination`. [Pagination](https://buildwithfern.com/learn/sdks/deep-dives/auto-pagination.md) |
| Retries with backoff | `client.retry` in `sdk-config.yml` or `x-fern-retries`. [Retries](https://buildwithfern.com/learn/sdks/deep-dives/retries-with-backoff.md) |
| Idempotency | `x-fern-idempotent` and `x-fern-idempotency-headers`. [Idempotency](https://buildwithfern.com/learn/sdks/deep-dives/idempotency.md) |
| Method names | `operationId` or `x-fern-sdk-method-name`. [Method names](https://buildwithfern.com/learn/sdks/deep-dives/customize-method-names.md) |
| Subset of endpoints | Audiences. [Audiences](https://buildwithfern.com/learn/sdks/deep-dives/audiences.md) |
| Server URL templating | [Server URL templating](https://buildwithfern.com/learn/sdks/deep-dives/server-url-templating.md) |
| WebSocket clients | AsyncAPI. [WebSockets](https://buildwithfern.com/learn/sdks/deep-dives/websocket-clients.md) |
| Server-sent events | `x-fern-streaming`. [SSE](https://buildwithfern.com/learn/sdks/deep-dives/sse-metadata.md) |
| Webhook signature verification | [Webhook verification](https://buildwithfern.com/learn/sdks/deep-dives/webhook-signature-verification.md) |
| README content | `docs.readme`. [README](https://buildwithfern.com/learn/sdks/deep-dives/readme.md) |
| XML bodies | [XML types](https://buildwithfern.com/learn/sdks/deep-dives/xml-encoded-types.md) |

## Workflow

1. Open the feature's page and follow it.
2. Run `fern check`, then `fern generate --preview` and inspect the generated client.
