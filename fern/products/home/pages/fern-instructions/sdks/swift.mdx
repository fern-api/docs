Use this for Swift-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: swift
       output:
         delivery: files
         path: ../sdks/swift
   ```

2. Set the package name and other Swift options from the Swift configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target swift --preview` and build the output with the usual Swift tooling.
4. To publish to Swift Package Manager, follow `sdks publish` and the Swift publishing page.
