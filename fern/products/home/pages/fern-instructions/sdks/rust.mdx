Use this for Rust-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: rust
       output:
         delivery: files
         path: ../sdks/rust
   ```

2. Set the package name and other Rust options from the Rust configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target rust --preview` and build the output with the usual Rust tooling.
4. To publish to crates.io, follow `sdks publish` and the Rust publishing page.
