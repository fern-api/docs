Use this for PHP-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: php
       output:
         delivery: files
         path: ../sdks/php
   ```

2. Set the package name and other PHP options from the PHP configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target php --preview` and build the output with the usual PHP tooling.
4. To publish to Packagist, follow `sdks publish` and the PHP publishing page.
