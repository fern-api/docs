Use this for Python-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: python
       output:
         delivery: files
         path: ../sdks/python
   ```

2. Set the package name and other Python options from the Python configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target python --preview` and build the output with the usual Python tooling.
4. To publish to PyPI, follow `sdks publish` and the Python publishing page.
