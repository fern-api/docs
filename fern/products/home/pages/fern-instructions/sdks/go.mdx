Use this for Go-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: go
       output:
         delivery: files
         path: ../sdks/go
   ```

2. Set the package name and other Go options from the Go configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target go --preview` and build the output with the usual Go tooling.
4. To publish to the Go module proxy, follow `sdks publish` and the Go publishing page.
