Use this for TypeScript-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: typescript
       output:
         delivery: files
         path: ../sdks/typescript
   ```

2. Set the package name and other TypeScript options from the TypeScript configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target typescript --preview` and build the output with the usual TypeScript tooling.
4. To publish to npm, follow `sdks publish` and the TypeScript publishing page.
