Use this for Ruby-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: ruby
       output:
         delivery: files
         path: ../sdks/ruby
   ```

2. Set the package name and other Ruby options from the Ruby configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target ruby --preview` and build the output with the usual Ruby tooling.
4. To publish to RubyGems, follow `sdks publish` and the Ruby publishing page.
