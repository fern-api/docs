Use this for C#-specific SDK setup. For what applies to every language, see `sdks`.

## Workflow

1. Add a target to `sdk-config.yml`:

   ```yaml
   targets:
     - language: csharp
       output:
         delivery: files
         path: ../sdks/csharp
   ```

2. Set the package name and other C# options from the C# configuration page. Look up each option there; don't guess names.
3. Run `fern check`, then `fern generate --target csharp --preview` and build the output with the usual C# tooling.
4. To publish to NuGet, follow `sdks publish` and the C# publishing page.
