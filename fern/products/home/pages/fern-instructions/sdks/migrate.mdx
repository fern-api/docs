Use this for config migrations and major generator or CLI upgrades.

## Move to sdk-config.yml

1. Preview: `fern sdk migrate --dry-run`. Narrow it with `--group`, `--language` or `--api`. `--strict` treats mapping problems as errors.
2. Apply: `fern sdk migrate`. It creates or merges `sdk-config.yml` beside the legacy configuration (`--output` to choose the path).
3. Run `fern check` and `fern generate --preview`, and compare the output with the current SDK.

## Upgrade the CLI and generators

1. `fern upgrade` updates `version` in `fern.config.json` and runs migrations. `fern downgrade` reverts it.
2. Read the CLI and generator changelogs for breaking changes before a major upgrade.
3. Update generator versions (`targets[].generatorVersion`, or `fern generator upgrade` for `generators.yml`).
4. Generate a preview and diff it against the published SDK before releasing.

## Rules

- Release major generator upgrades as a new major SDK version when the public API changes.
- Keep `.fernignore` and Replay settings when moving config.
