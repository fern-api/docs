Use this when the user's docs live on another platform.

## Workflow

1. From Mintlify: `fern init --docs --mintlify <path/to/mint.json>`. Most Mintlify components work as-is or through aliases.
2. From ReadMe: `fern init --docs --readme <readme-site-url>`.
3. From anything else: `fern init --docs`, then move pages into MDX, rebuild navigation in `docs.yml`, and copy branding. See `docs write` and `docs configure navigation`.
4. Add the API spec and an `api` navigation entry. See `docs api-reference`.
5. Add `redirects` from every old URL that changes. See `docs configure seo`.
6. Run `fern check`, review in `fern docs dev`, then publish a preview with `fern generate --docs --preview`.

## Rules

- Keep the old URLs working with redirects before switching the domain.
- Review migrated MDX for components the importer didn't convert. `fern check` reports them.
- Enterprise customers can ask Fern for a managed migration.
