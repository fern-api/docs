## Overview

You can extend Ask Fern's knowledge beyond your core documentation by indexing additional custom content. Adding materials such as internal FAQs, help desk tickets, knowledge base articles, research papers, and other resources helps Ask Fern provide more complete answers to developers.

The Documents API lets you upload, update, and delete custom documents that Ask Fern can reference when responding to user questions.

## How it works

The Documents API allows you to programmatically upload content that Ask Fern will index and search. You provide three pieces of information for each document:

- **document**: The actual text content that Ask Fern will index and search
- **title**: A descriptive title for the content
- **url**: A URL that will be shown as a citation when Ask Fern references this content

<Callout intent="info">
The URL parameter is used solely for citation purposes. Ask Fern does not crawl or fetch content from this URL. You must provide the full content in the `document` field.
</Callout>

This design allows you to index content that may not be publicly accessible via a URL, such as internal documentation, support ticket summaries, or proprietary knowledge base articles. When Ask Fern references your uploaded content in a response, it will display the URL you provided as the source, allowing users to click through for more information.

## Usage

To get started, [upload a document, title, and URL via the Documents API](/learn/ask-fern/api-reference/document/create-document). Here's an example:

```json wordWrap
{
    "document": "Ferns are plants native to the tropical and subtropical regions of the world. They are characterized by their fronds, which are large, leaf-like structures that are often found in the understory of forests.",
    "title": "What are ferns?",
    "url": "https://en.wikipedia.org/wiki/Fern"
}
```

This document will be indexed and made available to Ask Fern as context when users ask questions about ferns. If Ask Fern references this content in a response, it will include the URL as a citation.

## Datasources vs Documents API

If you want Ask Fern to automatically crawl and index a website, use [datasources](/learn/ask-fern/getting-started/how-it-works#datasources-coming-soon) in your `docs.yml` configuration instead. Datasources will crawl the specified URLs and extract content automatically, while the Documents API requires you to provide the content directly.
