Extend Ask Fern's knowledge beyond your core documentation by adding additional content sources like internal FAQs, support tickets, blog posts, and knowledge base articles.

There are two ways to add content:

- **Datasources** - Provide URLs to publicly accessible web content that Ask Fern will automatically crawl and index
- **Documents API** - Make API calls to upload specific content with precise control over what gets indexed

## Datasources <Badge intent="warning">Coming soon</Badge>

Use datasources to index publicly accessible web content like marketing sites and blog posts. Provide URLs in your [`docs.yml` file](/learn/ask-fern/configuration/setup#configuration), and Ask Fern will automatically crawl and index them.

```yaml docs.yml
ai-search:
  datasources:
    - url: https://example.com/blog
      title: Company blog
```

When referenced, Ask Fern cites the original URL as the source.

## Documents API

Make a request to the [Documents API](/learn/ask-fern/api-reference/document/create-document) for precise control over indexed content. This is ideal for content that isn't publicly accessible, like internal documentation, support ticket summaries, or proprietary knowledge base articles. Make API calls to upload the full content directly along with a title and URL.

```json Example wordWrap
{
    "document": "Ferns are plants native to the tropical and subtropical regions of the world. They are characterized by their fronds, which are large, leaf-like structures that are often found in the understory of forests.",
    "title": "What are ferns?",
    "url": "https://en.wikipedia.org/wiki/Fern"
}
```

<Info>Unlike datasources, you provide the full content in the `document` field. The URL is used solely for citations—Ask Fern does not crawl it.</Info>
