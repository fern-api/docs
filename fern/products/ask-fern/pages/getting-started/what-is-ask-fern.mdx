Fern AI Search indexes your documentation and provides an interface for your users to ask questions and get answers. We've found that it helps our customers:

- **Decrease the time to find needed information** - Help users quickly locate crucial documentation without navigating through a maze of tabs and endpoints.
- **Integrate your product faster** - Accelerate implementation with ready-to-use code samples that demonstrate practical applications.
- **Surface where your docs have gaps** - Identify documentation weaknesses through user feedback and search patterns.

## Search API Access

For applications that need programmatic access to search functionality, Fern provides Algolia credentials that can be used to directly query the documentation index. This enables you to:

- Integrate documentation search into your own applications
- Build custom search experiences
- Access search results programmatically

To get started with the Search API:

1. Contact Fern support to request Algolia credentials
2. Use the provided credentials to authenticate with Algolia's API
3. Query the documentation index using Algolia's search API

<Callout type="info">
The Search API uses Algolia under the hood, providing the same powerful search capabilities available on the documentation site.
</Callout>
