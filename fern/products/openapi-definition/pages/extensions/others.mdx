# Other Extensions

## x-fern-sdk-variables

The `x-fern-sdk-variables` extension allows you to define variables that can be reused across multiple endpoints in your OpenAPI definition. These variables are passed via the SDK client constructor and automatically injected into the relevant API paths.

```yaml
x-fern-sdk-variables:
  project_id:
    type: string 
    description: The ID of the project
    pattern: ^proj_[a-zA-Z0-9]+$
```

Usage in paths:
```yaml
/v1/connect/{project_id}/accounts:
  parameters:
    - name: project_id
      in: path
      required: true
      schema:
        type: string
        pattern: ^proj_[a-zA-Z0-9]+$
      x-fern-sdk-variable: project_id
```

## x-fern-pagination

The `x-fern-pagination` extension configures pagination handling for endpoints that return paginated results.

```yaml
x-fern-pagination:
  cursor: $request.after
  next_cursor: $response.page_info.end_cursor
  results: $response.data
```

## x-fern-sdk-return-value

Specifies which part of the response should be returned from the SDK method.

```yaml
x-fern-sdk-return-value: data
```

## x-fern-sdk-group-name

Groups related endpoints under a common namespace in the generated SDK.

```yaml
x-fern-sdk-group-name: users
```

## x-fern-sdk-method-name 

Sets the method name for the endpoint in the generated SDK.

```yaml
x-fern-sdk-method-name: list
```

## x-fern-ignore

Excludes an endpoint or schema from SDK generation.

```yaml
x-fern-ignore: true
```
