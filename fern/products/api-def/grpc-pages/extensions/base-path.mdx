---
title: Base path
description: Configure base paths for generated SDK clients using `x-fern-base-path` extension
---

Configure base paths for generated SDK clients:

```protobuf title="base_path_service.proto"
syntax = "proto3";

package userservice.v1;

service UserService {
  option (x_fern_base_path) = "/api/v1";
  
  rpc GetUser(GetUserRequest) returns (User);
}
```
