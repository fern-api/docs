---
title: Generate a Python SDK
description: Learn how to generate a Python SDK from an AsyncAPI specification using Fern.
---

Fern supports AsyncAPI SDK generation for Python, TypeScript, Java, C#, and Rust. This guide walks through generating a Python SDK from an AsyncAPI [v2.6.0](https://www.asyncapi.com/docs/reference/specification/v2.6.0) or [v3.0.0](https://www.asyncapi.com/docs/reference/specification/v3.0.0) specification.

## Prerequisites

- [Node.js](https://nodejs.org/) installed (required for the Fern CLI)
- An AsyncAPI specification file (JSON or YAML, v2.6.0 or v3.0.0)
- A Fern account (free to create at [buildwithfern.com](https://buildwithfern.com))

## Steps

<Steps>
<Step title="Install the Fern CLI">

```bash
npm install -g fern-api
```
</Step>

<Step title="Set up your fern folder">

Create a `fern/` directory in your project root and add your AsyncAPI spec inside it:

<Files>
  <Folder name="fern" defaultOpen>
    <File name="fern.config.json" />
    <File name="generators.yml" />
    <Folder name="asyncapi" defaultOpen>
      <File name="asyncapi.yml" />
    </Folder>
  </Folder>
</Files>

Create `fern/fern.config.json` with your organization name and the current Fern CLI version:

```json title="fern/fern.config.json"
{
    "organization": "your-organization",
    "version": "<Markdown src="/snippets/version-number-cli.mdx" />"
}
```

Create `fern/generators.yml` and reference your AsyncAPI spec:

```yaml title="fern/generators.yml"
api:
  specs:
    - asyncapi: ./asyncapi/asyncapi.yml

groups:
  python-sdk:
    generators:
      - name: fern-python-sdk
        version: <Markdown src="/snippets/version-number-python.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/python
```
</Step>

<Step title="Add the Python SDK generator">

If you left the `groups` block out of `generators.yml`, add the generator with the CLI instead:

```bash
fern add fern-python-sdk --group python-sdk
```

This command writes the same `python-sdk` group to `generators.yml`.
</Step>

<Step title="Validate your API definition">

Check that your AsyncAPI spec is valid before generating:

```bash
fern check
```

Fix any reported errors before proceeding.
</Step>

<Step title="Generate the SDK">

```bash
fern generate --group python-sdk
```

The first time you run this command, you are prompted to log in. Complete the browser-based authentication flow and generation continues automatically. Credentials are cached locally, so subsequent runs do not prompt again.

The generated SDK is written to `sdks/python/`:

<Files>
  <Folder name="fern" />
  <Folder name="sdks" defaultOpen comment="created by fern generate --group python-sdk">
    <Folder name="python" defaultOpen>
      <File name="__init__.py" />
      <File name="client.py" />
      <Folder name="core" />
      <Folder name="your-api-name" defaultOpen comment="the name of your API">
        <Folder name="errors" />
        <Folder name="types" />
      </Folder>
    </Folder>
  </Folder>
</Files>

<Note>Some files, including `pyproject.toml` and `README.md`, are only generated on the [Enterprise plan](https://buildwithfern.com/pricing). To get the fully generated SDK, [email us](mailto:support@buildwithfern.com).</Note>
</Step>
