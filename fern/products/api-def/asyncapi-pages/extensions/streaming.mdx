---
title: Streaming operations
description: Mark operations as streaming for appropriate SDK generation using `x-fern-streaming` extension
---

Mark operations as streaming for appropriate SDK generation:

```yaml title="asyncapi.yml" {6-9}
operations:
  streamEvents:
    action: receive
    channel:
      $ref: '#/channels/event~1stream'
    x-fern-streaming:
      type: server_sent_events
      termination: client_closes
```
