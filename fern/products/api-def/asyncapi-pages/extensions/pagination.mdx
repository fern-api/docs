---
title: Pagination
description: Configure pagination for operations that return multiple results using `x-fern-pagination` extension
---

Configure pagination for operations that return multiple results:

```yaml title="asyncapi.yml" {6-11}
operations:
  listUserEvents:
    action: receive
    channel:
      $ref: '#/channels/user~1events'
    x-fern-pagination:
      cursor: next_cursor
      results: events
      next_cursor: pagination.next_cursor
      has_next_page: pagination.has_next_page
```
