---
title: Retry behavior
description: Configure retry behavior for operations using `x-fern-retry` extension
---

Configure retry behavior for operations:

```yaml title="asyncapi.yml" {6-10}
operations:
  sendCriticalAlert:
    action: send
    channel:
      $ref: '#/channels/alerts'
    x-fern-retry:
      max_attempts: 3
      exponential_backoff: true
      initial_delay: 1000
      max_delay: 30000
```
