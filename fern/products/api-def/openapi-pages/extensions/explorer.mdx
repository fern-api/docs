---
title: API Explorer control
description: Enable or disable the API Explorer using `x-fern-explorer` and `x-fern-explorer-enabled`
---

Use `x-fern-explorer` to set the default API Explorer availability for your API, and `x-fern-explorer-enabled` to override it per operation. This is commonly used to disable the Explorer for destructive endpoints or payment flows. If omitted, the Explorer is enabled by default.

## Global

To disable the API Explorer for your entire API, add `x-fern-explorer` at the root level:

```yaml title="openapi.yml" {1}
x-fern-explorer: false
```

## Endpoint

To control the API Explorer for individual endpoints, use `x-fern-explorer-enabled`:

```yaml title="openapi.yml" {4,9}
paths:
  /users:
    get:
      x-fern-explorer-enabled: true
  /users/{userId}:
    delete:
      x-fern-explorer-enabled: false
```

In this example, the `GET /users` endpoint has the Explorer enabled, while the `DELETE /users/{userId}` endpoint has it disabled.
