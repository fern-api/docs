---
title: API Explorer visibility
description: Control API Explorer visibility using the `x-fern-explorer` extension
---

The `x-fern-explorer` extension controls whether an endpoint appears in the API Explorer (also known as the API playground) in your documentation. This extension works at the operation level, allowing you to show or hide individual endpoints from the interactive API testing interface.

By default, all endpoints are visible in the API Explorer. Use this extension to hide specific endpoints that shouldn't be tested interactively, such as destructive operations or endpoints that require special setup.

## Usage

Add `x-fern-explorer` to any operation in your OpenAPI specification. The extension accepts a boolean value:

- `true`: Show the endpoint in the API Explorer (default behavior)
- `false`: Hide the endpoint from the API Explorer

```yaml title="openapi.yml" {4}
paths:
  /plants/{plantId}:
    delete:
      x-fern-explorer: false
      summary: Delete a plant
      operationId: deletePlant
      parameters:
        - name: plantId
          in: path
          required: true
          schema:
            type: string
      responses:
        '204':
          description: Plant deleted successfully
```

In this example, the `DELETE /plants/{plantId}` endpoint won't appear in the API Explorer, preventing users from accidentally deleting plants through the interactive documentation.

## When to use this extension

Consider hiding endpoints from the API Explorer when:

- The endpoint performs destructive operations (delete, bulk updates)
- The endpoint requires complex setup or configuration that can't be easily tested interactively
- The endpoint is deprecated and you want to discourage its use
- The endpoint is for internal use only and shouldn't be exposed to external developers

## Related extensions

- [`x-fern-ignore`](./ignore): Completely exclude an endpoint from SDK generation and documentation
- [`x-fern-availability`](./availability): Mark endpoints as beta, generally-available, or deprecated
