gRPC is a modern, open-source, high-performance Remote Procedure Call (RPC) framework that can run in any environment. It uses Protocol Buffers (protobuf) as the interface definition language and supports multiple programming languages. 
Fern is compatible with gRPC services and can generate SDKs and documentation from your `.proto` files.

For a working example, see the [gRPC demo docs](https://grpc-demo.docs.buildwithfern.com/) and its [GitHub repository](https://github.com/fern-demo/grpc-demo).

The sample service created by `fern init --grpc`:

```protobuf user_service.proto
syntax = "proto3";

package userservice.v1;

import "google/api/annotations.proto";
import "google/protobuf/empty.proto";
import "google/protobuf/timestamp.proto";

option csharp_namespace = "UserService.V1";

// Manages user accounts
service UserDirectory {
  // Create a new user account
  rpc CreateUser(CreateUserRequest) returns (User) {
    option (google.api.http) = {
      post: "/v1/users"
      body: "*"
    };
  }

  // Get a user by ID
  rpc GetUser(GetUserRequest) returns (User) {
    option (google.api.http) = {
      get: "/v1/users/{id}"
    };
  }

  // List users with pagination
  rpc ListUsers(ListUsersRequest) returns (ListUsersResponse) {
    option (google.api.http) = {
      get: "/v1/users"
    };
  }

  // Update a user
  rpc UpdateUser(UpdateUserRequest) returns (User) {
    option (google.api.http) = {
      patch: "/v1/users/{id}"
      body: "*"
    };
  }

  // Delete a user account
  rpc DeleteUser(DeleteUserRequest) returns (google.protobuf.Empty) {
    option (google.api.http) = {
      delete: "/v1/users/{id}"
    };
  }
}

enum UserStatus {
  USER_STATUS_UNSPECIFIED = 0;
  USER_STATUS_ACTIVE = 1;
  USER_STATUS_INACTIVE = 2;
  USER_STATUS_SUSPENDED = 3;
}

message User {
  string id = 1;
  string email = 2;
  string name = 3;
  int32 age = 4;
  google.protobuf.Timestamp created_at = 5;
  UserStatus status = 6;
}

message CreateUserRequest {
  string email = 1;
  string name = 2;
  int32 age = 3;
}

message GetUserRequest {
  string id = 1;
}

message ListUsersRequest {
  int32 page_size = 1;
  string page_token = 2;
}

message ListUsersResponse {
  repeated User users = 1;
  string next_page_token = 2;
  int32 total_count = 3;
}

message UpdateUserRequest {
  string id = 1;
  string email = 2;
  string name = 3;
  int32 age = 4;
  UserStatus status = 5;
}

message DeleteUserRequest {
  string id = 1;
}
```

## Get started with `fern init`

`fern init` creates a `fern/` folder with a `generators.yml` that generates a C# SDK. Run it from your project root.

```bash title="terminal"
# Sample gRPC service
fern init --grpc

# Your own .proto file or directory of .proto files
fern init --proto ./proto
```

`--grpc` creates a sample unary service. `--proto` takes a local path, copies the `.proto` files into `fern/proto/`, and adds the `google/api` protos if they're imported and missing. `target` is set to the file that defines a `service`; when several files define one, `target` is omitted and every file is compiled. The two flags can't be combined with each other or with `--openapi`, `--fern-definition`, `--docs`, `--mintlify`, or `--readme`. See the [generators.yml reference](/learn/api-definitions/grpc/generators-yml-reference) for configuration options.

Then generate the SDK:

```bash title="terminal"
fern generate
```

`fern generate` compiles the `.proto` files on your machine, downloading [buf](https://buf.build/docs/installation) the first time, and builds the SDK in Fern's cloud. The SDK is written to `sdks/csharp`.

### Supported proto features

The C# SDK supports unary RPCs and standard protobuf messages, with these exceptions:

- **Streaming RPCs** (server, client, and bidirectional) aren't supported yet.
- **`google.protobuf.Struct` and `google.protobuf.FieldMask`** fields aren't supported yet. Use a `map<string, string>` or `string` field instead.
- **A service can't share its name with the first part of `csharp_namespace`.** For example, rename `service UserService` or change `option csharp_namespace = "UserService.V1";`.

`fern init --proto` warns you if your files use streaming RPCs, `Struct`, or `FieldMask`.

### Other languages

Only the C# SDK contains a gRPC client. For other languages, Fern converts the proto to OpenAPI and generates a REST client that follows the `google.api.http` routes. These clients send HTTP/JSON, which a native gRPC server doesn't accept, so they require a gateway in front of the server that translates HTTP/JSON to gRPC, such as [grpc-gateway](https://github.com/grpc-ecosystem/grpc-gateway) or Envoy's gRPC-JSON transcoder. Streaming RPCs are generated as plain `POST` methods and don't stream.
