---
title: Timeout settings
description: Configure timeout settings for methods using `x-fern-timeout` extension
---

Configure timeout settings for methods:

```yaml title="openrpc.yml" {6-8}
methods:
  - name: report.generate
    summary: Generate large report (may take time)
    params:
      - name: reportConfig
        schema:
          $ref: '#/components/schemas/ReportConfig'
    x-fern-timeout:
      seconds: 300
      description: "Report generation can take up to 5 minutes"
    result:
      name: report
      schema:
        $ref: '#/components/schemas/Report'
```
