---
title: Export from Fern Definition to OpenAPI
description: Export your Fern Definition files to OpenAPI using Fern's CLI or generator.
---

There are two ways to export your Fern Definition to OpenAPI 3.1:

## Using the CLI (Recommended)

The simplest way to export your Fern Definition to OpenAPI is using the `fern export` command:

<CodeBlock title="Terminal">
```bash
fern export --format openapi
```
</CodeBlock>

By default, this will output OpenAPI YAML files to `./generated/openapi`. You can customize the output path:

<CodeBlock title="Terminal">
```bash
fern export --format openapi --output ../my-openapi-spec
```
</CodeBlock>

## Using the Generator

Alternatively, you can use the `fern-openapi` generator by updating your `generators.yml` file:

<CodeBlock title="generators.yml">
```yaml
- name: fernapi/fern-openapi
  version: 0.0.31
  config:
    format: yaml # options are yaml or json
  output:
    location: local-file-system
    path: ../openapi # relative path to output location
```
</CodeBlock>

Then run:

<CodeBlock title="Terminal">
```bash
fern generate
```
</CodeBlock>

Both approaches prevent lock-in to the Fern Definition format by allowing you to export to OpenAPI at any time. This lets you:
- Switch to using OpenAPI if needed
- Use your API definition with OpenAPI tools
- Share OpenAPI specs with third parties

The exported OpenAPI 3.1 files will maintain all your API definitions, types, and documentation while following OpenAPI best practices.
