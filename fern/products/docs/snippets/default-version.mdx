<Note title="Default versions" id="default-version">

  Versions appear in a dropdown on your site in the order listed in `docs.yml`. The default version uses unversioned paths like `example.com/getting-started`, and other versions use versioned paths like `example.com/v2/getting-started`. The first version in your `versions` list is the default unless another version [sets `default: true`](/learn/docs/configuration/versions#set-the-default-version).

  Fern automatically handles version routing by [redirecting](/learn/docs/seo/redirects) broken versioned links to the default version. Canonical URLs point to the unversioned path to consolidate SEO signals. To override this for version-specific pages, see [SEO metadata](/learn/docs/seo/setting-seo-metadata#canonical-url).
</Note>
