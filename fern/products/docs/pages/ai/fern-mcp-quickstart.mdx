This guide connects your coding agent to [Fern's MCP server](/learn/docs/ai-features/fern-mcp-servers) from scratch. When you're done, your agent can look up `docs.yml` syntax, components, and CLI commands, and read your sites, deployments, and reader activity without leaving your terminal.

## Prerequisites

- A Fern account. Sign up or log in at the [Fern Dashboard](https://dashboard.buildwithfern.com/).
- The Fern CLI:

  ```bash
  npm install -g fern-api
  ```

<Steps>
  <Step title="Log in">

  Authenticate the CLI with your Fern account:

  ```bash
  fern login
  ```

  </Step>
  <Step title="Install the MCP server">

  Register Fern's MCP server with your coding agent:

  ```bash
  fern mcp install
  ```

  If your Fern account belongs to more than one organization, pass `--org` to pick the one to connect:

  ```bash
  fern mcp install --org <org>
  ```

  Agents load MCP servers at startup, so a server registered mid-session becomes callable in the next session.

  </Step>
  <Step title="Verify the connection">

  Start a new session in your coding agent and ask it something only your Fern data can answer, for example:

  - "Which of my docs sites had the most traffic this week?"
  - "What's the status of my latest docs deployment?"
  - "How do I add a tab to `docs.yml`?"

  A working connection answers with your organization's data. The server returns only what your Fern account can already see.

  </Step>
</Steps>
