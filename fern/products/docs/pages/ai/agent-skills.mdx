[Agent skills](https://www.skills.sh) are reusable instruction sets that teach coding agents (Claude Code, Cursor, Codex, Copilot, and others) how to work in a specific tool or framework. Fern publishes official skills in the [`fern-api/skills`](https://github.com/fern-api/skills) repository so agents can follow Fern conventions without custom prompting.

## Install

Install all Fern skills into your project with one command:

```bash
npx skills add fern-api/skills --all
```

The CLI detects your agent and writes skills to the correct location (`.claude/skills/`, `.agents/skills/`, etc.).

To install a single skill, pass `--skill`:

```bash
npx skills add fern-api/skills --skill fern-docs
```

Add `-g` to install globally instead of into the current project.

## Available skills

| Skill | Description |
|-------|-------------|
| `fern-docs` | Building Fern docs sites: `docs.yml` configuration, navigation, MDX pages, custom components, landing pages, and changelog entries. |

Once installed, agents load the relevant skill automatically when the task matches. Asking an agent to "add a changelog entry" or "build out the docs" pulls in `fern-docs` without additional configuration.

## How skills work

Skills use progressive disclosure. The agent sees only a short name and description up front, then loads the full skill content when the current task matches. A request to write a docs page loads `fern-docs`; an unrelated coding task loads nothing.

Each skill contains:

- **When to use it** and what it covers
- **The workflow to follow**, including file conventions, config patterns, and common footguns
- **Curated links** to the relevant Fern documentation pages

Skills complement Fern's other AI access methods. While [`llms.txt`](/learn/docs/ai-features/llms-txt) and [Markdown access](/learn/docs/ai-features/markdown) give agents raw documentation content, and the [MCP server](/learn/docs/ai-features/mcp-server) provides a query interface, skills give agents opinionated procedural guidance for specific tasks.
