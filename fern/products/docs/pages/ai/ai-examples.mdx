---
title: AI-generated examples
description: Fern no longer generates API examples with AI. Existing ai_examples_override.yml files still apply, and new examples are defined in your API definition.
---

Fern no longer generates request and response examples with AI. Starting with Fern CLI version 5.147.4, `fern generate --docs` doesn't call the AI example service while publishing. The `ai-examples` setting in `docs.yml` (`enabled` and `style`) is still accepted so existing configurations validate, but it has no effect.

Examples that were already generated keep appearing in your [API Reference](/learn/docs/api-references/overview). Fern still applies any `ai_examples_override.yml` file next to an OpenAPI spec. The file uses the [`x-fern-examples`](/learn/api-definitions/openapi/extensions/request-response-examples) format, so you can edit or extend it by hand. If `ai_examples_override.yml` is listed in `.gitignore`, it's no longer regenerated during publishing; commit the file to keep its examples.

## Add new examples

Define examples in your API definition:

- OpenAPI `example` and `examples` fields on parameters, request bodies, and responses.
- [`x-fern-examples`](/learn/api-definitions/openapi/extensions/request-response-examples) to associate request and response pairs or define multiple named examples for an endpoint.

To make examples from `ai_examples_override.yml` or another overrides file portable to non-Fern OpenAPI tools, use [`fern api enrich`](/learn/cli-api-reference/cli-reference/general-commands#fern-api-enrich) to merge them into native OpenAPI example fields.
