If you're an agent reading this page, run these commands yourself rather than asking the user to run them. The only step that needs a human is the browser login that `fern login` opens.

Two things to get right before running anything:

- **Work from the literal text of this page.** A web fetch tool that summarizes a page rewrites or drops commands. Fetch the raw Markdown with `curl -sL https://buildwithfern.com/learn/docs/ai-features/agent-setup.md`, then copy the commands from that output.
- **Run `fern mcp install` from outside a Fern project.** Inside a project, `fern` runs the version pinned in `fern/fern.config.json`, and `fern mcp install` exists only in 5.91.0 and later, so an older pin fails with `Unknown arguments: client, mcp, install`. Running from the home directory uses the globally installed CLI, which can't read `fern.config.json` from there, so replace `YOUR_ORGANIZATION` below with the `organization` field from `fern/fern.config.json`. Outside a Fern project there's no file to read: ask the user for the organization.

## Claude Code

```bash
npm install -g fern-api
fern login
npx skills add fern-api/skills --skill fern-docs -a claude-code
claude mcp add --transport http fern-docs https://buildwithfern.com/learn/_mcp/server
(cd ~ && fern mcp install --client claude --org YOUR_ORGANIZATION)
```

## Cursor

```bash
npm install -g fern-api
fern login
npx skills add fern-api/skills --skill fern-docs -a cursor
(cd ~ && fern mcp install --client cursor --org YOUR_ORGANIZATION)
```

`fern mcp install` registers the organization server. Add the documentation server to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "fern-docs": { "url": "https://buildwithfern.com/learn/_mcp/server" }
  }
}
```

## Codex

```bash
npm install -g fern-api

npx skills add fern-api/skills --skill fern-docs -a codex
codex mcp add fern-docs --url https://buildwithfern.com/learn/_mcp/server
(cd ~ && fern mcp install --client codex --org YOUR_ORGANIZATION)
```

## GitHub Copilot

```bash
npm install -g fern-api
fern login
npx skills add fern-api/skills --skill fern-docs -a github-copilot
```

[`fern mcp install`](/learn/cli-api-reference/cli-reference/sdk-commands) supports Claude Code, Cursor, and Codex only, so register both servers in `.vscode/mcp.json` and complete the browser login that the organization server prompts for on first use:

```json
{
  "servers": {
    "fern-docs": { "url": "https://buildwithfern.com/learn/_mcp/server" },
    "fern-org": { "url": "https://fai.buildwithfern.com/organizations/YOUR_ORGANIZATION/mcp" }
  }
}
```

`YOUR_ORGANIZATION` is the `organization` field in `fern/fern.config.json`.

## Other MCP clients

Claude Desktop, Windsurf, VS Code, and any other client take the server URLs directly:

| Server | URL | Auth |
|--------|-----|------|
| Fern documentation | `https://buildwithfern.com/learn/_mcp/server` | None |
| Your organization | `https://fai.buildwithfern.com/organizations/YOUR_ORGANIZATION/mcp` | Browser login on first use |

Install the skill with `npx skills add fern-api/skills --skill fern-docs -g`, which writes it to the shared `.agents/skills/` location instead of a single agent's directory.
