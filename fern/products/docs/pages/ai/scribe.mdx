Fern Scribe is a technical writing agent that keeps your docs aligned as your product evolves. You can request documentation updates by tagging `@Scribe`, and it drafts targeted edits to your documentation via GitHub pull requests.

Scribe understands Fern components and your custom styling, learns your writing style, and makes edits that fit your existing content organization. It responds to PR comments, including feedback from automated review tools. You can customize its behavior to match your team's style guide and workflow.

## How to use Fern Scribe

Install the Slack app and tag `@Scribe` in any channel to request documentation updates. When you mention Scribe, it analyzes your request and creates a pull request with the suggested documentation changes.

Scribe only responds to messages where it's directly tagged with `@Scribe`.


## Setup

To start using Fern Scribe, add it to your Slack workspace and invite it to channels where your team discusses documentation. To install Fern Scribe in your organization's Slack workspace, you must be a Slack admin.

<Steps>
<Step title="Get your unique install link">

Use the [API Explorer](/learn/ask-fern/api-reference/slack-scribe/get-scribe-slack-install-link) to get a unique Slack installation link for your organization. Provide:
- Your Fern token
- Your GitHub repository in `owner/repo` format (e.g., `acme/docs`)

You can alternatively use this cURL request:
```bash
curl -G https://fai.buildwithfern.com/scribe/slack/get-install \
     -H "Authorization: Bearer <YOUR_FERN_TOKEN>" \
     --data-urlencode github_repo=<OWNER/REPO>
```

Follow the URL returned in the response.

</Step>
<Step title="Add to your workspace">
You'll be redirected to Slack to authorize Fern Scribe. Select the workspace where you want to add Scribe and click **Allow**.

</Step>
<Step title="Add to channels">

Once installed, add Scribe to Slack channels where your team discusses documentation. Team members can then tag `@Scribe` to request documentation updates.

</Step>
</Steps>

## Usage

In any channel where Scribe has been added, tag `@Scribe` and describe the documentation change you need. Scribe will analyze your request and create a pull request to your connected GitHub repository.

Example requests:
- `@Scribe add a section about authentication to the getting started guide`
- `@Scribe update the API reference to include the new /plants endpoint`
- `@Scribe fix the typo in the installation instructions`

Scribe will respond in the thread with a link to the pull request it created.
