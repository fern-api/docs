Fern Autopilot is a GitHub App that automates SDK generation and configuration management for your Fern projects. When you push changes to your repository, Autopilot automatically triggers SDK generation and keeps your CLI and generator versions up to date.

## How it works

When you install Fern Autopilot on your repository, it monitors your Fern configuration repository for changes. On each push to the default branch, Autopilot:

1. **Detects configuration changes** - Identifies updates to your API definition or `generators.yml` files
2. **Triggers SDK generation** - Automatically runs SDK generation for all configured generators
3. **Reports status** - Creates GitHub check runs showing generation progress and results
4. **Manages versions** - Optionally keeps your Fern CLI and generator versions up to date

## Features

Fern Autopilot provides the following capabilities:

**Automatic SDK generation** triggers generation for all configured SDK generators whenever you push changes to your default branch. Results appear as GitHub check runs on your commits, showing success or failure status for each generator.

**CLI version updates** automatically creates pull requests to update your Fern CLI version when new releases are available, keeping your configuration current with the latest features and fixes.

**Generator version updates** monitors your configured generators and creates pull requests to update them to newer versions, ensuring your SDKs benefit from the latest improvements.

**Preview generation** generates SDK previews for version bump pull requests, allowing you to review changes before merging.

## Setup

Once you have access to Fern Autopilot, installation involves:

1. Installing the Fern Autopilot GitHub App on your organization
2. Granting access to your Fern configuration repositories
3. Configuring which features to enable for your organization

After installation, Autopilot begins monitoring your repositories and automatically triggers SDK generation on pushes to the default branch.

## Viewing generation results

SDK generation results appear as GitHub check runs on your commits. Each check run shows:

- Overall generation status (success, failure, or in progress)
- Individual results for each configured generator
- Detailed output logs for troubleshooting failures

You can view these results directly on your commit or pull request in GitHub.
