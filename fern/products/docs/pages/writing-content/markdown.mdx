# Images

Images can be added in multiple ways:

## Markdown Syntax

Use standard Markdown syntax for basic images:

```md
![Alt text](./path/to/image.png)
```

## HTML Tags

For more control over image display, use HTML img tags:

```html
<img src="./path/to/image.png" alt="Description" />
```

## Image Options

### Disabling Zoom

By default, images are zoomable when clicked. To disable zoom functionality, add the `noZoom` attribute:

```html
<img src="./path/to/image.png" alt="Description" noZoom />
```

### Responsive Images

Images automatically scale to fit their container width while maintaining aspect ratio. You can further control sizing using standard HTML attributes:

```html
<img src="./path/to/image.png" alt="Description" width="500" />
```

### CSS Classes

Apply CSS classes to control image styling:

```html
<img src="./path/to/image.png" alt="Description" className="rounded shadow" />
```

## Image Best Practices

- Always include descriptive alt text for accessibility
- Use appropriate image formats (PNG for screenshots, SVG for icons)
- Optimize images for web use to reduce load times
- Consider providing dark mode alternatives for interface screenshots
- Keep image dimensions reasonable for documentation viewing
