Fern documentation is configured at two levels: **site-level** settings in `docs.yml` that apply globally, and **page-level** settings in frontmatter that control individual pages.

## Site-level configuration

The `docs.yml` file controls your site's appearance, structure, and behavior. Here is a minimal example:

```yaml docs.yml
# yaml-language-server: $schema=https://schema.buildwithfern.dev/docs-yml.json
navigation:
  - section: Home
    contents:
      - page: Introduction
        path: ./intro.mdx
      - folder: ./auth
        title: Authentication
  - api: API Reference
navbar-links:
  - type: secondary
    text: Contact support
    url: https://example.com/support
  - type: primary
    text: Login
    url: https://example.com/login
```

### Organizing content beyond basic navigation

For larger documentation sites, Fern provides three features that layer on top of sections, pages, and folders:

- **[Tabs](/learn/docs/configuration/tabs)** — Group sections of content into switchable tabs (for example, "Guides" and "API Reference"). Use tab variants to show different content perspectives within a single tab.
- **[Versions](/learn/docs/configuration/versions)** — Add a dropdown version selector when you maintain multiple versions of your documentation. Each version can have its own navigation, tabs, and API references.
- **[Products](/learn/docs/configuration/products)** — Add a product switcher for multi-product documentation sites. Each product can contain its own versions, tabs, sections, and pages.

## Page-level configuration

Use [frontmatter](/learn/docs/configuration/page-level-settings) in individual `.mdx` files to override site-level defaults for a specific page. Frontmatter controls titles, meta descriptions, slugs, layout, availability badges, and visibility of page elements like the table of contents.

## Which configuration level to use

- **Branding, colors, layout** — Set once in `docs.yml` under [site-level settings](/learn/docs/configuration/site-level-settings).
- **Sidebar structure** — Define in [navigation](/learn/docs/configuration/navigation). Use [tabs](/learn/docs/configuration/tabs) to group sections, [versions](/learn/docs/configuration/versions) for version-specific content, or [products](/learn/docs/configuration/products) for multi-product sites.
- **Per-page overrides** — Use [frontmatter](/learn/docs/configuration/page-level-settings) to customize titles, descriptions, layouts, or hide elements on individual pages.
