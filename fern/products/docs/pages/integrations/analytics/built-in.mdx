title: Built-in analytics

---

Every Fern documentation site includes a built-in analytics dashboard. Open the **Web Analytics** view in the [Fern Dashboard](https://dashboard.buildwithfern.com) to see traffic and engagement metrics for your site without adding any configuration or third-party account.

<Note>
Built-in analytics is separate from [forwarding analytics events](/learn/docs/integrations/overview) to third-party providers. The built-in dashboard works automatically, whereas providers like Google Analytics, PostHog, Segment, and Mixpanel receive events only after you configure them under `analytics:` in `docs.yml`. See the [analytics events reference](/learn/docs/integrations/analytics/events) for the full list of forwarded events.
</Note>

## View your analytics

1. Open the [Fern Dashboard](https://dashboard.buildwithfern.com) and select your docs site.
2. Go to the **Web Analytics** view.
3. Select a time period (7, 14, 30, 90, or 180 days). Use **Refresh** to recompute the metrics from the most recent data.

## Available metrics

| Metric | Description |
| --- | --- |
| Overview | Page views, unique visitors, and sessions over the selected period. |
| Top pages | Your most viewed pages. |
| Top countries | Geographic distribution of visitors. |
| Traffic channels | Traffic grouped by source, such as Direct, Organic, and Referral. |
| Device types | Breakdown across Desktop, Mobile, and Tablet. |
| Referring domains | External sites driving traffic to your docs. |
| LLM file views | Access to `llms.txt` and Markdown versions of your pages. |
| API Explorer requests | Requests sent from the [API Explorer](/learn/docs/api-references/api-explorer), with success and failure counts. |
| LLM bot traffic | AI crawler access, grouped by provider. |

<Note>
Analytics data reflects a delay of roughly three to four hours as events replicate from the underlying event pipeline. Recent traffic may not appear immediately.
</Note>
