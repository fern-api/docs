## What is Postman?

[Postman](https://www.postman.com/) is an application for easy RESTful API exploration. You can use Postman to test API calls without having to write code. You can save credentials to make it easier to test API calls in various environments, such as sandbox and production.

Postman collection generation is included with Fern Docs, allowing you to generate a collection full of example requests and responses and publish it directly to Postman. The configuration for the Postman generator lives in your fern folder, in a file called [`generators.yml`](/sdks/overview/project-structure#generatorsyml).
