[Postman](https://www.postman.com/) is a popular API platform that lets developers test, document, and share API requests. Postman collection generation is included with Fern Docs, allowing you to generate a collection full of example requests and responses and publish it directly to Postman. The configuration for the Postman generator lives in your fern folder, in a file called [`generators.yml`](/sdks/overview/project-structure#generatorsyml).
