## Publish Postman collections to Fern

You can generate a Fern Docs site directly from your Postman collection. Fern automatically creates an API Reference from your collection with request details, sample code, and an interactive API Explorer. You can also add guides, tutorials, and other content alongside the reference, and customize branding such as your domain, logo, and colors.

See [Postman's Fern integration docs](https://learning.postman.com/docs/fern/overview) for setup instructions.

### Claim a site generated by Postman

Postman generates a Fern Docs site for every Postman team with public workspaces, on any plan. The site covers the whole team rather than a single collection, with a welcome page, a quickstart, and an API Reference built from the team's public collections. It's live at `<team-name>.docs.buildwithfern.com` before anyone claims it, and it syncs with the team's public collections once every 24 hours, before and after it's claimed.

A team admin claims the site once for the whole team, from the **Publish docs** button on any collection's **Overview** tab in Postman, then signs in with their Postman account. The admin who claims the site becomes the admin of the Fern organization and can [invite the rest of the team](/learn/dashboard/configuration/permissions). This is separate from [claiming a guest session](/learn/docs/getting-started/try-without-account#claim-the-work), which moves a site or SDK published without a Fern account into your organization.

Postman's docs cover the [steps to claim your team's site](https://learning.postman.com/docs/fern/document-a-collection#claim-your-teams-fern-docs-site) and [fixes for claim errors](https://learning.postman.com/docs/fern/document-a-collection#troubleshoot-claiming), such as an expired claim link or a sign-in with a different Postman account.


## Fern-to-Postman generator (deprecated)

Fern's Postman collection generator is no longer actively maintained. To get your API endpoints into Postman, import your OpenAPI specification directly. See [Postman's OpenAPI import docs](https://learning.postman.com/docs/integrations/available-integrations/working-with-openAPI/) for instructions.
