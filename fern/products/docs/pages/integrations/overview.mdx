## Enable analytics

You can define your analytics configuration in `docs.yml`. You only need to include entries for the platforms you want to connect.

```yaml docs.yml
analytics:
  posthog:
    api-key: ${POSTHOG_API_KEY}
    endpoint: https://self.hosted.posthog.com/
  segment:
    write-key: ${SEGMENT_WRITE_KEY}
  intercom:
    app-id: ${INTERCOM_APP_ID}
    endpoint: https://intercom.custom-instance.com/
  fullstory:
    org-id: ${FULLSTORY_ORG_ID}
```

### Environment variables

If your docs configuration is public, don't add secret values directly to `docs.yml`.
Instead, reference an environment variable by using the syntax `${VARIABLE_NAME}`.

<Note>
If you are using GitHub Workflows to trigger docs generation, you must make sure that the environment variables
are available during the workflow run.

```yaml {4}
- name: Publish Docs
  env:
    FERN_TOKEN: ${{ secrets.FERN_TOKEN }}
    POSTHOG_API_KEY: ${{ secrets.POSTHOG_PROJECT_API_KEY }}
  run: |
    npm install -g fern-api
    fern generate --docs
```

</Note>


## Connect other integrations via custom JavaScript

<Markdown src="/snippets/enterprise-plan.mdx"/>

You can integrate any third-party tool that supports HTML tag-based installation — including analytics platforms, session recording tools, support widgets, and more — using [custom JavaScript](/docs/customization/custom-css-js#custom-javascript).

To add a tool, paste its embed snippet (typically a `<script>` tag provided by the vendor) into your [custom JS configuration](/docs/customization/custom-css-js#custom-javascript). This works with tools like:

- **Analytics:** Google Analytics, Segment, Mixpanel, PostHog, Amplitude
- **Session recording:** Hotjar, FullStory, LogRocket
- **Support and chat:** Intercom, Zendesk, Crisp
- **Tag managers:** Google Tag Manager (which can then load additional tools)

If a tool can be installed by adding a script tag to an HTML page, it can be integrated with your Fern docs using this method.

For example, to add Google Tag Manager, paste its embed snippet into your `custom.js` file:

<CodeBlock title="custom.js">
```javascript
// Google Tag Manager
(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-XXXXXX');
```
</CodeBlock>

Then reference the file in your `docs.yml`:

<CodeBlock title="docs.yml">
```yaml
js: ./custom.js
```
</CodeBlock>

For setup details and loading strategies, see [Custom JavaScript](/docs/customization/custom-css-js#custom-javascript).
