The `navigation` key in `docs.yml` is the foundation of your Fern documentation site's structure. It controls what appears in the sidebar, how content is organized, and how readers move through your docs.

## How navigation is configured

All navigation is defined in `docs.yml`. The `navigation` key accepts a list of sections, tabs, or other navigation elements that make up your sidebar.

```yaml docs.yml
navigation:
  - section: Getting Started
    contents:
      - page: Introduction
        path: ./pages/intro.mdx
      - page: Quickstart
        path: ./pages/quickstart.mdx
  - api: API Reference
```

For sites with tabs, the `navigation` key maps each tab to its own layout:

```yaml docs.yml
tabs:
  guides:
    display-name: Guides
    icon: fa-regular fa-book
  api:
    display-name: API Reference
    icon: fa-regular fa-puzzle

navigation:
  - tab: guides
    layout:
      - section: Getting Started
        contents:
          - page: Introduction
            path: ./pages/intro.mdx
  - tab: api
    layout:
      - api: API Reference
```

## Key concepts

- **Sections** group related pages together in the sidebar and can be nested for multi-level hierarchies.
- **Pages** are individual `.md` or `.mdx` files referenced by path.
- **Folders** let Fern auto-discover all Markdown files in a directory.
- **Tabs** divide your docs into distinct top-level areas.
- **Versions** and **Products** add switchers for multi-version or multi-product documentation.
