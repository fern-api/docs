---
title: Add an announcement banner to your docs
subtitle: Prominently highlight new features, updates, or important information
---

An announcement banner is a great way to draw attention to new features and product launches. When configured, the announcement bar appears at the top of your docs site. After the user dismisses the bar, it will reappear the next time you update the announcement.

```yaml docs.yml
announcement:
    message: "🚀 New feature: Announcements are available! (<a href=\"https://buildwithfern.com/learn/docs/building-your-docs/announcements\" target=\"_blank\">Learn more</a>) 🚀"
```

Markdown and HTML is supported in the announcement message. You can include links, images, and other formatting. [Custom CSS](/docs/customization/custom-css-js#custom-css) can be used to customize the style of the announcement.

## Product and version-specific announcements

Announcements can be configured at multiple levels to target specific products or versions. The override hierarchy is:

1. **Version-level** (always respected if defined)
2. **Product-level** (if defined, used when no version-level announcement exists)
3. **Config-level** (fallback when no product or version-level announcement is defined)

### Version-level announcements

To configure an announcement for a specific version, add the `announcement` property to the version's configuration file:

```yaml version-docs.yml
announcement:
    message: "This version is deprecated. Please upgrade to v2."

navigation:
  - page: Getting started
    path: ./getting-started.mdx
```

### Product-level announcements

To configure an announcement for a specific product, add the `announcement` property to the product's configuration file:

```yaml product-docs.yml
announcement:
    message: "New SDK features available! Check out the changelog."

navigation:
  - page: Overview
    path: ./overview.mdx
```

### Config-level announcements

Config-level announcements are defined in the root `docs.yml` file and serve as the default for all products and versions:

```yaml docs.yml
announcement:
    message: "Welcome to our documentation!"

products:
  - display-name: API Reference
    path: ./products/api/api.yml
```
