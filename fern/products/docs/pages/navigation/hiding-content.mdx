--- 
title: Hiding content in your site
---

If you would like to _hide_ a section, page, or version, you can add `hidden: true` to its configuration. Hidden content is accessible by URL only. 

<Tabs>
<Tab title="Hidden page">
```yaml title="docs.yml"
navigation: 
  - section: Introduction
    contents: 
      - page: My Page
        path: ./pages/my-page.mdx
      - page: Hide and Seek
        hidden: true
        path: ./pages/hide-and-seek.mdx
  - api: API Reference
```

</Frame>
</Tab>
<Tab title="Hidden section">
```yaml title="docs.yml"
navigation: 
  - section: Introduction
    contents: 
      - page: My Page
        path: ./pages/my-page.mdx
  - api: API Reference
  - section: Hidden Section
    hidden: true
    contents: 
      - page: Hide and Seek
        path: ./pages/hide-and-seek.mdx
```

<img src="hidden-section.png" alt="A site with a hidden section" />
</Frame>
</Tab>
<Tab title="Hidden version">
```yaml title="docs.yml"
versions:
  - display-name: Latest
    path: ./versions/latest.yml
  - display-name: v2
    path: ./versions/v2.yml
  - display-name: v1 (Legacy)
    path: ./versions/v1.yml
    hidden: true
```

Hidden versions will not appear in the version selector dropdown, site search results, or search engine indexes, but users can still access them directly via URL. The default version (the first version in your `versions` list) cannot be hidden.

Learn more about [versioning](/learn/docs/configuration/versions).
</Tab>
</Tabs>
