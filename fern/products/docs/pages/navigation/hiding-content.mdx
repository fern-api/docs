--- 
title: Hiding content in your site
---

<Markdown src="/snippets/agent-directive.mdx"/>

Fern provides two different ways to hide content, depending on what you want to hide it from:

| Method | Where to set it | What it does |
|--------|----------------|-------------|
| `hidden: true` | Navigation config (`docs.yml`) | Hides the page from the sidebar. The page is still accessible by URL and indexed by search engines. |
| `noindex: true` | [Page frontmatter](/learn/docs/configuration/page-level-settings#noindex) | Hides the page from search engine results and [llms.txt](/learn/docs/ai-features/llms-txt) endpoints. The page still appears in the sidebar. |

<Note>
These two options serve different purposes and can be used together. For example, you might want an internal reference page that's hidden from both navigation and search engines by setting `hidden: true` in `docs.yml` and `noindex: true` in the page's frontmatter.
</Note>

## Hide from navigation

To hide a section, page, or version from the sidebar, add `hidden: true` to its configuration in `docs.yml`. Hidden content is still accessible by URL.

<Tabs>
<Tab title="Hidden page">
```yaml title="docs.yml"
navigation: 
  - section: Introduction
    contents: 
      - page: My Page
        path: ./pages/my-page.mdx
      - page: Hide and Seek
        hidden: true
        path: ./pages/hide-and-seek.mdx
  - api: API Reference
```

<Frame>

</Frame>
</Tab>
<Tab title="Hidden section">
```yaml title="docs.yml"
navigation: 
  - section: Introduction
    contents: 
      - page: My Page
        path: ./pages/my-page.mdx
  - api: API Reference
  - section: Hidden Section
    hidden: true
    contents: 
      - page: Hide and Seek
        path: ./pages/hide-and-seek.mdx
```

<Frame>
<img src="hidden-section.png" alt="A site with a hidden section" />
</Frame>
</Tab>
<Tab title="Hidden version">
```yaml title="docs.yml"
versions:
  - display-name: v3
    path: ./versions/v3.yml
  - display-name: v2
    path: ./versions/v2.yml
  - display-name: v1 (Legacy)
    path: ./versions/v1.yml
    hidden: true
```

<Info>The default version (the first version in your `versions` list) can't be hidden.</Info>
</Tab>
</Tabs>

## Hide from search engines

To prevent a page from being indexed by search engines and excluded from `llms.txt` endpoints, add `noindex: true` to the page's [frontmatter](/learn/docs/configuration/page-level-settings#noindex). The page remains visible in the sidebar and accessible by URL.

```mdx title="my-page.mdx"
---
title: My internal page
noindex: true
---
```

You can also use `nofollow: true` to prevent search engines from following links on a page. For more details on SEO-related frontmatter options, see [SEO metadata](/learn/docs/configuration/page-level-settings#seo-metadata).
