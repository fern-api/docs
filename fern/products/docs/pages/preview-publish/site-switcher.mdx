On a [multi-source](/learn/docs/preview-publish/multi-source) domain, each sub-path is a separate docs site published from its own repository. The site switcher adds a dropdown to the header that lists the other sites on the domain, so readers can jump from `/product-a` to `/product-b` without a hand-maintained list of links in every repository.

## How it works

Fern builds the list of sites for you. When a repository publishes to a multi-source domain, Fern records every live site on that domain, and that snapshot is what the switcher displays. `theme.site-switcher` only controls whether the switcher appears and how it presents the sites.

- **Labels** come from each site's `title` in `docs.yml`. Sites without a title use a label generated from the last segment of the basepath (`/sdk-user-guide` becomes "Sdk User Guide").
- **Nested sites** such as `/seeds/sunflower` are listed directly after their parent (`/seeds`). If the parent isn't published, the nested site is listed as a top-level entry.
- **The root site** at `/`, if any, isn't listed. When a reader is on the root site, the switcher reads "Home".
- **Selecting a site** opens that site's homepage (`/{basepath}/`). Unlike the [product switcher](/learn/docs/configuration/products), it doesn't try to keep the reader on the same page, because sibling sites have unrelated page paths.
- The switcher renders only when at least two sites would be listed, and it never appears on preview URLs.

<Note>
The list of sites is a snapshot taken when each site publishes. When a new site joins the domain, existing sites list it after their next publish.
</Note>

## Enable the site switcher

<Steps>

<Step title="Set up multi-source docs">

Publish each sub-path from its own `fern/` project with `multi-source: true`, as described in [Multi-source docs](/learn/docs/preview-publish/multi-source).

</Step>

<Step title="Add `theme.site-switcher` to your configuration">

Because `theme` belongs to the [global theme](/learn/docs/customization/global-themes#what-the-theme-controls), set `site-switcher` in the control repository's `docs.yml`, then re-export and re-upload the theme. Every site that uses the theme picks it up on its next publish:

```yaml control-repo/fern/docs.yml
theme:
  site-switcher:
    enabled: true
```

```bash
fern docs theme export
fern docs theme upload --name my-org-theme
```

Sites that don't use a global theme can set the same block in their own `docs.yml`.

</Step>

<Step title="Republish each site">

Run `fern generate --docs` from each source repository so its snapshot picks up the setting and the current list of sites.

</Step>

</Steps>

## Customize the list

```yaml docs.yml
theme:
  site-switcher:
    enabled: true
    order:
      - /dynamo
      - /brev
      - /nemo
    hide:
      - /internal-playground
    labels:
      /holoscan/sdk-user-guide: Holoscan SDK
    show-products: true
```

<ParamField path="theme.site-switcher.enabled" type="boolean" required={false} default="false" toc={true}>
  Show the site switcher in the header.
</ParamField>

<ParamField path="theme.site-switcher.order" type="list of strings" required={false} toc={true}>
  Basepaths to list first, in the given order. The remaining sites follow alphabetically by label. Nested sites follow the same rule under their parent.
</ParamField>

<ParamField path="theme.site-switcher.hide" type="list of strings" required={false} toc={true}>
  Basepaths to leave out of the switcher. Hiding a basepath also hides every site nested beneath it.
</ParamField>

<ParamField path="theme.site-switcher.labels" type="map of strings" required={false} toc={true}>
  Display labels keyed by basepath. Overrides the site's `title`.
</ParamField>

<ParamField path="theme.site-switcher.show-products" type="boolean" required={false} default="false" toc={true}>
  List each site's top-level [products](/learn/docs/configuration/products) indented beneath it. Each product links to its page on that site, or to the product's external link.
</ParamField>

## Place the switcher in a custom header

By default, the site switcher sits in the header ahead of the product and version switchers. If you use a [custom header](/learn/docs/customization/custom-header-footer), render it with `<Fern.SiteSwitcher />` from the `Fern` prop. It renders nothing when the switcher is turned off.

```tsx components/CustomHeader.tsx
export default function CustomHeader({ Fern }) {
  return (
    <header>
      <Fern.Logo />
      <Fern.SiteSwitcher />
      <Fern.ProductSwitcher />
      <Fern.Search />
    </header>
  );
}
```
