---
title: Embedded mode
description: Hide the header, footer, and sidebar when embedding docs in iframes or dashboards
---

Embedded mode strips the header, footer, and sidebar (including navigation and logo) from a Fern Docs site so a page renders as content only. Use it to:

- Surface docs inside a product dashboard or admin panel
- Embed a page in an iframe without the standard navigation chrome
- Render content-only views in another application

Pages served with `embedded=true` omit the `frame-ancestors` Content Security Policy directive, so any origin can load them in an iframe. Without the parameter, only the docs site's own origin and Fern's hosts can frame the page.

## Enable embedded mode

Add the `embedded=true` query parameter to the URL:

<Frame>
    <iframe
    src="https://elevenlabs.io/docs/overview/intro?embedded=true"
    style="width: 100%; height: 500px; border: none; border-radius: 8px;"
  ></iframe>
</Frame>

```jsx HTML
    <iframe
    src="https://elevenlabs.io/docs/overview/intro?embedded=true"
    style="width: 100%; height: 500px; border: none; border-radius: 8px;"
  ></iframe>
```

Embedded mode persists across navigation within a session, so internal links keep it active without the query string on every URL. `?embedded=true` is also required for the embed to work on third-party domains: without it, the page's `frame-ancestors` Content-Security-Policy restricts embedding to `*.buildwithfern.com` hosts, and browsers will block the iframe on any other domain.

## Keep the header, footer, or sidebar

Embedded mode hides the header, footer, and sidebar by default. Add `header=true`, `footer=true`, or `sidebar=true` alongside `embedded=true` to keep that element:

| Parameter | Effect |
|-----------|--------|
| `embedded=true&header=true` | Keeps the header, hides the footer and sidebar |
| `embedded=true&footer=true` | Keeps the footer, hides the header and sidebar |
| `embedded=true&sidebar=true` | Keeps the sidebar, hides the header and footer |
| `embedded=true&header=true&footer=true&sidebar=true` | Keeps all three; the page still allows framing from any origin |

```jsx HTML
<iframe
  src="https://elevenlabs.io/docs/overview/intro?embedded=true&sidebar=true"
  style="width: 100%; height: 500px; border: none; border-radius: 8px;"
></iframe>
```

<Note>
The sidebar only renders when the iframe is at least 1024px wide.
</Note>

## Embed external pages

[Embedding external pages in your docs](/learn/docs/writing-content/markdown-media#external-sites) uses the same `<iframe>` syntax, without `?embedded=true`.
