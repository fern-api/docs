Shakespeare mode is a built-in easter egg that applies a parchment-themed visual style and translates page text into Shakespearean English. When activated, it overrides your site's theme with warm brown tones, swaps fonts to a medieval style, and replaces common words with their Shakespearean equivalents (for example, "you" becomes "thou" and "is" becomes "'tis").

## Activation

Add the `shakespeare=true` query parameter to any documentation URL:

```
https://docs.example.com/getting-started?shakespeare=true
```

Shakespeare mode can also be toggled from the theme selector dropdown in the header, where it appears as a fourth option alongside Light, Dark, and System.

## What it does

When Shakespeare mode is active:

- **Parchment theme** — Overrides CSS design tokens to apply a rustic brown color palette, including background, borders, sidebar, and code blocks. The page is forced into light mode.
- **Text translation** — Visible text is translated client-side using word replacements (for example, "do" becomes "doth", "are" becomes "art"). Code blocks, scripts, SVGs, and form inputs are skipped.
- **Candlelight effect** — A pulsing amber glow appears at the bottom of the viewport.
- **Medieval soundtrack** — A looping audio track plays at low volume with a mute toggle in the banner bar.
- **Banner** — A fixed banner displays at the top of the page with a button to restore the original theme.

## Deactivate

Click the **Restore Original** button in the banner, or select a different theme (Light, Dark, or System) from the theme selector dropdown. The original content, theme, and styling are fully restored.
