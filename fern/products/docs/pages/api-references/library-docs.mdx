---
title: Library docs generator
description: Generate MDX documentation pages from your Python or C++ library source code and include them in your Fern Docs site.
---

<Markdown src="/snippets/agent-directive.mdx"/>

The library docs generator produces MDX documentation pages from your library source code and integrates them into your Fern Docs navigation. It parses your Python or C++ library to generate pages for modules, classes, functions, and types with cross-reference links and hierarchical navigation.

<Note>
This feature is in **Beta** and supports Python and C++ libraries.
</Note>

## Configuration

<Steps>
<Step title="Define your libraries in docs.yml">

Add a `libraries` section at the top level of your `docs.yml`. Each entry defines a library name, source location, output directory, and language.

```yaml docs.yml
libraries:
  plant-sdk:
    input:
      git: https://github.com/acme/plant-sdk-python
    output:
      path: ./static/plant-sdk-docs
    lang: python
```

| Property | Description |
|----------|-------------|
| `input.git` | GitHub URL of the repository containing the library source code. |
| `input.subpath` | Optional path within the repository to the library source (for monorepos). |
| `output.path` | Directory where the generated MDX files are written, relative to the `fern/` directory. |
| `lang` | The language of the library. Supported values: `python`, `cpp`. |

For a monorepo where the library code lives in a subdirectory:

```yaml docs.yml
libraries:
  plant-sdk:
    input:
      git: https://github.com/acme/monorepo
      subpath: packages/plant-sdk
    output:
      path: ./static/plant-sdk-docs
    lang: python
```

</Step>
<Step title="Add a library reference to your navigation">

Add a `library` navigation item that references the library name you defined in the `libraries` section:

```yaml docs.yml {7}
libraries:
  plant-sdk:
    input:
      git: https://github.com/acme/plant-sdk-python
    output:
      path: ./static/plant-sdk-docs
    lang: python

navigation:
  - section: Getting started
    contents:
      - page: Overview
        path: ./pages/overview.mdx
  - library: plant-sdk
```

You can optionally override the display title and URL slug:

```yaml docs.yml
navigation:
  - library: plant-sdk
    title: Plant SDK Reference
    slug: plant-sdk-reference
```

</Step>
<Step title="Generate the library docs">

Run the CLI command to generate MDX files from your library source code:

```bash
fern docs md generate
```

To generate docs for a specific library only:

```bash
fern docs md generate --library plant-sdk
```

The command clones the repository, parses the source code, and writes MDX files and a `_navigation.yml` file to the output directory.

</Step>
<Step title="Preview locally">

Run the local development server to see your library docs alongside the rest of your site:

```bash
fern docs dev
```

The library docs appear as a navigation section with pages for each module, class, function, and type in your library.

</Step>
<Step title="Publish">

When you publish your docs, include a `fern docs md generate` step before `fern generate --docs` to ensure the library documentation is up to date:

```bash
fern docs md generate
fern generate --docs
```

</Step>
</Steps>

## C++ libraries

For C++ libraries, set `lang: cpp`. You can optionally provide a path to a custom Doxyfile:

```yaml docs.yml
libraries:
  plant-core:
    input:
      git: https://github.com/acme/plant-core-cpp
    output:
      path: ./static/plant-core-docs
    lang: cpp
    config:
      doxyfile: ./Doxyfile
```

The generator produces pages for classes, structs, functions, enums, typedefs, and variables, with template parameters, method overload tabs, and hierarchical namespace navigation.

## Multiple libraries

You can define and reference multiple libraries in the same `docs.yml`:

```yaml docs.yml
libraries:
  plant-python-sdk:
    input:
      git: https://github.com/acme/plant-sdk-python
    output:
      path: ./static/python-docs
    lang: python
  plant-core:
    input:
      git: https://github.com/acme/plant-core-cpp
    output:
      path: ./static/cpp-docs
    lang: cpp

navigation:
  - section: SDKs
    contents:
      - library: plant-python-sdk
      - library: plant-core
```

Running `fern docs md generate` processes all libraries in parallel.
