## What's in each section

- **[Generation](/learn/docs/api-references/generate-api-ref)** — Set up API Reference pages for [REST](/learn/docs/api-references/generate-api-ref), [Webhook](/learn/docs/api-references/generate-webhook-ref), [WebSocket](/learn/docs/api-references/generate-websocket-ref), [OpenRPC](/learn/docs/api-references/generate-openrpc-ref), [gRPC](/learn/docs/api-references/generate-grpc-ref), [GraphQL](/learn/docs/api-references/generate-graphql-ref), or [library](/learn/docs/api-references/library-reference) documentation from an OpenAPI spec or Fern Definition.
- **[Customization](/learn/docs/api-references/customize-api-reference-layout)** — [Reorder sections and endpoints](/learn/docs/api-references/customize-api-reference-layout), filter with [audiences](/learn/docs/api-references/audiences), and [write Markdown within your API Reference](/learn/docs/api-references/write-markdown-in-api-reference).
- **[Code exploration](/learn/docs/api-references/sdk-snippets)** — Display [SDK snippets](/learn/docs/api-references/sdk-snippets) or [HTTP snippets](/learn/docs/api-references/http-snippets), and let users make live requests with the [API Explorer](/learn/docs/api-references/api-explorer).

## How it works

Add your API definition to the `/fern` directory and reference it in `docs.yml`:

```yaml docs.yml
navigation:
  - api: API Reference
```

Fern reads your [OpenAPI specification](/learn/api-definitions/openapi/overview) or [Fern Definition](/learn/api-definitions/ferndef/overview) and generates a full API Reference with endpoint documentation, type schemas, and [AI-generated examples](/learn/docs/ai-features/ai-examples). For setup details, see [Generate REST API Reference](/learn/docs/api-references/generate-api-ref).
