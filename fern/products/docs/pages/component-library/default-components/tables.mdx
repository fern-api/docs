---
title: Table
description: Display data in rows and columns using markdown tables with optional sticky headers, search, and pagination.
---


Tables display data in rows and columns using standard markdown syntax. For longer datasets, sticky headers keep column labels visible while scrolling, pagination splits rows across pages, and expandable tables collapse to a preview until expanded.

## Usage

Create tables using standard markdown syntax with pipes (`|`) and hyphens (`-`):

<div className="highlight-frame">
  <div className="highlight-frame-content-not-prose">
  | Plant | Light Requirements | Water |
  |-------|-------------------|-------|
  | Fern | Partial shade | Weekly |
  | Snake Plant | Low to bright indirect | Bi-weekly |
  | Monstera | Bright indirect | Weekly |
  </div>
</div>

```jsx Markdown
| Plant | Light Requirements | Water |
|-------|-------------------|-------|
| Fern | Partial shade | Weekly |
| Snake Plant | Low to bright indirect | Bi-weekly |
| Monstera | Bright indirect | Weekly |
```

## Variants

### Sticky headers

The `<StickyTable>` component adds a fixed header that remains visible while scrolling. Use sticky tables for longer datasets where users need to reference column headers throughout the table.

  | Snake Plant | Low to bright indirect | Bi-weekly |
  | Monstera | Bright indirect | Weekly |
  | Pothos | Low to bright indirect | Weekly |
  | Fiddle Leaf Fig | Bright indirect | Weekly |
  | Peace Lily | Low to medium indirect | Weekly |
  | Rubber Plant | Bright indirect | Weekly |

### HTML paginated tables

Alternatively, add the `paginate` attribute to an HTML table element. Set `pageSize` to control rows per page, and add `expandable` for a **Show all** control. Combine with `searchable` and `sticky` as needed:

```jsx Markdown
<table paginate pageSize={5} className="fern-table">
  ...
</table>
```

```jsx Markdown
<table paginate pageSize={5} expandable searchable sticky className="fern-table">
  ...
</table>
```

## Custom styling

Sticky tables can be styled independently from regular tables. To add custom styling, target the `.fern-table.sticky` selector:

```css
.fern-table.sticky {
  //custom css here
}
```

## Properties

### `<StickyTable>` properties

<ParamField path="children" type="markdown table" required={true}>
  The markdown table to display with sticky headers. The table must be formatted using standard markdown table syntax.
</ParamField>

### `<SearchableTable>` properties

<ParamField path="children" type="markdown table" required={true}>
  The markdown table to display with search functionality. The table must be formatted using standard markdown table syntax.
</ParamField>

<ParamField path="placeholder" type="string" required={false}>
  Custom placeholder text for the search input. Defaults to `"Search..."`.
</ParamField>

### `<StickySearchableTable>` properties

<ParamField path="children" type="markdown table" required={true}>
  The markdown table to display with both sticky headers and search functionality. The table must be formatted using standard markdown table syntax.
</ParamField>

<ParamField path="placeholder" type="string" required={false}>
  Custom placeholder text for the search input. Defaults to `"Search..."`.
</ParamField>

### `<PaginatedTable>` properties

<ParamField path="children" type="markdown table" required={true}>
  The markdown table to paginate. The table must be formatted using standard markdown table syntax.
</ParamField>

<ParamField path="pageSize" type="number" required={false} default="10">
  Number of rows to display per page.
</ParamField>

<ParamField path="expandable" type="boolean" required={false}>
  Collapses the table to a single page with a **Show all** control that expands it to every row.
</ParamField>

<ParamField path="sticky" type="boolean" required={false}>
  Keeps the table header visible while scrolling.
</ParamField>

### `<PaginatedSearchableTable>` properties

<ParamField path="children" type="markdown table" required={true}>
  The markdown table to paginate and filter. The table must be formatted using standard markdown table syntax.
</ParamField>

<ParamField path="pageSize" type="number" required={false} default="10">
  Number of rows to display per page. Pagination applies to the filtered rows.
</ParamField>

<ParamField path="expandable" type="boolean" required={false}>
  Collapses the table to a single page with a **Show all** control that expands it to every matching row.
</ParamField>

<ParamField path="sticky" type="boolean" required={false}>
  Keeps the table header visible while scrolling.
</ParamField>

<ParamField path="placeholder" type="string" required={false}>
  Custom placeholder text for the search input. Defaults to `"Search..."`.
</ParamField>

### HTML `<table>` attributes

<ParamField path="sticky" type="boolean" required={false}>
  When set on an HTML table element, makes the table header sticky during scrolling.
</ParamField>

<ParamField path="searchable" type="boolean" required={false}>
  When set on an HTML table element, adds a search input above the table that filters rows in real-time using case-insensitive substring matching.
</ParamField>

<ParamField path="paginate" type="boolean" required={false}>
  When set on an HTML table element, splits the rows into pages with previous and next controls.
</ParamField>

<ParamField path="pageSize" type="number" required={false} default="10">
  Number of rows to display per page when `paginate` is enabled.
</ParamField>

<ParamField path="expandable" type="boolean" required={false}>
  When set alongside `paginate`, collapses the table to a single page with a **Show all** control.
</ParamField>

<ParamField path="placeholder" type="string" required={false}>
  Custom placeholder text for the search input when `searchable` is enabled. Defaults to `"Search..."`.
</ParamField>

<ParamField path="className" type="string" required={false}>
  CSS class name(s) to apply to the table. Use `fern-table` for default Fern styling.
</ParamField>
