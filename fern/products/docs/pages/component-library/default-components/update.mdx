---
title: Update
description: Add a dated changelog entry with tags inside any page.
---

The `<Update>` component renders one changelog entry inside a regular page: a linkable label, an optional description and tags, and the entry body. Use it for release notes kept on a single page. For a dedicated changelog with one file per entry, use [changelog pages](/learn/docs/configuration/changelogs).

## Usage

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <Update label="2026-10-29" description="v1.2.0" tags={["Feature", "Fix"]}>
      Added bulk plant imports and fixed pagination on large gardens.
    </Update>
  </div>
</div>

```jsx Markdown
<Update label="2026-10-29" description="v1.2.0" tags={["Feature", "Fix"]}>
  Added bulk plant imports and fixed pagination on large gardens.
</Update>
```

## Properties

<ParamField path="label" type="string" required={true}>
  The entry's label, usually a date or version. The label is also the entry's anchor: `label="2026-10-29"` links as `#2026-10-29`.
</ParamField>

<ParamField path="description" type="string" required={false}>
  Text shown under the label.
</ParamField>

<ParamField path="tags" type="string[]" required={false}>
  Tags shown as badges under the label.
</ParamField>

<ParamField path="id" type="string" required={false}>
  A custom anchor that replaces the one derived from `label`.
</ParamField>
