---
title: Mintlify compatibility
description: Fern renders Mintlify components as-is. Learn which work unchanged and how to move aliased ones to Fern names.
---

Fern renders pages written with Mintlify components without changes.

## Components that work as-is

These components have the same name and props in Fern:

`<Accordion>`, `<AccordionGroup>`, `<Badge>`, `<Callout>`, `<Card>`, `<CardGroup>`, `<Check>`, `<CodeGroup>`, `<Color>`, `<Frame>`, `<GitHub.Repo>`, `<Icon>`, `<Info>`, `<Mermaid>`, `<Note>`, `<ParamField>`, `<Prompt>`, `<Step>`, `<Steps>`, `<Tab>`, `<Tabs>`, `<Tile>`, `<Tip>`, `<Tooltip>`, `<Update>`, `<Warning>`

## Aliased components

These render through a Fern component. They work unchanged, but you can switch to the Fern name:

| Mintlify | Fern |
|----------|------|
| `<ResponseField name="...">` | [`<ParamField path="...">`](/learn/docs/writing-content/components/parameter-fields) |
| `<Expandable>` | [`<Accordion>`](/learn/docs/writing-content/components/accordions) |
| `<Danger>` | [`<Error>`](/learn/docs/writing-content/components/callouts) |
| `<Columns>` | `<ColumnGroup>` |
| `<Tree>`, `<FileTree>`, `<Tree.Folder>`, `<Tree.File>` | [`<Files>`, `<Folder>`, `<File>`](/learn/docs/writing-content/components/files) |
| `<RequestExample>`, `<ResponseExample>` | [`<CodeGroup>`](/learn/docs/writing-content/components/code-blocks) |
| `<View title="...">` | [`<Tabs>` and `<Tab title="...">`](/learn/docs/writing-content/components/tabs) |
| `<Panel>` | [`<Aside>`](/learn/docs/writing-content/components/aside) |
| `<Visibility for="humans">` | [`<llms-ignore>`](/learn/docs/ai-features/customize-llm-output) |
| `<Visibility for="agents">` | [`<llms-only>`](/learn/docs/ai-features/customize-llm-output) |
| `<Visibility for="signed-in">` | [`<If loggedIn={true}>`](/learn/docs/writing-content/components/if) |
| `<Visibility for="signed-out">` | [`<If loggedIn={false}>`](/learn/docs/writing-content/components/if) |
| `<Visibility for={{ groups: [...] }}>` | [`<If roles={[...]}>`](/learn/docs/writing-content/components/if) |
| Card `img` | Card `src` |
| Badge `color` | Badge `intent` |

## Move to Fern components

<Steps>
<Step title="Rename the tags">

Replace each Mintlify tag in the table above with its Fern equivalent, including the closing tag.

</Step>
<Step title="Rename the props">

On `<ParamField>`, rename `name` to `path`. On `<Card>`, rename `img` to `src`. On `<Badge>`, replace `color` with an `intent`.

</Step>
<Step title="Wrap adjacent views in tabs">

Wrap each run of adjacent `<View>` elements in one `<Tabs>`, and turn each `<View>` into a `<Tab>`.

</Step>
<Step title="Preview the site">

Run `fern docs dev` and check the converted pages.

</Step>
</Steps>
