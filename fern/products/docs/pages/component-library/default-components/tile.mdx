---
title: Tile
description: Link to a page with a visual preview above its title and description.
---

The `<Tile>` component renders a linked card with a preview area (an image or any other content) above a title and description. Use it for visual galleries of pages, such as templates or integrations. For text-first links, use a [card](/learn/docs/writing-content/components/cards).

## Usage

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <Tile href="/learn/docs/writing-content/components/overview" title="Components" description="Browse every built-in component.">
      <img src="https://placehold.co/300x120/png" alt="Components preview" />
    </Tile>
  </div>
</div>

```jsx Markdown
<Tile href="/learn/docs/writing-content/components/overview" title="Components" description="Browse every built-in component.">
  <img src="/images/components-preview.png" alt="Components preview" />
</Tile>
```

## Properties

<ParamField path="href" type="string" required={true}>
  The URL the tile links to.
</ParamField>

<ParamField path="title" type="string" required={false}>
  The title shown below the preview.
</ParamField>

<ParamField path="description" type="string" required={false}>
  Supporting text shown below the title.
</ParamField>
