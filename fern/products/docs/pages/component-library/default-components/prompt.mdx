The `<Prompt>` component displays a prompt with a description, icon, and action buttons. Use it to share reusable prompts that readers can copy or open directly in AI tools like Cursor, Claude, or ChatGPT.

## Usage

```jsx Markdown
<Prompt
  description="Generate **clear**, *concise* documentation."
  icon="paperclip"
  iconType="solid"
  actions={["copy", "cursor"]}
>
You are a **technical writing assistant**. Write documentation that is clear, accurate, and concise.
- Use second-person voice ("you") and active verbs.
- Start procedures with a goal-oriented heading.
- Before writing, ask clarifying questions about the end users of the documentation, their goals, and their needs.
</Prompt>
```

## Variants

### Copy only

When only the `copy` action is specified (or no actions are provided), the component displays a single "Copy prompt" button.

```jsx Markdown
<Prompt
  description="Summarize a plant care guide."
  icon="seedling"
  actions={["copy"]}
>
Summarize the care instructions for this plant species. Include watering frequency, sunlight requirements, and soil preferences.
</Prompt>
```

### Single open-in action

When one open-in action is specified alongside `copy`, the component shows both a "Copy prompt" button and an "Open in" button.

```jsx Markdown
<Prompt
  description="Review **API endpoint** documentation."
  icon="code"
  actions={["copy", "cursor"]}
>
Review this API endpoint documentation for completeness. Check that all parameters are documented, error responses are listed, and examples are provided.
</Prompt>
```

### Multiple open-in actions

When multiple open-in actions are specified, they collapse into a dropdown menu labeled "Open in..." with options for each tool.

```jsx Markdown
<Prompt
  description="Draft a **plant taxonomy** entry."
  icon="leaf"
  actions={["copy", "cursor", "claude", "chatgpt"]}
>
Draft a taxonomy entry for a new plant species. Include the scientific name, common name, family, native habitat, and distinguishing characteristics.
</Prompt>
```

## Properties

<ParamField path="description" type="string">
  A short description displayed next to the icon. Supports basic markdown formatting: `**bold**` and `*italic*`.
</ParamField>

<ParamField path="icon" type="string | ReactElement">
  The icon displayed alongside the description. Accepts a [Font Awesome](https://fontawesome.com/icons) icon name, a URL to an image, or a React element.
</ParamField>

<ParamField path="iconType" type="string">
  The Font Awesome style for the icon (e.g., `solid`, `regular`, `light`, `duotone`). Only applies when `icon` is a Font Awesome icon name.
</ParamField>

<ParamField path="actions" type="string[]" default='["copy"]'>
  The action buttons to display. Available options: `copy`, `cursor`, `claude`, `chatgpt`.
</ParamField>

<ParamField path="children" type="string | ReactNode" required={true}>
  The prompt text. This content is copied to the clipboard when the user clicks "Copy prompt" or sent to the selected AI tool.
</ParamField>
