---
title: Indent
description: Add visual hierarchy with indentation and guide lines for nested content
---

The `<Indent>` component creates visual hierarchy by adding left indentation with a vertical guide line. Unlike the `<Folder>` component which only accepts `<File>` and `<Folder>` children, `<Indent>` works with any React children, making it ideal for creating hierarchical structures with mixed content types like accordions, parameter fields, code blocks, and text.

Use this component when you need to show nested relationships, hierarchical API documentation structures, or any content that benefits from visual indentation.

## Usage

<div className="highlight-frame">
<Indent>
  <div>This content is indented with a vertical guide line</div>
  <div>Perfect for showing hierarchical relationships</div>
</Indent>
</div>

```jsx Markdown
<Indent>
  <div>This content is indented with a vertical guide line</div>
  <div>Perfect for showing hierarchical relationships</div>
</Indent>
```

## Variants

### With accordions

Combine `<Indent>` with accordions to create expandable hierarchical documentation, such as class definitions with nested properties.

<div className="highlight-frame">
<Accordion title="class User">
  <Indent>
    <div><strong>Bases:</strong> BaseModel</div>
    <div><strong>Properties:</strong></div>
    <Indent>
      <ParamField path="id" type="string" required={true}>
        Unique identifier for the user
      </ParamField>
      <ParamField path="email" type="string" required={true}>
        User's email address
      </ParamField>
      <ParamField path="name" type="string">
        User's display name
      </ParamField>
    </Indent>
  </Indent>
</Accordion>
</div>

```jsx Markdown
<Accordion title="class User">
```

### Multiple nesting levels

You can nest `<Indent>` components multiple levels deep to show complex hierarchies. Each level adds another layer of indentation with its own guide line.

<div className="highlight-frame">
<div><strong>Root Level</strong></div>
<Indent>
  <div>First level of indentation</div>
  <Indent>
    <div>Second level of indentation</div>
    <Indent>
      <div>Third level of indentation</div>
    </Indent>
  </Indent>
</Indent>
</div>

```jsx Markdown
<div><strong>Root Level</strong></div>
<Indent>
  <div>First level of indentation</div>
  <Indent>
    <div>Second level of indentation</div>
    <Indent>
      <div>Third level of indentation</div>
    </Indent>
  </Indent>
</Indent>
```

### With parameter fields

Use `<Indent>` to organize API parameters in a hierarchical structure, showing relationships between parent and child properties.

<div className="highlight-frame">
<ParamField path="user" type="object" required={true}>
  User information object
</ParamField>
<Indent>
  <ParamField path="user.id" type="string" required={true}>
    Unique identifier
  </ParamField>
  <ParamField path="user.profile" type="object">
    User profile information
  </ParamField>
  <Indent>
    <ParamField path="user.profile.name" type="string">
      Display name
    </ParamField>
    <ParamField path="user.profile.avatar" type="string">
      Avatar URL
    </ParamField>
  </Indent>
</Indent>
</div>

### Mixed content types

The `<Indent>` component accepts any React children, allowing you to mix different component types within the same hierarchical structure.

<div className="highlight-frame">
<div><strong>API Response Structure</strong></div>
<Indent>
  <Note>All responses include standard metadata fields</Note>
  <ParamField path="status" type="number">
    HTTP status code
  </ParamField>
  <ParamField path="data" type="object">
    Response payload
  </ParamField>
  <Indent>
    <div>The data object structure varies by endpoint</div>
  </Indent>
</Indent>
</div>

```jsx Markdown
<div><strong>API Response Structure</strong></div>
<Indent>
  <Note>All responses include standard metadata fields</Note>
  <ParamField path="status" type="number">
```

## Properties

<ParamField path="children" type="ReactNode" required={true}>
  The content to be indented. Can include any React elements, components, text, or markdown.
</ParamField>

<ParamField path="className" type="string" required={false}>
  Optional CSS class name for custom styling. The component includes a `fern-indent` class by default for targeting with custom styles.
</ParamField>
