---
title: GitHub repository
description: Link to a GitHub repository with a repository card.
---

The `<GitHub.Repo>` component renders a card that links to a GitHub repository. The card is built from the `repo` property alone; Fern doesn't call the GitHub API, so the card shows no star counts or descriptions.

## Usage

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <GitHub.Repo repo="fern-api/fern" />
  </div>
</div>

```jsx Markdown
<GitHub.Repo repo="fern-api/fern" />
```

## Properties

<ParamField path="repo" type="string" required={true}>
  The repository as `owner/name` or as a full `https://github.com/owner/name` URL. The card doesn't render if the value isn't a valid repository reference.
</ParamField>

<ParamField path="variant" type="'inset' | 'flat'" required={false} default="inset">
  `flat` removes the card's shadow.
</ParamField>
