---
title: Color
description: Display color palettes as swatches with names and values.
---

The `<Color>` component displays color swatches, for example to document a design system's palette. Each `<Color.Item>` shows a swatch with its name and value. A value can differ between light and dark mode.

## Usage

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <Color variant="compact">
      <Color.Item name="primary" value="#16a34a" />
      <Color.Item name="surface" value={{ light: "#ffffff", dark: "#0b0b0b" }} />
    </Color>
  </div>
</div>

```jsx Markdown
<Color variant="compact">
  <Color.Item name="primary" value="#16a34a" />
  <Color.Item name="surface" value={{ light: "#ffffff", dark: "#0b0b0b" }} />
</Color>
```

## Variants

### Table

The `table` variant groups swatches into titled rows with `<Color.Row>`.

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <Color variant="table">
      <Color.Row title="Brand">
        <Color.Item name="brand-500" value="#0ea5e9" />
        <Color.Item name="brand-700" value="#0369a1" />
      </Color.Row>
      <Color.Row title="Neutral">
        <Color.Item name="gray-100" value="#f3f4f6" />
        <Color.Item name="gray-900" value="#111827" />
      </Color.Row>
    </Color>
  </div>
</div>

```jsx Markdown
<Color variant="table">
  <Color.Row title="Brand">
    <Color.Item name="brand-500" value="#0ea5e9" />
    <Color.Item name="brand-700" value="#0369a1" />
  </Color.Row>
  <Color.Row title="Neutral">
    <Color.Item name="gray-100" value="#f3f4f6" />
    <Color.Item name="gray-900" value="#111827" />
  </Color.Row>
</Color>
```

## Properties

### Color

<ParamField path="variant" type="'compact' | 'table'" required={false} default="compact">
  `compact` lays out swatches in a grid. `table` lays out `<Color.Row>` children as titled rows.
</ParamField>

### Color.Row

<ParamField path="title" type="string" required={false}>
  The row's label.
</ParamField>

### Color.Item

<ParamField path="value" type="string | { light?: string; dark?: string }" required={true}>
  A CSS color, or separate colors for light and dark mode. If only one of `light` or `dark` is set, it's used in both modes.
</ParamField>

<ParamField path="name" type="string" required={false}>
  The name shown under the swatch.
</ParamField>
