The `<SearchBar>` component renders a search button that opens your documentation's search dialog when clicked. This component is particularly useful for landing pages where you want to provide quick access to search functionality.

The SearchBar component integrates with your documentation's built-in search system, including AI-powered search if enabled.

## Usage

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <SearchBar />
  </div>
</div>

```jsx Markdown
<SearchBar />
```

## Variants

### Custom placeholder text

You can customize the placeholder text displayed in the search button.

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <SearchBar placeholder="Search our plant care guides..." />
  </div>
</div>

```jsx Markdown
<SearchBar placeholder="Search our plant care guides..." />
```

### Disabled state

The search button can be disabled when needed.

<div className="highlight-frame">
  <div className="highlight-frame-content">
    <SearchBar disabled />
  </div>
</div>

```jsx Markdown
<SearchBar disabled />
```

## Use cases

### Landing pages

The SearchBar component is especially helpful for landing pages where you want to provide prominent search access without the full navigation structure. This allows visitors to quickly find what they're looking for.

```jsx Markdown
# Welcome to our documentation

Find answers to all your questions about plant care.

<SearchBar placeholder="What would you like to learn about?" />

<CardGroup cols={2}>
  <Card title="Getting started" icon="seedling" href="/getting-started">
    Learn the basics of plant care
  </Card>
  <Card title="Advanced techniques" icon="leaf" href="/advanced">
    Master advanced growing techniques
  </Card>
</CardGroup>
```

### Custom layouts

Use the SearchBar component in custom page layouts where you want to control the exact placement of search functionality.

## Properties

<ParamField path="placeholder" type="string" required={false}>
  Custom placeholder text to display in the search button. If not provided, defaults to "Search" or the localized equivalent based on the page language.
</ParamField>

<ParamField path="disabled" type="boolean" required={false} default="false">
  Whether the search button is disabled. When disabled, the button cannot be clicked and appears in a disabled state.
</ParamField>

<ParamField path="lang" type="string" required={false}>
  Language code for localization (e.g., "en", "es", "fr"). Affects the default placeholder text if no custom placeholder is provided.
</ParamField>

## Notes

The SearchBar component automatically integrates with your documentation's search configuration, including:
- Standard keyword search
- AI-powered search (Ask Fern) if enabled in your docs configuration
- Search filters and scoping based on your navigation structure

The search dialog opened by this component is the same one accessed via the keyboard shortcut (Cmd+K or Ctrl+K) or the search button in your documentation's header.
