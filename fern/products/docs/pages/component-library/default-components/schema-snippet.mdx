---
title: Schema snippet
description: Learn how to use the SchemaSnippet component in Fern to display API type definitions as JSON code blocks in your documentation.
---


The `<SchemaSnippet>` component displays type definitions from your API Reference as a JSON code block. Use it on its own to display the JSON representation, or pair it with the [`<Schema>`](/learn/docs/writing-content/components/schema) component to show both the field-by-field breakdown and JSON together. When AI agents fetch the [Markdown version](/learn/docs/ai-features/markdown) of a page, the JSON code block is included as a fenced code block in the Markdown output.

<Note>
  The component only discovers types referenced by endpoints. Types exclusively used by websockets or webhooks won't be available. If multiple APIs have the same type name, the component returns the first match.
</Note>

## Usage

The component works with [API references already configured in your `docs.yml`](/learn/docs/api-references/overview). This example displays the `AIChatConfig` type as a JSON code block:

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <SchemaSnippet type="AIChatConfig" title="The AIChatConfig Object" />
  </div>
</div>

```jsx Markdown
<SchemaSnippet type="AIChatConfig" title="The AIChatConfig Object" />
```

## Combining with the Schema component

Use `<SchemaSnippet>` alongside `<Schema>` to display both the JSON representation and the detailed field breakdown:

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <SchemaSnippet type="AIChatConfig" title="The AIChatConfig Object" />
  <Schema type="AIChatConfig" />
  </div>
</div>

```jsx Markdown
<SchemaSnippet type="AIChatConfig" title="The AIChatConfig Object" />

<Schema type="AIChatConfig" />
```

## Properties

<ParamField path="type" type="string" required={true}>
  The name of the type to display. The component searches for this type across all endpoints in your API definition.
</ParamField>

<ParamField path="title" type="string" required={false}>
  Optional title displayed above the JSON code block.
</ParamField>

<ParamField path="className" type="string" required={false}>
  Optional CSS class name for custom styling.
</ParamField>

<ParamField path="highlight" type="number | number[]" required={false}>
  Line numbers to highlight in the code snippet. Accepts a single number, an array of numbers, or ranges (e.g., `{[1-3, 5]}`).
</ParamField>
