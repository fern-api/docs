---
title: 'Icons'
description: 'Use Font Awesome icons in your documentation'
---

The `Icon` component adds Font Awesome icons to your docs. All Font Awesome Pro styles are supported.

## Usage

<div className="highlight-frame">
  <div><Icon icon="seedling" /> Basic icon</div>
</div>

```jsx Markdown
<Icon icon="seedling" /> Basic icon
```

## Variants

### Sizes

<div><Icon icon="warning" size="7" /> Large icon</div>

```jsx Markdown
<Icon icon="warning" size="7" /> Large icon
```

### Colors

<div><Icon icon="check" color="#22C55E" /> Colored icon</div>

```jsx Markdown
<div><Icon icon="check" color="#22C55E" /> Colored icon</div>
```

### Font Awesome styles

<div style={{ display: 'flex', flexDirection: 'column', gap: '0.75rem' }}>
  <div><Icon icon="heart" /> Default (Solid)</div>
  <div><Icon icon="fa-regular fa-heart" /> Regular</div>

```jsx Markdown
<Icon icon="heart" /> Default (Solid)
<Icon icon="fa-regular fa-heart" /> Regular
<Icon icon="fa-light fa-heart" /> Light
<Icon icon="fa-thin fa-heart" /> Thin
<Icon icon="fa-duotone fa-heart" /> Duotone
<Icon icon="fa-sharp fa-solid fa-heart" /> Sharp Solid
<Icon icon="fa-brands fa-github" /> Brands
```

## Properties

<ParamField path="icon" type="string" required={true}>
  Name of the Font Awesome icon (e.g., "heart" or "fa-solid fa-heart")
</ParamField>

<ParamField path="color" type="string">
  Icon color (hex, RGB, or color name)
</ParamField>

<ParamField path="size" type="number">
  Size in 0.25rem increments (e.g., 4 = 1rem)
</ParamField>
