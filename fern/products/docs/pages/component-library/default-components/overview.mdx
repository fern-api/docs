Fern includes 15+ built-in components for creating interactive documentation. Components are reusable elements that you add to MDX pages to display structured content.

## Usage

Add components to MDX files using JSX syntax. For example, to add a [Card](/cards):

````jsx Markdown
<Card 
    title='Open Source' 
    icon='brands github' 
    href='https://github.com/fern-api/fern'
>
  Give us a star! Fern's CLI & docs source code is available on GitHub. 
</Card>
````

This renders as:

<div className="highlight-frame">
<Card 
    title='Open source' 
    icon='brands github' 
    href='https://github.com/fern-api/fern'
>
  Give us a star! Fern's CLI & docs source code is available on GitHub. 
</Card>
</div>
