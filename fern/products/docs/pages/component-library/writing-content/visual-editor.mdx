## Getting started

Log in to the [Dashboard](https://dashboard.buildwithfern.com/), connect your GitHub repository, then open Fern Editor from the top navigation. No local environment, CLI, or developer setup required—edit directly in the browser while your GitHub PR keeps your normal review and CI process.

To manage who has access to Fern Editor, see [Member permissions](/learn/dashboard/configuration/permissions). Admins and Editors can use the editor; Viewers have read-only access.

## GitHub-backed workflow

Every change you make in Fern Editor becomes a pull request. This preserves your docs-as-code workflow with full Git history, code review, auditability, CI checks, and merge control through branch protections—no surprises in production.

## Site settings

You can update your site's logo, favicon, and title directly from the editor. Navigate to site settings in the editor to make changes visually, without editing configuration files manually.

## Browser & device support

Fern Editor currently supports modern Chromium browsers on desktop. Mobile editing and support for other browsers are coming soon.

## Private Git providers

Fern Editor supports reading and writing to private GitHub or GitLab instances. Contact [support@buildwithfern.com](mailto:support@buildwithfern.com) to set up.
