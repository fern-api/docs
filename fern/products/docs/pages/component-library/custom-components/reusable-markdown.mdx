---
title: Reusable snippets
description: Reusable, custom markdown snippets to keep content in sync. Edit once, update everywhere.
---

Keep your documentation DRY (Don't Repeat Yourself) by defining a reusable Markdown snippet once, and then referencing it in multiple places. This way, you only need to update the snippet in one place to keep all references in sync.

Reusable snippets work well for constants (API limits, subscription prices, version numbers), repeated warnings or notes, and standardized formatting blocks.

<Steps>
<Step title="Create file structure">

Create a folder called `snippets` anywhere in your `fern` project. Inside the `snippets` folder, create a new Markdown file for each snippet you want to define.
    
```bash Example file structure {3, 6-8}
fern
└─ pages
    └─ my-tutorial.mdx
└─ assets
└─ snippets
    ├─ herbs.mdx  
    ├─ peace-lily.mdx    
    └─ trees.mdx
```
</Step>
<Step title="Create snippet">
In each snippet file, define the content you want to reuse.

```mdx title="snippets/peace-lily.mdx"
<Warning> Remember to water your plant at least twice a week. </Warning>
```
</Step>
<Step title="Use a snippet">

To use a snippet in your documentation, reference it by its file path (including the `.mdx` extension). For example, to include the `peace-lily` snippet from the folder structure above:

<Tabs>
    <Tab title="Markdown">
        <div className="modify-snippet">
        ```jsx
        Peace lilies are easy to grow and relatively trouble-free.

        <Markdown src="/snippets/peace-lily.mdx">
        ```
        </div>

    </Tab>
    <Tab title="Preview">
        Peace lilies are easy to grow and relatively trouble-free.
        
        <Markdown src="/snippets/peace-lily.mdx" />
    </Tab>
</Tabs>

<Note title="File paths">
    The `src` path is an absolute path that takes the `fern` folder as the root. The path is the same no matter which page you're referencing it from:

    | Folder structure | Reference |
    | --- | --- |
    | `fern/snippets/peace-lily.mdx` | `src="/snippets/peace-lily.mdx"` |
    | `fern/docs/snippets/peace-lily.mdx` | `src="/docs/snippets/peace-lily.mdx"` |
    | `fern/docs/guides/snippets/peace-lily.mdx` | `src="/docs/guides/snippets/peace-lily.mdx"` |
</Note>
</Step>
<Step title="Parameterized snippets">

Reusable markdown snippets support parameters that you pass as props to the Markdown component. Reference them inside the snippet with `{paramName}`.

Create a snippet with parameter placeholders:

```mdx title="snippets/watering-schedule.mdx"
Water your {plant} every {interval} days.
```

Pass parameters when including the snippet:

<Tabs>
    <Tab title="Markdown">
        ```jsx
        <Markdown src="/snippets/watering-schedule.mdx" plant="peace lily" interval="3" />
        ```
    </Tab>
    <Tab title="Preview">
        <Markdown src="/snippets/watering-schedule.mdx" plant="peace lily" interval="3" />
    </Tab>
</Tabs>

You can use multiple parameters in a single snippet:

```mdx title="snippets/plant-care.mdx"
The {plant} thrives in {light} light and prefers {temperature} temperatures.
```

```jsx
<Markdown src="/snippets/plant-care.mdx" plant="fern" light="indirect" temperature="moderate" />
```

</Step>
</Steps>
