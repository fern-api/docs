Fern provides a comprehensive set of CSS selectors that allow you to customize the appearance of your documentation site. This reference lists all available `.fern-*` selectors, their purpose, default styling, and important usage notes.

<Warning>
  When applying custom CSS to Fern selectors, be aware that some selectors use Tailwind CSS utility classes and CSS custom properties (variables). Your custom styles should work alongside these existing styles rather than completely overriding them.
</Warning>

## Layout and structure

### Selector: .fern-background-image

Background image container for the documentation site.

**Purpose:** Applies a fixed background image to the documentation layout.

**Default CSS:**
```css
.fern-background-image {
  background-attachment: fixed;
  background-size: cover;
  background-repeat: no-repeat;
  background-position-x: center;
  background-position-y: center;
}
```

**Usage notes:**
- The background image is fixed and won't scroll with the page content
- Ensure sufficient contrast between background and text for readability

### Selector: .fern-page-heading

Main page heading element.

**Purpose:** Styles the primary heading (h1) on documentation pages.

**Default CSS:**
```css
.fern-page-heading {
  margin-top: 0;
  margin-bottom: 0;
  display: inline-block;
  leading-tight: 1.25;
  text-wrap: balance;
  word-wrap: break-word;
}
```

**Usage notes:**
- Uses `text-wrap: balance` for improved heading layout
- Automatically breaks long words to prevent overflow

## Header components

### Selector: .fern-header

Main header container.

**Purpose:** Container for the documentation site header.

**Default CSS:**
```css

  backdrop-filter: blur(0.5rem);
  background-color: transparent;
}
```

**Usage notes:**
- Uses backdrop blur for a frosted glass effect
- Background is transparent by default to show the blur effect

**Purpose:** Container for navigation tabs in the header.

**Usage notes:**
- Hidden on mobile, visible on desktop (1024px+)
- Matches the blur effect of the main header

## Button components

### Selector: .fern-button

Primary button component.

**Purpose:** Styled button element with multiple variants.

**Default CSS:**
```css
.fern-button {
  transition-property: color, background-color;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  border-radius: var(--radius-2);
  height: 2.5rem;
  padding: 0.25rem 0.75rem;
  font-size: 0.875rem;
  cursor: pointer;
}

@media (min-width: 640px) {
  .fern-button {
    height: 2rem;
  }
}

.fern-button:hover {
  transition: none;
}
```

**Variants:**
- `.minimal` - Transparent background with subtle hover
- `.filled` - Solid background color
- `.outlined` - Border with transparent background
- `.primary` - Accent color variant
- `.success` - Green color variant
- `.warning` - Amber color variant
- `.danger` - Red color variant

**Size modifiers:**
- `.small` - Smaller button (height: 1.75rem on desktop, 1.5rem on mobile)
- `.large` - Larger button (height: 2.75rem on desktop, 2.5rem on mobile)
- `.square` - Square button with equal width and height

**Usage notes:**
- Disabled buttons have reduced opacity and cursor-not-allowed
- Use `.rounded` class for fully rounded buttons
- Use `.multiline` class to allow button text to wrap

### Selector: .fern-button-content

Content wrapper inside button.

**Purpose:** Wrapper for button content including icons and text.

**Default CSS:**
```css
.fern-button-content {

  flex-shrink: 1;
  align-items: center;
  height: 1.5rem;
  gap: 0.375rem;

```

### Selector: .fern-button-text

Text content within button.

**Purpose:** Text element inside button.

**Default CSS:**
```css

.fern-button:not(.multiline) .fern-button-text {

```

### Selector: .fern-button-group

Group of related buttons.

**Purpose:** Container for grouping multiple buttons together.

**Default CSS:**
```css

```

## Custom CSS best practices

When customizing Fern CSS selectors, follow these best practices:

1. **Use CSS custom properties**: Fern uses CSS variables extensively. Prefer modifying variables over hardcoded values when possible.

2. **Respect dark mode**: Many selectors use color variables that automatically adapt to dark mode. Test your customizations in both light and dark themes.

3. **Maintain accessibility**: Ensure sufficient color contrast and preserve focus states when customizing interactive elements.

4. **Use specificity appropriately**: Fern uses Tailwind's `@layer` directive. Your custom CSS should have appropriate specificity to override defaults without using `!important` excessively.

5. **Test responsive behavior**: Many selectors have different styles at different breakpoints. Test your customizations across mobile, tablet, and desktop viewports.

6. **Preserve transitions**: Many components use transitions for smooth interactions. Avoid removing transition properties unless intentional.

## Light and dark mode customization

Fern applies theme-specific CSS variables that automatically adapt to light and dark modes. Light mode uses the `.light` and `:root` selectors, while dark mode uses the `.dark` selector. Use Fern's CSS custom properties so your styles automatically adapt across themes.

### Key CSS variables

Fern provides the following CSS variables for theming:

**Color scales:**
- `--accent-1` through `--accent-12` - Accent color scale
- `--accent-a1` through `--accent-a12` - Accent color scale with alpha transparency
- `--grayscale-1` through `--grayscale-12` - Grayscale color scale
- `--grayscale-a1` through `--grayscale-a12` - Grayscale with alpha transparency

**Theme variables:**
- `--background` - Page background color
- `--card-background` - Card background color
- `--border` - Border color
- `--sidebar-background` - Sidebar background color
- `--header-background` - Header background color
- `--accent` - Primary accent color

### Dynamic backgrounds

Use CSS variables to create backgrounds that automatically adapt to the theme. Override with `.dark` selector only when you need theme-specific styling.

```css
/* Auto-adapts using Fern variables */
.fern-background-image {
  background-color: var(--background);
  background-image: linear-gradient(
    to bottom,
    color-mix(in srgb, var(--accent-9), var(--background) 85%) 0%,
    var(--background) 100%
  );
}

/* Explicit dark mode override for different gradient direction */
.dark .fern-background-image {
  background-image: linear-gradient(
    to bottom,
    var(--background) 0%,
    color-mix(in srgb, var(--accent-9), var(--background) 85%) 100%
  );
}
```

### Dynamic cards

Cards automatically adapt to theme changes when using CSS variables. Add explicit dark mode overrides only for properties like shadows that need theme-specific values.

```css
/* Plant catalog card that adapts to theme */
.fern-card.plant-card {
  background-color: var(--card-background);
  border-color: var(--border);
  color: var(--grayscale-12);
  box-shadow: 0 1px 2px var(--grayscale-a3);
}

.fern-card.plant-card.interactive:hover {
  box-shadow: 0 4px 12px var(--accent-a6);
}

/* Dark mode shadow adjustment */
.dark .fern-card.plant-card {
  box-shadow: 0 2px 6px var(--grayscale-a4);
}
```

### Dynamic text

Text colors automatically adapt when using Fern's grayscale and accent variables. Use `--grayscale-12` for primary text, `--grayscale-a11` for secondary text, and `--accent-11` for links.

```css
/* Plant species content */
.plant-content {
  color: var(--grayscale-12);
}

.plant-content .description {
  color: var(--grayscale-a11);
}

.plant-content a {
  color: var(--accent-11);
  text-decoration-color: color-mix(in srgb, var(--accent-11), transparent 50%);
}

.plant-content a:hover {
  color: var(--accent-12);
}
```

### Dynamic images

There are multiple approaches for adapting images to light and dark modes.

**SVG icons with currentColor (recommended):**

```html
<svg class="plant-icon" width="24" height="24" fill="currentColor">
  <!-- SVG paths -->
</svg>
```

```css
.plant-icon {
  color: var(--grayscale-11);
}

.plant-icon.accent {
  color: var(--accent-11);
}
```

**Swapping background images:**

```css
.hero-plant {
  background-image: url('/assets/plants/hero-light.png');
  background-size: cover;
  background-position: center;
}

.dark .hero-plant {
  background-image: url('/assets/plants/hero-dark.png');
}
```

**Using picture element with prefers-color-scheme:**

```html
<picture>
  <source srcset="/assets/plants/hero-dark.png" media="(prefers-color-scheme: dark)">
  <img src="/assets/plants/hero-light.png" alt="Plant species">
</picture>
```

<Warning>
  The `prefers-color-scheme` media query follows the operating system theme preference and may not match a manual theme toggle on your site. For perfect alignment with Fern's theme switcher, use the `.dark` selector approach instead.
</Warning>

**Using CSS filters (last resort):**

```css
.logo-monochrome {
  filter: grayscale(1);
}

.dark .logo-monochrome {
  filter: invert(1) grayscale(1);
}
```

<Warning>
  Avoid hardcoding hex colors in your custom CSS. Always use Fern's CSS variables to maintain proper contrast and theme consistency.
</Warning>
