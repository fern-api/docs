<Markdown src="/snippets/agent-directive.mdx"/>

Use GitLab CI/CD to automatically publish your Fern docs when changes are merged and generate preview links on merge requests.

<Info title="Prerequisites">
- Node.js version 18 or higher
- [The Fern CLI](/learn/cli-api-reference/cli-reference/overview#install-fern-cli) installed locally
- A Fern project with a `fern` folder ([quickstart](/learn/docs/getting-started/quickstart))
</Info>

## Set up CI/CD

<Steps>
### Generate a Fern token

Run [`fern token`](/learn/cli-api-reference/cli-reference/commands#fern-token) in your terminal from the directory containing your `fern` folder. This generates an organization-scoped token that authenticates the Fern CLI in CI/CD.

```bash
fern token
```

Copy the token output — you'll add it to GitLab in the next step.

### Add the token to GitLab

<Steps>
### Log in to GitLab
Log in to [GitLab](https://gitlab.com/users/sign_in) and navigate to your Fern docs repository.
### Navigate to CI/CD settings
Click **Settings** > **CI/CD**.
### Add the variable
Scroll to the **Variables** section, select **Expand**, then click **Add variable**. Set the key to `FERN_TOKEN`, paste the token from the previous step as the value, _deselect_ **Protect variable**, and click **Save changes**.
</Steps>

### Add the CI/CD pipeline

Create a `.gitlab-ci.yml` file in the root of your repository. The following pipeline publishes your docs when changes are merged to `main` and validates your API definition on merge requests:

```yaml .gitlab-ci.yml
stages:
  - check
  - publish_docs

before_script:
  - apt-get update -y
  - apt-get install -y curl
  - curl -sL https://deb.nodesource.com/setup_current.x | bash -
  - apt-get install -y nodejs
  - npm install -g fern-api

check:
  stage: check
  rules:
    - if: '$CI_PIPELINE_SOURCE == "merge_request_event"'
    - if: '$CI_COMMIT_BRANCH == "main"'
  script:
    - fern check

publish_docs:
  stage: publish_docs
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'
  script:
    - fern generate --docs
```

### Push to your repository

Commit and push the `.gitlab-ci.yml` file to your repository. The pipeline runs automatically when changes are merged to `main`.

</Steps>

## Preview docs on merge requests

You can extend the pipeline to post a preview link as a comment on merge requests. This requires a GitLab project access token.

<Steps>
### Create a project access token
1. In your GitLab repository, go to **Settings** > **Access Tokens**.
2. Click **Add new token** and configure the following:
   - **Token name**: a descriptive name (e.g., `fern-preview`)
   - **Expiration date**: set as needed (you'll need to regenerate once it expires)
   - **Role**: Reporter
   - **Scopes**: api
3. Click **Create project access token** and copy the token.

<Note title='Save your token'>
Save the generated token immediately — it won't be displayed after you leave the page.
</Note>

### Add the token to CI/CD variables
Follow the same steps as [adding the Fern token](#add-the-token-to-gitlab), but set the key to `REPO_TOKEN` and paste the project access token as the value.

### Add preview stages to the pipeline

Update your `.gitlab-ci.yml` to include a `preview_docs` stage:

```yaml .gitlab-ci.yml
stages:
  - check
  - preview_docs
  - publish_docs

before_script:
  - apt-get update -y
  - apt-get install -y curl
  - curl -sL https://deb.nodesource.com/setup_current.x | bash -
  - apt-get install -y nodejs
  - npm install -g fern-api

check:
  stage: check
  rules:
    - if: '$CI_PIPELINE_SOURCE == "merge_request_event"'
    - if: '$CI_COMMIT_BRANCH == "main"'
  script:
    - fern check

preview_docs:
  stage: preview_docs
  rules:
    - if: '$CI_PIPELINE_SOURCE == "merge_request_event"'
  script:
    - echo "Generating preview..."
    - |
      OUTPUT=$(fern generate --docs --preview) || true
      echo "$OUTPUT"
      DEMO_URL=$(echo "$OUTPUT" | grep -oP -m1 '(https://[^\s]+-preview-[^\s]+)(?: )')
      echo "Preview URL: $DEMO_URL"
    - |
      if [ -z "$DEMO_URL" ]; then
        echo "No preview URL found"
        exit 1
      fi
      curl --location --request POST \
        --header "PRIVATE-TOKEN: $REPO_TOKEN" \
        --header "Content-Type: application/json" \
        --url "https://gitlab.com/api/v4/projects/$CI_MERGE_REQUEST_PROJECT_ID/merge_requests/$CI_MERGE_REQUEST_IID/notes" \
        --data-raw "{ \"body\": \"Preview your docs [here]($DEMO_URL)\" }"

publish_docs:
  stage: publish_docs
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'
  script:
    - fern generate --docs
```
</Steps>
