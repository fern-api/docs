## Third-party imports in custom React components <Badge intent="warning" minimal>Beta</Badge>

<ChangelogTags>components</ChangelogTags>

Custom React components can now import third-party npm packages installed in your docs project's `node_modules`. The Fern CLI bundles these dependencies into your components at build time.

## Availability badges in the sidebar navigation

<ChangelogTags>navigation</ChangelogTags>

Availability set on a page, section, or folder now shows as a badge in the sidebar navigation, so you no longer need to hardcode a status like "(Beta)" in the title. `beta`, `pre-release`, and `in-development` render a badge; `deprecated` renders a badge and strikes through the title.

<Button intent="none" outlined rightIcon="arrow-right" href="/learn/docs/configuration/navigation#availability">Read the docs</Button>
