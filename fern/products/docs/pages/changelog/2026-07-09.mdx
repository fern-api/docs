## Availability badges in the sidebar navigation

<ChangelogTags>navigation</ChangelogTags>

Availability set on a page, section, or folder now shows as a badge in the sidebar navigation, so you no longer need to hardcode a status like "(Beta)" in the title. `beta`, `pre-release`, and `in-development` render a badge; `deprecated` renders a badge and strikes through the title.
