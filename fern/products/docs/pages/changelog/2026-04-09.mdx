## Standalone search widget

Embed Ask Fern's AI-powered search on any React site using the [`@fern-api/search-widget`](https://www.npmjs.com/package/@fern-api/search-widget) package. The widget renders a button that opens a search modal connected to your Fern Docs content. It requires React 19; all other dependencies are bundled.
