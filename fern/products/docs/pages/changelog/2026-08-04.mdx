## Generate library docs from a specific Git ref

<ChangelogTags>api-reference, docs.yml</ChangelogTags>

You can now generate [library documentation](/learn/docs/api-references/library-reference) from a specific branch or tag. Add `ref` to a library's `git` input to preview reference changes before they merge. Without it, generation reads the repository's default branch.

```yaml docs.yml {5}
libraries:
  plant-core:
    input:
      git: https://github.com/acme/plant-core-cpp
      ref: feature/new-planting-api
    output:
      path: ./static/plant-core-docs
    lang: cpp
```
