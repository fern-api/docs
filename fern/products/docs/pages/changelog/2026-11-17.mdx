## Popular searches

<ChangelogTags>search, docs.yml</ChangelogTags>

You can now show your site's most-searched queries when a reader opens the search box. Set `popular-searches` to `true` under `settings.search` in `docs.yml`, then publish with Fern CLI 5.218.1 or later. Only queries that return results for logged-out readers appear, so gated content isn't suggested.

```yml docs.yml
settings:
  search:
    popular-searches: true
```

## More CSS selectors for API Reference pages

<ChangelogTags>api-reference, customization</ChangelogTags>

API Reference pages have new stable CSS selectors, so you can style more of the page with custom CSS:

- Section headings, the endpoint URL and its path parameters, and the **Try it** button
- Code snippet headers, the response status code selector, and error rows
- Enum values, union variant selectors, and property rows (`.fern-api-property` and `.fern-api-property-header`)
- Webhook, WebSocket, GraphQL, and gRPC sections

If your custom CSS already targets `.fern-api-property` or `.fern-api-property-header` for `<ParamField>`, those rules now also apply to API Reference property rows.

## MCP sign-in on password, JWT, and OAuth sites

<ChangelogTags>ai, security, docs.yml</ChangelogTags>

Readers can now sign in to your site's [MCP server](/learn/docs/ai-features/mcp-server) from their MCP client through your site's password, JWT, or OAuth login, instead of pasting a token. Signed-in clients get results for the pages the reader's roles can access. Set `mcp-auth` to `true` under `page-actions.options` in `docs.yml`, then publish with Fern CLI 5.221.0 or later.

```yml docs.yml
page-actions:
  options:
    mcp-auth: true
```
