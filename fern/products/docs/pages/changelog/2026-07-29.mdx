## Fern Editor's AI agent follows your `AGENTS.md`

<ChangelogTags>ai, writing-content</ChangelogTags>

The Editor's AI agent now reads `AGENTS.md` from your repository root and from your `fern` folder before editing, and follows the style guide, terminology, and file layout those files define. Previously the agent only read files inside the `fern` folder, so a root-level `AGENTS.md` was invisible to it. The agent is also more opinionated about information architecture: it groups pages by reader task, keeps navigation shallow, and recommends a different structure when a request would make the site harder to navigate.
