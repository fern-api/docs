## Agent edits and styling previews in Fern Editor

<ChangelogTags>ai, developer-tools</ChangelogTags>

The AI agent now edits the draft you have open in Fern Editor. The canvas is read-only while the agent works, and the Editor reloads and repaints the page when the turn settles, so no browser refresh or pull request is involved. Requests started from the Dashboard hand off to the Editor and are applied live instead of opening a pull request.

The live preview also reflects uncommitted draft styling: custom CSS and the `colors` and `layout` settings in `docs.yml`. Custom JavaScript still runs only on the published site.
