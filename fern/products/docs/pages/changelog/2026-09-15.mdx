## Publish agent skills from a directory in your repo

<ChangelogTags>ai, docs.yml</ChangelogTags>

You can now point the "Install skills" page action at a skills directory in your docs repo with `page-actions.options.skills.path`. The Fern CLI validates each `SKILL.md`, generates the `/.well-known/skills/index.json` discovery manifest, and publishes the bundle with your docs, so users can install your skills with `npx skills add https://<your-docs-domain>` without a hand-maintained manifest.

```yaml docs.yml
page-actions:
  options:
    skills:
      path: ../.agents/skills
```
