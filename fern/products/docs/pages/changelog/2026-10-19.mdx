## Code block themes

<ChangelogTags>customization, docs.yml</ChangelogTags>

You can now choose the syntax-highlighting color scheme for code blocks, separately for light and dark mode, with `theme.code-blocks` in `docs.yml`. The selected themes apply to code blocks across the site, including API Reference request and response snippets, and code blocks take each theme's background color.

```yaml docs.yml
theme:
  code-blocks:
    light: github-light
    dark: github-dark
```
