## Hide line prefixes in code blocks

The `<CodeBlock>` component now supports a `hideLinePrefixes` prop that hides all line prefixes, including line numbers and the `$` or `>` symbols that appear in bash and terminal code blocks. This is useful for command examples where you want a cleaner look without any gutter content.

```bash hideLinePrefixes
npm install plantstore
```

The `hideLinePrefixes` prop differs from `showLineNumbers={false}` in that it also hides the command prompt symbols (`$` and `>`) that appear in bash, shell, and CLI code blocks.

Learn more about [code block options](/learn/docs/writing-content/components/code-blocks#hide-line-prefixes).

## Improved command continuation indicators

Bash and terminal code blocks now display `>` instead of `$` for continuation lines when a command spans multiple lines using `\`. This visual distinction makes it easier to identify multi-line commands.

```bash
curl -X POST https://api.plantstore.com/v1/plants \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Monstera"}'
```
