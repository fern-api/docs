## Walkthrough components

<ChangelogTags>components</ChangelogTags>

You can now guide readers through a sequence of steps with the `<Walkthrough>` and `<CodeWalkthrough>` components. Both pair a list of steps with a synced panel and support back/next navigation and a full-screen mode.

- `<Walkthrough>` renders each step's content in the panel as the active step changes.
- `<CodeWalkthrough>` highlights the line ranges of a shared code block, across multiple files.

<div className="highlight-frame">
  <div className="highlight-frame-content">
  <CodeWalkthrough>
    <Step title="Import the client" description="Bring in the SDK." highlight="1" />
    <Step title="Create the store" description="Instantiate the client." highlight="3" />
    <Step title="Water a plant" description="Call the watering endpoint." highlight="5-8" />
    <Step title="Handle the result" description="Log the confirmation." highlight="10" />

    ```ts water.ts
    import { PlantStore } from "@plantstore/sdk";

    const store = new PlantStore({ apiKey: process.env.PLANT_API_KEY });

    const receipt = await store.plants.water({
      plantId: "monstera-1",
      amountMl: 250,
    });

    console.log(`Watered ${receipt.plantId}`);
    ```
  </CodeWalkthrough>
  </div>
</div>
