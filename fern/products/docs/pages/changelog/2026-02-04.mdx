## Absolute imports with @ prefix

Import custom components using either relative paths or the `@/` prefix for absolute paths from your fern folder root. The `@/` prefix is useful for nested MDX files where relative paths like `../../../components/Banner` would be cumbersome.

```jsx
import { Banner } from "@/components/Banner"
// or use a relative path: import { Banner } from "../components/Banner"
```

Learn more about [custom React components](/learn/docs/writing-content/custom-react-components).

## Title source for folder navigation

By default, folder navigation derives page titles from filenames. You can now set `title-source: frontmatter` to use the `title` field from each file's frontmatter instead.

```yaml docs.yml
navigation:
  - folder: ./pages/guides
    title: Guides
    title-source: frontmatter
```

Files without a frontmatter `title` fall back to the filename-derived value.

Learn more about [folder navigation](/learn/docs/configuration/navigation#add-a-folder).
