## Custom placeholder for searchable tables

Searchable tables now support a `placeholder` prop to customize the search input placeholder text. By default, the placeholder displays "Search..." but you can set a custom value that better describes your table content.

```jsx Markdown
<SearchableTable placeholder="Filter plants...">
| Plant | Light Requirements | Water |
|-------|-------------------|-------|
| Fern | Partial shade | Weekly |
| Snake Plant | Low to bright indirect | Bi-weekly |
</SearchableTable>
```

This prop works with `<SearchableTable>`, `<StickySearchableTable>`, and HTML tables with the `searchable` attribute.

Learn more about [searchable tables](/learn/docs/writing-content/components/tables#searchable-tables).
