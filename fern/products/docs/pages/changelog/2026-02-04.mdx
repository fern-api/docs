## Absolute imports with @ prefix

Import custom components using either relative paths or the `@/` prefix for absolute paths from your fern folder root. The `@/` prefix is useful for nested MDX files where relative paths like `../../../components/Banner` would be cumbersome.

```jsx
import { Banner } from "@/components/Banner"
// or use a relative path: import { Banner } from "../components/Banner"
```

Learn more about [custom React components](/learn/docs/writing-content/custom-react-components).
