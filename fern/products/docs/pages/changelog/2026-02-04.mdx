## Title source for folder navigation

Control how page and section titles are derived when using folder navigation with the new `title-source` option. Set `title-source: frontmatter` to use the `title` field from each file's frontmatter, or `title-source: filename` (the default) to derive titles from file names.

```yaml docs.yml
navigation:
  - folder: ./pages/guides
    title: Guides
    title-source: frontmatter
```

When using `frontmatter`, if a file doesn't have a `title` in its frontmatter, the title falls back to the filename-derived value.

Learn more about [folder navigation](/learn/docs/configuration/navigation#add-a-folder).
