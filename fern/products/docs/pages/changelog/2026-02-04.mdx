## Absolute imports with @ prefix

Use the `@/` prefix in MDX import statements to reference files from your fern folder root. Instead of managing complex relative paths like `../../../components/Banner`, write `@/components/Banner`. The imports are automatically transformed to relative paths at publish time.

```jsx
import { Banner } from "@/components/Banner"
import { Card } from "@/components/Card"
```

Learn more about [custom React components](/learn/docs/writing-content/custom-react-components).
