## Fern Agent

<ChangelogTags>ai</ChangelogTags>

Fern Agent expands Fern Writer: it still opens documentation pull requests from a plain-language request in Slack, and it now also runs in the [Fern Dashboard](https://dashboard.buildwithfern.com/) and in your coding agent over MCP. 

It's an expert in Fern configuration, and it reads your organization's data — traffic, 404s, search queries, reader feedback, and Ask Fern conversations — so a single conversation can go from a metric to a pull request that responds to it.

## Connect your coding agent to Fern over MCP

<ChangelogTags>ai, developer-tools</ChangelogTags>

Fern now hosts two read-only MCP servers for the agent you build your docs with. The public documentation server answers questions about Fern itself — `docs.yml` syntax, components, CLI commands, and API definitions — and needs no authentication. The organization server is scoped to a single organization and returns only what your Fern account can already see: your sites and their configuration, deployment and preview-URL status, traffic and 404 analytics, search queries, Ask Fern conversations, and page feedback. Run `fern mcp install` to connect Claude Code, Cursor, or Codex to it.
