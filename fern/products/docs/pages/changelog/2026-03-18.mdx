## Stable named preview links

Pass `--id` to `fern generate --docs --preview` to create a stable, named preview URL that stays the same across multiple runs. Instead of generating a new random URL each time, the same `--id` value always produces the same preview URL.

```bash
fern generate --docs --preview --id my-feature
```

This is especially useful for pull request workflows — reviewers always have a single, up-to-date link instead of getting a new URL on every push. The updated [GitHub Actions workflow](/learn/docs/preview-publish/preview-changes#automate-with-github-actions) passes the branch name as the `--id`, so each PR gets one stable preview link automatically.
