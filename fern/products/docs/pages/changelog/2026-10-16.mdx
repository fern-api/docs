## Search prioritizes the current product and version by default

<ChangelogTags>search</ChangelogTags>

On sites with multiple products or versions, search now boosts results from the reader's current product and version by default. The boost only reorders results: pages from other products and versions still appear, and a strong title match elsewhere still ranks first. Sites without products or versions see no change. The new default applies after publishing with Fern CLI 5.160.0 or later. Set `settings.search.prioritize-current-product: false` in `docs.yml` to keep the previous ranking.
