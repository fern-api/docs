## LLM content visibility tags

Control what content appears to LLMs versus your documentation UI with new `<llms-only>` and `<llms-ignore>` tags.

Use `<llms-only>` to show content exclusively in LLM endpoints (like `/llms.txt`) while hiding it from the React UI:

```mdx
<llms-only>
  This technical context is only visible to AI assistants reading your documentation.
</llms-only>
```

Use `<llms-ignore>` to show content only in the documentation UI while excluding it from LLM outputs:

```mdx
<llms-ignore>
  <Callout intent="info">
    This callout appears in your docs but won't be included in LLM training data.
  </Callout>
</llms-ignore>
```

This allows you to customize content for different audiences—providing additional context for AI assistants while keeping your user-facing documentation clean and focused.
