## Bottom prompt for the Ask AI chat widget

<ChangelogTags>ai, components</ChangelogTags>

The `AskAiChat` widget now accepts `trigger="prompt"`, which replaces the corner launcher with a single-line prompt input pinned to the bottom center of the viewport. Visitors type their question into the page, and the chat opens directly above the input with that question already in flight.

Interacting with the page outside the chat closes it, selecting the prompt reopens the same conversation, and below 768px the chat is the same bottom drawer the corner launcher opens.
