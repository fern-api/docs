## Third-party imports in custom React components

<ChangelogTags>components</ChangelogTags>

Custom React components can now import third-party npm packages, including private ones. The Fern CLI inlines each dependency from your docs project's `node_modules` at build time, so nothing is fetched from a registry when your docs render. Requires Fern CLI version `5.67.0` or later.
