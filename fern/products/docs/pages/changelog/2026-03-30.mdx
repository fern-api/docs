## Tabs theme object configuration

The `theme.tabs` setting accepts an object with `style`, `alignment`, and `placement` properties as well as the existing string shorthand. Use `alignment: center` to horizontally center header tabs, and `placement` to control whether tabs appear in the header or sidebar.

```yaml docs.yml
theme:
  tabs:
    style: bubble
    alignment: center
    placement: header
```

The string shorthand (`theme.tabs: bubble`) is still supported for style-only configuration.
