## Custom Ask AI button text

<ChangelogTags>ai, customization, docs.yml</ChangelogTags>

You can now rename the **Ask AI** button to match your brand or assistant name. Set `ai-search.button-text` in `docs.yml` to replace the label on the header button and the **Ask AI** row in the search dialog. The same text is used as the accessible name of the Ask Fern panel. When unset, the default "Ask AI" label is used.

```yaml docs.yml
ai-search:
  button-text: Ask Plantstore AI
```
