## Sitemap `lastmod` timestamps

Your sitemap includes a `<lastmod>` timestamp on each page entry, reflecting when the page's content last changed. Search engines use this signal to prioritize crawling recently updated pages. Timestamps update automatically on each publish and ignore trivial formatting changes like whitespace or capitalization differences.
