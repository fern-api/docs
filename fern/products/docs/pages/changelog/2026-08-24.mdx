## Local library docs generation from git inputs

<ChangelogTags>api-reference, local-development</ChangelogTags>

`fern docs md generate --local` now supports `git` library inputs, which previously required remote generation. The CLI shallow-clones the repository at the configured `ref` (a branch, tag, or commit SHA) and parses it on your machine, honoring `subpath` for monorepos.

Requires Fern CLI 5.103.0 or later.
