## Local library docs generation from git inputs

<ChangelogTags>api-reference, local-development</ChangelogTags>

`fern docs md generate --local` now supports `git` library inputs, which previously required remote generation. The library source is read from the repository at the configured `ref` and parsed on your machine.

Requires Fern CLI 5.103.0 or later.
