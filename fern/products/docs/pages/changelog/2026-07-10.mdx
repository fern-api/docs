## Built-in analytics dashboard

<ChangelogTags>analytics, dashboard</ChangelogTags>

Every Fern documentation site includes a built-in analytics dashboard. Open the **Web Analytics** view in the [Fern Dashboard](https://dashboard.buildwithfern.com) to see page views, top pages, traffic channels, device types, referring domains, API Explorer usage, and AI bot traffic across selectable time periods — no configuration required.
