## Availability badges for API Reference endpoints in the sidebar

<ChangelogTags>navigation, api-reference</ChangelogTags>

Availability set on an API Reference section or endpoint now shows as a badge in the sidebar navigation, matching the behavior for pages, sections, and folders. Non-default states render a badge; the default available states don't.
