## Environment variable substitution

Use environment variables in your documentation content by enabling `substitute-env-vars` in your `docs.yml` settings. This allows you to inject dynamic values like API keys, URLs, or version numbers at build time using the `${VAR_NAME}` syntax.

```yaml docs.yml
settings:
  substitute-env-vars: true
```

Environment variables are substituted across Markdown/MDX content and API specifications. To output a literal `${VAR}` without substitution, escape it as `\$\{VAR\}`.

Learn more about [environment variable substitution](/learn/docs/configuration/site-level-settings#settingssubstitute-env-vars).
