## Hidden API endpoints are automatically noindexed

API endpoints set to `hidden: true` in `docs.yml` are automatically excluded from search engine indexing. You don't need to configure `noindex` for hidden endpoints — hiding an endpoint removes it from both the sidebar and search results.
