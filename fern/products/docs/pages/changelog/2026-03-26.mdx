## Prompt component

The new [`<Prompt>`](/learn/docs/writing-content/components/prompt) component displays a copyable prompt with optional "open in" actions for AI tools. Readers can copy the prompt text or open it directly in Cursor, Claude, or ChatGPT.

When multiple open-in actions are configured, they collapse into a dropdown menu.

```jsx Markdown
<Prompt
  description="Generate **clear**, *concise* documentation."
  icon="paperclip"
  iconType="solid"
  actions={["copy", "cursor", "claude"]}
>
You are a technical writing assistant. Write documentation that is clear, accurate, and concise.
</Prompt>
```
