## Ask AI trigger in dropdown menus

<ChangelogTags>ai, search</ChangelogTags>

`@fern-api/search-widget@0.3.0` splits `AskAiChat` into `AskAiChat.Root`, `AskAiChat.Trigger`, and `AskAiChat.Panel`, so the trigger can live inside a dropdown menu, popover, or command palette while the chat lives outside it. The release also adds `open`, `defaultOpen`, and `onOpenChange` props for controlled open state, a `trigger="none"` value that renders no button, and an `AskAiChat.Sparkles` icon component for building your own trigger.
