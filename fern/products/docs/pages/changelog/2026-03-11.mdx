## Dynamic OG images <Availability type="beta" />

Automatic Open Graph image generation is available for your docs site. When `og:dynamic` is set to `true` in your `docs.yml` metadata, Fern automatically generates a unique `og:image` for each page that doesn't have one set in frontmatter. You can optionally provide a custom background image with `og:background-image`.

```yaml docs.yml
metadata:
  og:dynamic: true
  og:background-image: ./images/og-background.png # optional
```
