## Dynamic OG images <Availability type="beta" />

Automatic Open Graph image generation is available for your docs site. When `og:dynamic` is set to `true` in your `docs.yml` metadata, Fern generates a unique 1200x630 social preview image for each page using the page title, your site logo, domain, and configured colors and fonts. You can also set a custom background image with `og:background-image`.

Pages with a custom `og:image` in frontmatter still use that image. If a global `og:image` is also configured, it applies to the homepage while all other pages receive a generated image.

```yaml docs.yml
metadata:
  og:dynamic: true
  og:background-image: ./images/og-background.png # optional
```
