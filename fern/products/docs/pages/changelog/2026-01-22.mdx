## Hide line numbers in code blocks

The `<CodeBlock>` component now supports a `showLineNumbers` prop that allows you to hide line numbers in the gutter. This is useful for cleaner presentation in certain documentation contexts.

```python showLineNumbers={false}
def get_plant(plant_id):
    return plants.get(plant_id)
```

Learn more about [code block options](/learn/docs/component-library/code-blocks#hide-line-numbers).
