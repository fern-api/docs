## Export your docs site from the CLI

<ChangelogTags>developer-tools</ChangelogTags>

You can now download a copy of your live docs site with `fern docs export`. Choose the format with `--format`:

- `html` (default): the full static site, including each page's Markdown copy, `llms.txt`, and assets. Serve it locally with `npx serve <folder>`.
- `md`: each page's Markdown and `llms.txt`.
- `pdf`: one PDF of the site, with the same cover, table of contents, header, and footer options as the Dashboard export.
