## Export your docs site from the CLI

<ChangelogTags>developer-tools</ChangelogTags>

You can now download a copy of your live docs site with `fern docs export`. Choose the format with `--format`:

- `html` (default): the full static site, including each page's Markdown copy, `llms.txt`, and assets. Serve it locally with `npx serve <folder>`.
- `md`: each page's Markdown and `llms.txt`.
- `pdf`: one PDF of the site, with the same cover, table of contents, header, and footer options as the Dashboard export.

## Sign in to SSO-protected docs from MCP clients

<ChangelogTags>ai, security</ChangelogTags>

MCP clients such as Claude Code, Cursor, and ChatGPT can now sign in to your site's [MCP server](/learn/docs/ai-features/mcp-server) through your site's SSO login, with no token to copy into a header. Register the server at `https://<your-docs-site>/_mcp/server?sign_in=true` and choose the client's **Sign in** or **Authenticate** option. Results are scoped to the user's roles, and sessions refresh automatically. Clients that don't sign in still read your public pages.
