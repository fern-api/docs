## Set up Fern with `fern init`

<ChangelogTags>developer-tools, ai</ChangelogTags>

Run `fern init` with no flags in a terminal to start a setup wizard. It finds your API spec and coding agents, then checks your organization name, creates a docs site from Fern's docs starter with your company's logo and colors, adds Fern's skills for your coding agent, creates a preview link, and generates your SDKs, asking before each step. Add `--guest` to try it without a Fern account.

Each step also runs on its own, for scripts and coding agents: `fern detect`, `fern org check`, `fern org create`, `fern docs brand`, `fern docs url check`, `fern agent setup`, and `fern init --docs --template`.
