## Try Fern as a guest

<ChangelogTags>developer-tools, ai</ChangelogTags>

You can now publish a docs site or generate an SDK without a Fern account. Add `--guest` to `fern generate` and the CLI publishes docs to a temporary `temp-<id>.docs.buildwithfern.com` site or downloads the SDK to your project. A coding agent handles every step and hands you the claim link.

To try it without installing anything, use the card on the guest mode page. Drop your own OpenAPI spec or add the Plant Store sample API, then publish a docs site, generate a TypeScript SDK, or both. Each build shows its log while it runs and ends with a claim link.

To keep what you build, open the claim link and sign in to the [Dashboard](https://dashboard.buildwithfern.com/), or run `fern login` and then `fern claim`.
