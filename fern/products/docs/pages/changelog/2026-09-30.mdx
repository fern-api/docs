## Sort endpoints by availability

<ChangelogTags>api-reference, docs.yml</ChangelogTags>

You can now order endpoints in your API Reference by their availability with the `sort-by-availability` option. Listed values come first, in the order you provide, followed by any remaining values in the default order. Combine it with `alphabetized: true` to sort endpoints alphabetically within each availability.

```yaml title="docs.yml"
navigation:
  - api: API Reference
    sort-by-availability:
      - beta
      - deprecated
```
