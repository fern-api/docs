## Readable API Reference Markdown for agents

<ChangelogTags>ai, api-reference</ChangelogTags>

API Reference endpoint and webhook pages served as Markdown — through `.md` URLs and `llms.txt` — now render a flattened property list instead of an OpenAPI schema dump. Requests, responses, and authentication appear as bullets with each property's name, type, required flag, and description, and nested objects are indented. Internal component schema names and `$ref` chains are gone, so agents consume far fewer tokens per endpoint. No configuration is required.
