## Automation site scope and run history

<ChangelogTags>ai</ChangelogTags>

Limit Fern Agent automations to specific docs sites to keep work within the intended sites and repositories. Select sites by their registered URL, such as `portal.example.com/product-1`, in the **Docs sites** field when creating or editing an automation, or name the sites in Fern Agent chat. Selecting **All docs sites** or leaving the selection empty includes every site in your organization.

The automations list shows the scope in a **Docs sites** column. Run history shows **Status** badges (**Running**, **Successful**, or **Failed**) for runs with tracked outcomes and links every pull request in **Pull requests**, labeled `owner/name#123`, including runs that edit multiple repositories.
