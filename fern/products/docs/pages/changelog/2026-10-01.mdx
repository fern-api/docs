## Automation improvements

<ChangelogTags>ai</ChangelogTags>

Two additions to docs automations:

**Scope runs to specific docs sites.** When your organization has more than one docs site, you can now limit an automation's runs to a subset of them. A new **Docs sites** field in the create and edit dialogs lets you pick the sites by their registered URL (host plus basepath, e.g. `portal.example.com/product-1`). Leaving it set to **All docs sites** keeps the existing behaviour. The automations list shows the scoped sites in a new **Docs sites** column.

**Run history shows status and pull requests.** The run history table now shows a status badge for each run (running, succeeded, or failed) and links directly to any pull requests the run opened, labelled by repository and PR number.
