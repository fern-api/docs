## Sidebar availability badges are now opt-in

<ChangelogTags>navigation, docs.yml</ChangelogTags>

Availability badges (`Beta`, `Deprecated`, and similar) and colored status dots no longer render next to navigation items in the sidebar by default. Set `layout.show-nav-availability-badges: true` in `docs.yml` to turn them back on. This controls only the sidebar badges; the page-header availability badge always renders.
