## Per-deployment values in self-hosted docs

<ChangelogTags>self-hosted, customization</ChangelogTags>

A self-hosted container can now resolve environment variables in the pages it serves, on each request. Values that differ per deployment stay in the generated site as placeholders, so one image serves every environment instead of being rebuilt for each. Only names listed in `FERN_RUNTIME_ENV_VARS` are resolved.
