## Role-based access control in local preview

<ChangelogTags>security, developer-tools</ChangelogTags>

`fern docs dev` now applies role-based access control the same way a preview link does. Use the role selector to view the site as a specific viewer and check which pages and navigation items each role sees. Password protection also works locally when you set `FERN_AUTH_TYPE=password` and `FERN_AUTH_SECRET` before starting the server.

## Choose the default version

<ChangelogTags>navigation</ChangelogTags>

You can now mark any entry in `versions` with `default: true` to make it the version served at your unversioned URLs, instead of relying on the first entry in the list. List order still sets the order of the version dropdown, so a preview or development version can appear first while a stable release keeps the canonical URLs, sitemap, and search. The flag also works in product versions.
