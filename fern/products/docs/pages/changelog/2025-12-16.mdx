## New default page actions

ChatGPT, Claude, and Cursor page actions are now enabled by default. These buttons allow users to quickly open documentation content in their preferred AI assistant or code editor.

To disable any of these actions, set them to `false` in your `docs.yml`:

```yaml docs.yml
page-actions:
  options:
    chatgpt: false
    claude: false
    cursor: false
```

[Learn more](/learn/docs/configuration/site-level-settings#page-actions-configuration) about configuring page actions.
