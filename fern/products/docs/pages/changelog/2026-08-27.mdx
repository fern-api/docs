## GraphQL schemas split across multiple files

<ChangelogTags>api-reference, generators.yml</ChangelogTags>

You can now generate a single GraphQL API Reference from a schema split across several SDL files, including Apollo Federation subgraphs. List each file as its own spec in `generators.yml` and give the specs the same `name`, and Fern compiles them into one schema: federation directives are stripped, `@inaccessible` members are omitted, and `@deprecated` members are marked as deprecated in the reference.
