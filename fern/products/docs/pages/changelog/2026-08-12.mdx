## Scroll-synced code walkthroughs

<ChangelogTags>components</ChangelogTags>

You can build scroll-synced code walkthroughs with the new `<ScrollWalkthrough>` component. Prose steps flow down the page while a code panel stays pinned beside them, following the reader's scroll position. Use this component for quickstarts and integration guides where successive steps add to the same few files.

<ScrollWalkthrough panelHeight="16rem">
  <Step title="Install the SDK" file="Terminal" focus="1">
    Add the Plant Store SDK to your project.
  </Step>
  <Step title="Create the client" file="garden.ts" focus="1-5">
    Point the client at your garden with an API key.
    <Substep file="garden.ts" focus="1">Import the client.</Substep>
    <Substep file="garden.ts" focus="3-5">Construct it with your API key.</Substep>
  </Step>
  <Step title="Add a plant" file="garden.ts" focus="7-11">
    Create your first plant record. The `wateringDays` interval drives care reminders.
  </Step>

  ```bash Terminal
  npm install @plantstore/sdk
  ```

  ```ts garden.ts
  import { PlantStore } from "@plantstore/sdk";

  const client = new PlantStore({
    apiKey: process.env.PLANT_API_KEY,
  });

  await client.plants.create({
    name: "Monstera deliciosa",
    light: "bright-indirect",
    wateringDays: 7,
  });
  ```
</ScrollWalkthrough>
