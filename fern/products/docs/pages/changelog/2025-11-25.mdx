## Extract specific lines from code files

The `<Code>` component now supports a `lines` prop to extract specific lines from source files. This is useful when you want to highlight a particular function or section without showing the entire file.

```tsx
<Code src="snippets/plant-service.py" lines={[6-7]} title="Get plant function" />
```

The `lines` prop supports single lines, ranges, and combinations like `[1-3,5,7-10]`.

[Learn more](/learn/docs/writing-content/components/code-blocks#extracting-specific-lines) about extracting specific lines from code files.
