## Inline CSS on MDX pages

Add CSS directly within an MDX page using a `<style>` tag for page-specific styles that don't need to be applied globally.

```mdx Markdown
<style>
{`
.custom-callout {
  background: linear-gradient(135deg, #2d5016 0%, #4a7c23 100%);
  padding: 16px;
}
`}
</style>

<div className="custom-callout">
  Content with custom styling.
</div>
```

Learn more about [custom CSS](/learn/docs/customization/custom-css-js#inline-css-on-mdx-pages).
