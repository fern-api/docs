## Organization-wide CLI version policy

<ChangelogTags>developer-tools</ChangelogTags>

You can now constrain the Fern CLI version used by every project in your organization with `fern org set cli-version`. Set a minimum version, a maximum version, a range, or an exact pin, and every project runs within it: a project below the minimum is bumped up, a project above the maximum is capped down, and a project already in range runs unchanged. Bounds are stored on the organization, so no `fern.config.json` has to change.

`fern org get` reports the policy in effect and `fern org unset cli-version` clears it. `fern upgrade` respects the same bounds when it writes a new version to `fern.config.json`.
