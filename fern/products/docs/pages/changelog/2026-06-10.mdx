## Agent skills

You can now install official Fern [agent skills](https://www.skills.sh) to teach coding agents like Claude Code, Cursor, and Copilot how to work in a Fern repository. The first skill, `fern-docs`, covers docs site authoring: `docs.yml` configuration, navigation, MDX pages, components, and changelog entries.

Install with one command:

```bash
npx skills add fern-api/skills
```
