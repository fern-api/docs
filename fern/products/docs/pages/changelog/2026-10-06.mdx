## AI-generated examples discontinued

<ChangelogTags>api-reference, ai, deprecated</ChangelogTags>

Fern no longer generates API Reference request and response examples with AI. Starting with Fern CLI version 5.147.4, `fern generate --docs` skips AI example generation, and the `ai-examples` setting in `docs.yml` has no effect. Existing `ai_examples_override.yml` files next to your OpenAPI specs are still applied, so committed examples keep appearing. Add new examples with OpenAPI `example` fields or `x-fern-examples`.
