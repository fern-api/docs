## Fleet site switcher for multi-source docs

<ChangelogTags>navigation, docs.yml</ChangelogTags>

Multi-source (fleet) docs sites can now show an automatic **site switcher** in the header: a dropdown listing every other live site on the same host. Membership is derived from the domain's live site registry at publish time, so no manual link maintenance is needed across repositories.

Enable it in your global theme:

```yaml theme.yml
theme:
  site-switcher:
    enabled: true
```

Optional keys control order, hide internal sites, override display labels, and show each site's top-level products indented beneath it (`show-products: true`). The [`theme.site-switcher`](/learn/docs/configuration/site-level-settings#theme-configuration) reference lists every option.
