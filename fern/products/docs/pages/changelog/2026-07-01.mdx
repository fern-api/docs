## Changelog layout configuration

<ChangelogTags>configuration, navigation</ChangelogTags>

You can now control the changelog layout via two settings. Set the site-wide default with `layout.changelog-layout` in `docs.yml`:

```yaml docs.yml
layout:
  changelog-layout: classic
```

- `timeline` (default) renders a searchable timeline of condensed entry cards.
- `classic` renders stacked full entries inline, preserving code formatting, copy buttons, and links.

Individual changelogs can override the site-wide setting by adding `layout` to their overview page frontmatter:

```mdx changelog/overview.mdx
---
layout: classic
---
```

The per-changelog override takes priority over the site-wide setting.
