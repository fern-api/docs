## Changelog layout configuration

<ChangelogTags>configuration, navigation</ChangelogTags>

You can now control the changelog layout site-wide via `layout.changelog-layout` in `docs.yml`. Set it to `classic` to render the legacy stacked layout with full inline entries, or leave it as `timeline` (the default) for the searchable timeline of cards.

```yaml docs.yml
layout:
  changelog-layout: classic
```

## Per-changelog layout override

<ChangelogTags>configuration, navigation</ChangelogTags>

Individual changelogs can override the site-wide layout by adding a `layout` property to their overview page frontmatter. This lets a single changelog use the classic layout while the rest of the site stays on the timeline, or vice versa.

```mdx changelog/overview.mdx
---
layout: classic
---
```
