## Link target property

Specify where links open using the `target` property. This applies to product links, tab links, page links, and navbar links. Options are `_blank` (new tab), `_self` (same tab, default), `_parent`, and `_top`.

```yaml title="docs.yml"
navbar-links:
  - type: filled
    text: Dashboard
    href: https://dashboard.example.com
    target: _blank
```
