## Page suggestions in agent 404 responses

<ChangelogTags>ai</ChangelogTags>

When an AI agent requests a `.md` URL that doesn't exist, the response now includes up to three "Similar pages" suggestions linking to the closest matching `.md` sources. This mirrors the suggestions human readers see on the 404 page, so agents can recover from a broken or outdated link without a separate lookup.
