## Paginated and expandable tables

<ChangelogTags>components</ChangelogTags>

You can now paginate long tables. `<PaginatedTable pageSize={n}>` splits rows across pages with a previous/next footer, and adding `expandable` swaps that footer for Show all / Show fewer controls. `<PaginatedSearchableTable>` combines search with pagination, filtering the full dataset before paginating the matches. The same behavior is available on raw HTML tables through the `paginate`, `pageSize`, and `expandable` attributes.

## Page suggestions in agent 404 responses

<ChangelogTags>ai</ChangelogTags>

Requests for a nonexistent `.md` URL now return up to three "Similar pages" suggestions linking to the closest matching sources, so agents can recover from a broken link without a separate lookup.
