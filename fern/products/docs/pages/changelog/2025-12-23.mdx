## Webhook payload snippet component

The new `<WebhookPayloadSnippet>` component displays webhook payload examples from your API Reference. Use it to embed live webhook payload examples in your documentation pages.

```jsx Markdown
<WebhookPayloadSnippet webhook="onOrderCreated" />
```

The component supports multiple identifier formats including operation ID, camelCase name, exact ID, ID suffix, and path.

Learn more about the [Webhook payload snippet](/learn/docs/writing-content/components/webhook-payload-snippet) component.
