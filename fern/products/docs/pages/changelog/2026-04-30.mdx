## Multi-source docs

Multiple teams can publish to the same custom domain from independent repositories. Set `multi-source: true` on your instance, use a [global theme](/learn/docs/customization/global-themes) for consistent branding, and configure search behavior in the Dashboard.

```yaml docs.yml
global-theme: my-org-theme

instances:
  - url: example.docs.buildwithfern.com/product-a
    custom-domain: docs.example.com/product-a
    multi-source: true
```
