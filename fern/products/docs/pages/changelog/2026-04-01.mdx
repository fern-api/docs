## Shakespeare mode

A new easter egg theme is available in the theme selector dropdown. Shakespeare mode transforms your docs with a parchment visual style and translates page text into Shakespearean English. Activate it from the theme dropdown or by adding `?shakespeare=true` to any page URL.
