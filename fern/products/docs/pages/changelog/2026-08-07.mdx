## Authenticate the MCP server with a bearer token

<ChangelogTags>ai, security</ChangelogTags>

MCP clients can now authenticate to the MCP server on an authenticated docs site by sending the docs JWT as `Authorization: Bearer <jwt>`. This unblocks clients that only support bearer tokens and can't set the `FERN_TOKEN` header.
