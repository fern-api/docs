## Scroll walkthrough component

<ChangelogTags>components</ChangelogTags>

You can now build scroll-synced code walkthroughs with `<ScrollWalkthrough>`. Prose steps flow down the page while a code panel stays pinned beside them: as each step or substep scrolls into view, the panel switches to that file and focuses the lines the step describes. Substeps target individual lines, so a step can walk through one file a few lines at a time without the reader clicking anything.

## Readable API Reference Markdown for agents

<ChangelogTags>ai, api-reference</ChangelogTags>

API Reference endpoint and webhook pages served as Markdown (through `.md` URLs and `llms.txt`) now render a flattened property list. Requests, responses, and authentication appear as bullets with each property's name, type, required flag, and description, and nested objects are indented. 

Internal component schema names and `$ref` chains aren't included to conserve tokens and improve readability.
