## Match `<If>` products and versions by display name

<ChangelogTags>components, navigation</ChangelogTags>

The `<If>` component can now gate content using the name readers see in the product or version switcher, such as `<If versions={["v1 (Legacy)"]}>`. This includes the default version, which is served at your docs basepath and has no slug of its own.
