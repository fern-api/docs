## Fern Agent automations

<ChangelogTags>ai</ChangelogTags>

You can now put Fern Agent on a schedule. An automation is a prompt Fern Agent works daily or weekly with nobody present: it reviews your reader feedback, unanswered Ask Fern questions, search queries, or analytics, reports back what it found, and opens a pull request when the prompt asks it to change the docs.

Create one on the **Automations** page in the [Fern Dashboard](https://dashboard.buildwithfern.com/), or describe the recurring work you want in the Fern Agent chat panel or in Slack. **Run now** shows what a run comes back with before the first scheduled one, and Fern reports every finished run in Slack to whoever scheduled it.
