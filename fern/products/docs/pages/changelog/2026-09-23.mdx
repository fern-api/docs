## Stricter Content Security Policy for sites with custom JavaScript

<ChangelogTags>security, docs.yml</ChangelogTags>

You can now remove `'unsafe-inline'` and `'unsafe-eval'` from your site's Content Security Policy when it loads custom JavaScript, Google Tag Manager, or analytics providers. List the hashes of the inline `<style>` tags your scripts insert under `settings.content-security-policy.style-hashes`, and set `allow-eval: false` to drop `'unsafe-eval'`.

```yaml docs.yml
settings:
  content-security-policy:
    style-hashes:
      - "sha256-Xn86JLDplvyEYS5Le9qI7kfofm28Yt4KSLpywXweBXo="
    allow-eval: false
```
