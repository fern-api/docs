## Callouts render as blockquotes in Markdown output

<ChangelogTags>ai</ChangelogTags>

Callout components (`<Callout>`, `<Info>`, `<Warning>`, `<Note>`, `<Tip>`, `<Success>`, `<Error>`, `<Check>`, and `<Launch>`) now render as Markdown blockquotes in `.md`/`.mdx` URLs, `llms.txt`, and `llms-full.txt` output. Previously, callout content was flattened into a plain paragraph, making it indistinguishable from body text for LLMs and RAG consumers.

The blockquote is led by a bolded label: the callout's `title` attribute if present, otherwise the capitalized intent name (for example **Warning** or **Tip**).

```md
> **Watch the roots**
>
> Repot before spring.

> **Tip**
>
> Mist daily.
```

The rendered HTML output and Copy Page mode are unchanged.
