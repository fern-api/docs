## "Edit this page" launch option

The "Edit this page" button now supports a `launch` option. When set to `dashboard`, clicking the button opens a screen where users can choose between starting a Fern Editor session for that page or going straight to the source in GitHub.

Learn more about the [`edit-this-page` configuration](/learn/docs/configuration/site-level-settings#edit-this-page-configuration).
