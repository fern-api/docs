## New Security page

We've added a comprehensive Security page to help enterprise security teams understand how Fern handles user credentials, authentication, and data storage.

The page covers:

- **Data storage and privacy**: User credentials are only stored in browser cookies and never persisted on Fern's servers
- **Authentication and API key injection**: Details on the client-side authentication flow for JWT and OAuth
- **Open-source transparency**: Information about auditing Fern's frontend code that handles credentials
- **Self-hosted deployments**: Options for organizations with strict security requirements
- **Implementation recommendations**: Guidelines for secure authentication setup

Read more at [Security](/learn/docs/security)
