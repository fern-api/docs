## Ask Fern docs domain per Slack channel

<ChangelogTags>ai</ChangelogTags>

The Ask Fern Slack app can now answer from a different docs domain in each channel. One workspace install serves several docs sites: set a per-channel override with the `/slack/channel-domain-override` endpoint, and channels without an override keep using the install domain. `/fern show` reports the domain a channel answers from.
