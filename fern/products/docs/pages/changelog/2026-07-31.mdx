## Ask Fern docs domain per Slack channel

<ChangelogTags>ai</ChangelogTags>

Installing the Ask Fern Slack app binds it to one docs domain, and every channel in the workspace answered from that domain. A channel can now override it: send a `POST` to `https://fai.buildwithfern.com/slack/channel-domain-override` to point a channel at a different docs site. Channels without an override keep using the install domain. 

The `/fern show` slash command reports the domain a channel answers from.
