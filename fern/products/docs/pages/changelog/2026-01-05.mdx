## Collapsed state for Runnable Endpoint

The `<RunnableEndpoint>` component now supports a `collapsed` prop that lets you control the initial display state. When set to `true`, the component renders collapsed by default with the form section hidden, allowing users to expand it on demand.

```jsx Markdown
<RunnableEndpoint endpoint="GET /api/plants/{plantId}" collapsed={true} />
```

This is useful when embedding multiple endpoints on a single page or when you want to reduce visual clutter while still providing interactive API testing capabilities.

Learn more about the [Runnable Endpoint](/learn/docs/writing-content/components/runnable-endpoint) component.
