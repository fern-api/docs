Enabling Ask Fern requires both a `docs.yml` configuration and activation through the [Fern Dashboard](https://dashboard.buildwithfern.com/). The `docs.yml` file declares where Ask Fern should be available and how it should behave, while the Dashboard toggle activates it and triggers content indexing.

## Step 1: Configure `docs.yml`

Add the `ai-search` configuration to your `docs.yml` file to declare where Ask Fern should be available:

```yaml docs.yml
ai-search:
  location:
    - docs
    - slack
```

The `docs.yml` configuration lets you specify which platforms Ask Fern is active on (`docs`, `slack`, or `discord`), customize the system prompt, and configure additional content sources. See [Configuration](#configuration) below for full details.

## Step 2: Activate in the dashboard

After configuring `docs.yml`, enable Ask Fern in the [Fern Dashboard](https://dashboard.buildwithfern.com/):

<Steps>
  <Step title="Navigate to your project">
    Open the [Fern Dashboard](https://dashboard.buildwithfern.com/) and select your documentation project.
  </Step>
  <Step title="Toggle Ask AI on">
    Find the Ask AI toggle and enable it. This triggers an automatic reindex of your documentation content.
  </Step>
  <Step title="Reindex (optional)">
    If you need to manually refresh the index after making documentation changes, use the reindex button in the Dashboard.
  </Step>
</Steps>

<Note>
After you enable Ask Fern, it needs to index your content before the [side panel](/learn/docs/ai-features/ask-fern/overview) can appear on your site. This typically takes a few minutes, though sites with extensive custom components may take longer. 
</Note>
