The [`@fern-api/search-widget`](https://www.npmjs.com/package/@fern-api/search-widget) package also ships `AskAiChat`, the Ask Fern chat experience without the keyword-search UI. It renders as a floating card anchored to a corner of the viewport, and becomes a bottom drawer below 768px. `cmd`/`ctrl` + `/` toggles the card and Escape closes it. Citations in answers link to your docs domain and open in a new tab.

`AskAiChat` has the same [prerequisites](/learn/docs/ai-features/ask-fern/search-widget#prerequisites) as the standalone search widget.

## Getting started

<Steps>
  <Step title="Install the package">
    <CodeBlocks>
    ```bash npm
    npm install @fern-api/search-widget react@19 react-dom@19
    ```
    ```bash pnpm
    pnpm add @fern-api/search-widget react@19 react-dom@19
    ```
    ```bash yarn
    yarn add @fern-api/search-widget react@19 react-dom@19
    ```
    </CodeBlocks>
  </Step>
  <Step title="Add the chat widget">
    Import `AskAiChat` and the bundled styles, then render the component with your docs domain. The component ships its own launcher button, pinned to the bottom-right corner.

    `AskAiChat` is a client component. In the Next.js App Router, the file that renders it requires the `"use client"` directive, otherwise the page fails with `TypeError: createContext only works in Client Components`. A static import is all that's needed: `next/dynamic` and `ssr: false` aren't required. The Pages Router, Vite, Create React App, and Remix need no additional configuration.

    ```tsx
    'use client';

    import { AskAiChat } from '@fern-api/search-widget';
    import '@fern-api/search-widget/styles';

    export function AskAi() {
      return <AskAiChat domain="https://docs.example.com" />;
    }
    ```
  </Step>
  <Step title="Match your product's theme">
    `theme` controls light and dark mode and `accentColor` sets the widget's accent: the sparkles, the send button, and links in answers. A single accent value covers both light and dark modes.

    ```tsx
    <AskAiChat domain="https://docs.example.com" theme="inherit" accentColor="#6b4eff" />
    ```
  </Step>
</Steps>

## Content Security Policy

`AskAiChat` makes the same runtime requests as the [standalone search widget](/learn/docs/ai-features/ask-fern/search-widget#content-security-policy), so allow those origins in `connect-src`. Rating an answer also posts to `https://fai.buildwithfern.com`, which belongs in `connect-src` as well.

## Properties

All standard HTML button attributes are also supported and forwarded to the trigger button.

<ParamField path="domain" type="string" required={true}>
  The URL of your published Fern Docs site (for example, `https://docs.example.com`). Include the full path if your docs aren't at the root (for example, `https://buildwithfern.com/learn`).
</ParamField>

<ParamField path="theme" type="'inherit' | 'light' | 'dark' | 'auto'" default="inherit">
  `inherit` follows the host page's theme (a `dark` class or `data-theme="dark"` on `<html>` or `<body>`) and switches live with it. `light` and `dark` pin the widget to that mode. `auto` follows the visitor's `prefers-color-scheme`.
</ParamField>

<ParamField path="accentColor" type="string">
  Accent color for the sparkles, send button, and links in answers. Accepts any CSS color (for example, `#6b4eff`), and derives the light and dark variants from it. Defaults to a neutral gray.
</ParamField>

<ParamField path="trigger" type="'floating' | 'inline'" default="floating">
  `floating` renders a styled launcher pinned to a corner of the viewport. `inline` renders an unpainted button to place and style yourself, such as in a nav bar. Both carry the sparkle icon and an `Ask AI` label by default.
</ParamField>

<ParamField path="placement" type="'bottom-right' | 'bottom-left' | 'top-right' | 'top-left'" default="bottom-right">
  The corner the launcher and card anchor to.
</ParamField>

<ParamField path="lang" type="string" default="en">
  Language code for the chat interface.
</ParamField>

<ParamField path="searchLocale" type="string">
  Locale used for retrieval. Defaults to `lang`.
</ParamField>

<ParamField path="icon" type="React.ReactNode">
  Icon element that replaces the trigger's sparkles icon.
</ParamField>

<ParamField path="children" type="React.ReactNode">
  Trigger content that replaces the default `Ask AI` label.
</ParamField>
