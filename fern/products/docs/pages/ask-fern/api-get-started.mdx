The Fern AI API allows you to manage your Ask AI configuration using Fern's public RESTful API. You can use the API to:

- Build your own support integrations that leverage Ask AI's AI-powered search
- Add custom context and FAQs to your documentation
- Source usage and analytics data from your Ask AI instances

## Authentication

Fern API requests require a bearer token for authentication. Use the CLI command [`fern token`](/learn/cli-api/cli-reference/commands#fern-token) to generate a bearer token. Tokens don't expire.
