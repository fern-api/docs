The `@fern-api/search-widget` package provides a standalone React component that brings Ask Fern's AI-powered search to any website, not just your Fern Docs site. Use it to embed a search modal in your dashboard, marketing site, or any React application.

<Note>
  The search widget requires React 19. All other dependencies are bundled.
</Note>

## Installation

<CodeBlocks>
```bash npm
npm install @fern-api/search-widget react react-dom
```
```bash pnpm
pnpm add @fern-api/search-widget react react-dom
```
```bash yarn
yarn add @fern-api/search-widget react react-dom
```
</CodeBlocks>

## Basic usage

Import the component and its styles, then render `SearchModal` with your documentation domain:

```tsx
import { SearchModal } from '@fern-api/search-widget';
import '@fern-api/search-widget/styles';

function App() {
  return (
    <SearchModal domain="https://docs.example.com" lang="en">
      Search Docs
    </SearchModal>
  );
}
```

The `domain` prop should point to your Fern Docs site (for example, `https://buildwithfern.com/learn`). The component renders a button that opens a search modal when clicked.

## Props

### Required

| Prop | Type | Description |
| --- | --- | --- |
| `domain` | `string` | The documentation domain to search against (for example, `https://docs.example.com`). |

### Optional

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `lang` | `string` | `"en"` | Language code for the search interface. |
| `icon` | `React.ReactNode` | — | Icon element to display in the button. |
| `className` | `string` | — | CSS class names for the trigger button. |
| `style` | `React.CSSProperties` | — | Inline styles for the trigger button. |
| `children` | `React.ReactNode` | — | Button content (text, icons, etc.). |
| `disabled` | `boolean` | — | Disables the button. |
| `onClick` | `function` | — | Additional click handler that runs before the modal opens. |

All standard HTML button attributes are also supported and forwarded to the trigger button.

## Styling the button

The `SearchModal` component renders a `<button>` element that you can style in three ways.

### Inline styles

```tsx
<SearchModal
  domain="https://docs.example.com"
  lang="en"
  style={{
    padding: '0.75rem 1.5rem',
    background: '#2563eb',
    color: 'white',
    border: 'none',
    borderRadius: '6px',
    cursor: 'pointer',
  }}
>
  Search Documentation
</SearchModal>
```

### CSS classes

```tsx
<SearchModal
  domain="https://docs.example.com"
  lang="en"
  className="my-search-button"
>
  Search
</SearchModal>
```

```css
.my-search-button {
  padding: 0.75rem 1.5rem;
  background: #2563eb;
  color: white;
  border: none;
  border-radius: 6px;
}
```

### Default class

Target the built-in `fern-search-button` class:

```css
.fern-search-button {
  padding: 0.75rem 1.5rem;
  background: #2563eb;
  color: white;
}
```

## Full example

```tsx
import { SearchModal } from '@fern-api/search-widget';
import '@fern-api/search-widget/styles';

function App() {
  return (
    <div className="app">
      <header>
        <h1>My Documentation</h1>
        <SearchModal
          domain="https://docs.mysite.com"
          lang="en"
          className="search-trigger"
        >
          Search Docs
        </SearchModal>
      </header>
    </div>
  );
}

export default App;
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Styles not loading">
    Verify that you import the CSS file:

    ```tsx
    import '@fern-api/search-widget/styles';
    ```
  </Accordion>
  <Accordion title="Button shows 'Loading...' or disappears">
    The button fetches an API key from your docs domain on mount. Check that:

    - The `domain` prop points to a valid Fern Docs site.
    - Network requests to `{domain}/api/fern-docs/search/api-key` succeed.
    - Your browser console has no CORS or network errors.
  </Accordion>
  <Accordion title="Modal does not open">
    The package requires React 19. If you see module resolution errors, confirm both `react` and `react-dom` are installed at version 19:

    ```bash
    npm install react@19 react-dom@19
    ```
  </Accordion>
</AccordionGroup>
