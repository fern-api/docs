<Warning>
This process is **legacy**. Check with the team for the latest approach.
</Warning>

## Steps

<Steps>
  <Step title="Enable the feature flag in PostHog">
    Go to PostHog → Feature Flags → click [**dashboard-enable-docs-analytics-tab**](https://us.posthog.com/project/10039/feature_flags/123712).
  </Step>
  <Step title="Add the customer organization">
    Add the organization name to the **Set 1** release conditions.
  </Step>
  <Step title="Verify">
    If the feature flag didn't work, try enabling `dashboard-enable-docs-ask-fern-tab` instead.
  </Step>
</Steps>
