title: Ask Fern Setup
description: How to enable Ask Fern (AI-powered search) for a customer's documentation site.
---

<Warning>
This process is **legacy**. Ask Fern enablement may now be handled differently. Check with the team for the latest approach before following these steps.
</Warning>

## Steps

<Steps>
  <Step title="Find the customer domain">
    Check the customer's `docs.yml` file to identify their domain name.
  </Step>
  <Step title="Open Vercel Edge Config">
    Go to [Vercel Edge Config stores](https://vercel.com/buildwithfern/~/stores) and find the `fern-docs-config` store.
  </Step>
  <Step title="Add the customer domain">
    Add the customer domain name as a value under both:
    - The `search-v2` key
    - The `ask-ai-enabled` key
  </Step>
  <Step title="Wait for propagation">
    Wait up to 15 minutes for the changes to propagate.
  </Step>
  <Step title="Trigger indexing">
    Navigate to the customer's reindex endpoint to index into Turbopuffer:
    ```
    https://{customer-domain}/api/fern-docs/search/v2/reindex/turbopuffer
    ```
  </Step>
</Steps>
