---
title: Minting JWTs
description: How to mint a JWT to access authenticated customer documentation for testing or debugging.
---

When you need to access a customer's authenticated docs (for testing or debugging), you can mint a JWT manually.

## Steps

<Steps>
  <Step title="Open jwt.io">
    Go to [jwt.io](https://jwt.io/) to create a token.
  </Step>
  <Step title="Set the secret key">
    Use the secret key from the customer's Vercel Edge Config entry.
  </Step>
  <Step title="Configure the payload">
    Set the `roles` and `iss` (issuer) fields in the payload. Get the roles from the customer's `docs.yml` and the issuer from the Vercel Edge Config.

    Example payload:
    ```json
    {
      "fern": {
        "roles": ["partners"],
        "issuer": "fern"
      }
    }
    ```
  </Step>
  <Step title="Set the fern_token cookie">
    Navigate to the customer's docs site and [add a cookie](https://developer.chrome.com/docs/devtools/application/cookies) named `fern_token` with the value of the generated JWT.
  </Step>
  <Step title="Verify access">
    Refresh the page to confirm that the authenticated content is now visible.
  </Step>
</Steps>
