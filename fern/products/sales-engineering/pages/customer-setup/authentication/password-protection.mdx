---
title: Password Protection
description: How to set up a global password for a customer's Fern documentation site.
---

Password protection adds a simple password gate across all pages of a customer's docs site.

## Edge config structure

Add an entry to the `authentication` section of the [Vercel Edge Config store](https://vercel.com/buildwithfern/~/stores) under `fern-docs-config`:

```json
"{org_name}.docs.buildwithfern.com": {
  "type": "password",
  "password": "{your-password}"
}
```

## Steps

<Steps>
  <Step title="Add edge config entry">
    Add the JSON configuration to the `authentication` section in the Vercel Edge Config store.
  </Step>
  <Step title="Check WorkOS redirect URIs">
    Make sure there are **no** Redirect URIs configured for this domain in WorkOS. If there are, remove them to avoid conflicts.
  </Step>
  <Step title="Revalidate docs">
    Trigger a revalidation by visiting:
    ```
    https://{customer-domain}/api/fern-docs/revalidate
    ```
  </Step>
  <Step title="Wait for propagation">
    Edge config changes may take 10–15 minutes to propagate.
  </Step>
</Steps>
