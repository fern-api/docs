## Post-demo follow-up

Use this template after setting up a customer's SDKs and docs migration:

```
Hey {name} 👋

I set up your SDKs as well as a full migration of your docs for you to check out:
https://{customer}.docs.buildwithfern.com

I added some time to your calendar next week so we can walk through the
Fern Docs/SDK config together.

Could you share your GitHub username(s) in advance so I can get you access
to the following repos:
- https://github.com/fern-demo/{customer}-config
- https://github.com/fern-demo/{customer}-csharp-sdk
- https://github.com/fern-demo/{customer}-typescript-sdk
- https://github.com/fern-demo/{customer}-python-sdk
```

<Note>
Replace `{name}` with the contact's name and `{customer}` with the customer's identifier. Adjust the SDK repos to match the languages you've generated.
</Note>
