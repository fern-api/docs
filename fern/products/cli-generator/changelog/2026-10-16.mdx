## Release workflow works on private repositories

<ChangelogTags>publishing, generators.yml</ChangelogTags>

GitHub artifact attestations require GitHub Enterprise Cloud on private repositories, so the generated release workflow failed every build there. The new `distribution.githubAttestations` option controls the attest step, and by default it runs only on public repositories.

## Server variables in a custom base URL

<ChangelogTags>features</ChangelogTags>

Placeholders such as `{region}` in a caller-supplied base URL (`--base-url`, `<NAME>_BASE_URL`, or a profile's base URL) are now filled from the matching flag, profile, environment variable, or spec default. Previously the literal placeholder was sent and the request failed.
