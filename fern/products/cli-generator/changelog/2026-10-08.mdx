## Create API keys with `profiles create --provision`

<ChangelogTags>auth, generators.yml</ChangelogTags>

Set `profiles.provisionOperation` to the operation that creates an API key (for example `iam.keys.create`). `profiles create` then gains `--provision`, which calls that operation with the credentials already in the environment and saves the returned key to the new profile. It's the create-side counterpart of `revokeOperation`.
