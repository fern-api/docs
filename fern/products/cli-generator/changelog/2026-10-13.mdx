## Faster shell completion on large CLIs

<ChangelogTags>commands</ChangelogTags>

`<cli> completion <shell>` now prints a small script that asks the CLI for candidates on each TAB, instead of a static script containing the whole command tree. On a CLI with about 13,700 commands, the zsh script was 14 MB and took over a minute to load on the first TAB.

## Prefixed API-key headers

<ChangelogTags>auth</ChangelogTags>

Header API-key schemes now send their configured prefix. An `auth-schemes` entry such as `{ header: X-Api-Key, prefix: Key }` sends `X-Api-Key: Key <credential>` whether the key comes from the flag, the environment variable, or the keyring entry `auth login` stores. Previously the bare credential was sent.
