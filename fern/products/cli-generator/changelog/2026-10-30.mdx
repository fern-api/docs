## macOS code signing in the release workflow

<ChangelogTags>publishing</ChangelogTags>

The generated release workflow now code-signs the macOS binaries when the CLI repository has the `CODESIGN_CERTIFICATE`, `CODESIGN_CERTIFICATE_PASSWORD`, and `CODESIGN_IDENTITY` secrets (an Apple Developer ID certificate). macOS keychain credentials are also read through `/usr/bin/security`, so one "Always Allow" lasts across upgrades.
