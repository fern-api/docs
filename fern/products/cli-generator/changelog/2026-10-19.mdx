## Guided API-key setup

<ChangelogTags>auth, generators.yml</ChangelogTags>

CLIs with `profiles.provisionOperation` configured now walk users through creating a key-backed profile in an interactive terminal. `auth login` and a bare `profiles create <name>` ask for a profile name and the credential, offer to create an API key with it, and store only the new key. `profiles remove` offers to revoke the profile's key. `provisionOperation` also accepts `flag`, `parameters`, and `profileParameters`.
