## Auth details in dry-run previews

<ChangelogTags>features</ChangelogTags>

`--dry-run` output now includes an `auth` block that reports the endpoint's security schemes and whether credentials would be attached (`resolved`, `missing`, or `supplied`). In a terminal, the default table format now prints the full request preview (URL, method, query parameters, and body) instead of only the header rows.
