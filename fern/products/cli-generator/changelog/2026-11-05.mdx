## Shared resources across specs merge

<ChangelogTags>generators.yml</ChangelogTags>

Specs under the same `namespace` that define a resource with the same name now merge that resource's commands instead of failing at startup with `Resource key collision`. The CLI errors only when two specs define the same command, and the error names the full command path.
