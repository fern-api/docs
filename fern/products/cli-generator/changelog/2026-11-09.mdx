## Set the CLI's display name

<ChangelogTags>generators.yml</ChangelogTags>

You can now set `displayName` to control the API name in the generated README and `reference.md` titles and in the crate's default description. A multi-spec workspace no longer takes its title from the first spec's `info.title`; without `displayName`, it uses a readable form of the binary name (`twilio-cli` gives "Twilio CLI").

## Accurate `reference.md` command paths

<ChangelogTags>commands</ChangelogTags>

The generated `reference.md` now lists the command paths the binary runs:

- A group named like its spec's `namespace` is hoisted into the namespace (`oauth authorize`, not `oauth oauth authorize`).
- A slash-separated namespace nests (`messaging bulk-messages create`, not `messaging-bulk-messages create`).
- HEAD and OPTIONS operations, such as CORS preflight endpoints, are no longer listed, since the binary doesn't expose them.
- Titles no longer double "CLI" when the name already ends in it.
