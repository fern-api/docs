## Installers download from your repository

<ChangelogTags>publishing, generators.yml</ChangelogTags>

When the generator delivers to a GitHub repository, the crate's `name`, `repository`, and `homepage` now default from that repository unless `packageIdentity` sets them. The shell and PowerShell installers download from your releases, and release assets are named `<binaryName>-*` instead of `fern-cli-sdk-*`.

## `--schema` describes custom commands

<ChangelogTags>commands</ChangelogTags>

`<cli> <custom-command> --schema` now returns the command's description and flags instead of failing with a discovery error, and root `--schema` lists registered custom commands in a `customCommands` array. Agents that discover commands through `--schema` can now see hand-written commands.
