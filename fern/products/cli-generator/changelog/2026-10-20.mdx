## Table columns with `x-fern-cli-table`

<ChangelogTags>features</ChangelogTags>

The `x-fern-cli-table` operation extension sets the columns that `--format table` shows for a command: header, field path, order, alignment, max width, date formatting, and optional hidden columns.

## Prompts for missing required inputs

<ChangelogTags>commands</ChangelogTags>

When stdin and stderr are both terminals, the CLI prompts for required inputs that no flag, `--params`, `--json`, profile, or global parameter supplied. Scripts, CI, and piped runs never prompt and keep the existing "is missing" error. Values marked `format: email` are now validated before the request is sent.

## Shorthand values for object flags

<ChangelogTags>features</ChangelogTags>

A flag whose value is an object with exactly one required string property now also accepts a plain value for that property: `--from a@x.com` sends `{"email":"a@x.com"}`, and `--to a@x.com,b@x.com` sends one object per entry. Values the spec marks `format: email` are validated before the request is sent.
