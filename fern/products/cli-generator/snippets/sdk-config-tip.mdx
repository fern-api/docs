<Tip title="Meet your new CLI generator">
Describe the CLI you want as a `cli` target in `sdk-config.yml`, next to your SDK targets. You declare shared settings like auth and package details once, and the CLI target inherits them. The target runs the newest CLI generator unless you pin `generatorVersion`.

Already using `generators.yml`? Follow the [SDK Config migration guide](/learn/sdks/legacy/generators/migration-guides/sdk-config) to migrate.
</Tip>
