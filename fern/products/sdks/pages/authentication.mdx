# Authentication

Fern-generated SDKs support multiple ways to configure authentication credentials for your API client. You can either directly set credentials in code or use environment variables for more secure credential management.

## Environment Variables

All Fern SDKs support reading authentication credentials from environment variables. This is the recommended approach for managing credentials securely, especially in production environments.

### API Key Authentication

For API key authentication, set the environment variable specified in your Fern definition:

<CodeBlock>
```bash
export MY_API_KEY=sk_123...
```
</CodeBlock>

Then in your code, configure the client to use this environment variable:

<CodeBlock>
```typescript
const client = new ApiClient({
  apiKeyEnvVar: "MY_API_KEY"
});
```
</CodeBlock>

### Bearer Token Authentication

For bearer token authentication, set the token in an environment variable:

<CodeBlock>
```bash
export MY_BEARER_TOKEN=Bearer abc123...
```
</CodeBlock>

Configure the client to use the environment variable:

<CodeBlock>
```typescript
const client = new ApiClient({
  tokenEnvVar: "MY_BEARER_TOKEN"
});
```
</CodeBlock>

## Direct Configuration

You can also configure authentication directly in code:

### API Key

<CodeBlock>
```typescript
const client = new ApiClient({
  apiKey: "sk_123..."
});
```
</CodeBlock>

### Bearer Token

<CodeBlock>
```typescript
const client = new ApiClient({
  token: "Bearer abc123..."
});
```
</CodeBlock>

<Callout intent="warn">
  Never commit API keys or tokens directly in your code. Use environment variables for secure credential management.
</Callout>

## Basic Authentication

For APIs using basic authentication:

<CodeBlock>
```typescript
const client = new ApiClient({
  username: "user",
  password: "pass"
});
```
</CodeBlock>

Or using environment variables:

<CodeBlock>
```bash
export API_USERNAME=user
export API_PASSWORD=pass
```
</CodeBlock>

<CodeBlock>
```typescript
const client = new ApiClient({
  usernameEnvVar: "API_USERNAME",
  passwordEnvVar: "API_PASSWORD"
});
```
</CodeBlock>
