Welcome to Fern SDKs. This page provides a quick overview of what you can accomplish with Fern's SDK generation capabilities.

## About Fern

Fern generates idiomatic, type-safe SDKs from your API definitions. Whether you're using OpenAPI, AsyncAPI, or Fern Definition format, you can produce production-ready client libraries in multiple programming languages.

## Getting started

To begin generating SDKs with Fern:

1. Define your API using OpenAPI, AsyncAPI, or Fern Definition
2. Configure your generators in `generators.yml`
3. Run `fern generate` to create your SDKs

## Example

Here's a simple example of calling an API endpoint using a generated SDK:

```typescript
import { PlantClient } from "@fern-api/plant-sdk";

const client = new PlantClient({ apiKey: "your-api-key" });

const plant = await client.plants.get("plantId");
console.log(plant.name);
```
