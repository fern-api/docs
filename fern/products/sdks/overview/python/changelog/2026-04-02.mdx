## 5.3.0
**`(feat):`** Add aiohttp auto-detection for async clients. When the `httpx-aiohttp` package is installed,
the async client automatically uses `HttpxAiohttpClient` instead of the default `httpx.AsyncClient`.
Adds optional `aiohttp` and `httpx-aiohttp` dependencies exposed via a `[aiohttp]` pip extra,
along with `DefaultAioHttpClient` and `DefaultAsyncHttpxClient` convenience classes in `_default_clients.py`.
