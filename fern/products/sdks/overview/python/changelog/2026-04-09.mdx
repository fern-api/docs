## 5.3.5
**`(fix):`** Fix wire test generation producing invalid syntax (e.g. `strategy=,`) for object
properties with literal/const types. Literal properties that resolve to nop values
are now filtered out of generated constructor arguments.


## 5.3.4
**`(fix):`** Fix boolean path parameters being serialized as Python-style `True`/`False`
instead of JSON-style `true`/`false` in URL paths. Adds `encode_path_param`
utility that ensures proper lowercase boolean encoding for path segments.
