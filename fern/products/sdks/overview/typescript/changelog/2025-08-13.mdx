## 2.8.0
**`(feat):`** Choose to use `pnpm` or `yarn` as the package manager for the generated SDK.
Configure this in _generators.yml_ like so:
```yml title="generators.yml"
# In generators.yml
groups:
  ts-sdk:
    generators:
      - name: fernapi/fern-typescript-sdk
        config:
          packageManager: pnpm
```
The default is `yarn`.
