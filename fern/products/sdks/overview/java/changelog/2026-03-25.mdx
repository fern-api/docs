## 4.0.7
**`(fix):`** Thread endpoint ID through dynamic snippet generator to differentiate
generated snippets by endpoint.


## 4.0.6
**`(fix):`** Fix custom license not being resolved in `build.gradle` when using
local generation (`--local`). The license file is mounted at `/tmp/LICENSE`
inside Docker, but the generator was looking for it at a relative path that
did not exist. The generator now checks `/tmp/<filename>` as a fallback.
Additionally, markdown formatting (headers, bold, etc.) is now stripped
from the first line of the license file when used as the license name.


## 4.0.5
**`(fix):`** Fix generated README exception handling snippet using `{org}ApiException`
instead of `{clientClassName}ApiException` when `client-class-name` is
specified in the Java custom config. The README now uses the same exception
type name that is actually generated in the SDK.
