## Adding custom logic

To get started adding custom code:

<Steps>
  <Step title="Create a new file and add your custom logic">
    ```swift title="Sources/Helper.swift"
    public enum Helper {
        public static func myHelper() {
            print("Hello World!")
        }
    }
    ```
  </Step>
  <Step title="Add your file to `.fernignore`">
    ```yaml {3} title=".fernignore"
    # Specify files that shouldn't be modified by Fern

    Sources/Helper.swift
    ```
  </Step>
  <Step title="Consume the helper">
    <Markdown src="/products/sdks/snippets/consume-method.mdx"/>

    ```swift
    import YourModule

    Helper.myHelper()
    ```
  </Step>
</Steps>

## Adding custom SDK methods

<Markdown src="/products/sdks/snippets/custom-sdk-methods-intro.mdx"/>

<Steps>
  <Step title="Update `generators.yml` configuration">
    Name your Fern-generated client something like `BaseClient` to reflect that this client will be extended.

    ```yaml {4} title="generators.yml"
    - name: fernapi/fern-swift-sdk
      version: <Markdown src="/snippets/version-number-swift.mdx" />
      config:
        clientClassName: BaseClient
    ```
  </Step>
  <Step title="Import and extend the generated client">
    First, import the Fern generated base client and extend it. Then, add whatever methods you want.

    ```swift title="Sources/MyClient.swift"
    import Foundation

    public class MyClient: BaseClient {
        public func myHelper() {
            print("Hello World!")
        }
    }
    ```
  </Step>
  <Step title="Update `.fernignore`">
    Add `MyClient.swift` to `.fernignore`.

    ```diff title=".fernignore"
    + Sources/MyClient.swift
    ```
  </Step>
  <Step title="Consume the method">
    Instead of constructing the generated client, your users will want to construct the extended client.

    ```swift
    import YourModule

    let client = MyClient()
    ```

    <Markdown src="/products/sdks/snippets/consume-method.mdx"/>

    ```swift
    client.myHelper()
    ```
  </Step>
</Steps>

## Adding custom dependencies

To add packages that your custom code requires, update the `Package.swift` in your SDK repository directly. Add the custom dependency to your `.fernignore` to ensure it persists across regenerations.

```diff title=".fernignore"
+ Package.swift
```
