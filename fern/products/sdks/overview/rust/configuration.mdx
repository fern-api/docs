---
title: Rust configuration
description: Configuration options for the Fern Rust SDK.
---

You can customize the behavior of the Rust SDK generator in `generators.yml`:

```yaml {6-9} title="generators.yml"
groups:
  rust-sdk:
    generators:
      - name: fernapi/fern-rust-sdk
        version: <Markdown src="/snippets/version-number-rust.mdx"/>
        config:
          crateName: acme_api
          clientClassName: AcmeClient
          enableWireTests: true
```

## Package configuration

<ParamField path="crateName" type="string" required={false} toc={true}>
The name of the generated Rust crate. This determines the crate name in `Cargo.toml` and how users will add your SDK as a dependency.

```yaml
config:
  crateName: acme_api
```
</ParamField>

<ParamField path="crateVersion" type="string" required={false} toc={true}>
The version of the generated crate. This sets the version field in `Cargo.toml`.

```yaml
config:
  crateVersion: "1.0.0"
```
</ParamField>

<ParamField path="clientClassName" type="string" required={false} toc={true}>
The name of the generated client struct. This allows you to customize the struct name that users will instantiate when using your SDK.

```yaml
config:
  clientClassName: AcmeClient
```
</ParamField>

<ParamField path="clientName" type="string" required={false} toc={true}>
An alternative name for the client used in generated code and documentation.

```yaml
config:
  clientName: Acme
```
</ParamField>

<ParamField path="environmentEnumName" type="string" required={false} toc={true}>
The name of the generated environment enum. This allows you to customize the enum name that defines your API environments (such as production, staging, development).

```yaml
config:
  environmentEnumName: AcmeEnvironment
```
</ParamField>

<ParamField path="extraDependencies" type="object" required={false} toc={true}>
Specify extra dependencies in the generated `Cargo.toml`. This is useful when you add custom code to your SDK that requires additional dependencies.

```yaml
config:
  extraDependencies:
    tokio: "1.0"
    tracing: "0.1"
```
</ParamField>

<ParamField path="extraDevDependencies" type="object" required={false} toc={true}>
Specify extra dev dependencies in the generated `Cargo.toml`.

```yaml
config:
  extraDevDependencies:
    mockall: "0.11"
```
</ParamField>

## Package metadata

These options configure metadata for crates.io publishing.

<ParamField path="packageDescription" type="string" required={false} toc={true}>
A description of the package that appears on crates.io.

```yaml
config:
  packageDescription: "Official Rust SDK for the Acme API"
```
</ParamField>

<ParamField path="packageLicense" type="string" required={false} toc={true}>
The license identifier for the package (for example, `MIT` or `Apache-2.0`).

```yaml
config:
  packageLicense: "MIT"
```
</ParamField>

<ParamField path="packageRepository" type="string" required={false} toc={true}>
The URL of the package's source repository.

```yaml
config:
  packageRepository: "https://github.com/acme/acme-rust"
```
</ParamField>

<ParamField path="packageDocumentation" type="string" required={false} toc={true}>
The URL of the package's documentation.

```yaml
config:
  packageDocumentation: "https://docs.acme.com/rust"
```
</ParamField>

## Generator feature flags

<ParamField path="enableWireTests" type="boolean" default="false" required={false} toc={true}>
Generates [mock server (wire) tests](/sdks/deep-dives/testing#mock-server-tests) to verify that the SDK sends the correct HTTP requests and correctly handles responses per the API spec.

```yaml
config:
  enableWireTests: true
```
</ParamField>

<ParamField path="generateExamples" type="boolean" default="true" required={false} toc={true}>
Controls whether code examples are generated in the SDK documentation.

```yaml
config:
  generateExamples: false
```
</ParamField>

## Cargo features configuration

<ParamField path="features" type="object" required={false} toc={true}>
Custom Cargo features that map feature names to lists of dependencies or features they enable.

```yaml
config:
  features:
    experimental:
      - dep-a
      - dep-b
    advanced:
      - sse
```
</ParamField>

<ParamField path="defaultFeatures" type="list of strings" required={false} toc={true}>
Override which features are included in the default feature set.

```yaml
config:
  defaultFeatures:
    - sse
```
</ParamField>

## README customization

<ParamField path="customReadmeSections" type="list of objects" required={false} toc={true}>
Add custom sections to the generated README file.

```yaml
config:
  customReadmeSections:
    - title: "Getting Started"
      content: "Follow these steps to get started with the Acme SDK..."
```
</ParamField>
