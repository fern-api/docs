## 3.78.1
**`(fix):`** Fix `TypeError: Cannot use 'in' operator to search for 'path' in undefined`
crash when `null` or `undefined` is passed to a file upload parameter at
runtime. The error is now a clear `TypeError` describing the expected types
instead of a cryptic `in` operator failure.


## 3.78.0
**`(feat):`** Add an `additionalBodyParameters` request option that spreads additional parameters into an
endpoint's JSON request body. Caller-supplied properties override matching keys in the endpoint
body, matching the behavior of the Python, Swift, and Ruby SDKs. Omitting the option leaves the
request body unchanged and never fabricates a body for bodyless requests.


## 3.77.3
**`(fix):`** Revert the automatic renaming of inlined path parameters that collide with request
body properties (introduced in 3.77.1). These collisions are now rejected at the CLI
level: `fern check` errors and asks the user to deconflict the names (e.g. via
`x-fern-parameter-name`).
