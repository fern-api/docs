## 3.103.0
**`(feat):`** With `enableForwardCompatibleEnums: true`, enum-typed attributes and text on XML (TwiML) types are open on the
wire: `fromXml` keeps a value the enum does not declare (e.g. a voice added after the SDK was generated) instead
of throwing, and it round-trips through `toXml`. Without the flag the parse error now lists at most 10 of the
allowed values instead of all of them.


## 3.102.1
**`(fix):`** Offset pagers no longer skip a page when a failed `getNextPage()` is retried. The pager now
advances its saved offset only after the next page loads successfully, so a retry re-requests
the same offset instead of moving past it.


## 3.102.0
**`(feat):`** Add opt-in `userAgentOnly` config. When enabled, generated clients send the `User-Agent`
header (including the structured form from `includePlatformHeaders`) but omit the
`X-Fern-Language`, `X-Fern-SDK-Name`, `X-Fern-SDK-Version`, `X-Fern-Runtime`, and
`X-Fern-Runtime-Version` headers. Disabled by default, so existing generated output is
unchanged. `omitFernHeaders` still takes precedence and drops the `User-Agent` too.


## 3.101.0
**`(feat):`** The generated `WebhooksHelper` HMAC verifier now accepts a per-call algorithm override via an optional `algorithm` parameter on `verifySignature`,
one of `sha1`, `sha256`, `sha384` or `sha512`. When omitted, the algorithm configured in
`webhook-signature` is used, so existing callers are unchanged. This lets one endpoint verify both
legacy HMAC-SHA1 (auth-token) and HMAC-SHA256 (shared-key) signed webhooks.
The verifier also logs a warning distinguishing an early failure (missing signature header) from a
failed verification (signature mismatch); it still returns `false` and never throws.


## 3.100.0
**`(feat):`** XML (TwiML) types keep text segments, typed children and undeclared `XmlElement` children in a single
ordered `content` sequence, so `toXml()` preserves the exact insertion/document order across child
types (e.g. `<Say>a</Say><Custom/><Say>b</Say>`) and `fromXml()` reconstructs it. Builders gain
`addText(text)` to interleave text with child elements (`Say.builder({ message: "Hi " }).addBreak(...).addText(" world")`),
and `addChild(XmlElement)` now appends in place rather than after all typed children.


## 3.99.1
**`(fix):`** XML-encoded (TwiML) types now include the `<?xml version="1.0" encoding="UTF-8"?>`
declaration by default when serialized to XML; pass the declaration flag as `false`
to omit it. Nested child elements and raw `XmlElement`s are still written without it.


## 3.99.0
**`(feat):`** SDK variables that declare an environment variable fallback (`env` in `api.yml` or `x-fern-env` on
`x-fern-sdk-variables`) are now optional client options. `normalizeClientOptions` resolves them from the
option first and then from the environment variable, and throws a clear error at client construction
when neither is set, instead of interpolating `undefined` into request paths.
