## 3.100.0
**`(feat):`** XML (TwiML) types keep text segments, typed children and undeclared `XmlElement` children in a single
ordered `content` sequence, so `toXml()` preserves the exact insertion/document order across child
types (e.g. `<Say>a</Say><Custom/><Say>b</Say>`) and `fromXml()` reconstructs it. Builders gain
`addText(text)` to interleave text with child elements (`Say.builder({ message: "Hi " }).addBreak(...).addText(" world")`),
and `addChild(XmlElement)` now appends in place rather than after all typed children.


## 3.99.1
**`(fix):`** XML-encoded (TwiML) types now include the `<?xml version="1.0" encoding="UTF-8"?>`
declaration by default when serialized to XML; pass the declaration flag as `false`
to omit it. Nested child elements and raw `XmlElement`s are still written without it.


## 3.99.0
**`(feat):`** SDK variables that declare an environment variable fallback (`env` in `api.yml` or `x-fern-env` on
`x-fern-sdk-variables`) are now optional client options. `normalizeClientOptions` resolves them from the
option first and then from the environment variable, and throws a clear error at client construction
when neither is set, instead of interpolating `undefined` into request paths.
