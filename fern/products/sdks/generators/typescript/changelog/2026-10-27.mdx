## 3.108.2
**`(fix):`** XML (TwiML) builders match the legacy call shapes: a child builder keeps the child's name even when it
collides with the element's text field (`dial().number("+1…")` adds a `<Number>` child; the text is set
with `text(...)` / `setNumber(...)`), every element builder has a uniform `text(...)` setter, and the
child-builder verbs are also available on the value itself (`new VoiceResponse().say("hi")`). Children added
through the value's verbs live in its ordered `content` (which `toXml()` renders); the typed child property
(`children`) is not updated by them.


## 3.108.1
**`(fix):`** Fix TS1484 compilation error in the generated XML (TwiML) runtime: `src/core/xml/builder.ts` imported the
`XmlSerializable` interface as a value, which the ESM build (`tsconfig.esm.json`, `verbatimModuleSyntax`)
rejects. The import is now type-only, so `pnpm build` succeeds for SDKs with xml-encoded types.
