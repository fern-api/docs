## 3.108.1
**`(fix):`** Fix TS1484 compilation error in the generated XML (TwiML) runtime: `src/core/xml/builder.ts` imported the
`XmlSerializable` interface as a value, which the ESM build (`tsconfig.esm.json`, `verbatimModuleSyntax`)
rejects. The import is now type-only, so `pnpm build` succeeds for SDKs with xml-encoded types.
