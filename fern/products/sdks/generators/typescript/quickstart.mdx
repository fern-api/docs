Generate a TypeScript SDK by following the instructions on this page. 

<Prompt
  title="Generate a TypeScript SDK"
  actions={["cursor", "claude", "chatgpt"]}
>
Generate a TypeScript SDK with Fern. Follow the [TypeScript SDK quickstart](https://buildwithfern.com/learn/sdks/generators/typescript/quickstart.md) step by step.
</Prompt>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK target">

Add a TypeScript target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: typescript
    output:
      delivery: files
      path: ../sdks/typescript
```

The target uses the newest supported TypeScript generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.

<Note>
  `fern init` adds a TypeScript target by default. If you already ran `fern init` and haven't modified `sdk-config.yml`, skip this step.
</Note>
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --target typescript
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/learn/cli-api-reference/cli-reference/sdk-commands#api) to specify the API you want to generate:

  ```bash
  fern generate --target typescript --api your-api-name
  ``` 
</Note>
