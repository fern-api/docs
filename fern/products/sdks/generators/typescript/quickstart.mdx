Generate a TypeScript SDK by following the instructions on this page. 

<Prompt
  title="Generate a TypeScript SDK"
  actions={["cursor", "claude", "chatgpt"]}
>
Generate a TypeScript SDK with Fern. Follow the [TypeScript SDK quickstart](https://buildwithfern.com/learn/sdks/generators/typescript/quickstart.md) step by step.
</Prompt>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK generator">

Run the following command to add the TypeScript SDK generator to `generators.yml`:

<Template
  data={{ GROUP_NAME: "ts-sdk" }}
  tooltips={{
    GROUP_NAME: (<p>The name of the <code>generators.yml</code> group that configures your TypeScript SDK's output location and other metadata. You can customize this group name to differentiate between multiple SDKs across different languages.</p>)
  }}
>
```bash
fern add fern-typescript-sdk --group {{GROUP_NAME}}
```
</Template>

This command adds the following `group` to `generators.yml`:

```yaml title="generators.yml"
  ts-sdk: # group name
    generators:
      - name: fern-typescript-sdk
        version: <Markdown src="/snippets/version-number-ts.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/typescript
```

<Note>
  `fern init` includes a TypeScript SDK generator by default. If you already ran `fern init` and haven't modified `generators.yml`, you can skip this step.
</Note>
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --group ts-sdk
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/cli-api-reference/cli-reference/commands#api) to specify the API you want to generate:

  ```bash
  fern generate --group ts-sdk --api your-api-name
  ``` 
</Note>
