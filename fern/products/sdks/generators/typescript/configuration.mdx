---
title: TypeScript configuration
description: Configuration options for the TypeScript target in sdk-config.yml.
---

Configure the TypeScript SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-8} title="sdk-config.yml"
targets:
  - language: typescript
    generation:
      naming:
        clientName: YourClientName
      namespaceExportName: AcmePayments
      packageManager: pnpm
      testFramework: jest
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy TypeScript configuration](/learn/sdks/legacy/generators/typescript/configuration).

The Zod version used by generated runtime schemas.
</ParamField>

<ParamField path="compilerOptions" type="object" required={false} toc={true}>
TypeScript compiler options for the generated project.
</ParamField>

<ParamField path="compilerOptions.target" type="string" required={false} toc={true}>
The JavaScript language target passed to TypeScript.
</ParamField>

<ParamField path="compilerOptions.module" type="string" required={false} toc={true}>
The module format passed to TypeScript.
</ParamField>

<ParamField path="compilerOptions.lib" type="list of string" required={false} toc={true}>
The runtime library definitions passed to TypeScript.
</ParamField>

<ParamField path="httpClient" type="object" required={false} toc={true}>
The HTTP client used by generated TypeScript code.
</ParamField>

<ParamField path="httpClient.name" type=""axios" | "fetch"" required={true} toc={true}>
The HTTP client used by generated TypeScript code.
</ParamField>

<ParamField path="packageManager" type=""pnpm" | "yarn"" required={false} toc={true}>
The package manager used by the generated project.
</ParamField>

<ParamField path="packageManagerVersion" type="string" required={false} toc={true}>
The package manager version used by the generated project.
</ParamField>

<ParamField path="testFramework" type=""jest" | "vitest"" required={false} toc={true}>
The test framework used by generated tests.
</ParamField>

<ParamField path="namingStrategy" type=""base" | "originalPropertyNames"" required={false} toc={true}>
How schema property names are converted into TypeScript identifiers.
</ParamField>

<ParamField path="bundle" type="boolean" required={false} toc={true}>
Whether the generated package includes bundled output.
</ParamField>

<ParamField path="exportClassDefault" type="boolean" required={false} toc={true}>
Whether the client class is also exported as the default export.
</ParamField>

<ParamField path="namespaceExportName" type="string" required={false} toc={true}>
The top-level namespace export name.
</ParamField>

<ParamField path="consolidateTypeFiles" type="boolean" required={false} toc={true}>
Whether generated types are consolidated into fewer source files.
</ParamField>

<ParamField path="allowCustomFetcher" type="boolean" required={false} toc={true}>
Whether callers can supply a custom fetch implementation.
</ParamField>

<ParamField path="useBrandedStringAliases" type="boolean" required={false} toc={true}>
Whether string aliases are emitted as distinct branded types.
</ParamField>

<ParamField path="useLegacyExports" type="boolean" required={false} toc={true}>
Whether the package emits the legacy export layout.
</ParamField>

<ParamField path="useBigInt" type="boolean" required={false} toc={true}>
Whether 64-bit integer values are represented with bigint.
</ParamField>

<ParamField path="serdeLayer" type="boolean" required={false} toc={true}>
Whether generated models use Fern serialization and deserialization helpers.
</ParamField>

<ParamField path="esmOnly" type="boolean" required={false} toc={true}>
Whether the package emits only ECMAScript modules.
</ParamField>

<ParamField path="scripts" type="list of object" required={false} toc={true}>
Additional scripts added to the generated package manifest.
</ParamField>
