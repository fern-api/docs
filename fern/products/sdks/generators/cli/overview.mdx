Fern's CLI generator produces a complete command-line tool from your API definition — the same source that powers your SDKs. Instead of asking users to write curl commands or integrate an SDK for quick tasks, you give them a native CLI they can install and run immediately.

## Why generate a CLI

### Let users automate without writing code

Teams that manage infrastructure, run CI/CD pipelines, or script repetitive workflows prefer a CLI over opening a browser or writing SDK code. A generated CLI gives them a tool that works in shell scripts, cron jobs, and pipelines out of the box.

### Ship a consistent developer experience

When your CLI is generated from the same API definition as your SDKs, commands map directly to endpoints. Users who already know your API can predict CLI behavior, and you avoid maintaining a separate command structure that drifts over time.

### Reduce time to first API call

A CLI removes the friction of setting up a project, installing dependencies, and writing boilerplate. Users authenticate once and start making API calls immediately:

```bash
# Authenticate
acme auth login

# Make an API call
acme users list --org production
```

### Support power users and internal teams

Internal engineering and DevOps teams often prefer CLI tools for day-to-day operations. A generated CLI gives them a first-class tool without requiring your team to build and maintain one from scratch.

## What you get

The CLI generator produces a distributable command-line tool with:

- **Commands mapped to your API endpoints** — each operation becomes a subcommand with flags derived from request parameters
- **Built-in authentication** — login flows, token management, and credential storage
- **Structured output** — JSON output by default for easy piping and parsing, with human-readable formatting available
- **Help text from your API descriptions** — documentation travels with the tool, so `--help` is always accurate
- **Tab completion** — shell completions generated automatically for bash, zsh, and fish

| Internal tooling | Give operations teams a purpose-built tool for common tasks |

## How it fits with SDKs

The CLI generator complements your SDKs rather than replacing them. SDKs are the right choice when users build applications on top of your API. The CLI is the right choice when users need to perform discrete operations — quick lookups, one-off mutations, or scripted workflows.

Both are generated from the same source, so they stay in sync automatically as your API evolves.
