---
title: Java configuration
description: Configuration options for the Java target in sdk-config.yml.
---

Configure the Java SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-8} title="sdk-config.yml"
targets:
  - language: java
    generation:
      naming:
        clientName: YourClientName
      packageLayout: flat
      useLocalDateForDates: true
      collapseOptionalNullable: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Java configuration](/learn/sdks/legacy/generators/java/configuration).

## Java options

<ParamField path="packageLayout" type=""flat" | "nested"" required={false} toc={true}>
Whether generated JVM packages use a flat or nested resource layout.
</ParamField>

<ParamField path="useLocalDateForDates" type="boolean" required={false} toc={true}>
Whether date-only values use LocalDate instead of OffsetDateTime.
</ParamField>

<ParamField path="collapseOptionalNullable" type="boolean" required={false} toc={true}>
Whether optional nullable values collapse into a single nullable representation.
</ParamField>

<ParamField path="gradleDistributionUrl" type="string" required={false} toc={true}>
The Gradle distribution URL written to the generated wrapper.
</ParamField>

<ParamField path="gradlePluginManagement" type="string" required={false} toc={true}>
Plugin management configuration added to the generated Gradle settings.
</ParamField>

<ParamField path="gradleCentralDependencyManagement" type="boolean" required={false} toc={true}>
Whether dependency versions are managed centrally in the Gradle project.
</ParamField>

<ParamField path="asyncStyle" type=""dedicated-client" | "twin-methods"" required={false} toc={true}>
Whether asynchronous operations use a separate client or co-located methods.
</ParamField>

<ParamField path="includeKotlinSnippets" type="boolean" required={false} toc={true}>
Whether Java SDK documentation includes Kotlin usage snippets.
</ParamField>
