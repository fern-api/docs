## 4.37.6
**`(fix):`** README generation in self-hosted GitHub mode can clone a private repository with a personal
access token again. Upgrades `@fern-api/generator-cli` to 0.12.1, which also sends the token as an
`Authorization` header. Before this, git in the generator image (libcurl 8.23+) dropped the token
from the clone URL and failed with `could not read Username`.


## 4.37.5
**`(fix):`** XML (TwiML) builders keep the legacy meaning of a String setter whose name is shared by the element's text
and a child element: `Dial.builder().number("+15551234567")` sets the text (`<Dial>+15551234567</Dial>`) as in
twilio-java, `number(Number)` adds the `<Number>` child and `addNumber(String)` adds a child with text; the
text property is no longer renamed to `text` (the `text(...)` alias stays).


## 4.37.4
**`(fix):`** XML (TwiML) serialization writes empty elements as `<Hangup/>` instead of `<Hangup />`, matching the legacy
twilio-java output byte for byte.
