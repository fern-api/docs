Generate a Java SDK by following the instructions on this page. 

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK generator">

Run the following command to add the Java SDK generator to `generators.yml`:

<Template
  data={{ GROUP_NAME: "java-sdk" }}
  tooltips={{
    GROUP_NAME: (<p>The name of the <code>generators.yml</code> group that configures your Java SDK's output location and other metadata. You can customize this group name to differentiate between multiple SDKs across different languages.</p>)
  }}
>
```bash
fern add fern-java-sdk --group {{GROUP_NAME}}
```
</Template>

This command adds the following `group` to `generators.yml`:

```yaml title="generators.yml"
  java-sdk: # group name
    generators:
      - name: fern-java-sdk
        version: <Markdown src="/snippets/version-number-java.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/java
```
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --group java-sdk
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/cli-api-reference/cli-reference/commands#api) to specify the API you want to generate:

  ```bash
  fern generate --group java-sdk --api your-api-name
  ``` 
</Note>
