## 2.92.10
**`(fix):`** The generator image keeps Alpine 3.22's libcurl (< 8.23). curl 8.23.0 strips credentials from the
effective URL it reports, which made git treat every authenticated https clone as a redirect and drop
the token, so README generation and GitHub output for private repositories failed inside the
container with "could not read Username for 'https://github.com'".


## 2.92.9
**`(fix):`** XML (TwiML) types match the legacy call shapes: when an element's text property has the same name as
one of its child elements, the child builder keeps the name (`message.Body("hi")` adds a `<Body>` child,
`dial.Number("+1…")` a `<Number>`) and the text property is renamed to `Text`; every element with text
content gets a `new Say("hi")` constructor next to the parameterless one; child builders whose text is a
`format: uri` string accept a `System.Uri` (`Redirect(new Uri("/voice", UriKind.Relative))`).
