## 2.92.6
**`(fix):`** XML (TwiML) `ToXml()` drops characters outside the XML 1.0 `Char` production (e.g. `\u0001`) from text, attributes and comments instead of throwing `ArgumentException`.


## 2.92.5
**`(fix):`** XML (TwiML) fluent child builders now take the element's text content as the first parameter, before
attributes, so legacy-style calls such as `response.Say("hi")` and `response.Dial("+15551234567")`
compile and set the content instead of an attribute. `ToXml(xmlDeclaration, indent)` adds an indented
output option.
