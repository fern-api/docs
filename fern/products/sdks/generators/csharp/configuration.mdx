---
title: .NET configuration
description: Configuration options for the C#/.NET target in sdk-config.yml.
---

Configure the C#/.NET SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-8} title="sdk-config.yml"
targets:
  - language: csharp
    generation:
      naming:
        clientName: YourClientName
      useOptionalWrapper: true
      simplifyObjectDictionaries: true
      explicitNamespaces: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy C#/.NET configuration](/learn/sdks/legacy/generators/csharp/configuration).

## C#/.NET options

<ParamField path="useOptionalWrapper" type="boolean" required={false} toc={true}>
Whether optional values use an explicit Optional wrapper.
</ParamField>

<ParamField path="simplifyObjectDictionaries" type="boolean" required={false} toc={true}>
Whether object schemas with arbitrary values use simplified dictionary types.
</ParamField>

<ParamField path="explicitNamespaces" type="boolean" required={false} toc={true}>
Whether generated resource groups use explicit nested namespaces.
</ParamField>

<ParamField path="rootNamespaceForCoreClasses" type="boolean" required={false} toc={true}>
Whether shared client classes are emitted in the root namespace.
</ParamField>

<ParamField path="includeExceptionHandler" type="boolean" required={false} toc={true}>
Whether generated client operations use a configurable exception handler.
</ParamField>

<ParamField path="experimentalExplicitNullableOptional" type="boolean" required={false} toc={true}>
Whether optional nullable properties distinguish omitted values from explicit nulls.
</ParamField>
