---
title: Ruby configuration
description: Configuration options for the Ruby target in sdk-config.yml.
---

Configure the Ruby SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-5} title="sdk-config.yml"
targets:
  - language: ruby
    generation:
      naming:
        clientName: YourClientName
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Ruby configuration](/learn/sdks/legacy/generators/ruby/configuration).
