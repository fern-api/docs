## 1.40.3
**`(fix):`** The generator image keeps Alpine 3.22's libcurl (< 8.23). curl 8.23.0 strips credentials from the
effective URL it reports, which made git treat every authenticated https clone as a redirect and drop
the token, so README generation and GitHub output for private repositories failed inside the
container with "could not read Username for 'https://github.com'".


## 1.40.2
**`(fix):`** XML (TwiML) child builders keep the legacy names even when they match the element's text attribute:
`dial { |d| d.number("+1…") }` adds a `<Number>` child and `message { |m| m.body("hi") }` a `<Body>` child,
while `d.number` without arguments still returns the attribute (`number=` sets it); every element with text
content also gets `text` / `text=` accessors. `add_number` / `add_body` remain available.
