## 1.37.1
**`(fix):`** Generate `float` and `double` fields and parameters as Ruby `Float` instead of `Integer`.
Decimal values (e.g. a balance of `100.57`) previously lost their fractional part when a
response was decoded or a request was sent. Integer types stay `Integer`.
Generated wire tests now also assert that numbers in request bodies reach the wire unchanged
and that numbers in mocked responses decode unchanged.
Integer and Float map keys nested in models now decode as numbers instead of staying symbols.


## 1.37.0
**`(feat):`** XML (TwiML) models can now carry XML comments. `comment(text)` adds `<!--text-->` inside the element at
its position in the ordered content (interleaved with `add_text` segments and child elements), while
`comment_before(text)` / `comment_after(text)` render a comment immediately before or after the element
itself (as a sibling in its parent, or around the root element after the XML declaration). Comments in
parsed documents are preserved by `from_xml` and round-trip through `to_xml`; `Element#add_comment` and
the new `Internal::Xml::Comment` node expose the same for untyped elements.


## 1.36.0
**`(feat):`** Generate a unit test file per XML-encoded (TwiML) type alongside the models, covering
fromXml/toXml round trips, escaping, unknown attributes/children, open enum passthrough,
child ordering, and rejection of malformed XML, wrong root elements and DOCTYPE declarations.
