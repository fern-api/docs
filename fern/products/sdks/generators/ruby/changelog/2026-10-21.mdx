## 1.39.4
**`(fix):`** XML (TwiML) serialization drops characters outside the XML 1.0 `Char` production (e.g. `\x01`) from text and attribute values instead of emitting XML that no parser accepts.


## 1.39.3
**`(fix):`** XML (TwiML) types accept the declaration flag positionally, like the legacy TwiML gem:
`response.to_s(false)` and `response.to_xml(false)` omit `<?xml ...?>`; the `xml_declaration:`
keyword still works.
