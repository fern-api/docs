---
title: PHP configuration
description: Configuration options for the PHP target in sdk-config.yml.
---

Configure the PHP SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-7} title="sdk-config.yml"
targets:
  - language: php
    generation:
      naming:
        clientName: YourClientName
      propertyAccess: public
      generateClientInterfaces: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy PHP configuration](/learn/sdks/legacy/generators/php/configuration).

## PHP options

<ParamField path="propertyAccess" type=""public" | "private"" required={false} toc={true}>
The visibility of generated PHP model properties.
</ParamField>

<ParamField path="generateClientInterfaces" type="boolean" required={false} toc={true}>
Whether interfaces are generated for PHP client classes.
</ParamField>
