## 2.28.3
**`(fix):`** XML (TwiML) constructors and fluent child methods accept enum cases for enum-typed attributes and
text, e.g. `new Break_(['strength' => BreakStrength::Weak])` or `['record' => [DialRecordItem::RecordFromAnswer]]`,
in addition to the raw string values. Previously passing the enum instance threw
`TypeError: Cannot assign BreakStrength to property Break_::$strength of type ?string`.


**`(fix):`** List-valued XML (TwiML) attributes accept a single space-separated string in addition to
an array, matching the legacy call style: `new Gather(['input' => 'speech dtmf'])` and
`$response->gather(['input' => 'speech dtmf'])` no longer throw a `TypeError`.
