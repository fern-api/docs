Generate a PHP SDK by following the instructions on this page. 

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK target">

Add a PHP target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: php
    output:
      delivery: files
      path: ../sdks/php/sdk
```

The target uses the newest supported PHP generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --target php
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/learn/cli-api-reference/cli-reference/sdk-commands#api) to specify the API you want to generate:

  ```bash
  fern generate --target php --api your-api-name
  ``` 
</Note>
