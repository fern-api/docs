Generate a PHP SDK by following the instructions on this page. 

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Prompt
  title="Generate a PHP SDK"
  actions={["cursor", "claude", "chatgpt"]}
>
Generate a PHP SDK with Fern. Follow the [PHP SDK quickstart](https://buildwithfern.com/learn/sdks/generators/php/quickstart.md) step by step.
</Prompt>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK generator">

Run the following command to add the PHP SDK generator to `generators.yml`:

<Template
  data={{ GROUP_NAME: "php-sdk" }}
  tooltips={{
    GROUP_NAME: (<p>The name of the <code>generators.yml</code> group that configures your PHP SDK's output location and other metadata. You can customize this group name to differentiate between multiple SDKs across different languages.</p>)
  }}
>
```bash
fern add fern-php-sdk --group {{GROUP_NAME}}
```
</Template>

This command adds the following `group` to `generators.yml`:

```yaml title="generators.yml"
  php-sdk: # group name
    generators:
      - name: fern-php-sdk
        version: <Markdown src="/snippets/version-number-php.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/php/sdk
```
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --group php-sdk
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/learn/cli-api-reference/cli-reference/sdk-commands#api) to specify the API you want to generate:

  ```bash
  fern generate --group php-sdk --api your-api-name
  ``` 
</Note>
