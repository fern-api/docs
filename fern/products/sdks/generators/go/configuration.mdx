---
title: Go configuration
description: Configuration options for the Go target in sdk-config.yml.
---

Configure the Go SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-8} title="sdk-config.yml"
targets:
  - language: go
    generation:
      naming:
        clientName: YourClientName
      legacyComplexModels: true
      smartCasing: true
      unionVersion: v0
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Go configuration](/learn/sdks/legacy/generators/go/configuration).

## Go options

<ParamField path="legacyComplexModels" type="boolean" required={false} toc={true}>
Whether complex models use the legacy Go representation.
</ParamField>

<ParamField path="smartCasing" type="boolean" required={false} toc={true}>
Whether generated Go names capitalize common initialisms.
</ParamField>

<ParamField path="clientConstructorName" type="string" required={false} toc={true}>
The generated root-client constructor name.
</ParamField>

<ParamField path="unionVersion" type=""v0" | "v1"" required={false} toc={true}>
The representation used for generated Go unions.
</ParamField>

<ParamField path="includeLegacyClientOptions" type="boolean" required={false} toc={true}>
Whether the client retains legacy constructor option helpers.
</ParamField>
