## 1.65.3
**`(fix):`** XML-encoded (TwiML) types now return their XML representation from
`String()` instead of JSON, and `ToXml()` prepends the
`<?xml version="1.0" encoding="UTF-8"?>` declaration. Use
`ToXmlElement().ToXml()` to serialize without the declaration.


## 1.65.2
**`(fix):`** `option.WithBodyProperties` now overrides generated request fields that share the same wire-format key
instead of returning a `cannot add extra property` error, so you can force or replace any JSON or form URL
encoded request body property. The generated README documents the option in a new "Additional Body
Properties" section, including that it isn't applied to multipart file upload or raw byte requests.
