## 1.70.7
**`(fix):`** Multipart form requests now send enum fields as plain form values (`DUE_DILIGENCE`)
instead of JSON-encoded strings (`"DUE_DILIGENCE"`), matching the other SDKs.
Lists of enums are sent the same way, one plain part per value.


## 1.70.6
**`(fix):`** `WebhooksHelper.verifyRequest` now parses `name=value` settings headers when
`webhook-signature.algorithm-header` sets `key-id-parameter`/`algorithm-parameter`
(e.g. Twilio's `X-Twilio-Webhooks-Signature-Settings: key=<id>,algorithm=HMAC_SHA256`),
so the key resolver receives the bare key ID instead of `key=<id>`. Requires IR 67.33.0.
