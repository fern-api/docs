<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.

<Step title="Add the SDK target">

Add a Go target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: go
    output:
      delivery: files
      path: ../sdks/go
```

The target uses the newest supported Go generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --target go
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/learn/cli-api-reference/cli-reference/sdk-commands#api) to specify the API you want to generate:

  ```bash
  fern generate --target go --api your-api-name
  ``` 
</Note>
