---
title: Python configuration
description: Configuration options for the Python target in sdk-config.yml.
---

Configure the Python SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-8} title="sdk-config.yml"
targets:
  - language: python
    generation:
      naming:
        clientName: YourClientName
      followRedirectsByDefault: true
      alwaysInitializeOptionals: true
      useTypedDictRequests: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Python configuration](/learn/sdks/legacy/generators/python/configuration).

## Python options

<ParamField path="pythonVersion" type="string" required={false} toc={true}>
The Python version targeted by the generated project.
</ParamField>

<ParamField path="pydanticVersion" type="string" required={false} toc={true}>
The Pydantic dependency version requirement.
</ParamField>

<ParamField path="pydantic" type="object" required={false} toc={true}>
Pydantic model-generation behavior.
</ParamField>

<ParamField path="pydantic.versionCompatibility" type=""v1" | "v2" | "both" | "v1-on-v2"" required={false} toc={true}>
The Pydantic major versions supported by generated models.
</ParamField>

<ParamField path="pydantic.frozen" type="boolean" required={false} toc={true}>
Whether generated Pydantic models are immutable.
</ParamField>

<ParamField path="pydantic.requireOptionalFields" type="boolean" required={false} toc={true}>
Whether Optional fields remain required unless they declare a default.
</ParamField>

<ParamField path="pydantic.unionNaming" type=""v0" | "v1"" required={false} toc={true}>
The naming strategy for generated union types.
</ParamField>

<ParamField path="pydantic.useFieldAliases" type="boolean" required={false} toc={true}>
Whether Pydantic field aliases preserve wire names.
</ParamField>

<ParamField path="client" type="object" required={false} toc={true}>
Python client file naming.
</ParamField>

<ParamField path="client.fileName" type="string" required={false} toc={true}>
The source file name for the Python client.
</ParamField>

<ParamField path="client.exportedFileName" type="string" required={false} toc={true}>
The file name used when exporting the Python client.
</ParamField>

<ParamField path="followRedirectsByDefault" type="boolean" required={false} toc={true}>
Whether generated HTTP clients follow redirects by default.
</ParamField>

<ParamField path="defaultBytesStreamChunkSize" type="number" required={false} toc={true}>
The default byte-stream iterator chunk size.
</ParamField>

<ParamField path="recursionLimit" type="number" required={false} toc={true}>
The Python recursion limit installed when the generated package is imported.
</ParamField>

<ParamField path="extras" type="object" required={false} toc={true}>
Published Python extras and their dependency names.
</ParamField>

<ParamField path="alwaysInitializeOptionals" type="boolean" required={false} toc={true}>
Whether optional model fields are initialized even when omitted.
</ParamField>

<ParamField path="useTypedDictRequests" type="boolean" required={false} toc={true}>
Whether request bodies are generated as TypedDict types.
</ParamField>

<ParamField path="additionalInitExports" type="list of object" required={false} toc={true}>
Additional names re-exported from the package initializer.
</ParamField>
