<Step title="Add the SDK target">

Add a Python target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: python
    output:
      delivery: files
      path: ../sdks/python
```

The target uses the newest supported Python generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.
</Step>

<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --target python
```

<Note>
  If you have multiple APIs, use the [`--api` flag](/learn/cli-api-reference/cli-reference/sdk-commands#api) to specify the API you want to generate:

  ```bash
  fern generate --target python --api your-api-name
  ``` 
</Note>
