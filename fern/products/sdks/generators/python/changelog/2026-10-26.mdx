## 5.41.10
**`(fix):`** Fix the README "Async Client" snippet dropping types imported from the package root.
Previously the whole `from <package> import <Client>, <Type>, ...` line of the sync
snippet was discarded, so the async example only imported the async client and
referenced request types that were never imported. The async snippet now imports
those names alongside the async client.


## 5.41.9
**`(fix):`** `update_forward_refs` now passes its namespace to `model_rebuild` under Pydantic v2. Models whose
forward references go through a union alias (e.g. a recursive `Union["Branch", Leaf, "Items"]` whose
members are imported under `TYPE_CHECKING`) were left incomplete, and parsing them raised
`PydanticUserError: ... is not fully defined`.
