## 5.33.2
**`(fix):`** Also emit the SPDX `license` in `[tool.poetry]` alongside the PEP 639 `[project]` license. Poetry 1.x
(including the `poetry` version pinned in the generated publish workflow) ignores the `[project]`
table, so since 5.32.0 packages built with it were published to PyPI without any license metadata.


## 5.33.1
**`(fix):`** Annotate generated WebSocket `__iter__` / `__aiter__` methods with `typing.Iterator[<Socket>Response]` /
`typing.AsyncIterator[<Socket>Response]` so type checkers infer iterated messages as the response union
(matching `recv()`) instead of `bytes | <Response>`.
