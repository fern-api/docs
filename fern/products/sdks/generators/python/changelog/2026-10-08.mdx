## 5.39.5
**`(fix):`** Fix the root client docstring example for global headers and root path parameters
that have a `client-default`. The example now passes the default as a keyword
argument (e.g. `version="2024-01-01"`) instead of a bare positional value, which
was a `SyntaxError` when it followed another keyword argument.


## 5.39.4
**`(fix):`** SSE unions discriminated by the `event:` line (`x-fern-discriminator-context: protocol`) now parse
both variant styles: envelope variants (`{event, data: Payload}`) are built from the `data:` JSON,
and payload variants (the `data:` JSON itself) get the `event:` value injected as the discriminant.
The event name no longer has to be repeated inside the `data:` JSON.


## 5.39.3
**`(fix):`** Stop automatically replaying requests after server disconnects or incomplete responses (`httpx.RemoteProtocolError`), which could duplicate non-idempotent POST/PATCH operations, even after a 200 status was received. Connection-establishment failures and HTTP-status retries are unchanged. Set `request_options={"retry_remote_protocol_errors": True}` only when replaying the request is safe to explicitly restore the previous behavior.


**`(fix):`** With `pydantic_config.skip_validation: true`, a union value that matches no known member is now
returned as its original data (the raw dict) instead of `None`. Previously a response carrying a
union variant added after the SDK was generated (e.g. a new `product` on a discriminated union), or
one missing its discriminant, silently decoded to `None` and its fields were lost. Known variants
still decode to their classes.


## 5.39.2
**`(fix):`** Generated `core/pydantic_utilities.py` now type-checks under pydantic 2.14, which made mypy report
`var-annotated` on the module-level `TypeAdapter` instances.


## 5.39.1
**`(fix):`** XML (TwiML) fluent child methods (`response.say(...)`, `gather.play(...)`, ...) keep document order on
Python 3.12+. The ordered content list is a pydantic private attribute, and the `runtime_checkable`
Protocol used to find it stopped matching on 3.12 (where `isinstance` uses `inspect.getattr_static`),
so children appended by the fluent methods were ordered after text and `add_child(...)` elements, e.g.
`r.say("a"); r.add_child(XmlElement("Custom")); r.say("b")` rendered `<Custom/><Say>a</Say><Say>b</Say>`.
