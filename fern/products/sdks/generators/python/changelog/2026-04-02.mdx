## 5.3.0
**`(feat):`** Add aiohttp auto-detection for async clients. When the `httpx-aiohttp` package is installed,
the async client automatically uses `HttpxAiohttpClient` instead of the default `httpx.AsyncClient`.
Adds optional `aiohttp` and `httpx-aiohttp` dependencies exposed via a `[aiohttp]` pip extra,
along with `DefaultAioHttpClient` and `DefaultAsyncHttpxClient` convenience classes in `_default_clients.py`.


## 5.2.2
**`(fix):`** Fix `extra_dependencies` override behavior so user-specified dependency
versions reliably take precedence over bundled generator defaults.
Previously, bundled dependencies (e.g., pydantic, typing_extensions) added
during generation would overwrite customer version pins from
`extra_dependencies`. User overrides are now protected from being
overwritten by internal dependency additions.
