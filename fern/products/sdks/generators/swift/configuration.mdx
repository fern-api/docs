---
title: Swift configuration
description: Configuration options for the Swift target in sdk-config.yml.
---

Configure the Swift SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-6} title="sdk-config.yml"
targets:
  - language: swift
    generation:
      naming:
        clientName: YourClientName
      nullableAsOptional: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Swift configuration](/learn/sdks/legacy/generators/swift/configuration).

## Swift options

<ParamField path="moduleName" type="string" required={false} toc={true}>
The Swift module name for the generated package.
</ParamField>

<ParamField path="nullableAsOptional" type="boolean" required={false} toc={true}>
Whether nullable values are represented as Swift optionals.
</ParamField>
