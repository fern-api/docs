Publish your public-facing Fern Swift SDK as a Swift package distributed via Git. After following the steps on this page, you'll have a versioned package that developers can install using Swift Package Manager.

<Info>
	This page assumes that you have:

	* An initialized `fern` folder, a GitHub repository for your Swift SDK, and a Swift target in `sdk-config.yml`. See [Generating an SDK (Swift)](/learn/sdks/generators/swift/quickstart).
</Info>

## Configure `sdk-config.yml`

Swift packages are distributed via Git repositories, so the Swift target delivers to GitHub. Set `output.delivery` to `github` and set `output.github.repository` to your SDK repository in `owner/name` format. Replace `YOUR_GITHUB_ORG/YOUR_REPO_NAME` with your values:

```yaml title="sdk-config.yml" {3-6}
targets:
  - language: swift # Generate the Swift SDK
    output:
      delivery: github # Push generated code to a GitHub repository
      github:
        repository: YOUR_GITHUB_ORG/YOUR_REPO_NAME # For example, plantstore/plantstore-swift
```

These are the only required fields. To control the target branch or how changes land (for example, as a pull request instead of a release), add [`branch`](/learn/sdks/reference/sdk-config#outputgithubbranch) or [`mode`](/learn/sdks/reference/sdk-config#outputgithubmode) under `github`.

## Publish as a Swift package

At this point, you're ready to generate a release for your SDK.

<Steps>
  <Step title="Generate your release">
    Regenerate your SDK and publish it to your repository:
    
    ```bash
    fern generate --target swift --version YOUR_VERSION
    ```

    Replace `YOUR_VERSION` with a semantic version such as `1.0.0`. Fern uses it as the Git tag for the release.
    
    Local machine output will verify that the release is pushed to your repository and tagged with the version you specified.
  </Step>
  
  <Step title="Verify package availability">
    Your Swift package is now available! Developers can add it to their projects by:
    
    - **In Xcode**: File → Add Package Dependencies → Enter your repository URL
    - **In Package.swift**: Add to dependencies array:
    
    ```swift
    dependencies: [
        // Repository from output.github.repository, and the minimum version to install
        .package(url: "https://github.com/YOUR_GITHUB_ORG/YOUR_REPO_NAME", from: "YOUR_VERSION")
    ]
    ```
    
    <Tip>
      Unlike other languages that rely on centralized registries, Swift packages are available as soon as they’re tagged and pushed to a Git repository.
      
      You can optionally submit your package to the community-maintained [Swift Package Index](https://swiftpackageindex.com/) for better discoverability.
    </Tip>
  </Step>
</Steps>
