Generate a Swift SDK by following the instructions on this page. 

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK generator">

Run the following command to add the Swift SDK generator to `generators.yml`:

<Template
  data={{ GROUP_NAME: "swift-sdk" }}
  tooltips={{
    GROUP_NAME: (<p>The name of the <code>generators.yml</code> group that configures your Swift SDK's output location and other metadata. You can customize this group name to differentiate between multiple SDKs across different languages.</p>)
  }}
>
```bash
fern add fern-swift-sdk --group {{GROUP_NAME}}
```
</Template>

This command adds the following `group` to `generators.yml`:

```yaml title="generators.yml"
  swift-sdk: # group name
    generators:
      - name: fern-swift-sdk
        version: <Markdown src="/snippets/version-number-swift.mdx"/>
        output:
          location: local-file-system
          path: ../sdks/swift
```
</Step>

<Step title="Generate the SDK">

  Run the following command to generate your SDK:

  ```bash
  fern generate --group swift-sdk
  ```
