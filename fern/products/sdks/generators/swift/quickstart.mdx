<Step title="Add the SDK target">

Add a Swift target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: swift
    output:
      delivery: files
      path: ../sdks/swift
```

The target uses the newest supported Swift generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.
</Step>

<Step title="Generate the SDK">

  Run the following command to generate your SDK:

  ```bash
  fern generate --target swift
  ```
