Generate a Rust SDK by following the instructions on this page. 

<llms-only>
If the user already has a `fern/` folder set up, they can skip the first two steps. Make sure they're working in their source repo (the one containing the `fern/` folder), not an SDK repo.
</llms-only>

<Steps>

<Markdown src="/products/sdks/snippets/init-fern-folder.mdx"/>

<Step title="Add the SDK target">

Add a Rust target to the `targets` list in `sdk-config.yml`:

```yaml title="sdk-config.yml"
targets:
  - language: rust
    output:
      delivery: files
      path: ../sdks/rust
```

The target uses the newest supported Rust generator. To pin a version, set [`generatorVersion`](/learn/sdks/reference/sdk-config#targetsgeneratorversion) on the target.
</Step>
<Step title="Generate the SDK">

Run the following command to generate your SDK:

```bash
fern generate --target rust
```

SDK users import `src/prelude.rs` with `use your_crate::prelude::*;`. The prelude re-exports the client, request and response types, and `StreamExt` for iterating [server-sent event streams](/learn/sdks/deep-dives/sdk-user-features#server-sent-events) and [paginated responses](/learn/sdks/deep-dives/auto-pagination).
