## 0.51.0
**`(feat):`** Add `preserveCrateNameHyphens` config option (default `false`). When enabled, hyphens in `crateName`
are kept in the generated `Cargo.toml` package name (e.g. `my-sdk` instead of `my_sdk`), as well as in the
docs.rs link, README install snippet, and default crates.io publish package name. Rust `use` paths keep
the underscored name (`use my_sdk::prelude::*`), matching how Cargo maps hyphenated package names.


## 0.50.0
**`(feat):`** Add the `userAgentFromPlatformHeaders` config option. When it is set to `true`, the default
`ClientConfig.user_agent` uses the IR's platform `User-Agent` value (`<package-name>/<version>`
by default, or the `user-agent` template from generators.yml), matching the other SDK generators.
The option defaults to `false`, which keeps the existing `<ApiName> Rust SDK` value. The Rust SDK
also falls back to `<ApiName> Rust SDK` when the IR has no platform User-Agent.
