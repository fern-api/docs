---
title: Rust configuration
description: Configuration options for the Rust target in sdk-config.yml.
---

Configure the Rust SDK in the `generation` block of its target in `sdk-config.yml`:

```yaml {3-7} title="sdk-config.yml"
targets:
  - language: rust
    generation:
      naming:
        clientName: YourClientName
      dateTimeType: offset
      capitalizeInitialisms: true
```

The target's `generation` block also accepts the [shared generation options](/learn/sdks/reference/sdk-config#generation), such as `naming`, `wireTests`, and `customCode`. Shared options set in the top-level `generation` block apply to every target, and a target's `generation` block overrides them. For `generators.yml` options, see the [Legacy Rust configuration](/learn/sdks/legacy/generators/rust/configuration).

## Rust options

<ParamField path="dateTimeType" type=""offset" | "utc"" required={false} toc={true}>
Whether datetime values preserve their offset or normalize to UTC.
</ParamField>

<ParamField path="capitalizeInitialisms" type="boolean" required={false} toc={true}>
Whether generated Rust names capitalize common initialisms.
</ParamField>

<ParamField path="features" type="object" required={false} toc={true}>
Cargo features and the dependencies or features each enables.
</ParamField>

<ParamField path="defaultFeatures" type="list of string" required={false} toc={true}>
Cargo features included in the crate default feature set.
</ParamField>
