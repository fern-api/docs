## 3.0.0
**`(break):`** The C# SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 3.0.0 is also the minimum version for generating C# SDK Config targets locally.

This release changes the generated SDK. See the [C# v3 migration guide](/learn/sdks/legacy/generators/migration-guides/csharp-v3) for details and code updates:

- Credentials are passed by name.
- Existing type names can be kept with configuration.
- Connection and timeout errors have their own exception types.
- Enums accept unknown values.
- Some exception bodies are no longer typed.
- SDK identification headers aren't sent.
- The project layout changes.
- Failed `POST` and `PATCH` requests aren't retried by default.
- Some URL characters are escaped differently.
- Some endpoints take a request object.
