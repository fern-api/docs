## 4.0.0
**`(break):`** The TypeScript SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 4.0.0 is also the minimum version for generating TypeScript SDK Config targets locally.

This release changes the generated SDK. See the [TypeScript v4 migration guide](/learn/sdks/legacy/generators/migration-guides/typescript-v4) for details and code updates:

- Some response and request types change shape.
- WebSocket channels change: an environment is a single URL, binary receive frames are typed as `ArrayBuffer | Blob`, and unexpected binary frames are reported as errors.
