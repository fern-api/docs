## 3.0.0
**`(break):`** The PHP SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 3.0.0 is also the minimum version for generating PHP SDK Config targets locally.

This release changes the generated SDK. See the [PHP v3 migration guide](/learn/sdks/legacy/generators/migration-guides/php-v3) for details and code updates:

- Responses are validated against the schema.
