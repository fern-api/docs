## 1.0.0
**`(break):`** The Rust SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 1.0.0 is also the minimum version for generating Rust SDK Config targets locally.

This release changes the generated SDK. See the [Rust v1 migration guide](/learn/sdks/legacy/generators/migration-guides/rust-v1) for details and code updates:

- `DateTime<Utc>` becomes `DateTime<FixedOffset>`.
- `Default` is only derived when every field is optional.
- `ApiError` variants carry the error body.
- Paginated list methods return a stream.
- Header parameters are method arguments.
- Union variants hold a data struct.
