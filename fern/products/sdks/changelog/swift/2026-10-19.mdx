## 1.0.0
**`(break):`** The Swift SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 1.0.0 is also the minimum version for generating Swift SDK Config targets locally.

This release changes the generated SDK. See the [Swift v1 migration guide](/learn/sdks/legacy/generators/migration-guides/swift-v1) for details and code updates:

- Numeric enums are generated as enums.
- Union types changed shape.
- Inline `anyOf` objects become one struct.
- Initializer argument order changed for some `allOf` types.
- Object schemas with empty `properties` become dictionaries.
- Binary properties are typed as `Data`.
- Some type names changed.
- Failed requests are retried three times by default.
