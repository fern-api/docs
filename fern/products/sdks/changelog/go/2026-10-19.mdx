## 2.0.0
**`(break):`** The Go SDK generator reads configuration from [`sdk-config.yml`](/learn/sdks/reference/sdk-config) instead of `generators.yml`. Run `fern sdk migrate` to create `sdk-config.yml` from your existing configuration. 2.0.0 is also the minimum version for generating Go SDK Config targets locally.

This release changes the generated SDK. See the [Go v2 migration guide](/learn/sdks/legacy/generators/migration-guides/go-v2) for details and code updates:

- Go 1.22 or later is required to build the generated SDK.
- Map fields no longer use pointers.
- Inline enum names no longer include random suffixes.
