<Warning title="Validate your SDK before you publish">
If you're publishing an SDK for the first time or your API is still in development, set up publishing only after you've validated the generated SDK. A released version is available to your users immediately, and most registries don't allow you to delete or replace it. Generate a [local preview](/learn/sdks/deep-dives/local-previews) with `fern generate --target <language> --preview`, then build and test the output.
</Warning>
