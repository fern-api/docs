<Tip title="Meet your new SDK generator">
Describe the SDK you want, not the generators that build it. You only have to declare shared settings like auth, retries and package details once, and every language target inherits them. Add an SDK in a single line: a new language target. Targets run the newest SDK generators unless you pin `generatorVersion`.

Already using `generators.yml`? Run `fern sdk migrate`, then follow the [SDK Config migration guide](/learn/sdks/legacy/generators/migration-guides/sdk-config).
</Tip>
