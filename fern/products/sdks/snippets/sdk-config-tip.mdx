<Tip title="Meet sdk-config.yml">
Describe the SDK you want, not the generators that build it. Declare shared settings like auth, retries, and package details once, and every language target inherits them. Adding an SDK is one line: a new language target. Targets run the newest SDK generators unless you pin `generatorVersion`.

Already using `generators.yml`? Run `fern sdk migrate`, then follow the [SDK Config migration guide](/learn/sdks/legacy/generators/migration-guides/sdk-config).
</Tip>
