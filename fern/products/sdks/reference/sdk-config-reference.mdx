The `sdk-config.yml` file configures SDK generation. It declares the API source, the settings shared by every SDK, and one target per language. Settings at the top level apply to every target; each target can override them.

Projects that still generate from `generators.yml` can move to `sdk-config.yml` with `fern sdk migrate`. The [legacy `generators.yml` reference](/learn/sdks/legacy/reference/generators-yml) documents the previous format.

```yaml title="sdk-config.yml" maxLines=10
schemaVersion: sdk-config/v1
sdkName: Plant Store
sdkVersion: 1.0.0

source:
  specs:
    - id: plant-store
      type: openapi
      path: ./openapi.yml

api:
  auth:
    schemes:
      - id: bearer
        type: bearer
        environmentVariable: PLANT_STORE_API_KEY

client:
  retry:
    maxAttempts: 3
  timeoutMs: 60000

package:
  description: Official SDK for the Plant Store API
  authors:
    - name: SDK Team
      email: sdk@example.com

targets:
  - language: typescript
    package:
      packageName: "@plant-store/sdk"
    output:
      delivery: github
      github:
        repository: your-organization/plant-store-typescript
      publish:
        registry: npm
        token: ${NPM_TOKEN}

  - language: python
    package:
      packageName: plant-store
    output:
      delivery: files
      path: ../sdks/python
```

## Credentials

Credential fields such as `output.publish.token` and `output.github.credentials` don't accept literal secrets. Use an environment expression such as `${NPM_TOKEN}`, which Fern resolves when it generates the SDK.

## Paths

Paths in `sdk-config.yml` are relative to the file. Absolute paths and paths that contain `..` segments are rejected.

## Override settings per target

A target inherits the top-level `sdkName`, `sdkVersion`, `client`, `docs`, `package`, and `generation` settings and overrides only the fields it sets. A target's `output` replaces the top-level `output` entirely. Every target needs an effective `output`, either from the top level or from its own block.

```yaml title="sdk-config.yml"
client:
  timeoutMs: 60000

targets:
  - language: typescript
    output:
      delivery: files
      path: ../sdks/typescript
  - language: python
    client:
      timeoutMs: 30000 # overrides the top-level value for Python only
    output:
      delivery: files
      path: ../sdks/python
```

## `source`

The API descriptions used to generate the SDKs. Each entry in `specs` sets exactly one of `path` (a local file) or `url` (an HTTP(S) resource).

```yaml title="sdk-config.yml"
source:
  specs:
    - id: plant-store
      type: openapi
      path: ./openapi.yml
      overrides:
        - ./openapi-overrides.yml
```

<ParamField path="source.specs[].id" type="string" required={true} toc={true}>

</ParamField>
<ParamField path="source.specs[].type" type="&quot;openapi&quot; | &quot;swagger&quot; | &quot;postman&quot; | &quot;asyncapi&quot; | &quot;graphql&quot;" required={true} toc={true}>

</ParamField>

## `output`

The default output delivery and publication configuration. A target's `output` replaces this block for that target.

```yaml title="sdk-config.yml"
targets:
  - language: typescript
    output:
      delivery: github
      github:
        repository: your-organization/plant-store-typescript
        mode: pull-request
      publish:
        registry: npm
        trustedPublishing: true
```

<ParamField path="output.delivery" type="&quot;files&quot; | &quot;zip&quot; | &quot;github&quot;" required={true} toc={true}>
  Where Fern delivers the generated SDK. `files` writes it to a directory, `zip` packages it as a ZIP archive, and `github` delivers it to a GitHub repository.
</ParamField>
<ParamField path="output.path" type="string" required={false} toc={true}>
  The destination directory for generated files. Applies to `delivery: files`.
</ParamField>
<ParamField path="output.fileName" type="string" required={false} toc={true}>
  The generated ZIP archive file name. Applies to `delivery: zip`.
</ParamField>
<ParamField path="output.github" type="object" required={false} toc={true}>
  GitHub repository delivery settings. Required for `delivery: github`.
</ParamField>
