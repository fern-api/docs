title: Customize method names

<Markdown src="/snippets/agent-directive.mdx"/>

Fern lets you customize SDK method and group names so that generated clients are intuitive. For example, instead of `client.postUsers` you can configure your SDK to produce `client.users.create()`.

<Note title="Casing is automatically configured">
  Fern automatically applies the appropriate casing for each SDK
  language: `snake_case` in Python, `camelCase` in TypeScript, `PascalCase` in
  Go, etc. Define the endpoint structure once and get
  correctly formatted methods across all generated SDKs.
</Note>

## Generated SDK behavior

<Tabs>
<Tab title="TypeScript">
```ts
const response = await client.users.create();

// Nested groups
const response = await client.admin.users.create();
```
</Tab>
<Tab title="Python">
```python
response = client.users.create()

# Nested groups
response = client.admin.users.create()
```
</Tab>
<Tab title="Java">
```java
var response = client.users().create();

// Nested groups
var response = client.admin().users().create();
```
</Tab>
<Tab title="Go">
```go
response := client.Users.Create()

// Nested groups
response := client.Admin.Users.Create()
```
</Tab>
</Tabs>

## Setting up custom method names

<Tabs>
<Tab title="OpenAPI">

Use the `x-fern-sdk-group-name` and `x-fern-sdk-method-name` extensions to control how endpoints map to SDK methods:

```yaml title="openapi.yml" {4-5}
paths:
  /users:
    post:
      x-fern-sdk-group-name: users
      x-fern-sdk-method-name: create
```
</Tab>
<Tab title="Fern Definition">

Method names map directly from your endpoint names and service `base-path`:

```yaml title="users.yml" {4, 6}
services:
  http:
    UsersService:
      base-path: /users
      endpoints:
        create:
          method: POST
          path: ""
```
</Tab>
</Tabs>
