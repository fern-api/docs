Global headers are headers used in every or most API endpoints. When configured, Fern generates an SDK that accepts these as constructor parameters. Users provide the value once, and the SDK automatically includes the header in all API calls.

## Generated SDK behavior

Fern automatically identifies headers used in every request (or the majority of requests) and marks them as global. You can also manually configure additional global headers.

```python
class Client:

  def __init__(self, *, api_key: str,
               userpool_id: typing.Optional[str])
```

## Setting up global headers

<Tabs>
<Tab title="OpenAPI">

Use the `x-fern-global-headers` extension to label additional headers as global or to alias global header names:

```yaml title="openapi.yml"
x-fern-global-headers:
  - header: custom_api_key
    name: api_key
  - header: userpool_id
    optional: true
```
</Tab>
<Tab title="Fern Definition">

Specify headers in your `api.yml` that are included on every request:

```yaml title="api.yml" {3}
name: api
headers:
  X-App-Id: string
```
</Tab>
</Tabs>
