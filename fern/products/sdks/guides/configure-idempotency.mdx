For endpoints configured as idempotent, Fern's SDKs allow users to specify idempotency headers. Typically the headers include `Idempotency-Key`, but you can also specify additional headers.

<Note>
  The generated SDKs only allow users to specify idempotency headers
  for idempotent endpoints. This ensures that users know exactly
  which invocations are idempotent and which aren't.
</Note>

});

## Setting up idempotency headers

Configure the idempotency headers your API uses, then mark individual endpoints as idempotent.

<Tabs>
<Tab title="OpenAPI">
```yaml title="openapi.yml" {1-3, 8}
x-fern-idempotency-headers:
  - header: Idempotency-Key
    name: idempotency_key

paths:
  /plants:
    post:
      x-fern-idempotent: true
```
</Tab>
<Tab title="Fern Definition">
```yaml title="api.yml"
name: api
auth: bearer
idempotency-headers:
  Idempotency-Key: string
  Idempotency-Expiration: optional<integer>
```

```yaml title="service.yml" {4}
service:
  endpoints:
    create:
      idempotent: true
```
</Tab>
</Tabs>
