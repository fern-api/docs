---
title: Webhook signature verification
description: Verify the authenticity of incoming webhook requests using Fern-generated SDK utilities
---

When you define webhooks in your API specification, Fern automatically generates signature verification functions in your SDKs. No additional configuration is needed.

## Using the generated verification utilities

Here's an example using a TypeScript SDK:

<CodeBlock title="TypeScript">
```ts
import { WebhooksHelper } from "your-sdk";

// In your webhook handler
app.post("/webhooks", (req, res) => {
  const signature = req.headers["x-signature"];
  const body = req.body;

  const isValid = WebhooksHelper.verifySignature({
    signature,
    body: JSON.stringify(body),
    secret: process.env.WEBHOOK_SECRET,
  });

  if (!isValid) {
    return res.status(401).send("Invalid signature");
  }

  // Process the webhook event
  // ...
});
```
</CodeBlock>

The exact method names and parameters depend on your API definition and the SDK language. Check your generated SDK's documentation for the specific utilities available.

Fern also generates strongly-typed models for webhook payloads and interactive [webhook reference documentation](/learn/docs/api-references/generate-webhook-ref).

<Note>
  The signing algorithm and header names are defined in your API specification.
</Note>
