Fern SDKs include utility methods for verifying webhook signatures, ensuring that all webhook events originate from your expected source and haven't been tampered with.

## Using the SDK's webhook verification utilities

When your API definition includes webhooks with signature verification, Fern generates utility methods in your SDK to handle verification. Here's an example using a TypeScript SDK:

<CodeBlock title="TypeScript">
```ts
import { WebhooksHelper } from "your-sdk";

// In your webhook handler
app.post("/webhooks", (req, res) => {
  const signature = req.headers["x-signature"];
  const body = req.body;

  const isValid = WebhooksHelper.verifySignature({
    signature,
    body: JSON.stringify(body),
    secret: process.env.WEBHOOK_SECRET,
  });

  if (!isValid) {
    return res.status(401).send("Invalid signature");
  }

  // Process the webhook event
  // ...
});
```
</CodeBlock>

The exact method names and parameters depend on your API definition and the SDK language. Check your generated SDK's documentation for the specific webhook verification utilities available.

## What Fern provides for webhooks

Fern helps with webhooks in several ways:

1. **Signature verification utilities**: Generated SDK methods to verify that incoming webhook requests are authentic.

2. **Webhook payload types**: Strongly-typed models for webhook payloads, making it easy to work with webhook data in your code.

3. **Webhook reference documentation**: Fern generates interactive webhook documentation from your API definition. See [Generate your webhook reference](/learn/docs/api-references/generate-webhook-ref) for setup instructions.

## How signature verification works

Webhook signature verification ensures that incoming requests are authentic and haven't been tampered with. The typical flow is:

1. Extract the signature from the request headers
2. Compute the expected signature using your webhook secret and the request body
3. Compare the signatures using a timing-safe comparison
4. Reject requests with invalid signatures

The Fern-generated SDK utilities handle this process for you, abstracting away the cryptographic details while ensuring secure verification.

<Note>
  The exact signing algorithm and header names are defined in your API specification. Consult your API documentation for the specific signature scheme used.
</Note>
